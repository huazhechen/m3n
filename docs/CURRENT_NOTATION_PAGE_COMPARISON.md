# 当前双谱式选宽与分页对比

> 本报告记录v90实际核心净空评分版本。后续v91已将五线谱行首改为谱号前0.8S、谱头后1.6S，尚未重跑全库；本报告数值保留为修改前基线。

2026-11-28，两种谱式改为按最终实际核心净空评分后，简谱与五线谱各自按当前生产策略重新计算全部117首，共234份结果。逐曲核对谱源SHA-256、曲目集合及共享字体哈希，全部一致；本报告两种谱式均为本轮新测结果。

文字字号及附件净空共用M；行首固定1S结构净空仅属于五线谱，计入宽度、不伸展、不评分。音符间方向权重简谱50∶50、五线谱75∶25，简谱组内系数0.75、五线谱为1，结构元素间隔权重均1。五线谱单音权重在四分及以下取时值本身，四分以上取平方根；简谱单音权重继续取平方根。选宽、断行、分页及成本求解共用，增页权重保持2。两种谱式的拥挤成本均使用逐间隔欠缺比例平方`max(0,1−g/舒适下限)²`，过松及均匀度公式保持不变。纵向成本改为同页相邻系统最终实际核心净空的逐间隔成本平均值，谱头和跨页间距不计；N仍负责布局拟合。纵向舒适区及惩罚公式均未改动。
