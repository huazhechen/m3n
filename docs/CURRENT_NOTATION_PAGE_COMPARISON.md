# 当前双谱式选宽与分页对比

2026-11-28，五线谱行首留白改为谱号前0.8S、谱头后1.6S后，重新计算117首五线谱，复用v90的117首简谱全量基线。本次代码仅修改五线谱专属行首几何；简谱配置与共用评分、断行、分页算法均未改动。逐曲核对谱源SHA-256、曲目集合及共享字体哈希，全部一致。

## 当前参数

| 参数 | 简谱 | 五线谱 |
|---|---|---|
| 基准 | M=24px | S=7.5px，音乐字号4S=30px |
| 横向三档 | 8／12／16px | 0.8／1.6／2.4S＝6／12／18px |
| 横向舒适区 | 16～24px | 2.4～3.6S＝18～27px |
| 纵向N范围 | 18～36px | 2～4S＝15～30px |
| 纵向舒适区 | 27～36px | 3～4S＝22.5～30px |

文字字号及附件净空共用M；谱号前固定0.8S（6px）、谱头后固定1.6S（12px）结构净空仅属于五线谱，后者量到首音最左音乐笔画，包含升降号、加线及倚音，计入宽度、不伸展、不评分。音符间方向权重简谱50∶50、五线谱75∶25，简谱组内系数0.75、五线谱为1，结构元素间隔权重均1。五线谱单音权重在四分及以下取时值本身，四分以上取平方根；简谱单音权重继续取平方根。选宽、断行、分页及成本求解共用，增页权重保持2。两种谱式的拥挤成本均使用逐间隔欠缺比例平方`max(0,1−g/舒适下限)²`，过松及均匀度公式保持不变。纵向成本改为同页相邻系统最终实际核心净空的逐间隔成本平均值，谱头和跨页间距不计；N仍负责布局拟合。纵向舒适区及惩罚公式均未改动。

## 与上一份统计对比

上一份报告为v90实际核心净空评分版本；本轮v91只修改五线谱行首固定几何：谱号前由0改为0.8S，谱头后由1S改为1.6S，每行固定占宽增加10.5px。简谱复用原基线；间距范围、舒适区、横向权重、纵向惩罚公式、字号与增页权重均保持原值。

| 谱式 | 上一份总页数 | 本轮总页数 | 变化 | 选宽变化曲目 | 行数变化曲目 |
