# 当前双谱式选宽与分页对比

本文为歌词三档两两净空改造前的v93历史基线；该改造影响两种谱式，以下结果尚未按新配置重跑。

2026-11-29，基于已部署451f（代码451f67de、策略v93）重跑117首五线谱，复用v90的117首简谱全量基线。与上一次五线谱全量统计v91对比时，包含v92符干／连奏线调整和v93符杠方向试算两轮改动，不是单独衡量v93。简谱配置及共用评分、断行、分页算法未改。谱源集合、逐曲SHA-256和共享字体哈希均一致。

## 当前参数

| 参数 | 简谱 | 五线谱 |
|---|---|---|
| 基准 | M=24px | S=7.5px，音乐字号4S=30px |
| 横向三档 | 8／12／16px | 0.8／1.6／2.4S＝6／12／18px |
| 横向舒适区 | 16～24px | 2.4～3.6S＝18～27px |
| 纵向N范围 | 18～36px | 2～4S＝15～30px |
| 纵向舒适区 | 27～36px | 3～4S＝22.5～30px |

文字字号及附件净空共用M；谱号前固定0.8S（6px）、谱头后固定1.6S（12px）结构净空仅属于五线谱，后者量到首音最左音乐笔画，包含升降号、加线及倚音，计入宽度、不伸展、不评分。音符间方向权重简谱50∶50、五线谱75∶25，简谱组内系数0.75、五线谱为1，结构元素间隔权重均1。五线谱单音权重在四分及以下取时值本身，四分以上取平方根；简谱单音权重继续取平方根。选宽、断行、分页及成本求解共用，增页权重保持2。两种谱式的拥挤成本均使用逐间隔欠缺比例平方`max(0,1−g/舒适下限)²`，过松及均匀度公式保持不变。纵向成本改为同页相邻系统最终实际核心净空的逐间隔成本平均值，谱头和跨页间距不计；N仍负责布局拟合。纵向舒适区及惩罚公式均未改动。

五线谱普通符干保留3.5S基准，仅外伸时最多收回0.5S；连奏线两端随音高调整。方向可选的普通连梁组在实际行宽下比较完整行墨迹高度，复用既有谱表外空间；该谱表有歌词且高度差不超过S/8（0.9375px）时优先朝上，整行不超过未整形高度。和音、倚音、连音组、奏法记号及延音线端点保持常规方向。

## 验证与版本

本轮统计对应已部署代码`451f67de`（页面版本`451f`），生产策略v93。117首新五线谱结果与复用的117首简谱基线、v91五线谱旧报告逐项核对，谱源集合、源文件SHA-256和三份共享字体实际二进制SHA-256均一致。全部赢家均完成精确几何复核，无复核失败；CSV逐项数据、差值及汇总已独立重算。

本轮未重跑简谱、未执行全库逐笔画审计，也未穷举全宽度精确枚举。符杠改动提交前的1854项包测试、5份固定宽度双谱式密度回归、4首720px实绘及生产全宽度搜索、Chromium／WebKit桌面和平板20个场景检查均已通过。本次全量统计串行执行，聚合RSS峰值820MiB。
