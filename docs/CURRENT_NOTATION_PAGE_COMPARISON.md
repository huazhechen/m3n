# 当前双谱式选宽与分页对比

> 本报告为 S=7px 的统计快照。后续已将正式配置改为 S=6.75px（音乐字号27px），本页数字尚未按新尺度重算。

2026-11-28，基于提交 `468f09dc09b3a415e1d873543bc753b26f6579e4`，重新计算全部 117 份谱源（`src/scores`、`src/works`、`src/examples`）。本报告替代此前改造前参数的当前报告。

共用参数为 M=24px、动态行距 N；五线谱专用基准 S=7px、倚音比例 0.6。简谱横向三档为 8／12／16px，舒适区为 16～24px；五线谱三档为 0.8S／1.2S／1.6S，即 5.6／8.4／11.2px，舒适区为 11.2～16.8px。

两种谱式均采用阅读器当前生产选宽策略，在 528～720px、步长 6px 的候选范围内搜索，候选估计后精确复核赢家。这里的“最优宽度”指当前生产策略选出的宽度，综合间距、字号缩小和增页代价；不表示穷举精确布局的理论最优，也不表示最少页数。参见[选宽规则](WIDTH_SEARCH.md)。

页数为每首独立按所选宽度排入 A4 的页数，合计不包含谱集合页、封面或目录。宽度为逻辑排版宽度，不是纸张宽度；固定 A4 版心下，更大的逻辑宽度对应更小的整体缩放比例。

## 总体结果

| 指标 | 简谱 | 五线谱 | 五线谱减简谱 |
|---|---:|---:|---:|
| 总页数 | 126 | 133 | +7（+5.6%） |
| 1 页曲目 | 109 | 104 | -5 |
| 2 页曲目 | 7 | 10 | +3 |
| 3 页曲目 | 1 | 3 | +2 |
| 平均选宽 | 563.28px | 581.18px | +17.90px |
| 选宽中位数 | 546px | 564px | +18px |
| 选中下限 528px | 39 首 | 20 首 | -19 首 |
| 选中上限 720px | 0 首 | 1 首 | +1 首 |

110 首（94.0%）页数一致，7 首（6.0%）五线谱各多 1 页，没有五线谱更少页的曲目。

| 简谱页数 → 五线谱页数 | 曲目数 |
|---|---:|
| 1→1 | 104 |
| 1→2 | 5 |
| 2→2 | 5 |
| 2→3 | 2 |
| 3→3 | 1 |

选宽方面，五线谱更宽 82 首（70.1%）、相同 19 首（16.2%）、更窄 16 首（13.7%）。逐曲宽度差中位数为 +18px，绝对差均值为 30.62px；绝对差不超过 12／24／48px 的分别有 44／67／93 首。

仅看页数相同的 110 首，五线谱平均更宽 24.82px：82 首更宽、19 首相同、9 首更窄。页数不同的 7 首五线谱全部更窄，因此全库平均差值会受到增页后选宽变化的影响。
