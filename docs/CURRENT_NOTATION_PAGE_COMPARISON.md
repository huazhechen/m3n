# 当前双谱式选宽与分页对比

2026-11-28，基于提交 `5c30b3324bae35dbcd037cc880cf083ce0ce145a`，重新计算全部117份谱源（`src/scores`、`src/works`、`src/examples`）。当前五线谱S=6.75px、音乐字号4S=27px、倚音比例0.6；两种谱式共用M=24px和动态行距N。最小行距18px，舒适区27～36px。

简谱横向三档为8／12／16px，舒适区16～24px；五线谱横向三档为0.8S／1.2S／1.6S，即5.4／8.1／10.8px，舒适区10.8～16.2px。

本报告中的“最优宽度”为阅读器当前生产策略在528～720px、步长6px范围内搜索并精确复核赢家后的选宽。它综合间距、字号和增页代价，不表示以最少页数为唯一目标，也不表示穷举精确布局的理论最优。规则见[宽度搜索](WIDTH_SEARCH.md)。

页数按每首独立排入A4统计，不含谱集合页、封面或目录。逻辑宽度增大意味着固定A4版心内的整体显示比例缩小，不表示纸张变宽。

绝对宽度差不超过12／24／48px的分别有44／69／97首。仅看页数相同的113首，五线谱平均选宽差为+22.73px。
