# 零时值对象随自然间距缩放

仅设置自然间距时，jpFun 原先只缩放有时值对象，拍号等零时值对象仍使用默认12px基础弹簧。正文22px、自然间距0.5em时，零时值控制间的自然空隙因此仍为1.2px，自研已使用1.1px；谱头音域连续三个对象会累积0.2px横差。

现统一将自然间距传入全部对象的弹簧计算。零时值对象继续按最小时值0.01的平方根缩放，保留小节线128、声部前缀0.45等原有弹簧比例；自研的小节线和低音前缀也去掉单参数模式下的固定缩放例外。省略自然间距的jpFun底层调用仍使用原默认值，配对最小／自然间距的计算不变。单参数模式仍按自然宽度选择换行，不改变音高、时值或字形。
