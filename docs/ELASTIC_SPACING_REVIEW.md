# 弹性间距典型谱例审视

2026-11-26，对比提交 `2d7cd309`（重构前的 master）和 `dbeca608`（弹性间距重构）。结论：简谱基本保持原来的视觉效果；五线谱改善了部分密集音型的可辨认性，但存在明显的篇幅代价和简单旋律压缩反例，尚不能判定为全面改善。

## 方法和边界

两个版本使用独立检出、相同谱源、真实字体、字号、默认设置和640px版宽。分别运行 `tools/compare-notation-density.mjs --screenshots`，输出连续 SVG、完整截图和包含分页结果的报告。检查首段、长谱中段及后段，并结合小节分行结果判断变化。进程串行运行，内存守卫记录两次浏览器检查峰值均为1519 MiB。

本次是固定宽度的视觉抽查，不代表每个宽度的效果，也不是对117首简谱最优宽度回归的替代。这里的页数是640px下实际分页结果，不能与自动选宽的页数混用。笔画检查改前、改后均无越界、无碰撞，因此本次改善主要涉及阅读疏密，而非消除原有碰撞。

可复现命令（在各自检出中运行，输出目录分别指定）：

```sh
python3 tools/run-low-memory.py node tools/compare-notation-density.mjs \
  --scores=badinerie_bwv1067_01,flower_dance_01,mozart_k545_01,ni_shi_wo_xin_ai_de_gu_niang_01,ma_li_you_zhi_xiao_gao_yang_01,ban_yin_jie_kou_qin_ji_ben_gong_01,wo_yao_ni_01,mo_li_hua_01 \
  --widths=640 --screenshots --output=.tmp/visual-review/after
```

本次截图、JSON报告和本地对照页面保留于重构工作树的 `.tmp/visual-review/`，`index.html` 为入口。截图为审视产物，不提交到 Git。

## 视觉判断

- **简谱：整体持平。** 《谐谑曲》《花之舞》《K545》的快速数字组仍清楚，局部组间留白重新分配，但不足以称为明显的视觉提升。《我要你》《你是我心爱的姑娘》的歌词仍可读，未看到新增的明显拥挤。这个结果验证了保持简谱原有密度的约束，没有证明新机制在所有简谱上更美观。
- **《谐谑曲》五线谱：阅读有所改善。** 连梁内音符更展开，升号、装饰音和连线周围更从容，原来部分窄而高的音型观感减轻。增加两行但仍为一页，代价相对可控。
- **《花之舞》五线谱：局部改善，整体代价偏大。** 密集连梁和高音加线较容易逐个辨认；行数增加约43%，连续高度从1715.1px增至2421.0px，并多一页。不能仅以自然间距为理由接受全部篇幅增长。
- **K545五线谱：得失并存。** 快速音阶更清楚，开头也更舒展；开头第一行由三小节改为两小节，长音区域留白增大。总行数增加约32%，从两页增至三页。整体均衡还需要校准，不能把所有新增留白都算成改善。
- **带歌词五线谱：空间改善，断句仍有限。** 《你是我心爱的姑娘》的三连音与歌词对位更展开；《我要你》的音符、歌词不再那么密集。但分别增加一行，且算法并未识别歌词语义和乐句，换行仍可能落在词语或句子内部。
- **《玛丽有只小羔羊》五线谱：明确的视觉反例。** 两行压成一行后，简单四分音符的横向距离变窄，符干显得相对更长，原来两行的乐句层次消失。虽然没有碰撞、总高度下降，但就此教学旋律而言，旧版更舒展、更容易分句。此前把一行结果当作正向密度表现的判断需要修正。
- **口琴基本功五线谱：可辨认性与练习完整性冲突。** 密集三连音不再挤成一串，这是明显改善；部分原本一行的练习展开为两行，扫视完整练习的便利性下降。总行数增加约38%，从三页变为四页，需结合练习段落整体评价。
- **《茉莉花》五线谱：变化温和。** 三行保持不变，横向空间及断行有所调整，没有密集谱例那样强烈的改善或劣化。

## 后续应优先解决的问题

保留自然间距、碰撞下限和全局分行机制。优先校准五线谱的自然长度与伸缩代价之间的关系，使适度压缩可以换取合理篇幅，同时避免简单短曲被压成一条长行。单纯缩短全部自然间距会同时损害密集音型的改善，不能作为统一处理。

分行评分还应考虑有依据的乐句、练习段落边界；目前的数学疏密均衡无法独自表达教学谱和练习谱的结构。新增验收应同时覆盖密集谱例的阅读空间、简单旋律的疏密及段落完整性，而非仅接受无碰撞或更新行数上限。本轮只记录审视结论，未调整排版参数或算法。
