# 网页谱面缩放

阅读页、编辑预览和首页谱例的简谱、五线谱均支持在谱面上滚动鼠标滚轮缩放：向上放大，向下缩小。触控板双指捏合（浏览器发出的 Ctrl＋wheel）和触屏双指捏合也缩放谱面；触屏单指仍可滚动阅读。

显示比例限制在原始适屏尺寸的50%～200%，切换曲目时恢复。非原始大小时，页面右上方、导航栏下方悬浮“复原”按钮，点击恢复100%并隐藏按钮；悬停提示和无障碍名称为“恢复原始大小”。缩放只修改网页显示尺寸，不重新排谱，不改变排版宽度、换行、分页或导出的图片和PDF。放大后可横向滚动查看超出屏幕的部分。缩放以鼠标位置或双指中心附近的纸张为参照补偿阅读位置；分页纸张重新换行或滚动到边界时，位置会受可用滚动范围限制。

实现位于 `src/lib/score-zoom.ts`，由 `ScoreRenderer` 注册并在卸载时清理监听器。CSS变量 `--score-zoom` 控制连续SVG和分页纸张的显示宽度；桌面分页继续以 `--reader-page-width` 为适屏基准。
