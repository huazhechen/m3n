# 谱面密度归一

目标是相同版宽和纸张下，两种记谱的信息密度与可读性接近，并使用一致的布局决策风格。字形、谱号、调号、加线和声部结构仍按各自记谱语义测量，不以页数完全相等作为验收条件。

## 第一阶段：统一横向选距

两种引擎均完整比较全部间距候选：先取最少A4页数，再按行自然密度变异系数、过度拉伸代价与末行留白评分，同分取较小间距。五线谱不再遇到“不增加页数”的较大间距就立即返回。显式硬换行、内部墨迹避让和谱源内容保持原有处理。

`packages/numbered-notation/src/layout-quality.ts` 提供共用密度统计和质量评分，简谱内部选距、五线谱内部选距及外层选宽使用同一实现。五线谱选宽直接读取引擎的质量元数据，避免内外两套指标漂移。`meanLineDensity` 为最小占宽／可用行宽的行均值，只作诊断。过度拉伸代价逐行计算 `max(0, 1 - 1.5 × density / targetRatio)²` 后取均值，质量分母增加其4倍；末行以实际目标宽度修正，单行曲目豁免。它使均匀但过松的候选也承担代价。它包含各引擎自己的最小间距与符号开销，不能解释为可见墨迹覆盖率或跨谱式可读性的等价量。

第一阶段没有修改音乐字号、歌词字号、行距和分页伸展规则，也没有引入未经物理尺寸校准的目标密度。字号因子只比较同一谱式内不同版宽，不能让两种音乐字体em自动等价。

## 第二阶段：测量与绘制一致

五线谱此前给所有八分及更短音符预留独立符尾宽度，即使它们已连杠且最终不绘制符尾。现在在符杠分组确定后，仅独立音符预留符尾占宽；倚音继续保留原有独立符尾空间。音符、附点、临时变音、歌词和其他附件的占位仍参与测量。这消除了快速音群中逐音累加的不可见占位，没有缩小字形或改变分组语义。

## 可重复对照

先运行 `npm run build:packages`，再串行运行：

```sh
M3N_MEMORY_LIMIT_MB=1750 python3 tools/run-low-memory.py node tools/compare-notation-density.mjs
```

默认比较《欢乐颂》《茉莉花》《你是我心爱的姑娘》《花之舞》在528／640／768px下的两种谱面。可用 `--scores=huan_le_song_01,mo_li_hua_01`、`--widths=640` 和 `--output=.tmp/notation-density` 限定范围和输出路径。工具通过浏览器路由加载隔离包，不启动开发服务器；构建子进程退出后才启动浏览器，两种谱面依次测量。报告记录页数、谱行数、平均行密度、密度变异系数、末行留白、连续高度及独立SVG越界／碰撞诊断。发现越界或碰撞时以失败退出。

## 第三阶段：先校准尺度，再统一纵向策略

2026-11-26，保留五线谱28px五线总高度和简谱30px小节线高度（24px数字em的1.25倍），两者相差约7%。这比直接对齐字体em更适合作为基础尺子。共用16px歌词。640px版宽映射A4内容宽时，五线间距约2.03mm，简谱数字实际墨迹高度约5.23mm；768px时五线间距仍约1.70mm。无需为了追平页数把五线谱核心字号降至24px。

两种谱式现在以共用24px单位解释谱源 `leading`，默认核心净空28.8px，页面伸展上限为最小净空的1.1倍。含歌词谱行起始净空按共用规则收紧；显式 `coreGap` 保持固定。混排曲集也使用同一策略。

五线谱歌词仅避让横向覆盖歌词列的音乐墨迹，且不高于底部谱线；无横向交集的谱号尾部和低音不再把整行歌词压低。全部歌词层参与避让。系统之间检查所有前序系统的墨迹及每行页底。结构性谱号保留完整墨迹边界，额外边缘净空按音乐字号的0.1倍计算，避免重复叠加完整装饰净空。

Segno与Coda统一按实际墨迹高度19.2px绘制及测量；五线谱不再直接套用SMuFL主音乐em（原Segno约22px、Coda约30px）。字号、测量与碰撞边界同步变化。

## 共用元素的统一排查

| 元素 | 处理 |
|---|---|
| 标题／副标题／署名／歌词 | 共用32／16／14／16px；五线谱普通文字及歌词由400字重改为共用500，绘制与测量同步 |
| 注释／和弦名 | 共用14px，段落标签仍用700字重 |
| D.S.／D.C.／To Coda／Fine | 共用16px，Fine为16.8px并统一句点 |
| Segno／Coda | 共用19.2px实际墨迹高度 |
| 小节号／指法／房子编号／反复次数 | 共用10／12／14.4／13px；五线谱补齐反复次数标注 |
| 力度 | 五线谱改用简谱同源Bravura专用字形，复用实际墨迹尺寸，普通表情文字仍为文字 |
| 延长／换气／重音／颤音／短波音／保持／特短断奏 | 共用实际墨迹高度，测量与绘制使用同一缩放 |
| 速度数字 | 共用16px；速度音符按五线谱记谱语义保留 |
| leading／歌词间距／分页伸展／候选质量 | 两种谱式共用策略函数，曲集混排同步 |

谱号、调号、符头、符干、加线、减时线、八度点及倚音布局依各自记谱结构保留。简谱跳音使用既有小三角字形，五线谱使用点形跳音，不因形状不同强制套用同一高度。标题换行和附件避让均按实际墨迹执行；排版结构不同不要求所有坐标相同。

## 验收与限制

完成上述统一后，在640px下审计全部109份曲库、作品与示例，两种谱式均无检测到的碰撞或越界。106份展示事件数相同的样本中，五线谱／简谱连续高度中位比为1.102，90分位为1.244，其中90份页数相同；其余3份展示事件数不同，未纳入高度比统计：《You Raise Me Up》存在分遍换调展开；《第二圆舞曲》有3个多小节休止占位，《天黑黑》有1个间奏占位，简谱计入虚拟事件而五线谱不计入。这些计数差异不能解释为丢音。连续高度剔除了分页阈值的跳变，更适合判断密度；不同声部、加线和附件的真实占高仍然保留。

全库审计：

```sh
M3N_MEMORY_LIMIT_MB=1750 python3 tools/run-low-memory.py node tools/compare-notation-density.mjs --all --widths=640 --output=.tmp/notation-density-final-all
```

`--screenshots` 保存相同实际宽度的并排PNG及诊断SVG；SVG依赖已安装字体。`--metrics-only` 跳过独立墨迹审计，只适合快速测量，不能作为碰撞验收。每曲启动独立浏览器释放原生字体缓存；生成、构建、测试与浏览器审计串行执行。

目标是尺度、决策和留白语义统一，允许因记谱结构产生必要差异；不能仅因某曲跨过分页阈值就缩小其字形。事件计数也不能证明所有分遍换调语义完全一致，遇到展开曲目仍须核对谱源和实际展示内容。

同版宽补充审计覆盖10首代表曲目的528／768px，共20组双谱式对照，涵盖快速音群、密集调号、多遍歌词、加线和换调展开，均无检测到的越界与碰撞。

验证记录：简谱1035项全量测试、五线谱300项全量测试，以及后续合入跳音定位修复的13项专项测试通过；曲集40项、应用集成12项、浏览器阅读／PNG／PDF三组回归通过。静态检查、包边界检查、托管构建、生成物更新及摘要校验通过。最终全库审计包含调号紧排与跳音定位修复；项目进程聚合RSS峰值1324MiB。
