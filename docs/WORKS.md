# 独立作品归档

独立作品采用 `/works` 列表页和 `/works/<slug>` 固定阅读链接，不增加首页、主导航或公共曲库入口。用于联奏、演出版及单独发布的改编，按链接定向分享。没有作品时显示空列表，不用示例曲占位。

谱源保存在 `src/works/<slug>.m3n`，直接放在该目录下；slug 使用小写英文字母、数字、下划线或连字符。源文件提交 Git，修改同一文件保留阅读链接，历史由 Git 记录。需要同时保留的不同编配使用不同 slug；标题及副标题可说明乐器、调性、时长和版本。导出 PDF、PNG 属于生成文件，不作为源文件归档。

独立作品使用独立的 `works-catalog.json`，只在进入作品页面时读取；不加入 `presetScores`、公共曲库搜索、曲库上一曲／下一曲或任何整册谱集构建。列表有搜索和标题／编辑时间排序。独立作品阅读页只在作品集合中切换，列表和阅读页均不混入浏览器本地作品。

阅读、播放和单曲 PNG／PDF 导出复用现有组件。`/works/<slug>/edit` 可编辑副本；浏览保存仍遵循现有编辑器规则，保存到浏览器本地作品，不覆盖仓库中的定稿。正式更新须修改源文件并提交 Git。新增字符后，运行 `node tools/prepare-builtin-pdf-font.mjs` 更新 PDF 字体子集。

页面声明 `noindex, nofollow`，部署响应同样设置 `X-Robots-Tag`。这些措施用于减少被搜索引擎收录，不提供身份认证；知道链接的人可以访问和转发。

默认部署的列表链接为 `/works`，本工作区 Code Shell 链接为 `/score/works`；作品、编辑和资源链接均遵循构建基路径，构建要求见 [托管说明](HOSTING.md)。

## 已归档作品

- `/works/snail-mushroom-waves`：《蜗牛与黄鹂鸟·采蘑菇的小姑娘·踏浪》，据用户上传的三张谱图移调连接，统一 C♯ 大调、四分音符每分钟75拍，不加伴奏与额外过门。蜗牛完整演奏两遍（88拍），采蘑菇全曲（114拍，保留三处2/4短小节），踏浪包含开头、主段两遍及结尾（96拍）；正文共298拍，约238.4秒，播放器起奏提示拍另计。蜗牛原图谱头写4/4，但逐小节实值为2/4，按实际时值校正；其他旋律及八度按图保留。
