# 简谱与五线谱双档最小间距分行

典型谱例及历次策略的视觉审视见[排版审视记录](ELASTIC_SPACING_REVIEW.md)。历史记录中的弹性简谱参数不再代表当前策略。最新硬下限双档方案与 master 的117份同谱源对照见[最优宽度对比](NUMBERED_WIDTH_COMPARISON.md)。

## 简谱：只有最小间距

新字体平方代价、生产剪枝与局部细搜的117首实测见[字体代价与局部细搜实测](NUMBERED_FONT_COST_REVIEW.md)。

简谱使用紧8px、松16px两档最小净空（24px音乐字号），没有自然间距、压缩范围或伸展单位点。两种谱式共用有方向性的相邻元素权重：`sqrt(dLeft) ** .75 * sqrt(dRight) ** .25`，四分音符时值为1，无时值的独立元素按1处理；附点、升降号和符尾仍属于音符实际占位。简谱共用减时线组内乘0.5，五线谱共用符杠组内不额外缩小。最小净空与额外拉伸共用该权重，不同组之间不再覆盖为固定净空。歌词和其他符号仍保留真实碰撞占位。显式 `minimumNoteGap` 只排指定档。每行从硬下限出发，将非负的剩余宽度按节奏权重分配；不足时不压缩，普通超宽小节先分片，不可拆超宽对象保留真实占宽。

固定宽度内两档分别生成完整横向候选图，按同一目标求全曲最优断行。候选行使用与渲染相同的独立约束链测量，不再用前缀差分估计行宽。强制换行禁止跨越该边界的候选行，但不截断全曲评分。已分片的不可拆对象仍遵守现有分片边界。

设某行最小占宽为 `M`、可用宽度为 `W`，定义拉伸率 `r = max(0, 1-M/W)`，表示需要填充的宽度占整行的比例，不是间距相对原值的增长倍数。普通行必须满足 `M ≤ W`。末行也按铺满评分；实际绘制时，普通简谱末行若铺满后的单位节奏净空不超过同节其他行平均值的1.5倍，则撑满；其余情况根据前行的单位权重拉伸量和既有阈值决定是否缩短。等宽小节继续按继承的单元宽度判断。定义：

```js
平均拉伸率 = 所有行拉伸率之和 / 行数
拉伸代价 = sum(r ** 2)
不均匀代价 = sum((r - 平均拉伸率) ** 2)
断行代价 = 拉伸代价 + 不均匀代价
```

每档内部先以贪心最紧凑断行的页数为上限，再以“总拉伸＋不均匀”求解不增页的断行方案。候选分页使用实际断行后的数值几何，默认逐元素避让，非核心间距系数为0.5。两档分别完成纵向布局与虚拟A4分页，先选页数少的；同页数使用共同的实际间距指标，不比较各自基线上的额外拉伸。

对每行按铺满状态求实际位置，逐个测量音乐字形／小节线之间的净空，并除以上述相邻元素权重，得到每个间隔的归一化净空 `g_i`。歌词约束仍影响位置，但歌词宽度不算作音乐字形宽度；固定附着符号、段落标题和其他控制符不作为可伸展间隔。各谱行、声部的全部有效间隔汇总，先逐项计算代价，再以全部间隔数量为分母平均；舒适区内的零代价间隔同样计入分母。不先求行平均，也不对各行代价再等权平均。

舒适下限取紧／松两档的算术平均，上限取松档的1.5倍。简谱为12～24px；五线谱为1.2～2.7谱间。两种谱式共用：

```js
lower = (tightGap + looseGap) / 2
upper = looseGap * 1.5
spacingCrampedCost = average(gaps.map(g => max(0, lower / max(EPSILON, g) - 1) ** 2))
spacingExpandedCost = average(gaps.map(g => max(0, g / upper - 1) ** 2))
rowGaps = lines.map(line => line.unitRhythmicGap).filter(defined)
mean = average(rowGaps)
deviations = rowGaps.map(g => ((g - mean) / max(EPSILON, mean)) ** 2)
spacingUnevenCost = average(deviations) + max(deviations)
spacingCost = spacingCrampedCost + spacingExpandedCost + spacingUnevenCost
fontSizeCost = 4 * max(0, (版宽 - 528) / 240) ** 2
totalCost = spacingCost + fontSizeCost + overflowCost
```

舒适区两端及内部的拥挤、过疏代价为零，两项系数均为1；不再持续奖励扩大留白。不均匀度仍参与最终评分，取各行单位节奏间距相对行均值偏差平方的平均值与最大值之和，系数为1。平均项表达整体均匀性，最差项避免极端拉伸短行被长曲的平均稀释；行内因歌词等占位产生的正常间隔差异不计入行间均匀度；即使所有间隔都在舒适区内，行间不均匀代价也不一定为零。同宽度先按页数、再按 `spacingCost + overflowCost`，完全同分取松档。跨宽度先按页数、再按 `totalCost`，再同分取较窄宽度。全部间距代价均非负，保持字体代价上界剪枝安全。不可拆超宽对象保留 `100 * max(0, M/W-1)²` 溢出惩罚。无可伸展音乐间隔的行不贡献样本。`layoutCost`及旧拉伸统计只作断行诊断，不参与最终排名。连续与分页选择一致，末行按铺满评分，实际渲染仍可缩短。

末行撑满／缩短的几何规则仍读取原有按节奏权重汇总的行平均间距，不改为逐间隔评分的算术平均，避免无关的末行几何变化。五线谱边界的两个半时值间隔分别归一化、分别评分，不能先合并后计算代价。

逐间隔舒适区首次对照见[逐间隔舒适区评分对照](SPACING_COMFORT_REVIEW.md)，恢复均匀度后的复核见[均匀度与异常短行修复](SPACING_UNIFORMITY_REVIEW.md)。

## 全曲最优的求解

记 `S=sum(r)`、`Q=sum(r²)`、行数 `k`，则横向目标可写为 `2*Q-S²/k`。动态规划在同一结束小节、同一行数保留 `(S, 2Q)` 的下凸包；后续相同的后缀只增加相同统计量，目标对这些统计量是凹函数，因此凸包上方状态不可能严格优于其下方顶点。保留全部有效顶点，不对拉伸率量化、不设候选数量上限。同统计量时让较早行多放小节。

另外用忽略不均匀项的最优后缀作为安全下界剪枝。该方法求目标下的全局最优，最坏状态量仍可能很大，不能声称固定多项式复杂度；实际曲目的状态量与耗时须测量。小规模以独立穷举核对。

## 五线谱：共用双档最小间距方案

五线谱使用0.6／1.8谱间两档最小净空，无压缩；与简谱共用上述相邻元素权重，四分音符对的权重为1。
两档共用1.2～2.7谱间的舒适区，使用与简谱相同的全曲断行、不增页约束、逐间隔最终评分和宽度搜索。
固定小节数据跨宽度缓存，动态完整高度由实际宽度下的候选行雕版后测量；相同行重复使用缓存。逐元素精准分页的非核心间距系数0.5。符号占位、行内避让和绘制仍由五线谱提供。
完整定义见[五线谱](STAFF_NOTATION.md)，迁移结果见[双档迁移评估](STAFF_TWO_TIER_REVIEW.md)。

## 首轮五线谱固定宽度的变化（dbeca608）

五线谱继续对超过自然占宽的压缩施加较强代价，因此密集谱例会增加行数。这是采用自然间距后的预期行为，不要求与简谱行数或页数一致。640px真实字体密度回归中，《花之舞》为33行／3页，K545为25行／3页，口琴基本功为47行／4页；简谱分别为30行／2页、23行／2页、40行／3页。《玛丽有只小羔羊》的五线谱可以自然容纳于1行，简谱仍为2行。

`tools/compare-notation-density.mjs` 的五线谱行数、高度与双谱式高度比门槛据此重新校准；K545简谱固定640px的连续高度为1553px，原1545px上限调整为1570px，其最优600px版宽和2页结果不变。音乐字号、谱间、歌词字号、事件完整性及零越界／零碰撞要求保持原值。

## 数值几何与分页约束

公开简谱API、阅读页面和谱集导出默认复用基础音符／文字度量，按实际断行与宽度重组共享歌词基线、曲线及附着符号，再以逐元素数值几何分页。分页与绘制使用同一布局。完整行快照只在几何依赖一致时复用，不再将独立小节的最终高度视为跨宽度常量。

带分页约束的求解使用乐观代价DP、逐步补充实际行几何和必要时的Lawler分区，不改变横向目标或贪心页数上限。实现与复现参数见[宽度搜索](WIDTH_SEARCH.md)。旧独立高度模型的结果保留在[历史缓存试验](NUMBERED_CACHED_ROW_HEIGHTS.md)。
