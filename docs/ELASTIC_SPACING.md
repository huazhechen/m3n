# 简谱最小间距分行与五线谱弹性间距

典型谱例及历次策略的视觉审视见[排版审视记录](ELASTIC_SPACING_REVIEW.md)。历史记录中的弹性简谱参数不再代表当前策略。最新硬下限双档方案与 master 的117份同谱源对照见[最优宽度对比](NUMBERED_WIDTH_COMPARISON.md)。

## 简谱：只有最小间距

简谱使用紧8px、松16px两档最小净空（24px音乐字号），没有自然间距、压缩范围或伸展单位点。时值平方根权重、连组内部0.5比例、固定组间净空、歌词和其他符号的真实碰撞占位继续保留。显式 `minimumNoteGap` 只排指定档。每行从硬下限出发，将非负的剩余宽度按节奏权重分配；不足时不压缩，普通超宽小节先分片，不可拆超宽对象保留真实占宽。

固定宽度内两档分别生成完整横向候选图，按同一目标求全曲最优断行。候选行使用与渲染相同的独立约束链测量，不再用前缀差分估计行宽。强制换行禁止跨越该边界的候选行，但不截断全曲评分。已分片的不可拆对象仍遵守现有分片边界。

设某行最小占宽为 `M`、可用宽度为 `W`，定义拉伸率 `r = max(0, 1-M/W)`，表示需要填充的宽度占整行的比例，不是间距相对原值的增长倍数。普通行必须满足 `M ≤ W`。末行也按铺满评分；实际绘制时才根据前行的单位权重拉伸量和既有阈值决定是否缩短。定义：

```js
平均拉伸率 = 所有行拉伸率之和 / 行数
拉伸代价 = sum(r ** 2)
不均匀代价 = sum((r - 平均拉伸率) ** 2)
断行代价 = 拉伸代价 + 不均匀代价
```

每档内部的断行仍以“总拉伸＋不均匀”求解，不纳入行距和页数。两档按横向代价升序完成纵向雕版与虚拟A4分页，当前候选已是一页时安全跳过更高代价档位，先选页数少的；同页数使用共同的实际间距指标，不比较各自基线上的额外拉伸。

对每行按铺满状态求实际位置，测量音乐字形／小节线之间的净空，除以时值平方根和连组权重。歌词约束仍影响排出的位置，但不把歌词宽度算作音乐字形宽度；固定附着符号的边、段落标题和其他控制符不作为可伸展间隔。每行取净空总和除以节奏权重总和，得到 `g`。各行等权：

```js
mean = average(gaps)
variance = average(gaps.map(g => (g - mean) ** 2))
spacingUnevenCost = variance / mean ** 2
spacingCrampedCost = (16 / mean) ** 2
spacingCost = spacingUnevenCost + spacingCrampedCost
fontSizeCost = 3 * max(0, (版宽 - 528) / 240) ** 2
totalCost = spacingCost + fontSizeCost + overflowCost
```

16px是两档共用的舒展评价尺度，不是各档的最小间距。同宽度先按页数、再按 `spacingCost + overflowCost`，完全同分取松档。跨宽度先按页数、再按 `totalCost`，再同分取较窄宽度。不可拆超宽对象保留 `100 * max(0, M/W-1)²` 溢出惩罚。无可伸展音乐间隔的行不参与间距统计。`layoutCost`及旧拉伸统计只作断行诊断，不参与最终排名。连续与分页选择一致，末行按铺满评分，实际渲染仍可缩短。

## 全曲最优的求解

记 `S=sum(r)`、`Q=sum(r²)`、行数 `k`，则横向目标可写为 `2*Q-S²/k`。动态规划在同一结束小节、同一行数保留 `(S, 2Q)` 的下凸包；后续相同的后缀只增加相同统计量，目标对这些统计量是凹函数，因此凸包上方状态不可能严格优于其下方顶点。保留全部有效顶点，不对拉伸率量化、不设候选数量上限。同统计量时让较早行多放小节。

另外用忽略不均匀项的最优后缀作为安全下界剪枝。该方法求目标下的全局最优，最坏状态量仍可能很大，不能声称固定多项式复杂度；实际曲目的状态量与耗时须测量。小规模以独立穷举核对。

## 五线谱：保留自然间距与弹性

五线谱继续通过 `elastic-spacing.ts` 和 `native-spacing.ts` 的弹簧路径求解。每个间隔有碰撞下限、自然长度和方向弹性；压缩到下限后停止收缩，不能满足的宽度保留硬下限。

其自然间距参考 LilyPond 的时值模型：基础时值为每小节最短时值中出现最多的一种，上限八分音符，同频取较短者。基础间隔为实际 Bravura 普通符头宽加1.2个谱间；时值每翻倍增加1.2个谱间，短于基础时值时按比例缩小符头后的留白。实际符号、歌词及多声部占位仍可能增大距离。此次简谱改动不调整五线谱的分行或选宽策略。

参考：[LilyPond 2.24 横向间距](https://lilypond.org/doc/v2.24/Documentation/notation/horizontal-spacing-overview)、[符号间隔计算](https://github.com/lilypond/lilypond/blob/stable/2.24/lily/note-spacing.cc)、[弹簧实现](https://github.com/lilypond/lilypond/blob/stable/2.24/lily/spring.cc)。

## 历史弹性方案的简谱回归约束

用 `tools/benchmark-numbered-spacing.mjs` 在真实字体的浏览器中逐曲执行完整粗搜／细搜。当前工具整批只启动一个浏览器和页面，预装共享曲库TTF，并跨曲目复用文字与固定符号度量；每曲重新创建布局任务，测完主动回收布局图。构建打包先退出，不启动开发服务器。基线和改后报告必须使用相同源码SHA-256和同一测量工具。报告同时记录整批墙钟时间、逐曲选宽时间、文字测量次数和缓存命中次数；不加 `--audit` 就不执行独立碰撞／越界审计。

验收目标：全部曲目的最优页数不变，至少95%的最优宽度变化不超过24px，最大变化不超过48px。记录全部例外，不以更换选宽评分、覆盖最优宽度或修改谱源满足约束。独立 SVG 笔画验收另行进行。

```sh
python3 tools/run-low-memory.py node tools/benchmark-numbered-spacing.mjs --output=.tmp/elastic-before/report.json
python3 tools/run-low-memory.py node tools/benchmark-numbered-spacing.mjs --baseline=.tmp/elastic-before/report.json --output=.tmp/elastic-after/report.json --check
```

## 首轮五线谱固定宽度的变化（dbeca608）

五线谱继续对超过自然占宽的压缩施加较强代价，因此密集谱例会增加行数。这是采用自然间距后的预期行为，不要求与简谱行数或页数一致。640px真实字体密度回归中，《花之舞》为33行／3页，K545为25行／3页，口琴基本功为47行／4页；简谱分别为30行／2页、23行／2页、40行／3页。《玛丽有只小羔羊》的五线谱可以自然容纳于1行，简谱仍为2行。

`tools/compare-notation-density.mjs` 的五线谱行数、高度与双谱式高度比门槛据此重新校准；K545简谱固定640px的连续高度为1553px，原1545px上限调整为1570px，其最优600px版宽和2页结果不变。音乐字号、谱间、歌词字号、事件完整性及零越界／零碰撞要求保持原值。
