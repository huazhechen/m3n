# 简谱与五线谱三档最小间距分行

当前算法、参数、评分与覆盖选项见[三档候选与统一纵向间距](VERTICAL_SPACING.md)。简谱8／12／16px、五线谱0.8／1.6／2.4谱间分别产生一套按占比软目标评分的断行，再固定断行搜索保持页数的最大统一纵向行距，最后统一比较页数及实际间距代价。前两档每行占比软目标2/3，最宽档1/2，低于目标增加代价但不淘汰；末行、段落末行和强制换行均计算占比及留白代价。

简谱采用前后均衡的相邻元素权重：`sqrt(dLeft) ** .5 * sqrt(dRight) ** .5`；五线谱保持前后75%／25%的权重。四分音符时值为1，无时值的独立元素按1处理。简谱增时线保留同组关系，间距时值按八分音符0.5处理，不改变实际演奏时长、事件身份或歌词归属；组内系数仍为0.75。五线谱不再施加组内折扣，系数为1；其单音权重在四分音符及以下按时值线性计算，超过四分音符按时值平方根计算，再取前后75∶25加权几何平均。附点、升降号、符尾与歌词保留实际占位。最小净空和额外拉伸共用该节奏权重。简谱的小节线、谱内Segno／Coda、调号、拍号、速度及D.C.／D.S.等无时值元素统一使用无时值间距系数 `zeroDurationGapRatio=1`，两侧均按四分音符基准，不读取相邻音符或增时线的时值；三档最小净空分别为8／12／16px。最小净空、额外拉伸及节奏间距评分归一化共用此权重。导航文字到其后导航文字／小节线仍为刚性连接，但其净空也从同一系数计算；Segno与前置小节线、行内段名到后续符号等既有刚性连接保持原语义。其他间隔保持原规则。行内碰撞、末行继承宽度和超宽小节分片规则保持独立。

以下为历次实现与视觉回归记录，不代表当前搜索流程。

## 首轮五线谱固定宽度的变化（dbeca608）

五线谱继续对超过自然占宽的压缩施加较强代价，因此密集谱例会增加行数。这是采用自然间距后的预期行为，不要求与简谱行数或页数一致。640px真实字体密度回归中，《花之舞》为33行／3页，K545为25行／3页，口琴基本功为47行／4页；简谱分别为30行／2页、23行／2页、40行／3页。《玛丽有只小羔羊》的五线谱可以自然容纳于1行，简谱仍为2行。

## 数值几何与分页约束

公开简谱API、阅读页面和谱集导出默认复用基础音符／文字度量，按实际断行与宽度重组共享歌词基线、曲线及附着符号，再以逐元素数值几何分页。分页与绘制使用同一布局。完整行快照只在几何依赖一致时复用，不再将独立小节的最终高度视为跨宽度常量。

带分页约束的求解使用乐观代价DP、逐步补充实际行几何和必要时的Lawler分区，不改变横向目标或贪心页数上限。实现与复现参数见[宽度搜索](WIDTH_SEARCH.md)。旧独立高度模型的结果保留在[历史缓存试验](NUMBERED_CACHED_ROW_HEIGHTS.md)。
