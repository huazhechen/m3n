# VexFlow 五线谱疏密审视

日期：2026-11-20。先重新搜索曲库与独立作品共103首的五线谱建议版宽，再检查实际墨迹、逐曲缩略图及重点原尺寸谱面；修复排版后重新搜索、验证建议版宽。搜索以页数、安全和 ±5px 稳定性为条件，是启发式结果，不代表所有可能版宽的全局最优。

## 发现与修正

加强像素检查后发现6处原检查未覆盖的碰撞，涉及《当年情》《梨花又开放》《如愿》《第二圆舞曲》《一千个伤心的理由》《月半小夜曲》。房子线／挂钩与连奏线、连音组数字或休止符发生实际接触。原因是单个房子被加入“已按组处理”集合，却没有建立分组，因而跳过最后的完整避让。现在只有真正分组的房子跳过单独处理；单个及跨行续接房子都完成最终避让。同排房子仍共用基线。

碰撞检查现在包含房子、行内调号，以及独立音符／和弦／休止符之间的实际重叠。只把包围框作为候选，使用不透明像素确认；符杠与符干的有意连接仍允许。检查临时添加的角色属性在结束后恢复，避免改变最终SVG。

《伴随着你》的末尾D段只有7个音符，却被铺满整行。此前短末行规则排除了具名乐段。现在短尾段也继承前行的单位伸展量，在不超过整行60%时自然收尾；保留段名、硬换行和字形尺寸。该例末行从约2.47倍最小占宽降至约1.28倍，避免尾声突然变松。

开启小节号时，《梨花又开放》还出现行间极小接触：输出阶段再次调整编号横坐标，使此前避让测量失效。现在编号只在排版测量前定位，文字展开不再改变编号位置，并保留4px文字净空。

行距按五线谱主体定义核心：单谱表为五条谱线的外边界，大谱表取整组谱表的外边界。歌词、符干、加线、弧线与文字不再扩大核心边界，而由横向重叠的实际墨迹决定额外避让。核心最小净空与避让要求取最大值，避免既计入歌词高度、又叠加整份核心间距。更改此规则后再次刷新全库建议版宽。

## 保留的空间

没有统一压缩所有谱行或强制撑满A4。多遍歌词增加的高度、调号与倚音占宽、关系符号净空属于必要空间；只有少量谱行的短曲保留页尾留白。完整页内仍按既有26.4～32px核心净空策略安排，避免短曲为了填满纸张而放大行距。

横向密度以分行伸展量和歌词实际墨迹辅助筛选，再审视原图。长时值、作者硬边界和练习谱不应与密集十六分音符采用同一个“填充率”阈值。检查未显示需要普遍调大或调小默认字号、歌词层距或谱行距。

## 本轮验证结果

最终刷新103首，共回写62份谱源；每首建议宽度及±5px共309项检查通过。按五线核心规则重新搜索后，24首的建议宽度与此前规则不同；《同桌的你》可在720px下由两页收为一页。其余曲目的最佳页数保持不变。

渲染器191项单元测试、像素审计器8项回归及五线谱13项端到端测试通过。开启小节号后的103首和6个专项夹具也通过边界及像素碰撞检查。

## 复验入口

- `npm run refresh:staff-widths -- --fresh`：修复后的全库搜索与候选邻域验证。
- `node tools/verify-staff-layout.mjs --measure-numbers`：额外检查开启行尾小节号后的全库版面。
- `npm run test:staff-layout`：全库及特殊夹具的越界、系统间和系统内像素检查。
- `node --test tools/native-ink-collisions.test.mjs`：像素检查器本身的回归。
- 渲染器单元测试覆盖单个房子避让与短尾段；五线谱端到端测试覆盖分页、等宽小节、大谱表歌词、播放定位、PNG和矢量PDF。

搜索结果位于 `.tmp/staff-widths/report.json`。本轮逐曲预览与辅助疏密数据位于 `.tmp/staff-spacing-audit/`；它们是工作区审视产物，不作为固定坐标快照。未来更改排版后应重新生成。
