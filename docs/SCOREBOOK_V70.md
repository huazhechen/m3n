# 第七十版：《秋樱》第二段尾句对位

根据LRCLIB逐行歌词及网易云逐字YRC，将《秋樱》第二段末句由 `い% | さ%せ%てください{%2} |` 改为 `{%2} | {%3}いさせてください |`。仅调整该遍歌词槽位，使「いさせ」后移、「て」对应较长音、「い」接尾部长音。旋律、节奏及第一段歌词保持不变；详见[核查记录](../scorebook/秋樱歌词核查.md)。

沿用前9个句首校准，三套LRC的末句入词偏差降至0.075～0.218秒；YRC末句八字入词偏差均方根0.098秒、最大0.196秒。时间资料包含标注误差和演唱弹性，本次修正不代表全曲逐音验收。

重新试排《秋樱》的全部候选宽度，其他曲目仅在谱源、渲染器和字体摘要一致时复用已验证试排。仍采用[第六十九版合页规则](SCOREBOOK_V69.md)，保留前两章顺序及32逻辑px曲间净空。全册88首、76页，《秋樱》在第25页，建议宽度660px。
