# 整行高度、不增页目标方案与master全量对照

目标方案为独立小节高度缓存、中心线上/下核心分别合并、整行避让、
非核心间距系数0.3、每档不超过贪心方案页数、字体代价系数8。
启用48px粗搜、补24px、局部6px细搜及全部已有安全剪枝。
“全量”指117首全部实际求解，不是遍历所有41个宽度；
以下目标宽度是本次局部搜索的赢家，不声称全范围离散最优。

master复用已有的全范围报告，不重新运行：
.tmp/font8-master-full/current.json，冻结版本fcc3f355。
目标报告为 .tmp/row-envelope-master-comparison/current.json。
逐首源码SHA-256和三字体SHA-256全部一致；
目标的宽度、页数、行数与上一轮目标方案117首结果完全一致。
