- 等宽反复边界：一次性引子与反复部分分为不同乐句，满足同乐句小节播放次数一致。
- 等宽并行低音：`B:` 末尾使用普通对位线，结束结构仍由 `N:` 控制。
- 等宽器乐括号／歌词：两个器乐小节不配歌词，末尾一个有词音符只配一个字。
