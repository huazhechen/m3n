## 侧边变音谱例的微小纵差归因

`side-accidental.m3n` 在固定调升半音、320px 时约0.014076px的音符纵差，已由只读插桩及解析弧带查询解释：指法数字2的推进宽5.5px，实绘宽5px。参考 `TextAboveAttachment` 用推进与实绘的并集查询下方弧带，最终横向区间为 `[82.4789604,87.9789604]`；自研使用实绘区间 `[82.7289604,87.7289604]`。弧带在两区间的上沿相差0.014077497px，与DOM量得纵差一致到浮点精度。两版全局指法文字位置相同，音符与弧带因各自测得净空产生这一微小相对差别。

证据 `.tmp/side-arc-query-probe.mjs`、`.tmp/side-arc-query-spacing.json`、`.tmp/side-arc-query-summary.json`。查询由32次二分的连续弧带切片给出，不是粗像素采样误差。参考推进盒为通用文字提供保守占位，自研按实际笔画避让符合项目实测原则；依据用户允许保留合理微差的要求，不增加坐标补偿或扩大比较阈值。该例原始像素报告仍保留为有差异，不宣称严格零像素一致。
