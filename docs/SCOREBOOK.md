# 谱集与网页统一渲染

第六十版起，本说明取代 `NUMBERED_NOTATION.md` 中第五十五版等历史谱集排版记录。谱集没有独立的排谱策略，只在网页渲染结果之间选择宽度，然后缩放到A4。

## 渲染与页面

`tools/scorebook-layout.mjs` 直接调用 `src/lib/render-score.ts` 的 `renderScoreInto`，只传谱面文档、版宽和分页模式。不改临时文档，不注入文字测量器，不设置紧凑模式、逐曲间距、等行高、隐藏署名或隐藏低音，不重新分行或切页。合页只把完整连续SVG放到同一张纸上。基本功也使用同一入口，其等宽小节来自谱头 `{equal-measures=true}`。

统一应用入口的谱内页边距为0.5em（当前22px数字对应11px），随整张谱一起缩放；底层引擎仍允许调用方显式指定边距。谱行核心区取主旋律、低音、替代旋律及各声部歌词的实际最高、最低点；八度点、附点、减时线属于音符主体。倚音及其内部标记、圆滑线、延音线、连音组数字与括线不计入核心区，仅按实际碰撞留12px净空。相邻两行核心区之间至少留24px；表情、奏法、倚音、发夹及其他核心区外图形超出核心区时，按实际横向碰撞保留12px净空，只增加必要距离。显式段间距继续额外保留，页首不叠加。所有距离与音符、歌词、线条一起等比缩放，没有谱集独立行距候选。网页、打印预览与谱集使用同一设置。

分页沿用网页的A4内容比例273/186。每个原生SVG页通过网页导出的 `a4ImagePlacement` 等比放入210×297mm纸张，四边至少12mm；内容顶部对齐，水平方向居中。只修改最外层SVG的位置与尺寸，不移动内部图元。长曲自然分为多页，每首独立起页；同一篇内相邻短曲允许合页，不跨篇、不拆曲。封面、目录和三篇顺序属于谱集装订信息。

## 最佳宽度

独立曲目遍历540～760px，步长10px，共23个候选；每个候选验证W−5／W／W＋5三个宽度，页数必须一致，内部断行不要求一致。相邻候选复用重复宽度，69个验证位置只渲染47个独立宽度。浏览器完成字体加载后检查实际图形边界、音符和歌词重叠；渲染失败或检查不合格的候选不参与选择。所有候选均失败时构建报错，不静默放宽几何标准或使用旧宽度。

选择顺序明确为：

1. 全谱集总页数最少，包括相邻短曲合页。
2. 同页数时所有曲目版宽之和最小，使A4中的音符尽量大。
3. 两者相同时优先让前页容纳更多完整曲目。

`tools/scorebook-packing.mjs` 按原顺序动态规划。独立曲目仍按原生页数、版宽选择；组合页固定使用640px，不参与宽度搜索；合页中每首曲目必须在640px下通过分页和连续模式的安全检查，且原生只有一页。完整连续SVG的高度加曲间22px（1em）留白须能装入A4版心；保留每首的标题、署名、低音及谱内0.5em边距。所有曲目使用640px逻辑宽度和同一缩放比例，不分别缩小来凑页；另检查635／645px下同一组合仍能合页。组合页成员的单曲最佳宽度按约定直接设为540px，报告以 `width` 记录单曲建议、`bookWidth` 记录实际谱集版宽。`sharePage: false` 禁止该曲合页，`breakBefore: true` 强制曲首换页。报告的 `sharedPages` 记录合页宽度、成员和纵向位置。

“最佳”指满足上述规则的候选，不是全整数宽度或人工审美判断。试排不修改源码中的显式换行和等宽标记，也不为减少页数改变音乐内容。

PDF生成并验证成功后，独立曲目的稳定候选宽度、合页成员的固定540px写回每首谱源的 `{preferred-width=…}`，并提交Git。网页解析器、曲库元数据和渲染入口统一读取该字段，缺省720；显式传入的阅读版宽优先。字段只允许在谱头声明一次，值为320～2560之间的整数，单位为逻辑px。更改源谱和渲染器后重新构建可更新最佳宽度，完整候选与拒绝原因保存在本地报告。回写前核验全部源文件摘要，拒绝覆盖试排期间的修改。

## 构建和检查

运行 `npm run build:scorebook`。无需开发服务器：Vite只构建离线浏览器包，Playwright通过本地路由提供资源，不访问外网。构建先保存原生页面，再共用导出字体子集打包矢量PDF；打包只保持已排字形的基线，不重新排谱。PDF使用真实A4尺寸，检查页数、嵌入字体、无栅格图片及导出越界。只有PDF成功生成后才回写谱头建议宽度。

`npm run test:scorebook` 检查共同宽度合页、顺序与篇章边界、容量和宽度选择规则、网页与谱集SVG一致、A4只缩放外层、署名／低音／替代声部保留及长曲原生分页。生产构建验证网页能够直接读取谱头的建议宽度。`.tmp/scorebook-v63-web/index.html` 和 `pages/` 提供本地逐页预览。

PDF、布局和体积报告、排序CSV仍为本地生成物，不提交Git。`npm run compact:scorebook` 可以根据最近构建的页面重新打包PDF；旧逐曲字号保留和谱集回流逻辑已删除。

## SVG与PNG留白

网页连续渲染在SVG外四边各留谱面宽度6%的白底留白，独立于谱内0.5em边距。容器总宽为谱面宽度的112%，CSS内边距按容器宽度的6/112计算，手机与桌面一致；不改变SVG内部排版或导出内容。网页分页模式展示完整210×297比例的A4纸张，SVG放入四边12mm的版心，顶部对齐、水平居中；桌面适屏计算也按整张A4纸的比例进行。

图片导出在所有已渲染页面外添加一层白底SVG画布，四边各留原谱最大宽度的5%。例如640px谱面四边各留32px，总宽704px。内部SVG只平移，不重新排版；多页先按原高度纵向拼接，再为整图加一次外框。SVG和PNG共用 `frameScoreImage`，PNG按带框后的尺寸栅格化。PDF直接使用12mm纸张边距，不叠加这层5%外框。

第六十一版按当时规则生成：88首、80页，29首短曲组成10个720px组合页；组合页成员的单曲建议为640px。全部曲目重新选宽并核对回写结果，58首的建议值发生变化。导出验证无越界、无栅格图片，PDF约5.7MB。本地文件为 `scorebook/循序渐进乐谱集-简谱-v61.pdf`。

第六十二版按540～720px及当时的核心区规则生成：88首、93页，22首短曲组成9个640px组合页，成员单曲建议为540px；80首建议宽度发生变化。全部回写值与报告核对一致，组合页通过635／640／645px容量检查，导出无越界、无栅格图片，PDF为5,927,084字节。本地文件为 `scorebook/循序渐进乐谱集-简谱-v62.pdf`。

第六十三版完成核心区及房子墨迹避让更新后的试排：88首、89页，24首组成9个640px组合页；73首建议宽度相对已提交谱源发生变化。导出无越界、无栅格图片，PDF为5,906,248字节，文件为 `scorebook/循序渐进乐谱集-简谱-v63.pdf`。随后网页保留最小0.4em、自然0.6em，将符杠组内系数从0.8改为0.6，并增加0.1em最小间距下限；组间间距不收紧。按要求本次不因间距调整重排PDF或再次回写最佳宽度，现有PDF与宽度报告仍对应此前的组内0.8系数。

## 基本功两页试排

2026-11-17，搜索上限提高至760px。独立段落标题按装饰参与12px碰撞避让，与核心区24px规则取所需距离的最大值，不额外增加12px段间距。最小／自然间距0.3／0.5em，符杠组内及撑满余量系数0.5，下限0.1em。保留全部练习分隔和等宽小节，用正常网页入口试排540～760px并验证±5px：最窄稳定两页候选为760px，755／760／765px均为两页、33谱行，无墨迹越界和音符／歌词相交。独立PDF采用A4四边12mm、矢量图形及嵌入字体，约252KiB；未刷新整册，未回写最佳宽度。
