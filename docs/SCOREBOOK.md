# 谱集与网页统一渲染

当前全量生成与一键刷新流程见[第七十五版](SCOREBOOK_V75.md)，行距规则见[第七十四版](SCOREBOOK_V74.md)；组合算法沿用[第六十九版：疏密均衡与精确合页](SCOREBOOK_V69.md)。下文保留此前版本的生成记录。

第六十版起，本说明取代 `NUMBERED_NOTATION.md` 中第五十五版等历史谱集排版记录。谱集没有独立的排谱策略，只在网页渲染结果之间选择宽度，然后缩放到A4。

## 渲染与页面

`tools/scorebook-layout.mjs` 直接调用 `src/lib/render-score.ts` 的 `renderScoreInto`，传谱面文档、版宽和分页模式；合页容量检查采用各曲最小核心净空（默认1.2em，即26.4px，谱头 `{leading=…}` 可覆盖）的最大值。不改临时文档，不注入文字测量器，不注入逐曲间距、不隐藏署名或低音，不重新分行或切页。合页复用同一引擎测量的完整谱行，在整页统一提高核心净空后输出各曲连续SVG。基本功也使用同一入口，其等宽小节来自谱头 `{equal-measures=true}`。

统一应用入口的谱内页边距为0，留白由A4纸张或外部画布提供；行尾小节号带从文字墨迹向上、下、左各扩展2px、右侧不扩展的白底，与小节线上方保留2px间距并右对齐小节线实际墨迹最右侧，置于顶层且不参与碰撞避让；底层引擎仍允许调用方显式指定边距。谱行核心区按音符横向占宽加权，包含圆滑线、延音线和三连音数字／括线的局部边界；歌词保留完整实际占位，详细规则见[简谱渲染](NUMBERED_NOTATION.md)。默认连续模式相邻两行核心区之间至少留1.2em（26.4px）；默认分页模式按此下限判断分页，再逐页统一提高核心净空参数至26.4～32px内可容纳的最大值（包含末页），每处仍取核心要求和碰撞要求的最大值，碰撞净空随核心参数取一半（13.2～16px），碰撞主导的间距也随之调整；表情、奏法、倚音、发夹及其他核心区外图形超出核心区时，按实际横向碰撞保留核心参数一半的净空，只增加必要距离。行内具名段落的12px段间距继续额外保留，页首不叠加；独立段落标题按装饰参与核心参数一半的局部碰撞避让，与当前核心净空所需距离取最大值，不额外叠加段间距。所有距离与音符、歌词、线条一起等比缩放，分页和合页默认采用26.4～32px核心参数规则，各曲可通过谱头 `{leading=…}` 设置最小核心净空，参数单位为音乐字号的em，当前仅基本功设置为0.8em（17.6px），分页在17.6～32px内拟合，连续模式为17.6px。网页、打印预览与谱集使用同一设置。

分页沿用网页的A4内容比例273/186。每个原生SVG页通过网页导出的 `a4ImagePlacement` 等比放入210×297mm纸张，四边至少12mm；内容顶部对齐，水平方向居中。只修改最外层SVG的位置与尺寸，不移动内部图元。长曲自然分为多页，每首独立起页；同一篇内相邻短曲允许合页，不跨篇、不拆曲。封面、目录和章节顺序属于谱集装订信息。

## 最佳宽度

宽度扰动检测已彻底删除。选宽、合页及宽度刷新仅检查实际候选宽度，不探测邻近宽度，也不要求邻近宽度页数一致。下文旧版本记录中的扰动验收只描述历史结果。

每个版宽先由统一渲染器按0.4em确定页数基准，再在0.6～0.4em之间以0.05em步长选择不增加页数的最大音符间距；连续与分页共用选距和换行，最后才伸展纵向间距。同一版宽内选择不增加页数的最大间距（上限0.6em）；不同版宽之间按下述综合质量评分选择。

简谱、五线谱阅读器与本地／在线PDF共用候选遍历、综合质量评分和最终择宽，统一使用480～720px、20px整档，共13档候选。两种谱式只保留各自的排版测量适配器。先取有效候选中页数最少者，再以字号保留比例除以 `1＋谱行自然密度变异系数＋0.5×末行留白比例` 的综合质量分择优，同分取较窄宽度。合页固定在640px检查成员单曲是否均为一页谱且合计高度（含曲间距）可装入A4版心；通过后，仅在480～640px、20px整档候选下检查组内容量，选择成员平均质量最高者，同分取较窄宽度。候选不足时该组不合页。

排版内部的音符、歌词、连线、装饰及谱行避让一直启用，仍按实际墨迹和相交关系计算位置与必要间距。生产选宽只读取这份布局的页数、谱行数、连续高度和质量指标，不为每档候选生成、挂载SVG，也不执行排版完成后的独立越界／碰撞扫描。独立验收作为测试运行：`--audit-layout` 会对全部实际候选生成SVG并扫描边界和碰撞，在验收模式中排除不合格候选。关闭独立验收不关闭布局内部的几何约束和避让。

选择顺序明确为：

1. 全谱集总页数最少，包括相邻短曲合页。
2. 页面组合仍按页数与疏密代价优化；同分时比较综合质量分。
3. 同一组合的版宽按质量分选择，同分时取较窄宽度；曲序保持确定。

`tools/scorebook-packing.mjs` 在固定顺序章节中按原顺序动态规划；允许重排的章节使用精确集合分组搜索。集合状态以BigInt位掩码标识，并只缓存实际到达的状态。合页先以640px进行资格检查，再在480～640px、20px整档内以统一质量评分为通过资格的组合选择共同宽度；成员使用相同逻辑宽度和缩放比例，不分别缩小来凑页。按谱头最小核心净空（默认1.2em，即26.4px）得到的连续SVG高度加曲间最小32px留白须装入A4版心；合页确定后统一拟合核心净空，并均分剩余段后距。保留每首标题、署名和低音，谱内边距为0。`sharePage: false` 禁止该曲合页，`breakBefore: true` 强制曲首换页。报告条目的 `width` 记录独立曲目选宽，`bookWidth` 记录实际谱集版宽；`sharedWidthSearch` 单独记录合页的640px准入宽度和480～640px搜索范围。合页曲目清单及调整前后对照见[合页清单](SCOREBOOK_SHARED_PAGES.md)。

“最佳”指480～720px全部20px整档中先满足最少页数、再取综合质量分最高的有效候选，不代表所有整数宽度或人工审美的全局最优。试排不修改源码中的显式换行和等宽标记，也不为减少页数改变音乐内容。

谱集PDF仍根据每首曲目的离线版面测量结果选择宽度；网页曲谱不读取或保存该版宽，每次打开时由浏览器自动搜索。两者共用质量评分；独立SVG安全验收仅在测试模式启用。

## 构建和检查

乐谱库顶部的“导出谱集”恢复自 Git 历史实现，导出全部内置简谱，不受搜索筛选影响，不包含本地作品或独立作品。每次读取最新谱源，使用与阅读页相同的质量评分，在480～720px内按20px档选宽，并兼顾字号大小、谱行密度与末行留白；试排与实际输出均使用零谱内页边距，不读取旧的谱源宽度或离线报告。

保留封面、两列目录、章节顺序、曲目网页链接及完整短曲合页。在线与本地PDF导出共用选宽器、几何安全检测和质量评分。合页逐首按解析后的乐谱文档准备字体，与单曲测量保持同一字体选择，避免临时合并源码加载额外字体后改变后续曲目的行数或页数。合页先按640px判断资格，再为整组搜索综合质量最高的共同宽度；曲间最小留白为32px。仅配置允许的章节可为合页重排。复用每次导出内的测量结果，字体使用当前三字体策略。

打开导出弹窗后一次完成选宽、章节合页、页面生成、字体嵌入与PDF打包，全程提供进度、取消及失败重试。只有PDF文件完全生成后显示“下载 PDF”，点击直接下载内存中的文件，不再启动第二轮生成；关闭弹窗释放结果。以下本地脚本继续负责本地整册、单曲发布PDF和校验稿。

### 独立脚本

一次执行全量刷新：

```sh
node tools/refresh-score-pdfs.mjs
```

脚本可从任意工作目录调用，依次构建渲染包、搜索整册内部版宽并生成和校验整册PDF、刷新全部单曲PDF和现有校验稿。使用 `config/scorebook/editorial-plan.json` 中的版本和输出路径，重复执行会刷新该版本；需要新版时先修改配置。任一步失败立即停止，后续步骤不会执行。依赖已安装的项目npm包、Chromium和Poppler命令（`pdfinfo`、`pdffonts`、`pdfimages`）；不启动开发服务器。PDF与详细报告仍按下述规则作为本地生成物保存。

乐谱库由 `npm run build:scorebook` 搜索谱集内部版宽；独立作品执行 `node tools/refresh-numbered-works.mjs` 可生成离线版面报告。两者均不修改谱源。报告保存在 `.tmp/numbered-work-widths/report.json`。

运行 `npm run build:scorebook`。`node tools/build-scorebook.mjs --probe-only` 仅完成全库宽度试排，在临时目录保存 `width-probes.json`，不输出PDF、不修改谱源。默认每次全量重测，不自动读取旧候选；`--force-measure` 明确要求全量重测。原有 `--reuse-widths=报告路径` 仅供手动复用已验证的试排结果以调整目录或打包，先核验渲染器与字体摘要，再逐曲核验源文件摘要；不能与强制重测同时使用，且必须匹配是否执行独立验收。性能对照不使用复用结果。无需开发服务器：Vite只构建离线浏览器包，Playwright通过本地路由提供资源，不访问外网。构建先保存原生页面，再共用导出字体子集打包矢量PDF；打包只保持已排字形的基线，不重新排谱。PDF使用真实A4尺寸，检查页数、嵌入字体、无栅格图片及导出越界。

整册生成先准备全部曲目的字体，再开始任何候选测量。本地与在线使用同一顺序，避免后加载的重叠中文子集改变Canvas文字边界，使前面曲目的选距、分行和页数发生漂移。最终实绘沿用这套已准备完毕的字体集合；本地保留测量页数与实绘页数必须相等的断言。

本地每次执行同时写出 `measurement-timings.json`，可用 `--timing-report=路径` 保存独立快照。测量结束和页面实绘结束时立即保存检查点，PDF打包失败也保留已完成阶段的计时。报告包含逐曲墙钟时间合计 `scoreWallMs`、总耗时、浏览器包构建、PDF字体准备、浏览器初始化、整册字体准备 `fontPreparationMs`、全库宽度测量、章节合页搜索、页面实绘和PDF打包，以及逐曲／逐候选的解析与字体准备、横向布局、SVG生成、DOM挂载、墨迹边界和碰撞检测。布局内部继续记录自动间距试排次数，以及投影／谱头、水平尺寸测量、分行、水平放置、装饰／歌词和纵向分页耗时；这些是 `layoutMs` 的子项。`projectionMs` 进一步记录曲目投影 `scoreProjectionMs` 和谱头几何 `headerGeometryMs`；`decorationsLyricsMs` 进一步记录关系线 `relationsMs`、房子 `voltasMs` 和歌词放置 `lyricsPlacementMs`。这些子项只覆盖对应计算，不与父项重复相加。纵向排布进一步拆出谱行墨迹 `laneInkMs`、核心区墨迹 `coreInkMs` 和页面拟合 `pageFitMs`，并统计实际文字测量次数 `textMeasureCalls`。连续版检测单独嵌套在 `continuous` 中；`continuousMs`、`pagedRenderMs`、`totalMs` 是包含子项的合计，不能与其子项相加。报告还记录理论比较对数 `possiblePairs`、空间筛选后的实际比较对数 `testedPairs`和最慢的10首曲目。手动复用的旧候选计时不计入本轮工作量汇总。

文字度量只在当前生成任务内复用：字体准备完毕后创建 `NumberedTextMeasurementCache`，以完整文字和有效字体样式（字体族、字号、字重、正体／斜体）区分；度量始终按左对齐取得实际墨迹，文字锚点在后续几何中处理。页面选宽、本地／在线谱集的同一任务共用度量；单次页面布局默认也在间距试排间共用。新任务创建独立对象，不读写磁盘，不跨任务保存文字度量、候选或排版结果。每次开始布局检查字体集合与加载状态，变化时清除旧度量，避免后加载字体污染选宽。自定义 `textMeasurer` 继续由调用者负责其度量策略。

计时中的 `textMeasureRequests` 是引擎请求数，`textMeasureCalls` 是实际 Canvas 测量次数，`textMeasureCacheHits` 是本任务复用次数；前者等于后两项之和。`textMeasureCacheResets` 记录字体集合首次绑定或变化。各候选记录自己的增量，不重复累计整册缓存命中。 固定音乐字符的归一几何和SVG片段也只在同一任务内复用，按字形、目标墨迹高度、宽度和居中方式区分；返回不可变结果，字体变化时与文字度量一起清除。`fixedSymbolRequests`、`fixedSymbolBuilds`、`fixedSymbolCacheHits` 分别记录请求、实际构建和复用次数，不复用整曲排版或候选。

每个候选只建立一次 `PreparedNumberedNotationScore`，评分直接读取已有布局，分页／连续版共用横向布局；同曲的候选复用解析文档和字体准备。碰撞检查先按横坐标筛选，再以原来的0.5px相交阈值逐对核验，诊断顺序保持不变。纵向谱行碰撞改用横坐标扫描和两个堆计算所需分离量，保留原来的严格水平相交条件；歌词布局直接按绘制时的文字／线条几何和六位小数坐标计算墨迹，省去生成交互属性和解析SVG的往返，普通音符的投影、谱行墨迹和核心区也直接计算绘制图元边界，复杂装饰保留原测量路径，不改变实际避让。最终SVG绘制保持原样。生产选宽的13档候选只进行完整布局；`--audit-layout` 才对候选执行真实SVG边界和碰撞验收。页面自动选宽、本地与在线导出共用 `tools/lib/numbered-width-measurement.mjs`；五线谱页面和本地测量共用 `tools/lib/staff-width-measurement.mjs`，适配器均交给 `tools/scorebook-width.mjs` 遍历与择宽。独立验收使用空间筛选；在线生产导出复用布局并跳过独立验收，返回值的 `measurementTimings` 提供总量、测量／合页／实绘阶段及逐曲逐候选计时，不显示在产品界面。
