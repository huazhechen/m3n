# 谱集与网页统一渲染

第六十版起，本说明取代 `NUMBERED_NOTATION.md` 中第五十五版等历史谱集排版记录。谱集没有独立的排谱策略，只在网页渲染结果之间选择宽度，然后缩放到A4。

## 渲染与页面

`tools/scorebook-layout.mjs` 直接调用 `src/lib/render-score.ts` 的 `renderScoreInto`，只传谱面文档、版宽和 `paged: true`。不改临时文档，不注入文字测量器，不设置紧凑模式、逐曲间距、等行高、隐藏署名或隐藏低音，不重新分行、切页或合页。基本功也使用同一入口，其等宽小节来自谱头 `{equal-measures=true}`。

统一应用入口的谱内页边距为0.5em（当前22px数字对应11px），随整张谱一起缩放；底层引擎仍允许调用方显式指定边距。行距沿用通用排版的24px（22px音乐设计字号下），与音符、歌词、线条一起等比缩放。没有谱集独立行距候选。网页、打印预览与谱集使用同一设置。

分页沿用网页的A4内容比例273/186。每个原生SVG页通过网页导出的 `a4ImagePlacement` 等比放入210×297mm纸张，四边至少12mm；内容顶部对齐，水平方向居中。只修改最外层SVG的位置与尺寸，不移动内部图元。长曲自然分为多页，每首独立起页。封面、目录和三篇顺序属于谱集装订信息。

## 最佳宽度

每首曲子遍历640～800px，步长10px，共17个候选。浏览器完成字体加载后检查实际图形边界、音符和歌词重叠；渲染失败或检查不合格的候选不参与选择。所有候选均失败时构建报错，不静默放宽几何标准或使用旧宽度。

选择顺序明确为：

1. 原生分页数最少。
2. 同页数时版宽最小，使A4中的音符更大。

“最佳”指满足上述规则的候选，不是全整数宽度或人工审美判断。试排不修改源码中的显式换行和等宽标记，也不为减少页数改变音乐内容。

PDF生成并验证成功后，选出的宽度写回每首谱源的 `{preferred-width=…}`，并提交Git。网页解析器、曲库元数据和渲染入口统一读取该字段，缺省720；显式传入的阅读版宽优先。字段只允许在谱头声明一次，值为320～2560之间的整数，单位为逻辑px。更改源谱和渲染器后重新构建可更新最佳宽度，完整候选与拒绝原因保存在本地报告。回写前核验全部源文件摘要，拒绝覆盖试排期间的修改。

## 构建和检查

运行 `npm run build:scorebook`。无需开发服务器：Vite只构建离线浏览器包，Playwright通过本地路由提供资源，不访问外网。构建先保存原生页面，再共用导出字体子集打包矢量PDF；打包只保持已排字形的基线，不重新排谱。PDF使用真实A4尺寸，检查页数、嵌入字体、无栅格图片及导出越界。只有PDF成功生成后才回写谱头建议宽度。

`npm run test:scorebook` 检查宽度选择规则、网页与谱集SVG一致、A4只缩放外层、署名／低音／替代声部保留及长曲原生分页。生产构建验证网页能够直接读取谱头的建议宽度。`.tmp/scorebook-v60-web/index.html` 和 `pages/` 提供本地逐页预览。

PDF、布局和体积报告、排序CSV仍为本地生成物，不提交Git。`npm run compact:scorebook` 可以根据最近构建的页面重新打包PDF；旧逐曲字号保留、合页和谱集回流逻辑已删除。

## SVG与PNG留白

图片导出在所有已渲染页面外添加一层白底SVG画布，四边各留原谱最大宽度的5%。例如640px谱面四边各留32px，总宽704px。内部SVG只平移，不重新排版；多页先按原高度纵向拼接，再为整图加一次外框。SVG和PNG共用 `frameScoreImage`，PNG按带框后的尺寸栅格化。PDF直接使用12mm纸张边距，不叠加这层5%外框。
