# 谱集构建

屏幕、打印预览、单曲导出及整册谱集共用 `src/lib/render-score.ts` 的渲染入口。谱集仅负责选宽、短曲合页、封面目录及 A4 装订，不修改谱源或乐谱内部坐标。

## 版面与选宽

单曲选宽、评分及合页搜索范围见[宽度搜索](WIDTH_SEARCH.md)。共同宽度完整搜索528～624px间的17个6px档位，任一档满足容量即可参与合页；所有成员使用同一缩放比例。音乐、歌词、署名、低音及显式换行完整保留，谱内页边距为0。

连续布局使用谱源指定的最小核心净空，默认28.8px；分页及合页在基础值至其1.1倍之间拟合净空。曲间基础留白来自 `scoreLayoutConfig`。实际笔画的避让要求始终生效。每页按273/186内容比例等比放入210×297mm纸张，四边至少12mm，内容顶部对齐、水平居中。

## 曲目组合

`config/scorebook/library-categories.json` 与 `editorial-plan.json` 定义章节、顺序、合页和重排约束，网站分类与谱集共用分类来源。所有正式章节允许章内重排，使用精确集合分组联合选择曲目组合和共同宽度；先最小化总页数，同页数比较阅读代价与页面疏密之和。短曲只在同章内整曲合页；`sharePage: false` 要求该曲独占页面，但不限制它前后其他曲目配对；`breakBefore: true` 强制新页并划定重排边界。

报告的 `width` 是单曲选择，`bookWidth` 是实际谱集宽度，`sharedWidthSearch` 保存6px完整搜索范围和任一可行宽度准入策略，`packing.readingCost` 单列各组阅读代价之和。封面和目录没有正文页脚；正文页脚链接到曲目。封面版本号与下载文件名使用构建时 Git 短提交号。

目录按章节独立排成两栏，每章先左栏向下、再右栏向下，章节名居中通栏显示，两侧加横线。分页保持章节完整和原有顺序，按章节高度平衡两页；统一字号根据可用高度、实测标题及页码宽度动态调整。

## 构建与字体

网页导出复用曲库共享谱源与三字体包，见[共享资源](LIBRARY_RESOURCES.md)。整册导出沿用选择的简谱／五线谱及小节号设置。

本地运行 `npm run build:scorebook`，单曲批量导出使用 `npm run export:score-pdfs`。本地工具从实际谱源和装订文字生成 `.tmp/scorebook-font/text.ttf`，使用锁定的 fonttools；可通过 `M3N_FONT_PYTHON` 指定解释器。Barlow、Bravura及思源黑体与网页同源。

`config/scorebook/` 保存提交的配置；`scorebook/` 与 `.tmp/` 只保存可重建的 PDF、布局报告和字体，不提交 Git。生成结果维护见[生成物](SCORE_ARTIFACTS.md)。
