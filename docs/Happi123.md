# 快乐123简谱

快乐123简谱（简称：快乐谱、快乐123、Happi123,三者等价）是一套描述简谱（Numbered musical notation）的文本语言。
以下是快乐123简谱的语法教程。

## 基本结构

```h123
{title:新年好}
{subtitle:Happy New Year}
{key_signature:F}
{time_signature:3/4}

1_1_15,|3_3_31|1_3_55|4_3_2-|
2_3_44|3_2_31|1_3_25,|7,_2_1-|||

{lyric}
Happy_ New Year
Happy_ New Year
Happy_ New Year To You All
We Are Singing_
We Are Dancing_
Happy_ New Year To You All
{/lyric}

{lyric}
新年好呀，新年好呀，祝贺大家 新年好。
我们唱歌，我们跳舞，祝贺大家 新年好。
{/lyric}
```

一首完整的快乐123简谱由以下元素构成：

- 头部：元信息（标题、副标题、调号、拍号等）

```h123
{title:新年好}
{subtitle:Happy New Year}
{key_signature:F}
{time_signature:3/4}
```

- 中间：简谱，使用一些形象的符号来描述简谱

```h123
1_1_15,|3_3_31|1_3_55|4_3_2-|
2_3_44|3_2_31|1_3_25,|7,_2_1-|||
```

- 尾部：支持多行歌词块，可选，没有歌词就空着
```h123
{lyric}
Happy_ New Year
Happy_ New Year
Happy_ New Year To You All
We Are Singing_
We Are Dancing_
Happy_ New Year To You All
{/lyric}

{lyric}
新年好呀，新年好呀，祝贺大家 新年好。
我们唱歌，我们跳舞，祝贺大家 新年好。
{/lyric}
```


## 头部元信息


| 标签                    | 说明     | 示例                        |
| ----------------------- | -------- | --------------------------- |
| `{title:文本}`          | 曲目标题 | `{title:生日歌}`            |
| `{subtitle:文本}`       | 副标题   | `{subtitle:Happy birthday}` |
| `{category:文本}`       | 曲目分类 | `{category:华语流行}`       |
| `{singer:文本}`         | 演唱者   | `{singer:王杰}`             |
| `{composer:文本}`       | 作曲者   | `{composer:陈志远}`         |
| `{lyricist:文本}`       | 作词者   | `{lyricist:陈乐融}`         |
| `{key_signature:调}`    | 调号     | `{key_signature:F}`         |
| `{time_signature:拍号}` | 拍号     | `{time_signature:3/4}`      |
| `{bpm:数字}`            | 速度     | `{bpm:72}`                  |


> **必须包含**：至少需要标题、调号和拍号

> `{time_signature:M/N}` 分子M为小节拍数，分母为N分音符为一拍，比如 `3/4` 代表 4分音符为一拍，一小节为3拍。

首个 `{time_signature:M/N}` 定义初始拍号。后续同名标签可以写在完整小节之间，用于中途换拍，例如 `...|{time_signature:2/4}11|{time_signature:4/4}1111|`。

## 音符与休止符

| 名称     | 语法      | 示例 | 说明               |
| -------- | --------- | ---- | ------------------ |
| 普通音符 | `1` - `7` | `5`  | do 到 si           |
| 休止符   | `0`       | `0`  | 表示停顿           |


## 升降音与还原

| 名称     | 语法 | 示例 | 说明     |
| -------- | ---- | ---- | -------- |
| 升记号   | `#`  | `5#` | 升半音   |
| 降记号   | `b`  | `5b` | 降半音   |
| 还原记号 | `n`  | `5n` | 取消升降 |


## 高低音标记

| 名称     | 语法 | 示例  | 说明       |
| -------- | ---- | ----- | ---------- |
| 低音     | `,`  | `5,`  | 低八度     |
| 高音     | `'`  | `5'`  | 高八度     |
| 倍高音   | `"`  | `5"`  | 高两个八度 |
| 三倍高音 | `"'` | `5"'` | 高三个八度 |
| 倍低音   | `,,` | `5,,` | 低两个八度 |


## 时值与节奏

| 名称         | 语法  | 示例   | 时值(以四分音符为1拍) |
| ------------ | ----- | ------ | --------------------- |
| 八分音符     | `_`   | `5_`   | 0.5拍                 |
| 十六分音符   | `=`   | `5=`   | 0.25拍                |
| 附点音符     | `.`   | `5.`   | 1.5拍                 |
| 二分音符     | `-`   | `5-`   | 2拍                   |
| 三个四分音符 | `--`  | `5--`  | 3拍                   |
| 全音符       | `---` | `5---` | 4拍                   |



- 可组合使用，如 `5_.`（附点八分），时值为 0.5 + 0.25 = 0.75拍
- 休止符 和 节奏符，与 普通音符 同规则， 比如：`0_` 代表 休止半拍。
- **每小节时值总和必须符合拍号规定**

比如 `{time_signature:3/4}`，每个小节音符（包括普通音符，休止符和节奏符）的时值之和必须等于3。同样：
- `{time_signature:4/4}` 表示每小节必须有4拍（四分音符为一拍）。
- `{time_signature:3/8}` 表示每小节必须有1.5拍（四分音符为一拍）。

```h123
{title:时值示例}
{time_signature:3/4}
{!拍号：3/4 表示四分音符为一拍，每小节3拍 !}
{!注意时值的计算，保证每小节的时值是对的!}

555| {! 1 + 1 + 1 = 3拍 ✓ !}
5_5_05| {! 1/2 + 1/2 + 1 + 1 = 3拍 ✓ !}
5.5_5| {! 3/2 + 1/2 + 1 = 3拍 ✓ !}
5-- | {! 1+1+1=3拍 ✓ !}
(3:555)5| {!  2/3 + 2/3 + 2/3 + 1 = 3拍 ✓ !}
```

```h123
{title:4/4拍示例}
{time_signature:4/4}
{!常见错误：小节时值总和不足4拍!}

5,_5,_1_3_| {! 错误：0.5+0.5+0.5+0.5=2拍 ✗ 不足4拍 !}
5,5,13| {! 正确：1+1+1+1=4拍 ✓ !}
5,-5,-| {! 正确：2+2=4拍 ✓ !}
5_5_5_5_5_5_5_5_| {! 正确：8×0.5=4拍 ✓ !}
```


## 连音与连奏

| 名称            | 语法        | 示例        | 说明                  |
| --------------- | ----------- | ----------- | --------------------- |
| 普通连音线      | `( ... )`   | `(5 5 5)`   | 三个音连贯演奏        |
| 同音连音        | `(5 5)`     | `(55)`      | 等于 `5-`（2拍）      |
| 同音连线（tie） | `(t:555)`   | `(t:555)`   | 3拍连音，相当于 `5--` |
| 三连音          | `(3: ... )` | `(3:5 5 5)` | 三音均分两拍          |


- ✅ 支持嵌套：`(5(5)5)`，`(3:55(5)5)` 等。


## 小节线与换气符号

| 名称   | 语法     | 示例             | 说明                               |
| ------ | -------- | ---------------- | ---------------------------------- |
| 小节线 | `\|`     | `1 2 3 4 \|`     | 普通小节线                         |
| 段落线 | `\|\|`   | `1 2 3 4 \|\|`   | 分段小节线                         |
| 结束线 | `\|\|\|` | `1 2 3 4 \|\|\|` | 曲终小节线                         |
| 换气符 | `v`      | `1-v 2-`         | 代表 唱 do ，接着换气，然后再唱 re |

## 标签与分段播放

- `play` 代表 播放的循序
- `mark` 代表 段落的标签

```h123
{play: A B B}

{mark:A} 1 2 3 4 ||
{mark:B} 3 4 5 6 ||
```

演奏顺序等于

```h123
1 2 3 4 ||
3 4 5 6 ||
3 4 5 6 ||
```

## 歌词语法

歌词使用 {lyric}...{/lyric} 标签包裹，可以包含多段歌词（如中英文各一段）。歌词必须与乐谱中的音符顺序严格对应。

1. 音符与歌词对应原则

- 一个音符（`1`–`7`）对应一个歌词单位。
- 延长符 `-`（如 `1--`）不单独算音符，仍只对应一个歌词单位。
- 休止符 `0` 不需要填词。

2. 中文歌词
- 一个汉字 = 一个音符。
- 标点符号和空格不计入歌词，无需填词。
- 若某音符下无词，用 `_` 占位。

3. 英文歌词
- 一个单词 = 一个音符。
- 单词间用空格分隔。
- 音节拆分可用连字符：`Hap-` `py。`
- 无词处同样用 `_` 占位。

4. 占位符 `_` / `;`
- `_` 和 `;` 都表示该音符下不填词，用于对齐后续歌词。
- 常用于休止后、换气处或旋律延续但无新词时。

### M3N 导入方言

为保留 M3N 的歌词对位，Happi123 导入支持以下扩展写法：

- `+字`：将该歌词项强制映射到下一处延音目标；例如 `1~ 1` 配合 `甲+乙`，`乙` 对位到第二个 `1`。
- `(词组)`：将词组视为一个歌词项，整体对位到一个音符；导入 M3N 后显示下划线延长记号，词组内标点不带下划线。
- Happi123 的 `:|` 统一转换为 M3N 的普通后反复线 `:||`；弱起反复中的互补不完整小节由 M3N 校验器识别。


### 示例1:中文歌词

```h123
5,_5,_|531|(7,6,)4_4_|312|1--|||

{lyric}
祝生你日快乐！_
祝你生日快乐！
{/lyric}
```

歌词和音符对应关系表

| 音符 | 歌词 |
| ---- | ------ |
| 5,_  | 祝     |
| 5,_  | 你     |
| 5    | 生     |
| 3    | 日     |
| 1    | 快     |
| 7,   | 乐！   |
| 6,   | _      |
| 4_   | 祝     |
| 4_   | 你     |
| 3    | 生     |
| 1    | 日     |
| 2    | 快     |
| 1--  | 乐！   |

- `(7,6,)` 对应 `乐！`，但只占一个音符位置。
- `6,` 下用 `_` 跳过，因为`乐！`已填在前一音。

## 创作乐谱流程

1. 确定元信息：`标题`、`调号`、`拍号`、`BPM`等。
2. 作曲：按照`音符`、`高低八度`、`时值`、`小节线`等语法完成乐谱小节创作。
    - 正确使用`时值`和`高低音记号`，检查位置正确（音符后）。
    - 严格按照`拍号`来谱写每小节，确保每小节时值之和等于`4*拍号分子/分母`
    - 要按照`首调记谱法`记谱，大调式结尾一般为为`1`，小调为`6`。
3. 作词：
    - 第一步：按照歌词语法，确定需要填词的音符有哪些，根据音符时长，确定要填词的乐句。
    - 第二步：根据要填词的乐句，生成类似 `XXX, XX。`句式, `X`代表代填的词，数量必须等于音符数量。
    - 第三步：按照第二步的句式，替换`X`成歌词文字，注意不要增减字数。比如:`你好啊，中国。`是好的。

> 掌握以上语法规则，您将成为快乐123简谱专家！建议对照示例曲谱实践验证。
