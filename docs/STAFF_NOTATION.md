# 五线谱显示

设置中的记谱按钮显示当前状态，点击后选择“首调”“固定调”或“五线谱”。默认首调简谱；沿用旧固定调设置作为首次迁移值，之后保存三态选择。文档内只提供播放控制的谱例始终使用首调简谱。

五线谱读取独立的谱头建议版宽 `{staff-preferred-width=…}`（代码字段 `staffPreferredWidth`），缺省720逻辑px；允许320～2560之间的整数，只能在谱头声明一次。简谱继续读取 `{preferred-width=…}`。打开曲谱或切换谱式时采用对应建议值，之后手动调整或适应容器宽度优先。五线谱支持源码点击定位、现有播放器高亮、移调、连续／分页，以及单曲 PNG／矢量 PDF 导出。整本谱集始终使用简谱，不提供五线谱谱集。

## 统一排版策略

五线谱与简谱共享作者指令和页面策略，保留五线谱的谱号、调号、符干、加线、大谱表及关系符号。不要求同宽时分行、横坐标和页数相同。

- `{br}` 是硬换行；具名乐段另起谱行。普通 `---` 仍只划分乐句，不强制起行。
- 段名以方框显示；段名后的 `{br}` 使其独占谱行上方位置，速度放在段名上方，段名和演奏说明依次紧邻下方旋律，并与首个音乐系统保持同页。占宽超过半行的长段名自动上置、按可用宽度折行。段间固定增加12px留白，不参与弹性拉伸。
- `{...qpm}` 与播放始终表示四分音符每分钟数；五线谱速度标记按拍号显示常用拍值。复合八分拍号（如6/8、9/8、12/8）使用附点四分音符，其数值按时值换算，播放速度不变；标记音符、等号和数值之间使用对称留白。
- `{equal-measures=true}` 同样作用于五线谱：每行以最密小节为下限分配相同格宽，保留各小节内部节奏布局。它不是音符等距。
- `{leading}` 使用统一音乐设计尺度22px的em，默认1.2（26.4px）。它规定平均核心净空下限，真实笔画另保留参数一半的碰撞净空。同系统上下五线谱维持大谱表组织，不把该值直接当作Verovio谱表间距。

排版先由真实引擎测量整段小节与各候选行首的谱号、调号、拍号成本，再使用 `@m3n/notation` 的共享 `planScoreLines` 动态规划，按行内密度和相邻行密度差选择强制边界内的全局组合。候选不能压缩最小占宽。超宽小节在所有声部共有的事件边界处分片，优先整拍，保持连音组不可拆分；内部小节线隐藏，各片保留原书写编号、歌词和源事件身份。

横向以 `spacingLinear=0.25`、`spacingNonLinear=0.5` 为紧凑测量基准，再依次试0.375、0.34375、0.3125、0.28125，选择不超过基准A4页数的最大间距。每档都重新测量、分行、实际笔画纵排和分页，不假定单调。末行继承上一行的单位伸展量，等宽模式继承小节格宽；继承宽度不超过可用宽度60%时留白，否则撑满。没有可继承前行或新乐段入口时撑满。只移动对齐点，不缩放字形、歌词、五线或线宽。

浏览器先测量真实serif文字字体，将歌词实际占宽反馈到MEI显示投影，交给引擎做水平避让。歌词以16px为设计字号，首层到音乐主体净空6px，层间实际墨迹净空4px。空词槽保留交互身份，但不进入引擎的空白歌词层。多层歌词需要扩大大谱表净空时，通过MEI谱表间距交回引擎整体重排，使低音谱表、贯穿小节线、大括号和关系符号保持一致；左侧为大括号保留占位。长段名与说明文字按实际宽度折行；附属文字按实际横向重叠笔画避让，连音数字与括线整体避让符杠，关系曲线、括线及描边参与最终系统边界。最终小节若因行首或跨行关系比测量结果更宽，会反馈占宽并重新分行。

纵向使用按横向占宽加权的音乐核心与完整图元碰撞要求。先在最小净空下分页，仅首页预留实测谱头高度；分页确定后逐页（含末页）把净空放宽至32px内能容纳的最大值，原下限超过32px时维持下限。多余空间留在页底，段间距及谱头不拉伸。连续模式使用最小净空；两种模式共用选定的系统、音符横坐标及字形，分页只移动完整系统。

谱头与简谱共用内容策略和文字折行：标题、副标题、演唱与署名按实测占位布局，长演奏顺序按宽度折行，段名方框及箭头使用矢量图元。小节号按实际书写小节累计，多小节休止占对应小节数。

布局入口支持 `pageMargin` 和 `coreGap`，通用应用默认谱内边距0，纸张边距由外层提供。与简谱相同，调用方的 `coreGap` 只改变输出纵排，横向自动选距仍使用谱头行距作为虚拟A4基准。单个谱行或谱头与首行无法放入A4时，连续模式仍保留紧凑基准布局，分页明确报错。建议版宽仍独立；变调访问仍按绝对音高需要展开，不与首调简谱强求相同分行。

同小节内处于同一局部高度、横向互不重叠的渐强／渐弱线共用基线，并整体避让音乐主体。相邻渐变线之间按实际笔画占宽判断，不用额外横向留白将已有空隙误判为碰撞、平白增加纵向层数；实际重叠的渐变线仍分别避让。

## 独立渲染入口

开启“小节号”后，仅在每行最后一小节的末尾小节线上方显示该小节的编号，文字右对齐；行尾位于跳房子范围内时，小节号移到房子上方、保持在框线之外，与简谱一致。关闭时全部隐藏。屏幕、PNG 与 PDF 共用该规则。

`@m3n/score-renderer/staff` 按需加载；简谱显示、播放和谱集不导入该入口。`src/lib/render-score.ts` 仅在五线谱分支调用 `prepareStaffScore`，屏幕与单曲导出使用相同参数。简谱内核保持独立。首次进入五线谱时，从动态模块下载到排版资源初始化完成，复用音色加载的通用对话框显示“加载五线谱资源”和不定进度，支持后台加载；完成或失败后关闭。资源在当前页面内复用，后续切换谱式及调整宽度不再重复弹窗，失败后重新进入可重试。

`packages/score-renderer/src/staff/score-mei.ts` 从现有 `ScoreDocument` 生成 MEI，仅作显示投影，不重新解析源码，不修改传入的领域文档。沿用 `scoreEventIds`，与当前播放器、源码映射共享事件身份。带变调或八度基准的乐段访问按实际演奏顺序展开显示，保留歌词、源事件 ID 与播放遍次；普通反复保持紧凑谱面。播放仍由项目的演奏编译器与 SpessaSynth 完成，不使用 Verovio MIDI 或时间查询。

Verovio 工具实例只在一次同步排版期间存活，结束即释放；WASM 初始化复用，失败可重试。单次导出会话缓存连续与分页排版。SVG 字形引用展开为路径，嵌套文字按实际坐标展开，SMuFL 文字使用 Leipzig 路径，屏幕、PNG 与 PDF 共用结果。PDF 允许五线谱的路径字形不携带简谱数字字体；简谱仍要求其数字字体。

## 引擎来源

使用历史精简 Verovio 6.2.0（上游 commit `43f806031bfff2c64003fc8ddd9910820445f6ab`），npm 包装器固定为相同版本。产物在 `packages/score-renderer/vendor/verovio/`，保留 Leipzig 字形、MEI 输入等既有裁剪范围，并应用本地测量与目标小节宽度补丁。独立 WASM 约2.98MB，本站按需加载，无 CDN。普通构建无需 C++ 工具链。

许可证、字体声明、完整上游源码、补丁和重建脚本位于 `public/licenses/verovio/`；具体重建要求见该目录的 `README.txt`，产物校验值见 vendor 中的 `build.json`。

## 一键刷新最佳宽度

与简谱的 `tools/build-scorebook.mjs`、`tools/scorebook-width.mjs` 放在同一目录：

```sh
npm run refresh:staff-widths
# 只试排并生成报告，不回写：
npm run refresh:staff-widths -- --probe-only

# 强制重新测量所有乐谱库与独立作品，不复用历史候选
npm run refresh:staff-widths -- --fresh
```

`tools/refresh-staff-widths.mjs` 自动构建所需包，使用真实浏览器和网页相同的五线谱引擎及A4分页参数。与简谱共用 `probeWidthCandidates` 和 `chooseBestWidth`：在540～720逻辑px的10px整档范围，先粗测540／600／660／720px的页数，对进入当前最少页数区间的采样段二分细化，随后检验拟选整档及相邻整档。仅对拟选候选W−5／W／W＋5三点页数一致时完整生成SVG，核验页数、有效几何、墨迹边界、谱行间及行内实际像素碰撞与A4页高，失败则继续探索邻档或其他采样候选；重复宽度及完整SVG检查均复用。按实测稳定候选先取最少页数，再取最小宽度，不进行谱集合页。页数不保证严格单调，因此采用粗采样和局部验证补充二分，不保证未采样区间中的全局最优，不再预先遍历全部39个宽度。无稳定安全候选或解析／排版失败时，不回写任何谱源。

扫描 `src/scores/` 乐谱库与 `src/works/` 独立作品，在各目录内按文件名顺序逐曲试排，报告的 `file` 保留 `scores/` 或 `works/` 前缀。每曲关闭独立浏览器，释放完整渲染进程与WASM内存。只有渲染器／引擎摘要和源文件SHA256均匹配才复用已有候选，选定宽度及两侧仍重新完整渲染验证；`--fresh` 强制重新执行启发式搜索，可与 `--probe-only` 组合。段落标题通过MEI的 `rend halign="left"` 左对齐，避免默认居中越过页左边界；页面布局按最终实测上沿放置完整系统，容纳中文回退字体实际墨迹，不额外扩大A4画布。
