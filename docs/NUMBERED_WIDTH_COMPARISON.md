# 简谱最优宽度：当前方案与 master 对照

基线为 master `fcc3f355`，当前引擎为 `282f9f77`。两套引擎都使用基线 worktree 中同一批谱源，逐首 SHA-256 一致；《暗香》使用该 master 的更新版本，未将谱源变化计入宽度差异。范围包括曲库、独立作品和示例，共117份。

master 使用其原有24px粗搜和赢家附近6px细搜；当前方案为8／16px最小间距两档，全曲动态规划仍包含总拉伸，两档都完成分页、页数优先，同页数比较实际单位节奏间距的不均匀与紧凑代价；跨宽度再加字体缩小代价，同样页数优先，并搜索528～768px的全部6px离散档位。这是两套实际选宽策略的结果对比，没有调整参数以贴近基线。

最优宽度不变40份，变窄4份，变宽73份。58/117份的差异不超过24px，82/117份不超过48px，最大绝对差异96px。

页数不变117份，减少0份，增加0份。本轮按要求不执行碰撞和越界检查。当前全批次复用同一浏览器、页面、共享字体与文字度量；修改前引擎从单曲字体切换到共享TTF时，112份宽度不变，5份变化6px；独立复测确认字体输入存在差异。因此本表master与当前引擎都统一使用同一套共享TTF，不把字体输入变化混入评分比较。
