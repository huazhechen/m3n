# M3N 简谱渲染

简谱采用纯浏览器链路：`ScoreDocument → @m3n/numbered-notation → @m3n/jpfun → SVG`。jpFun 的 TypeScript 核心源码已保存在 `packages/jpfun`，固定上游版本与本地补丁；旧的自绘 `core/` 和字形 JSON 已移除。源码来源、Apache-2.0 许可和维护记录见 [UPSTREAM.md](../packages/jpfun/UPSTREAM.md) 与 [CHANGES.md](../packages/jpfun/CHANGES.md)。选型背景见[历史整改方案](NUMBERED_NOTATION_REMEDIATION.md)。

## 调用与职责

```ts
await prepareNumberedNotationFonts()
const score = NumberedNotationScore.create(document)
const pages = score.render({ width: 800, paged: true, includeBass: true })
// score.diagnostics 包含投影与引擎诊断。
```

渲染选项 `measureNumbers: true` 仅在每行主旋律末尾的小节线上方添加该书写小节的小节号，默认关闭。编号跨乐段连续，多小节休止按包含的小节数递增；低音与替代旋律不重复编号。数字使用引擎原生 `@up` 附着于后小节线，参与避让和行高计算；与后一小节前反复线共用边界时，编号附着于该反复线，保留事件身份与播放时间轴。阅读控制面板的小节号开关长期保存到本地，不改变打印参数。

渲染选项 `fixedDo: true` 将谱面按实际音高显示为固定C调简谱（`1=C`），非C大调自然音统一用♯拼写。转换包含原调号、谱中转调、临时变音及其小节内作用域、八度、和音、连音组、低音、倚音与替代旋律；每个变化音显示升号，自然音不额外显示还原号。阅读面板的♯开关保存到本地，与小节号开关独立；不修改谱源或播放音高；打印与下载沿用当前显示配置。

渲染选项 `transpose` 为整数半音偏移。阅读面板移调同时更新播放和谱面：首调模式直接更新谱头及谱中转调的调号，保留相对数字；固定调模式保留 `1=C`，将音符、低音、倚音与替代旋律按移调后的实际音高重新拼写，跨八度时同步更新八度点。显示转换保留事件身份，不修改源文档或重建播放器。移调入口为显示当前演奏调的单个按钮（固定调模式仍显示演奏调），点击打开双层五度圈选择对话框：顶部为 C 大调／A 小调，顺时针按纯五度排列，外圈为大调，内圈为关系小调。同一扇区的两个入口选择相同调号，移调保留原曲调式；当前调性深色高亮，对应的关系调浅色提示，原曲调号始终以加粗外框标出。圆心与底部不显示说明文字。小调乐曲的入口和选中项显示小调名称。选择目标调后，以谱面原调为基准取最短半音偏移（−5 至 +6），相差 6 半音时统一上移；选择原调恢复零偏移。移调仅在当前乐曲页面临时生效，切换乐曲或重新打开时恢复原调，不读取或写入全局移调缓存。对话框支持 Escape、关闭按钮和点击遮罩退出。

唯一音乐输入是 `ScoreDocument`；适配器不读取乐谱源码、MEI、Verovio SVG 或 MIDI。`projection.ts` 负责领域语义到 jpFun 脚本的投影，`lyrics.ts` 负责歌词槽位与遍次，`svg.ts` 只添加交互分组和属性，不移动或重新绘制音符与关系线。

简谱显示与导出不初始化 Verovio。播放时按需加载自研演奏编译器与 SpessaSynth，反复与导航由领域计划生成统一 MIDI 时间轴。`@m3n/score-renderer/view` 提供轻量页面工具，`/playback` 和 `/player` 是独立的动态入口；运行时不再加载 Verovio 或 WASM。渲染库、WASM、字体和音源必须来自本站构建产物，禁止使用第三方运行时资源外链。

应用只保留简谱排版；播放使用独立的 PlaybackScore 动态入口。旧的谱式开关和五线谱排版、导出、配对构建器均已删除。

从头播放时先按当前 BPM 发出三拍起奏提示，与拍号、弱起和节拍器开关无关；首个音符（含休止符）依次显示红、黄、绿圆形背景，第三拍结束后进入正文播放。暂停后续播不重复提示。显式段落顺序播放时，顶部演奏顺序同步高亮当前出现位置，重复段落的不同位置分别跟随。正文从零时刻开始高亮，包括开头的 `0` 休止符。

`scoreEventIds(document)` 是 MEI 与简谱共享的事件身份映射。唯一 DOM `id` 与可以重复的 `data-m3n-id` 分开：连音组子音符、长音增时线和长休止保留父事件身份，各自拥有唯一的可视 ID。小节跨系统或跨页时保留逻辑小节 ID，避免重复 DOM ID。歌词另带 `data-m3n-rendition` 和 `data-m3n-passes`，支持点击定位与反复遍次高亮。低音谱表共享旋律的反复小节线，避免并行声部的锚点错位。

## 语义支持

小调采用主音记为 `6` 的唱名：`{key=Am}` 的 `1` 对应 C4、`6` 对应 A4，谱头和谱中调号显示为 `6=A`；大调仍显示 `1=主音`。移调保留数字并更新主音音名，固定 C 调显示由同一实际音高解析生成，播放与导出共用该约定。旧版小调主音为 `1` 的输入迁移见[手册 §3.2](MANUAL.md#32-调号与调式)。

| 范围 | 行为 |
| --- | --- |
| 音高、变音、八度、八度区间 | 投影为 jpFun 数字音符及上下点；每个和音成员应用相同规则 |
| 时值、附点、延音、休止 | 保留精确时值；长音拆为首音与增时线，同小节内可表达为整拍增时线的同音延续自动使用横线；仍需弧线时从首音数字起弧，跨行时分段。长休止使用多个 0；多小节休止显示小节数 |
| 和音、低音、多声部 | 交给 jpFun 排列与对齐；导出可排除低音而不改变旋律事件 ID |
| 连音组、倚音、琶音 | 使用原生连音组、复合倚音和琶音；长/短倚音由自研演奏编译器处理 |
| 延音线、连奏、发夹 | 原生关系附件处理跨行；合并相邻连奏；支持单事件短发夹及文字形式 |
| 装饰、指法、力度 | 延长号、跳音、重音、保持音、断音、换气、颤音、指法与力度均有投影 |
| 调号、拍号、速度 | 显示页头和谱中变化；渐快/渐慢显示文字及目标速度，播放使用现有时间轴 |
| 反复、跳房子、导航 | 反复线、次数、房子括线及 D.S./D.C./Fine/Segno；播放由领域计划与自研演奏编译器负责 |
| 歌词与文字 | 中文标点、英文词、多行、共享遍次、空槽、延音与间奏跳过；括号词组保留下划线；文字、和弦、段落标题 |
| 器乐区间 | `{inst}…{/}` 投影为原生区间圆括号；按谱行分段，支持换行、分页，保留休止符与长音增时线 |

适配器对未映射的后缀产生 `NUMBERED_UNSUPPORTED_MARK`，应用显示提示；引擎错误会终止本次渲染并显示原因。领域层未表达的功能不会通过重新扫描源码补猜。引擎拍号警告仅作参考，M3N 的领域校验继续负责弱起、跨乐句小节和双谱表规则。

自研版的歌词遍次编号与歌词正文共用字号和字体。横向占位读取实际绘制的歌词、编号和下划线包络，并保留字体实测前进宽度所包含的左右边距；不再用较小编号字号及独立估算间隔决定换行。首尾标点仍绘制并参与避让，演唱文字的中心对准音符，不随标点偏移。测量与绘制共用同一歌词片段，空槽不增加可见字形占位。jpFun参考版同样以基线坐标下的实测片段供横向求解与绘制共用：文字起点独立于墨迹盒左缘，字形负边距、编号外伸与下划线圆端半线宽均参与占位；下划线覆盖实绘文字范围。

自动减时线连接读取当前拍号：6/8、9/8、12/8 等复拍子每三个八分音符分组，例如 6/8 的六个连续八分音符分成 3＋3；谱中变拍从新小节起生效。双声部分别连接，小节线重置拍组，已知拍号的小节在行内拆分后仍保留原拍组位置。显式连梁和单个分割作用域保留指定的连接范围。连音组内部保持共同减时线；组的入口和出口均可与同拍相邻细分音共享已有的减时线层级，额外层级只覆盖自身书面时值需要的音符，不跨越拍组边界连接不同连音组。播放 MEI 同样按复拍子的三个分母单位分组；这不改变音符时值或播放速度。

### 同音延续的简谱表达

同一小节中，`~` 连接的同音音符或和音，如果后续音符落在完整四分音符拍的位置、时值为整数个四分音符，且没有独立歌词、奏法、说明、调号／拍号／速度／力度变化或连奏区间起点，则后续音符显示为增时线。连奏区间在此结束不阻止转换。同音判断与领域校验共用 `resolveScorePitches`，包含临时变音继承、调号和八度。例如 `6~ 6~ 6~ 6` 显示为 `6 — — —`，`[135:h]^~ [135:h]^` 显示为和音后接三根增时线。未用 `~` 相连的重复音保留数字，避免将重新发音误写为延续。

跨小节、切分位置、短于四分音符或含连音组的延音保留同音连线；连音组取最后一个有音高的子音符作为起点。增时线之后若仍需跨小节连线，弧线从原始数字或和音起弧。此规则只改变简谱投影，不修改 M3N、MEI 或播放时间轴；每个原始事件保留自己的 SVG 身份和点击位置，增时线组带 `data-m3n-role="sustain"`。引擎增时线不消费歌词槽位，后续各段歌词仍与原音符对齐。

连奏线的末端落在区间内最后一个实际数字音符或和音上；区间末尾是普通长音时取其首个数字，是同音延续增时线时回溯到对应的原始数字，是连音组时取最后一个有音高的子音符。渐强、渐弱线仍延伸至完整时值末端。例如《后来》两处“一旦错过就不再”的 `1e~ 1e^` 显示为 `1 — —`，连奏线收在该高音 `1` 上。

连奏线与仍需保留的同音连线重叠时，连奏线排在外层，按完整弧带留出间隙，包括共用起止音、换行及分页的情况。弧线的高度和音乐端点保持原有含义，外层弧线整体上移并计入行高；只在一个音上首尾相接的相邻弧线不因此抬高。

两版嵌套弧线均按横向重叠区内相向的实际曲线边缘计算最小净空，保留音乐字号的0.15倍间距。计算使用曲线区间界逐步收敛，误差上限为音乐字号的百万分之一；不以整条弧线的矩形包络代替局部曲线，也不按屏幕像素采样或追加栅格余量。外层上移后仍重新检查侧边图元的实际碰撞。

显式关闭后重新开始的连奏区间分别保留，不因音符相邻而合并；嵌套连奏线由内到外投影，避免短弧反而浮到长弧外侧。渐强、渐弱发夹通过原生 `@dyn(...)` 排在音符上方，避让高八度点及连奏线，并预留谱行空间；跨行继续保留方向和开口进度，不改变领域区间或播放。自研发夹按最终谱行的实际横向长度连续分配开口，跨页不重启；首尾取宿主音乐的实绘边缘，单音、和音和倚音区间均可显示。延续段避让范围内的小节线也计入实测净空，开口、线宽与留白按音乐字号比例派生。两版渐变线均按横向范围内的实际墨迹确定上下位置，不把统一数字0的排版盒空白当作可见数字高度；已放置附件也按实际局部包络参与。

本轮逐曲扫描在 41 首内置曲目中识别并转换 315 处整拍延续，含《ANDY》《后来》《天空之城》《黄昏》等。记录中的次数按原始后续事件计数，一个事件可以产生多根增时线。

同一小节内，同音级、同八度的重复显式变音只印一次；出现不同变音时重新显示，小节线和调号变化重置状态。投影保留每个音符完整变音，用原生 `@note(...,showacc=false)` 隐藏冗余字形和占位，不修改音高、时值或播放。倚音仍独立显示，不参与主音的显示状态。两版升号、降号与还原号使用相同的完整矢量轮廓：升号保留各横杠独立的斜率和端点，降号弧部由两段二次曲线组成，还原号按两条连续折线绘制。所有变音记号均使用圆端、圆接头，线宽为所在数字字号的0.06倍；普通音符、和音、倚音、调号与音域共用这一绘制约定。自研轮廓保存在自身模块中，生产渲染不调用jpFun；横向逻辑宽度与字体比例规则保持独立，碰撞检查读取完整路径及描边。

### 换调再现的乐段入口

`{order=A,B,A@Db}` 在顶部将相关访问标为 `A（1=C）`、`A（1=D♭）`；共用A段入口通过原生 `@key(...,visits="1:C4;2:Db4")` 生成两行调号。各行沿用普通调号的16px数字字体和原生升降号，整体按音乐轴居中，完整包络参与横向间距、行高、自动换行及分页。相同调性的访问合并编号，单一演奏调不增加编号。源码中的谱段只保留一份，播放编译器按每次目标调展开主旋律、低音、替代旋律及段内转调；MEI也展开目标音高。固定调显示按演奏顺序展开各次绝对音高与对应歌词，保留原事件的交互身份及遍次；阅读移调更新入口各行和顶部调性。语法与示例见[手册 §5.1](MANUAL.md#51-指定乐段演奏顺序)。 自研版同样支持首调下的分遍次多行调号及段内转调：调号前缀、矢量升降号、主音分别绘制，行间避让读取文字及矢量的实测包络，整个块沿实测音乐数字的中心轴对齐；谱头与谱中调号共用测量和绘制。自研版现支持 `fixedDo`、`transpose` 和 `tempoScale`：固定调按已解析的实际音高重新拼写，含低音、和音、连音组、倚音与替代旋律；分段换调再现时展开各遍音高和所选歌词，保留原事件身份及遍次；首调移调更新谱头、谱中和分遍次调号；速度倍率更新谱头及谱中拍速（含休止起点）。谱头音域沿用同一音高统计与当前显示选项。显示变换不修改谱源或播放数据。演奏顺序换成多行且谱头超出一页时，按实测行分页，不缩小内容或压缩行距。 两版的演奏顺序分行共用实测规则：读取普通前缀／箭头、粗体段名、方框内边距与单元间隙的完整宽度，依次装入版心；不再按固定前缀宽度或中英文字符数估算。段名保持完整，顺序、重复访问及转调文字不变。

## 排版与字体

支持至少 320px 的版宽。分页使用 A4 去掉四边 12mm 后的内容比例 `273 / 186`，连续模式按实际内容扩展高度。页头与正文均由 jpFun 渲染。桌面阅读页（>720px 且不满足触屏布局条件）按剩余窗口高度等比显示完整分页，多页居中并排，放不下一行时换行并纵向滚动；≤720px，或主要输入为粗指针且不支持悬停（`pointer: coarse` 与 `hover: none`）时，横竖屏均保留全宽纵向滚动。显示缩放不改变谱面排版和导出尺寸。

渲染选项 `pageMargin` 与 `systemGap` 分别控制四边页边距和相邻谱行核心区之间的最小净空（px），底层默认为32和24，必须是非负有限数值。每行核心区取所有音符和歌词实际图形的最高点、最低点，包含主旋律、低音、替代旋律及各声部歌词，音符主体包含八度点、附点和减时线。倚音及其内部标记、圆滑线、延音线、连音组数字与括线均不计入核心区，仅参与12px局部碰撞避让。核心区采用整行上下边缘，不因横向错开而收缩；相邻核心区至少留24px。核心区以外的表情、奏法、倚音、发夹等按实际横向碰撞至少保留12px净空，超出核心区时只增加必要距离，不再额外叠加24px。显式 `systemGap` 覆盖核心区净空时，碰撞净空取其一半。检查所有先前谱行，避免高图形跨过中间谱行后碰撞；显式段间距额外保留，页首不叠加。显式 `uniformSystemHeight` 保留整行等高包络。jpFun底层通用调用未启用 `systemSpacing` 时保留原有 `@page(gap=…)` 语义；简谱适配器统一启用核心区与装饰分开的间距规则。网页统一入口将谱内页边距设为0.5em（当前11px），谱集直接复用这一入口；A4外侧统一留12mm。所有距离随整谱等比缩放，不设置谱集独立行距。当前谱集构建见[SCOREBOOK.md](SCOREBOOK.md)。

自动换行按候选行的空余／压缩空间平方和选择分配。两种分配代价相同时，优先让前面的行容纳更多小节；jpFun与自研版采用相同的归一化浮点容差，避免累计测量坐标的舍入误差改变断行。真实宽度导致的代价差异仍按较低代价处理，不为这一偏好改变最小净空、段落边界或歌词占位。

谱头`{equal-measures=true}`启用行内小节等宽，省略或显式`false`时关闭。领域层解析为布尔配置，经适配器传入jpFun横向求解：每行划分相同宽度的小节单元，先保留完整行的歌词、括号和并行声部约束，再在各单元内用原生弹簧求解音符。小节线锚点等距，音乐附件在此之后计算，最终SVG不再移位。自研版同样先建立整行实测约束，再固定可见小节线边界，分别求解等宽单元内的音符；小节线前的弹簧不参与单元内部的余量分配。末尾小节线按完整实绘宽度留在版心内，共享反复边界、双声部、歌词与器乐括号的预留不在每个单元重新计算。自动换行按候选行的最密小节乘以小节数计算容量，单个过密小节继续使用原生分拍规则；显式换行、播放、反复及事件身份不变。数字字号不变。当前内置谱仅每日基本功启用等宽小节。

未设置成对间距时，等宽模式在完整小节线字形两侧各预留线高的0.55倍（22px音符时约15.13px），单线及反复线均参与。设置最小／自然成对间距时，安全净空已计入音符与小节线的物理宽度，不再叠加这份额外预留，避免小节线两侧留白远大于音符分组间隔。渲染选项 `wrap: "compact"` 在自然小节宽度下允许自动换行容纳更多小节，由原生弹簧求解器重新分配音符间距，歌词、变音及关系仍参与布局；不压缩字形。等宽模式仍只对稀疏小节收紧容量：每小节不超过4个有时值节点、各节点至少一拍，且无宽歌词约束；等宽快速音型和宽歌词保留正常容量。默认 `wrap: "normal"`；未显式指定间距时统一使用下述最小／自然间距策略。此选项调整换行容量，不承诺固定的最小净空；紧凑导出需检查实际字形、歌词重叠与裁切。该选项是渲染选项，不是新增M3N语法。

渲染选项 `noteGapEm` 设置有时值音符之间的基础自然间距，单位为正文数字字号的倍数，必须为非负有限数值。`0.3` 在22px正文中对应四分音符的6.6px基础间距（每侧3.3px），短音符和长音符按时值平方根缩放，同一符杠组内的相邻弹簧乘0.5，组间不收紧；默认省略时与 `minimumNoteGapEm: 0.3` 配对使用自然间距 `0.5`。此参数在自然测量和最终求解中同时生效，保留歌词及装饰约束，不缩小字形或改变演奏时值；它不是固定的最终字形净空，歌词、装饰、整行撑满及行宽约束会改变实际间隔。局部装饰内部排列保持原样。

配对使用 `minimumNoteGapEm: 0.3` 和 `noteGapEm: 0.5` 时，引擎分别测量最小／自然两套布局。前者决定候选行能否容纳小节，后者用于比较候选的疏密；不再以自然宽度乘固定比例排除候选。最小预留纳入最终求解占位，自然值与最小值之差作为可压缩余量。两档都同比缩放音符、休止、增时线、小节线和其他零时值控制对象的原生横向弹簧，保留时值平方根与连梁比例；有时值对象的间距在上述缩放后保留 `minimumNoteGapFloorEm: 0.1` 的下限（22px字号下2.2px，每侧1.1px），不额外叠加到已有间距上；自然弹簧同样不会低于这一底线。显式只传自然间距仍保留旧的单参数模式；显式最小间距低于0.1em时默认下限随其收小，也可显式覆盖下限，下限必须非负且不大于最小基础间距。不改变字形、歌词尺寸或竖向间距。歌词／装饰继续按实际占位参与约束，谱行仍撑满；整曲采用全局行间平衡，不采用单行贪心塞满。自研引擎在强制换行、乐段边界处结束横向间距链，各段独立测量最小／自然宽度，不把另一行的内部间距留在新行两端；乐段名位于前反复线之前，二者按最终绘制顺序参与测量。两值必须为非负有限值且最小值不大于自然值；只有自然值时兼容原单参数行为。配对模式下普通与紧凑换行共用实际最小宽度判定，不再使用旧容量比例。

`uniformSystemHeight: true` 启用段内分档等行高。共享范围来自 `ScoreDocument.paragraphs` 的原谱乐句区间（`===`、`---` 分段），由领域解析器提供，适配器不回读源码。自动换行、`{br}` 与分页不改变所属段落；同一谱行包含多个段落时，取这些段落预留的并集。引擎通过原生 `@spacing({音乐},group="段落标识")` 分组，在每段内按各轨道的音符、八度点、奏法和关系记号分别统一音乐基础预留，其他段的高八度或装饰不再撑高本段。没有乐句信息的文档保持整曲共享的兼容行为。

每段保留普通/房子两档：只有房子实际经过的谱行（含跨行中间行）使用较高上沿。歌词不参与音乐最大值，按各行实际可见行数从音乐下沿另加空间。乐段名采用行内 `@text(...,frame=true)`，方框原生预留内边距、不消费歌词槽、不改变时值；`===名称{br}` 将方框标题作为 `@text(...,frame=true,above=首音,local=true,linestart=true)` 附件置于练习说明之上，后面的音乐换行且标题与首音共同分页；练习说明采用 `@text(...,above=目标,local=true)`，只在所在行避让并预留实际高度，不计入本段最低音乐行高；和弦名称仍参与音乐预留。跨页沿用本段档位，两版均不将整页空白额外分摊到行间，页头独立排版。jpFun的分页铺满分支与换页铺满参数已删除，自动换页、显式换页和末页统一保留自然行距。

房子线标签使用正文数字字体、字号为正文的0.6倍，钩线长度来自标签实测墨迹高度，标签在钩线内按墨迹居中。线条、钩线和标签共用绘制几何测量，包含描边与文字外伸；仅实际首段绘制标签与左钩，仅实际末段绘制右钩，中间续段只预留横线本身。小节拆行与分页保留房子区间身份。起止端使用实际小节线锚点；续段从音乐主体左沿起笔，不读取歌词宽度。相邻房子线共享高度，各自范围内的音符、控制与关系附件决定所需净空。小节号与反复次数附着于实际后小节线并沿其锚点居中，次数在下、小节号在上，房子线在两者测量后放置；共用反复边界和小节拆行不重复编号，仅行末实际小节线显示编号。

房子下折钩的墨迹下沿默认距小节线上沿2px；顶部横线、标签文字和两端钩线分别按实际横向范围与音符、控制、装饰及关系墨迹检查2px净空，仅在碰撞时整体上移。房子内部空白不作为障碍，相邻房子仍共享高度。房子线的基础上沿读取音乐主体的实绘包络；前置拍号、调号和速度等控制单独按实际横向范围参与避让。范围外控制保留自身谱行高度，但不会通过音符组合盒抬高房子线。范围内的控制、外侧装饰和已放置关系仍参与净空计算。

自研小节线的可见性在绘制、谱行包络、声部打包和关系避让中共用：仅在含有该声部音符的片段绘制边界，替代旋律不绘制小节线，拆分小节的中间片段不凭空补线。行高从实际可见边界图元测量，不为未绘制的小节线预留高度；显式等行高仍按所属组的实际最大包络统一。

局部标题与本行音乐预留的内部间隔为标题字号的0.4倍（普通非局部文字仍为0.5倍）；与上一行的距离由 `systemGap` 另行保障。

该模式保留事件身份、时值和原生关系几何，不移动最终 SVG 图元。SVG 谱行以 `data-m3n-paragraph` 和 `data-m3n-volta` 标记段落及房子分类，开发检查可读取这些属性。核对节距时需考虑相邻两行的段落、房子档位、实际歌词行数及局部标题。当前网页和谱集默认按自然高度排版。

第六十版谱集读取 `scorebook/editorial-plan.json` 的三篇编排和曲目顺序，直接调用网页 `renderScoreInto`；只遍历640～800px、步长10px的版宽，同篇内相邻短曲可按共同宽度合页，以全谱集页数最少、曲目宽度之和最小为选择顺序，整页等比缩放进A4。长曲沿用原生分页；不拆曲合页，不改变内部图元。逐曲间距、固定页数、等行高特例和回流已删除。基本功的等宽小节来自谱源 `{equal-measures=true}`。PDF生成成功后，最佳宽度写回谱源的 `{preferred-width=…}`；网页默认读取该字段，缺省720。详细规则见[谱集构建说明](SCOREBOOK.md)。

`npm run build:scorebook` 只构建简谱，已删除配对构建器和五线谱配置。



谱集保留网页统一入口显示的署名与低音，不再修改临时文档或设置逐曲隐藏选项。

适配器在每个`g.system`输出`data-m3n-top`、`data-m3n-bottom`，边界包含引擎记录的本行音乐对象及关系区域。房子线等关系保留全局坐标和原来的绘制层；谱集分页取原生边界与实际图形边界的并集，避免只按最近距离把下一行房子线留在上一页。此元数据不改变音乐图元或交互身份。

谱行撑满时，新增空间按同符杠组内0.5、组间1的权重分配，不按时值再次缩放；同一间隙存在多个声部时取最大权重，缺席声部占位使用默认权重1。刚性组合内部不参与拉伸，压缩求解规则保持不变。谱行统一撑满版心，包括显式换行前的短行和最后一行。适配器通过 `@page(fillRatio=0)` 启用引擎原生的行宽分配，长音练习等自然宽度较短的行也与其他行右端对齐。

同一声部内连续的同类关系记号按谱行对齐：三连音等连音组的括线、相邻房子线分别取组内能避让全部内容的共同高度；相邻自动连音线统一弧高。同一谱行上的弧线两端取较高音符（含高八度点）的高度，绘成水平对称的弧带；同时检查中间音符，若弧带下沿会碰到高音点或数字，则只整体上移所需的距离。跨行弧线各段也检查本行中间音符。普通音符间隔会断开对齐组，跨行、跨声部与嵌套层级分别处理；不同种类的记号不共用高度，显式指定的弧高保持原值。适配器启用 `compileScore({alignRelations:true})`，引擎默认仍保留局部高度布局。

自研延音线和连奏线同样按乐句的时间相接关系建立自动弧高组：共享端点，或后一弧线紧接前一末音结束时进入同组；普通音符、休止及替代旋律中未演奏的间隔断开分组。嵌套的内外层独立，旋律、低音、替代声部及不同乐段所属声部不混合。分组在自动换行前建立，每个谱行只取本行完整弧线的最大自然弧高，保留各自音符端点及实测避让；跨行的开放段不被其他谱行的长弧额外抬高。对齐不修改源谱和演奏时间轴。 两版弧线端点连接主音数字、八度点与奏法的实测上沿，不取整个倚音或升降号组合的最高点。侧边的倚音、升降号仍按各自绘制图元的实测包络参与局部避让；只有弧带与其相交才上移，嵌套弧线排入外层后再次检查。

自研引擎以字号作为设计尺度，正文、装饰音、歌词、说明、标题等字号由同一音乐字号按比例派生；线宽、点径、钩长、内边距及必要净空也使用相对值。字号比例只定义图形样式，不作为字形的实际占用高度。文字取实际字体的上伸部、下伸部、宽度和斜体伸出；图形取最终绘制图元及笔画的包络，贝塞尔曲线求真实极值。布局与 SVG 共用这些图元和最终放置结果。关系线、奏法、外侧装饰、房子线、歌词及辅助标签分别按实际重叠区域避让，不再按装饰个数或嵌套层数累加固定高度。与 jpFun 存在差异时，以实际净空、自然行距和正确分页为准。

歌词下划线从实际文字下沿向下留出歌词字号0.1倍净空，再放置笔画，避免穿过字母下伸部；行高包含更新后的线条包络。小节线和反复线也参与局部文字避让，额外反复次数置于其实际上沿之外，无关位置的高音不抬高该标签。

八度区间`{8va}`／`{8vb}`与音符自身八度累加后，只以最终八度点显示；自研版不再叠加要求重复移调的8va／8vb虚线。旋律、低音、和音及替代旋律共用这一规则，范围语义和播放保持。

浏览器的两份实现均使用 Canvas 的真实字形升部、降部与左右外伸定位文字，不将字号直接当作实际高度或按字号估算基线。jpFun的多行文字保持指定的基线间距，完整占位取所有行的墨迹并集；居中按实际墨迹中心修正。其减时线从正文实际下沿向外保留音乐字号的0.12倍净空，下八度点同样避让实际下伸部，不再向字体盒内部缩进。数字墨迹中心与音乐锚点及八度点对齐，列宽仍统一使用数字0的度量。自研八度点、附点和单音／连梁减时线也从同一正文实测边界定位；减时线横向以数字0的实测占位宽度居中，排除变音和附点；同一层的相连音符绘制为一条完整线，并接管各音的对应局部线，孤立的更深层仍单独绘制。声部避让使用同一份完整连梁图元。离线估算测量器以`inkBottom`区分名义盒与估计墨迹下沿。没有 Canvas 的调用环境可注入 `textMeasurer`；默认离线测量器只提供估算，用于无字体环境下运行，不等同于最终字体实测。

文字测量的逻辑宽度与墨迹边界分别保存：逻辑宽度以前进宽度为基准，狭字符沿用字号四分之一的最小布局宽度；墨迹保留真实左右外伸，供绘制、避让与安全检查使用，不再把墨迹宽度重复并入逻辑宽度。方框文字在前进盒和实际墨迹的并集之外留内边距，支持左、中、右对齐及多行；自研正文乐段框、独立标题框与演奏顺序框遵循相同原则。

连音线连接折叠音符或和弦时，端点取最上方的实际音符；`tr` 等零时值标记置于弧线外侧并预留空间，避免弧线连到标记上。

旋律与低音同时显示时，每个谱表系统左侧都显示连接两声部的括号，包括显式换行、自动换行和分页后的系统。适配器启用 jpFun 的 `@voices(...,repeatconnect=true)`，由引擎在每组左侧预留连接符列并绘制；隐藏低音后不显示连接符。

通用 `autoWrap` 先以自然宽度布局，再根据包含歌词的实际横向占位平衡小节。自然小节的紧凑模式对超过版心的自然宽度使用较低的压缩代价：自然宽度包含可收紧空隙，不能与不可压缩的字形占位等同；最终仍由原生求解器处理歌词和图形约束，全部谱行保持撑满。普通模式及等宽模式的压缩代价保持。具名乐段通过 `@br()` 强制换行，名称以14px粗体方框文字置于音符同行的行首；平行声部共享分行结果。段标末尾只有显式 `{br}` 才将标题与音乐分行；当前基本功的两处标题及《土耳其进行曲》各段采用此方式。开头反复线、调号、拍号和速度跟随首音，不留在标题行。密集小节需要拆行时平衡各行长度，优先在完整四分音符拍点换行，避免拆散节拍并留下很短的尾行。连音组内部不主动拆分，组首换行放在整个连音组之外。同一时刻的调号、拍号和速度只在每个声部插入一次换行，跟随后续音符。

渲染选项 `wrapWidthRatio`（0 < 值 ≤ 1，默认1）只影响自动断点，最终谱行仍按完整版心撑满。当前网页和谱集均使用默认值；旧版谱集根据页面余量进行二次回流的流程已删除。

前反复线归属后一个小节。同一系统内，它替代同一边界上没有导航记号或反复次数标注的普通线、双小节线。自动或显式换行将边界分开时，上一行保留结束小节线，下一行保留前反复线；合并的双向反复号也拆为上一行的后反复号和下一行的前反复号。自动插入的记号不改变音乐时值、播放顺序或原始事件源码范围。字形、歌词、连线、装饰和分页由引擎处理，适配器不再对最终横坐标做压缩补偿。

同一乐句出现共享遍次标记时，全部歌词行都显示各自的遍次，例如 `1.`、`2.4.`、`3.`。相邻乐句的歌词行与遍次对应关系保持一致时，连续段落中每行只标一次，`---`、换行和分页不重复标记；对应关系变化、无歌词乐句、新乐段或新反复开始时重新标记。标记由引擎独立排在各行首个可见歌词的左侧并预留空间，歌词正文仍与音符居中对齐；跳过的空槽不提前消耗标记，整句为空时顺延到后续乐句的首个可见歌词。

歌词高度按每个谱行、每条轨道的实际可见歌词行计算。适配器启用引擎的 `@voice(...,compactlyrics=true)`，整行为空的歌词段不再预留行高，例如《国际歌》后半段共用一行歌词时收起第二、三行的空白；同一谱行的不同房子段可分别收起不存在的歌词行：例如左侧第一房子只有第一段、右侧第二三房子只有第二三段时，两处均从第一条可见歌词基线开始。显式零宽占位保留对应行距。空槽继续保留原始歌词段号与播放遍次，视觉收起不改变反复播放时的对应关系。两版的歌词视觉层均按正文、遍次前缀、行名及下划线的实际包络定位共同基线，首行净空为音乐字号0.32倍，后续行间净空为0.24倍；仅完全不可见的占位层使用字母M作为字体行的估算，不用M决定可见歌词的位置。自研版按每个音符位置实际存在的歌词槽计算视觉层级，基线保存在各自音符上，绘制、替代声部避让和分页使用同一结果；同一视觉层的高度按歌词、遍次前缀及下划线的实绘包络计算。不存在的歌词行可收起，已分配但内容为空的槽位和显式零宽字符保留对齐位置。

替代旋律的遍次文字排在音符前，与音乐数字的实测视觉轴对齐，独立预留零时值列；主旋律和替代旋律的同拍音符保持同列，不让文字吸收主旋律首音。单一第二遍替代旋律省略遍次，多条替代声部或其他遍次显示；同一替代片段跨小节时只在开头标一次，不额外增加上方说明行。页头多行标题仍共享居中列，该规则限于页头的零时值内容。

器乐标记 `{inst}…{/}` 使用 jpFun 的 `@paren(from,to)` 在音符两侧绘制普通圆括号；跨行、跨页时每个含该区间音符的谱行片段各显示一对。括号使用数字字体和字号，与所在声部的数字行对齐，不随八度点、减时线、和音或装饰拉伸。两端按括号字形的实际宽度预留横向空间，并保留紧凑间隔。嵌套及相邻器乐区间合并，单音符、休止符、和音、连音组和长音都保留；没有 `{inst}` 的纯器乐谱不自动加括号。括号不改变事件身份、时值、歌词对位或播放顺序。

自研引擎的多小节休止 `{rest=N}` 绘制为带端帽的粗横梁，上方使用正文字号显示数量，不绘制普通“0”。横梁最小长度为音乐字号的3倍，较宽数量按实际字体宽度扩展；笔画、端帽和数量共同参与占位与行高测量。休止时长不拉长横向弹簧，与相邻小节线组成紧凑块，整行剩余宽度分配给其他自由间隔；并行声部仍参与物理净空约束。小节编号按休止数量推进。

多小节休止独立保存起点的调号、拍号与速度；紧接其前的设置在休止开始处生效，两版在休止符前绘制相应记号，后续音符不重复打印。休止时长按该起点拍号计算，自研播放在同一拍点更新速度与节拍时间轴；并行低音继承旋律同拍点的设置，反复展开保留休止快照。不添加虚假音符事件或改变原有事件身份。

Segno 从小节级导航信息读取，固定排在该小节开头，与音符行的视觉轴对齐，并随首个音符或休止符换行、分页；谱中变调、变拍、变速、连音组及多小节休止均保留该目标符号。兼容事件级导航信息时，同一小节只显示一次 Segno。

两版 Segno、D.S.、D.C. 使用项目内的填充矢量轮廓，按真实曲线极值归一化，完整墨迹高度分别为导航字号的1.15、0.9、0.9倍；横向占位由同一轮廓的宽高比决定。自研保存独立SVG资产，不以系统字体或近似描边代替。Fine继续使用实测文字；各导航记号均以实际墨迹中心对齐音乐视觉轴。

Fine、D.C.、D.S. 排在末音或休止符之后、小节线之前，与音符行的视觉轴对齐。引擎通过小节线的 `before` 内容预留完整横向占位，导航记号跟随末尾小节线换行、分页，不额外抬高房子线；原生反复和跳转语义仍由记号保留。反复次数继续显示在小节线上方，房子线仍避让音符、高低八度点、连奏线和上方标注。 自研导航文字以音乐数字的实测视觉轴为中心，用实际升部／降部定位基线；预留宽度覆盖左右外伸及前进宽度，测量与绘制共用同一片段，不按字号比例估算基线。

谱集只在具名乐段结尾补双小节线，普通乐句换行不自动添加；原有反复、导航和终止语义保留。行内段名的具名乐段之间额外留白12px；独立标题行按装饰参与12px局部碰撞避让，不额外增加段间距，标题到下方音乐仍保留5.6px。行内段名通过原生 `@br(gap=12)` 参与排版与分页；页首不保留额外间距，普通乐句换行不受影响。乐段名默认是行首方框文字，采用700粗体、14px字号，与音符共用视觉轴；原生文字对象包含3.5px内边距和1px框线，与首音同属谱行及分页边界，可点击定位首音。位置文字（如练习说明）、和弦名称仍位于音乐上方，采用14px常规字重，通过 `@text(...,above=标签)` 在连音括线、连奏线及渐强渐弱等关系排好后按层避让。奏法符号继续贴近音符。

无框说明文字和和弦名称以首字符的逻辑中心对准宿主音符，保留和弦根音的锚点；按前进占位与实际墨迹的并集约束页边界、查询邻近障碍并为后续标注预留范围，负侧承和右侧外伸不能被忽略。独立乐段标题框继续靠谱行左侧排列。行内文字的逻辑前进宽度保持独立；每行绘制包络使用该行的实际前进量、对齐锚点与墨迹边界，不用前进盒代替可见字形。

音符自身的八度点保持完整；其外侧由近到远依次排奏法符号（跳音、保持音、顿音、重音）、装饰与指法、力度与渐强渐弱等说明文字。简谱中的 `{tip}` 跳音统一显示为 7px 实心楔形，与高音八度圆点区分；`{str}` 重音仍显示为 `>`。力度或说明文字不会插在跳音与八度点之间；后置标记的书写顺序不改变这几类标记的内外层次。此显示约定不改变 M3N 奏法语义或播放。

两版颤音 `tr` 与上波音 `prall` 使用一致的项目填充矢量字形；自研独立保存完整轮廓资产，不使用系统文字、近似折线或参考排版代码。曲线实际极值决定横向中心和占位，颤音墨迹高度为音乐字号的12/22倍，上波音为同一高度的0.55倍。显示、导出、装饰避让和分页共用同一实绘轮廓，随音乐字号同比缩放。

自研八级力度`ppp/pp/p/mp/mf/f/ff/fff`使用项目内独立保存的m、f、p填充轮廓与字距组合，不使用系统斜体文字，也不运行jpFun代码。以全部曲线实际极值归一化并居中，f系墨迹高度为音乐字号的12/22倍，p系按同一字形设计保留0.79341的高度比例；横向宽度、避让、行高和分页读取最终实绘轮廓。`sfz`沿用两版共有的13/22音乐字号常规实测文字。指法、贴音奏法及装饰层级保持。

自研拍号的上下数字分别按实测升部、降部定位，两者到分数线的净空均为拍号字号的0.08倍。分数线、小节线、增时线和多小节休止横梁共用音乐数字0的实测视觉轴（相对字母基线为实际高度的一半减去实际升部）；D.S.／D.C.／Fine、调号和遍次文字同样使用这一轴。谱行预留直接读取实际绘制小节线的包络，测量与绘制不再独立使用0.3倍字号估算。拍号几何缓存随控制项进入布局和绘制；数字按实际墨迹中心对齐分数线。

两版速度记号采用项目的填充矢量轮廓，音符底部对齐速度文字基线，文字的实测墨迹中心对齐音乐轴；不使用椭圆加描边符干估算高度，也不追加固定基线补偿。自研版缓存同一份速度几何供测量与绘制使用，谱头、谱中变化和多小节休止起点保留拍单位分母。全音符、二分音符使用透明空心符头，八分至六十四分音符保留相应符尾层数；jpFun的占位包含超出符头基线的完整符尾。显示速度仍按分母换算，速度倍率不修改源数据或以QPM保存的演奏时间轴。

三连音等连音组先排音符、八度点与贴音奏法，再排数字及括线；颤音、指法等外层装饰和 `p/mp/mf/f` 等力度、速度表情位于括线外侧。力度作用于组首，但不作为组首音符盒的一部分把括线抬到自身上方。jpFun 投影在关系记号之后注册带宿主标签的符号／文字附件，自研布局同样先固定括线再放外层标记；符号按实测范围避让。相邻音符的装饰与表情横向交叠时，仍先装饰、后表情，不由事件先后顺序颠倒内外层级。该规则不将跳音、保持音、重音等贴音奏法移到括线外侧，不改变演奏时值或力度。 两版连音组数字统一使用谱面数字字体并按实测墨迹居中；数字、横线、端钩分别以实际绘制包络（含描边）检查净空，保留音乐字号的0.14倍间隔。侧边变音记号只在与某个括线图元横向相交时抬高括线，不再以整组最高外伸统一抬升。相邻连音组在各自净空计算后取共同高度；嵌套括线和内容框仍按内外层避让，预留范围包含完整文字外伸与描边。

这套外层顺序同样适用于普通单音、和音和倚音宿主。两版按外层标记或说明文字的完整横向占位查询实际相交的音乐图元；连线按该范围内的曲线最高点避让，不用整条连线的最高点，也不在音符与贴音奏法之间预留连线的名义高度。贴音奏法的实际上沿参与连线端点。只有最上层音乐成员的高八度点直接暴露时，连线端点才在其墨迹之外再留音乐字号的0.05倍净空；上方已有跳音、保持音、重音等贴音奏法时连接奏法的实测上沿，不重复叠加八度点净空。和音内部成员的八度点不影响最上层成员的端点。外层装饰、力度、倚音和侧边变音不改变这一规则。装饰、指法和力度留音乐字号的0.12倍净空，和弦名及局部说明仍使用各自的文字间隔。外层标记在页边处按完整墨迹限制位置，不改变音符的横向间距。延长记号使用项目音乐字形的双三次曲线与独立圆点，轮廓和描边随符号字号同比缩放。自研重音和换气也使用项目内独立矢量轮廓，换气不依赖系统字体；重音与延长记号的描边使用圆端点、圆连接。两版贴音重音的完整描边纳入音符折叠占位及连线端口，保留公共实测净空，不能把名义轮廓高度当作完整墨迹高度。渐强渐弱的开口、描边和净空按音乐字号计算，小节线长度只作为避让障碍，不能参与字号取值。两版上方符号附件以完整绘制墨迹预留占位和页边范围，包含缩放后的描边，不把符号内部的底部留白叠加到公共净空。jpFun 的上方符号附件保留颤音、波音、延长和力度对宿主的演奏效果；导航记号仍使用时间对象。文字附件可通过 `gap` 指定随音乐字号变化的净空，省略时沿用原文字类型的间隔。

jpFun 音符的变音记号按最终绘制路径的真实极值及完整描边计入固有墨迹边界，普通音符、和音与倚音子域共用这一占位。该边界与数字主体、肩线、视觉轴及装饰起点分开，补齐行高与分页预留时不移动八度点或减时线，也不把变音记号上沿叠加为新的数字顶部。连线端点读取数字中轴处的实绘上沿；连音组先按音乐主体及嵌套内容定位，再逐一用括线、端钩和数字的横向范围避让侧边墨迹，不把整组变音外框作为统一抬高量。项目启用关系对齐时，跨行连线的中间延续段也按音乐主体的实测连接位置定位，小节线和侧边变音只在真正与连线交叠时参与避让；无音乐内容的空行保留原轨道回退规则。

跨行连线的左侧延续段从该声部首个音乐排版单元的分配边缘开始；字体侧边留白不使续线额外缩进，右侧开口仍延伸到谱行边界。这里的边缘属于续线对齐规则，实际墨迹继续独立参与碰撞检查。谱中控制列位于首音之前时，延续段也从首个音乐单元开始，不强行贯穿左侧控制列。

并行声部同拍出现的调号、拍号及速度按种类共享各自的零时值列，避免把同一全局设置重复计算两次横向空间；不同种类保持独立，不与有时值的音符合列。同一声部连续书写的多个设置仍按原顺序各占一列，不折叠或删除事件。

有前倚音时，奏法先附在主音上，再由引擎 `@grace` 包裹。倚音按主音数字的肩线定位在左上侧；顿音与无倚音的同音高主音保持相同相对高度，不因横向分离的倚音额外抬高。装饰、指法与力度等外层标注在关系线排好后按实际相交的倚音／主音图元避让；横向分离的高倚音不额外抬高无交叠的标记或说明。高八度点、和音、原始事件分组及播放保留。

两版的多音倚音组均保留随音乐字号和书面时值变化的自然净空；组内相邻减时线连成一束，采用与正文连梁一致的0.5倍间距系数，整组保持刚性，不因外部版宽变化压成零间隙。jpFun 的宿主组合及其他局部组合继续使用各自原有规则。

上方复合符号对外保留完整占位，同时分别发布实际绘制图元供局部避让查询。房子横线、端钩及遍次文字只避让与自身横向相交的符号图元；例如力度 mf 的右侧高笔画不作为左侧端钩的障碍，仍保留2px实绘净空。

自研倚音字号为音乐字号的0.7倍，沿用正文数字字体；指法和其他装饰字号保持各自设置。括号层数保留为每个倚音的书面时值，相邻倚音连接共同拥有的减时线层级，混合层数不丢失。倚音数字、变音、八度点、减时线和末端小钩共用测量与绘制结果，不再按每音固定14px占位；局部间距按书面时值和字号计算，整块保持刚性，不随外部整行撑满拉伸。块底部相对主音数字的实测肩线定位，连接减时线在组内实际数字的最深下沿外保留净空，八度点从数字或减时线的实际边缘向外排列；文字和外层装饰避让完整图元包络。短、长倚音的原有演奏规则不受此显示实现影响。两版倚音减时线均使用倚音字号的0.055倍线宽，末钩使用0.07倍线宽，圆端／圆接头随字号缩放，不设固定像素下限。两版均取数字主体／变音记号逻辑宽度与实绘包络的并集，变音记号内部的设计边距不因实际笔画向内收窄而被删除；实际笔画仍独立用于碰撞检查。自然间距的刚性子域同时预留逻辑音符盒和实际字形外伸、圆端半线宽；子域内部边框也读取相同实绘边界，避免求解净空和边框内边距重复计入。

和音的琶音标记与倚音可组合使用：先在和音左侧绘制琶音，再将倚音放在更外侧，奏法与装饰仍属于主和音。jpFun琶音包装向交互层转发和音标签，保留事件ID及播放定位。自研琶音以实际音符、变音、八度点、减时线与附点的实绘边界定位，波浪线的完整描边纳入横向占位；高度贴合和音上下沿，不因固定波形片段的重复而越过端点。后续延音线不重复绘制或预留琶音宽度。

主标题与副标题分别按自身文字宽度居中，对准页面内容区中线，不受彼此长度和两侧署名、调号、拍号、拍速宽度影响。演唱者以“XXX 演唱”作为居中副标题行，已有副标题保留在其前。右侧仅按“AAA 作词”“BBB 作曲”和曲调来源逐行右对齐，各行独立测量；缺失内容不占行，同名作词作曲分别保留。编曲信息继续保存在源数据中，不显示在页眉。署名、调号、拍号和拍速置于主标题区下方；副标题及演唱者行不再独占垂直空间，与左右信息按各行实绘范围判断是否能并排，横向保留16px净空，发生碰撞时才将对应侧栏下移，并保留5px纵向净空。主副标题保持独立居中，多行副标题和各署名行逐行检查，不因某一行较宽而浪费其他行的可用空间。页眉总高度取居中内容及两侧最终实绘底边的最大值，演奏顺序和正文从该底边继续排列；拍速后显示旋律音域，直接用“最低音~最高音”表示，不加文字标签，数字、变音记号与八度点沿用简谱字形。音域按实际音高统计旋律（含和音、连音组、倚音与替代旋律），不计伴奏低音或休止符；纯休止时省略。首调以开头调性表示，固定调以实际音高的 C 调数字表示并随移调更新。调号、拍号、拍速、音域各项之间固定留 16px 间隔。音域数字与分隔符分别按自身字体实测音乐轴对齐；数字保留完整主体占位，分隔符按字体前进宽度推进，内部间隔沿用零时值控制列的自然间距。八度点、升降号分别计入谱头避让。谱头各项横向排列与碰撞预测共用前进盒和实绘墨迹的并集，字形外伸同样占据项间净空与页边界。左右信息按各自实测完整宽度判断是否能并排，并预留16px净空；能放下时从同一顶部排列，作者行数不再将左侧调拍速下推。按各行实测占位同时检查横向和纵向碰撞，左侧仅下移至最近的无碰撞位置，碰撞处保留5px净空；后续的长署名不影响与其不相交的左侧信息。各署名和来源行的宽度互不影响。不使用600px等固定版宽门槛。预览与导出共用该布局。

拍速记号统一使用拍号分母对应的音符，不使用附点；数值按 `qpm × 分母 ÷ 4` 换算，谱中变速也遵循此规则。例如《我和我的祖国》的 `6/8`、`80qpm` 显示八分音符 = 160，实际播放仍为 80 qpm。简谱与播放共用这一换算规则。

浏览器加载字体后使用 `CanvasTextMeasurer`，离线测试可注入 `textMeasurer`。音符、调号、拍号及拍速数字（包括谱中变速）统一使用原样嵌入的 Barlow Semi Condensed Medium（SIL OFL 1.1），字形比原先的 Liberation Mono 更窄高、笔画更清晰。同一资源用于测量、显示和 SVG 导出，无 CDN 字体请求；固定来源、文件校验和及许可见 `public/licenses/barlow`。CSS 家族别名保持 `M3N Numbers`，静态 Medium 字体映射为引擎使用的普通字重，避免合成加粗。阅读时中文及普通文字使用系统 serif 字体，因此不同系统的文字度量可能不同；下载时文字统一转为本站 Noto Serif CJK SC 字形轮廓。

## 导出与验证

阅读、打印预览与最终导出调用相同接口、当前版宽、速度倍率、移调、固定调、小节号与分页选项。打印面板只提供横排SVG、PNG、PDF三个下载按钮，无独立宽度或低音开关；SVG和PNG将当前分页结果纵向拼接，并在完整谱面四边各加原谱最大宽度5%的白色外框；PDF按当前分页输出，使用12mm纸张边距，不叠加图片外框。两种谱式均提供 SVG 矢量图、PNG 连续图和 A4 多页矢量 PDF。导出时数字沿用内嵌字体，中文使用本站按需加载的 Noto Serif CJK SC，文字转成路径，不依赖接收设备字体；文字不可选择或搜索。轮廓坐标先对齐到 0.001px，避免 opentype.js 2 将接近整数的小数舍入为 NaN、造成字形笔画缺失；导出遇到无效坐标会明确失败。PDF 经 svg2pdf.js 写入矢量路径，不嵌入 Canvas 图片。字体许可与重建方法见 `public/licenses/noto-serif/`。

`npm run build:scorebook` 生成共用字体子集的矢量PDF，直接使用 `outputPdf` 文件名；`npm run compact:scorebook` 可从最近一次构建保存的 `unoutlined-pages.json` 单独重建PDF。命令校验版次、渲染器摘要和全部谱源摘要，拒绝过期布局。导出解析SVG的可寻址字符，处理空白、tspan、UTF-16索引和旋转，将每个字形固定到原来的基线位置；常规字形由Chromium嵌入并共用字体子集，粗体使用0.015倍字号描边。使用网页导出的Noto Serif CJK SC和Barlow字体资源，不重新排谱或转为图片。

第六十版A4简谱PDF共102页，5,566,771字节。实际核验纸张为A4、全部字体包含Unicode映射且无栅格图片；导出逐字检查基线误差不超过0.001px。体积、字体子集、页数和PDF摘要保存在本地 `scorebook/PDF体积记录.json`，不再提供独立轮廓PDF构建分支。

局部替代旋律通过 ScoreDocument.alternatives 关联主小节，简谱适配器投影为原生 `@ossia` 并行音轨。替代音轨有独立歌词、与主谱相同的字号、括号；普通第二遍省略遍次提示，其他分支在行首标注遍次；无替代内容的谱行不保留空轨。替代行按其横向范围内实际可见的主谱和歌词下沿定位，不再被同一谱行其他小节的第二行歌词推远；连线及邻近文字仍参与避让。MEI 仅为播放展开，主谱与源码映射保持紧凑。语法见[手册 §5.4](MANUAL.md#54-替代旋律)。

自研横向约束按每个声部自身的相邻音符计算连梁间距；其他声部插入更细时值或控制列时，不中断该声部的连梁缩距，同声部控制与小节边界仍按原规则处理。缺席声部的弹性占位只读取音乐本体及最小间隔预留，不复制其他声部的歌词或括号扩宽；实际声部保留这些附件的完整实测占位。

两版括号按音乐轴及各自字体墨迹居中，包围音乐本体而非歌词；歌词扩宽不能移动括号。jpFun 的括号占位包含实际左右外伸。自研向说明文字、和弦及外层奏法提供左右括号各自的实绘区域，中间空白不形成障碍；实际相交的括号仍保留净空。三连音的数字与线保留完整节奏组及表情层级，弧线继续查询相交范围内的曲线高度。

房子线在隐式延音线、显式连线、渐强渐弱及外层装饰／力度排好后测量，完整包围这些音乐层级；和弦名、局部说明及独立段名随后放置。jpFun 适配器统一延后登记房子线，不让源码中后写的显式连线绕过其避让。

自研引擎中，替代声部每个小节的括号也参与横向约束：以实际括号宽度加音乐字号0.05倍净空预留两端位置，自动换行或超宽小节拆分后各片段重新预留。括号通过共享关系图元测量和绘制，实际包络参与谱行高度及局部避让，不使用独立的固定横向偏移。

两版自然布局按最终绘制图元的局部包络放置替代声部，逐对比较横向重叠部分，并留音乐字号0.32倍净空；不把互不相交的上下极值组合成额外障碍。jpFun 的净空使用解析时音乐字号，不受同一谱行高小节线或其他文字字号影响。远处的第二行歌词和括号中间的空白不再形成整行障碍；空歌词槽不占避让空间。文字、框线、音符、连梁、控制、关系线、小节线及辅助标签均参与测量，谱行总包络在声部放置后用于分页。完整低音声部及显式等行高模式仍按完整声部包络加声部间隙排布。

标题保留32px字号，按当前版宽与实际字体测量自动折行。居中文字在排版阶段测量 SVG 字形边界并修正中心偏差；不移动最终 SVG，不放宽0.5px检查容差。

两版谱头共用同一折行策略，显式换行会重置本行可用宽度，自动换行优先保留合适的词或括号边界。一个标题／副标题块内部按自身字号的1.25倍推进基线，完整占位取各行实测升降部的并集；不同文本块之间留5个设计像素的净空。原副标题与“XXX 演唱”是两个独立块，不能把块间净空当作多行文本的行距累加。


第四十八版谱集分页先保证页面容量和最少页数，随后优先保留能在一页容纳的完整反复、乐句和延音，同等条件让前页容纳尽可能多的谱行；取消各页剩余空白的均衡评分。相邻短曲合页同样优先填满前页。超出一页容量的长反复或长乐句允许续页，几何安全检查与至少三行续页要求仍生效。

## 自研排版候选的验收状态

默认显示和导出继续使用 jpFun。`native-score.ts` 及相关模块仅用于开发对照，未从公共入口导出。几何边界和事件映射通过不代表视觉一致；必须逐曲核对行距、音符间距、换行、分页、歌词和关系线后才能替换。运行 `node tools/compare-numbered-engines.mjs --all-widths --screenshots --require-parity` 生成差异报告并在不一致时失败；报告按运行时间独立保存在 `.tmp/numbered-parity/<运行标识>/index.html`。显式传入 `--baseline-ref=<commit>` 可选择已核实的jpFun实现版本，省略时对照当前工作区的两份实现及相同谱源快照，并记录实现和谱源哈希；显式指定历史提交仅用于诊断，历史报告仍保留。`--self-check --pixels` 对基准自身做逐通道零差异自检，自检失败返回非零。像素截图逐一放在同一视口原点采集，随后恢复左右并排供人工查看，避免并排位移本身引入曲线光栅差异。

页眉左右侧按实际占用宽度加侧间距判断是否能并排，不使用固定600px断点：放得下时顶部对齐，署名行数不会单独把左侧调号／拍号／速度下推；各行在横纵两向真实相交时，仅将左侧信息下移至无碰撞的位置；不再用整个多行署名的联合外框强制整块堆叠。各署名和来源行独立右对齐。jpFun与自研版均采用该规则。真实字体下89首曲目、320／599／600／800／1000px共445个页眉的两版检查均无左右碰撞。

前反复线与前一小节的普通／双小节线在同行共用边界；自动换行时恢复前一行原有线型，不将双小节线降为单线。适配器通过`@bar(3,preceding=1)`保留双线来源，不改变反复播放。相关宽度回归使用当前《超级玛丽》顺读谱源，具名乐段另用独立样例验证。

两版双声部连谱符号均由独立的粗括线和细连接线组成，粗括线上下使用项目自研的收尖曲线钩。端点使用主旋律主音本体顶部和低音主音本体底部的实测包络，包含八度点及减时线，不延伸到歌词、倚音或外层表情；几何全部按音乐字号比例生成，并留在已预留的一个音乐字号宽度内，不设固定像素的粗线下限。每条可见双声部谱行单独绘制，自动换行、分页继续显示，隐藏低音时不绘制。jpFun通用多声部的部分连接、重叠连接及曲线大括号继续保留，均使用对应声部的实测端点；无音乐内容的声部才回退到声部轴。

谱中调号、拍号、拍速等独立的零时值控制列会断开减时线，两侧仍各自按拍组连梁；共享控制列同时断开旋律和低音的对应连梁。控制列之前的首音带有谱头设置时，不影响其后同拍音符继续连梁。

自研谱中调号、拍号、拍速、段标、遍次和Segno缓存最终绘制的各个图元，用于连线、连音组和外层附件避让。控制列的完整包络仍参与行高和横向占位，但拍号分子旁等空白区域不成为障碍；连线仅在真实弧带与图元相交时抬升，连音组按其线条及数字的实际横向范围保留净空。嵌套关系移动后的再次避让也使用同一图元集合。
