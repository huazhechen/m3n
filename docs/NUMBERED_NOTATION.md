# 简谱渲染设计

> 更新日期：2026-08-15  
> 实现：`packages/score-renderer/src/numbered-layout.ts`、`numbered-score.ts`

## 依据与边界

任务指定的 `Encaik/simple-notation` 在本次工作环境中因 DNS 不可用而无法取得；没有将其未审计的实现或推测写入本项目。设计依据是本地已有的 `jianpu-abc` 源码（`/tmp/jianpu-abc-src`）以及本仓库的 [VEROVIO.md](VEROVIO.md)。

从 `jianpu-abc` 吸收的是设计方法，而不是其代码：布局必须发生在 SVG 绘制之前；时值以节拍比例决定横向空间；只在小节边界换系统；歌词先参与宽度和行高计算，再绘制。Verovio 继续负责 MEI 到 MIDI、时间映射和播放控制。简谱不重新解析 M3N，也不构建第二份音乐语义模型。

| 需求 | 本地 `jianpu-abc` 的核心做法 | M3N 的独立实现 |
| --- | --- | --- |
| 优雅横向布局 | `measureLayoutMetric` 先根据节拍槽、音符字号、拍间隙和小节线计算自然宽度 | 每个事件预留数字、和弦、时值和文字的最大最小宽度，再累计为小节自然宽度 |
| 换行与对齐 | 先按自然宽度分系统，完整行按目标宽度伸缩，显式断行优先 | 只在小节边界贪心断行，尊重 M3N 的 `breakBefore` / `breakAfter`，非尾行两端对齐 |
| 碰撞避让 | 临时记号、附点、短时值底线和歌词都进入 slot/line-height 计算；底线按拍分组保留边界净空 | 歌词、标记和音符符号先决定事件盒宽；短时值线完全绘制在事件盒内，下一事件不能侵入该盒 |
| 歌词对齐 | 歌词文字以事件中心为锚，含歌词行采用更高的 line height | 直接以 `ScoreLyricBlock` 的目标源码范围绑定 `ScoreEvent`，歌词宽度加入该事件约束并提高系统高度 |
| 交互 | 渲染事件保留稳定 ID，播放和源码导航不重新匹配图形 | 复用 M3N/MEI 的 `m3n-e-N`，Verovio 的时间映射直接定位 SVG 元素 |

## 数据流

```text
M3N -> analyzeM3N -> ScoreDocument
                       |                 \
                       v                  -> MEI -> Verovio -> MIDI/time map
             NumberedScore
                       |
             numbered-layout -> SVG pages
```

`ScoreDocument` 是唯一的简谱输入。事件按解析顺序分配 `m3n-e-N`，与 MEI 的稳定事件 ID 对齐。因此播放高亮、源码定位和鼠标选音不需要另一张映射表。

## 布局算法

`buildNumberedLayout` 分四步工作：

1. 为每个 `ScoreEvent` 计算最小格宽。最小宽度取数字/和弦、时值比例、临时记号与八度点、歌词文本、和弦符号或力度文字中的最大值，并加上明确的相邻净空。
2. 将事件宽度累计为小节自然宽度。短时值不会被强制扩大为整拍，长时值则按拍长比例占据更多空间。
3. 仅在小节边界贪心换行，同时尊重 `breakBefore` / `breakAfter`。已装满的系统会等比例两端对齐；最后一行保留自然宽，避免把尾行压得松散或扭曲。
4. 系统高度按是否包含歌词决定，分页从系统边界切开，永不切开小节或歌词行。

这使碰撞避免成为约束输入而非绘制后的补丁：新的可见元素必须先提供自己的最小宽度或行高。当前实现用事件的歌词和标记文本参与宽度预留，数字、变音号、八度点和时值线都在这个已分配的事件盒内绘制。

## 歌词对齐

歌词块按其 `targetStart` / `targetEnd` 过滤旋律事件，依次绑定到可发音事件。延音事件默认跳过，除非歌词显式要求落在延音目标上。这与现有 M3N 歌词语义一致。每个歌词文字以对应事件的中心点为锚，宽度则提前参与事件盒计算；歌词存在的系统使用更高的基线，避免与下一系统相撞。

## Verovio 协作

简谱 SVG 由浏览器原生 DOM 创建，不调用 Verovio 排版。这样数字、下划线和歌词能遵循简谱的节拍网格。Verovio 仍被创建并保留在 `ScoreRenderer` 中，提供 MIDI、反复展开后的时间位置和 `elementsAtTime`。返回的 XML ID 查询到简谱的同名事件元素，播放和源码高亮在两种记谱之间一致。

## UI 与测试

渲染设置中的“简谱渲染”开关保存在 `m3n:numbered-notation`。关时使用原有 Verovio 五线谱；开时 `NumberedScore` 渲染 `ScoreDocument`，播放控制保持可用。

`numbered-score.test.ts` 覆盖了小节不拆行、稳定事件 ID、歌词锚点、短时值节奏线，以及歌词宽度导致的系统换行。后续增加装饰、跨系统延音或多声部时，应先为该元素增加布局约束测试，再添加绘制逻辑。
