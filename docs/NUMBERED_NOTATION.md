# M3N 简谱渲染

`@m3n/numbered-notation` 是 M3N 的原生简谱渲染包。它以 M3N 的语义模型、类型和页面布局直接生成 SVG；字形资产保留其原始 MIT 许可文本。

`NumberedNotationScore.create(document).render(options)` 的唯一音乐输入是 `ScoreDocument`。它不读取 M3N 源文本、语法树、MEI 或 Verovio SVG。应用使用同一份 `ScoreDocument` 驱动简谱视图，仍以 MEI/Verovio 提供 MIDI、播放时序与五线谱视图。

## 支持范围

适配器从 `ScoreDocument` 投影标题、右上角署名（演唱者优先、否则作曲者）、调号、拍号、速度、旋律/低音、休止、小节线、反复、跳房子、歌词、延音、连音组、力度、渐强/渐弱、文字和显式换行。`tuplet` 事件会展开为独立的顺序音符，使用简谱的连音组标记和紧凑时值布局，不会被投影为竖排和音；其 SVG 子音符仍以父事件 ID 供编辑器定位。速度使用节拍字形并按页头比例缩放。事件保留稳定的 `m3n-e-N` ID，因此点击选音、播放高亮和源码定位仍与现有交互契约一致。

M3N 的 `chord` 事件投影为一个节奏锚点及其上方竖排音高；竖排间距和低八度点号避让由适配器补充。分页不采用固定系统数，而是按实际的歌词、声部和系统高度装页。

`{lg}` 连奏区间投影为连线。相邻且中间没有音符的区间合并为一条；跨系统的单一连奏使用 continuation 线段。延音连线与显式连音组标记仍按各自的 `ScoreDocument` 语义渲染。

当前 `ScoreDocument` 没有结构化表达的功能不会由渲染器猜测或旁路读取：任意自定义 SVG、嵌套声部和没有对应字段的装饰记号均不支持。它们必须先成为 `ScoreDocument` 的正式语义，才可加入渲染。

`{ac(...)}` 与 `{ap(...)}` 后缀会映射为主音后的简谱倚音组；嵌套括号决定其时值层级，音高、临时变音和八度与主音使用同一投影规则。

## 页面行为

分页视图以 `1000 × 1415` 为基准。应用会将用户选择的乐谱宽度直接写入简谱布局；主体字体、字形、边距和行距已经按 `0.6` 预设，而标题、调号、拍号、速度和署名使用与五线谱一致的页头度量。渲染器不提供运行时缩放参数，也不以虚拟宽度重排。连续模式会按系统数扩展 SVG viewBox 高度。

## 验证

包级测试验证简谱页面、字形、字体和稳定事件 ID，并验证渲染不依赖 `ScoreDocument.source` 的内容；还覆盖低音和音避让、按歌词高度分页和自动换行的两端对齐。端到端测试覆盖简谱开关、页面渲染和事件定位。
