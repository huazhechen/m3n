# 简谱渲染设计

> 更新日期：2026-08-15  
> 实现：`packages/score-renderer/src/numbered-layout.ts`、`numbered-score.ts`

## 依据与边界

简谱的视觉和排版依据是本地克隆的 [Open Fanqie](https://github.com/Linho1219/open-fanqie)（`/tmp/open-fanqie`）。渲染器采用其 MIT 许可 SVG 字形资产（见 `OPEN_FANQIE_NOTICE.md`），但不导入其源码、解析器或运行时包。

`ScoreDocument` 是 `NumberedScore` 的唯一音乐输入。渲染器不会重新解析 M3N，也不会建立第二套音乐语义；Verovio 仍只负责 MEI、MIDI、播放时间轴与五线谱。

| Open Fanqie 的视觉规则 | M3N 的实现 |
| --- | --- |
| 默认字号为 18，普通音符步进 37.5、短时值音符步进 25、小节线间隙 35 | `numbered-layout.ts` 用相同的比例建立节拍列，在响应式宽度下等比缩放 |
| 歌词在排版前占用后继音符和小节线之前的空间 | CJK 按一格、ASCII 按半格计算；超宽歌词沿用 `250 / 9 - 25` 的溢出规则 |
| 每个系统以小节为原子，并与可打印右边界对齐 | 系统只在小节边界断行；每行的终止小节线固定在右边界 |
| 短时值下划线按同一拍内连续音符成组 | `numbered-beam` 按节拍和线级连续绘制，休止不无故截断分组 |
| 页首显示调号、拍号、速度、标题和署名 | 简谱专用 header 从 `ScoreDocument` 直接绘制 `1=调`、纵向拍号和图形四分音符速度记号 |
| 反复、跳房子和导航记号属于乐谱结构 | 前/后反复线、次数、跳房子框、Segno、Fine、D.S.、D.C. 都由 `ScoreMeasure` 的结构字段绘制 |

## 数据流

```text
M3N -> analyzeM3N -> ScoreDocument -> NumberedScore -> SVG pages
                                  \-> MEI -> Verovio -> MIDI/time map
```

事件按 `ScoreDocument` 的解析顺序保留 `m3n-e-N` ID。播放高亮、源码定位和鼠标选音因此能继续复用已有的 MEI/Verovio 映射。

## 排版约束

1. 小节先被分析为节拍列，再得到自然宽度；绘制阶段不改变事件顺序或节拍归属。
2. 前反复线会先占用一个完整的小节线列，避免与第一个音符或反复点重叠。
3. 每行缩放到同一可打印宽度，最后小节线严格定位在右侧内容边缘。
4. 变音号、附点、八度点、短时值线、长时值延长号、歌词和小节线都在布局或字形阶段预留净空。
5. 八度低音点会根据下划线级数继续下移，高音点则向上逐个叠放；不会落入数字或节奏线。
6. 跳房子框和导航文字会占用系统上方留白，歌词行则独立地占用数字下方留白。

分页页纸外框已经由应用层统一提供 10 mm 留白。简谱 SVG 只保留很小的内部 gutter，因此与五线谱预览拥有相同的有效内容宽度。

## 验证

`numbered-score.test.ts` 覆盖稳定事件 ID、歌词行、歌词溢出、连续下划线、附点、前/后反复、跳房子、速度/调号/拍号 header，以及 Fine、D.C.、D.S.。任何新的装饰或结构记号都必须先增加布局或 SVG 输出测试，再加入绘制逻辑。
