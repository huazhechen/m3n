# M3N 简谱渲染

链路为 `M3N → ScoreDocument → @m3n/numbered-notation → SVG`。公共入口 `NumberedNotationScore` 使用自研实现，音乐输入只读取领域文档。

## 调用与模块

```ts
import { NumberedNotationScore, prepareNumberedNotationFonts } from '@m3n/numbered-notation'

await prepareNumberedNotationFonts()
const score = NumberedNotationScore.create(document)
const pages = score.render({ width: 720, paged: false })
```

`native-model.ts` 建立领域投影；`native-horizontal.ts` 测量横向间距；`native-layout.ts` 组织谱行、纵向布局与分页；`native-svg.ts` 绘制SVG；`lyrics.ts` 负责歌词槽位与遍次。应用统一通过 `src/lib/render-score.ts` 调用，屏幕和导出消费相同排版结果。

`scoreEventIds(document)` 提供渲染、源码定位与演奏共用的事件身份。DOM `id` 唯一，`data-m3n-id` 可在拆分片段中重复；连音组子音符与增时线保留原事件关联。改变版宽或分页不会重建播放器。

## 显示选项

- `width`、`paged`、`pageMargin`：版宽、分页和谱内边距。统一应用入口默认谱内边距为0，留白由A4纸张或外部画布提供。
- `includeBass`：是否显示低音；不重编号其他事件。
- `fixedDo`：按实际音高显示固定C调简谱，保留 `1=C`；不改变演奏音高。
- `transpose`：半音偏移，更新调号；固定调模式同时重写数字及八度点。页面把相同偏移传给播放器，原文档不变。
- `tempoScale`：显示速度倍率，与页面演奏倍率同步。
- `measureNumbers`：仅在每行主旋律末尾小节线上方显示书写小节号；多小节休止按实际小节数累计。小节号按实测文字右边缘对齐行尾小节线。小节号与反复次数按实测文字墨迹检查画布边界，越界时向内移动，避免小边距裁切。
- `coreGap`：显式指定核心净空参数，供共同宽度合页等场景使用；省略时采用上述连续／分页策略。`systemGap` 显式设置仍保持固定行距配置。
- `uniformSystemHeight`：按领域乐句范围统一音乐高度，歌词另按实际行数占位；网页默认使用自然行高。
- `noteGapEm`、`minimumNoteGapEm`：自然及最小音符间距，按音乐字号计。

完整类型以公共入口导出的选项为准。阅读偏好、移调按钮、速度与播放操作见[架构](ARCHITECTURE.md)。

## 字体、墨迹与避让

音乐字号是设计尺度，装饰、歌词、标题字号及线宽、点径、钩长、内边距按比例派生。文字使用真实字体的上伸、下伸及左右外伸，图形使用最终绘制图元及描边包络，贝塞尔曲线求实际极值。逻辑推进宽度与墨迹范围分别保存。

布局与SVG共用绘制几何。渐强／渐弱线跨行续接从该行音乐分配边缘开始，不额外向左外伸；左右边界包含半个描边宽度，零谱内边距时笔画也完整留在画布内。避让查询只考虑横向重叠的真实笔画；房子、器乐括号、发夹等内部空白不成为实心障碍。浏览器先准备内嵌数字字体；无Canvas环境可注入 `textMeasurer`，默认离线估算不等同于字体实测。

三连音等节奏括线优先贴近音符，外层表情再避让。跨行延音线或连奏线若在续行首音结束，断行和水平排版为弯曲段补足必要的行首前间距（正常转弯长度0.54em）；该空间计入可用版宽，不增加统一页边距，也不影响没有此类续接的行。关系层按区间与嵌套关系放置；延音线、连奏线、渐变线、外侧奏法、房子线、歌词和标题分别参与最终谱行包络。房子标签与钩线按实测墨迹定位，跨行续段保留区间身份，不重复首段标签。

## 音符与关系

单音、和音、低音、休止、倚音、连音组、八度点和减时线都直接从领域事件生成。减时线按拍组连接；复拍子按三个分母单位分组。和音按所有音高的完整墨迹占位。变音记号的小节内显示状态独立于实际演奏音高。

同音延音的完整拍可显示增时线；切分、短拍及跨小节连接保留弧线。增时线保留独立点击与播放身份，不额外消费歌词。显式关闭后重新开始的连奏区间分开，嵌套关系从内到外排布。八度区间与音符本身八度累加，只显示最终八度点。

## 谱头、歌词与分行

标题、演唱副标题、左侧调拍速与右侧作词／作曲／来源按实际占位共享垂直空间；只有发生横向碰撞才另起高度。副标题不强制独占一行。演奏顺序读取领域访问顺序。

歌词的文本、下划线、占位及强制延音目标从领域语义派生；反复遍次使用 `data-m3n-rendition` 和 `data-m3n-passes`。歌词字号为16px（音符字号22px时）；音符主体最低边界到第一排歌词顶部的净空为6px，相邻两排歌词实际墨迹之间的净空为4px，随谱面等比缩放。歌词下划线避开文字下伸部，歌词行数与实际墨迹共同决定谱行高度。

横向分配保留刚性组合和最小净空，剩余宽度在允许的间隙分配；同符杠组内与组间采用不同伸缩权重。同小节内相邻音符组之间固定预留最小净空0.4em（22px字号时8.8px），不按时值缩放；组内仍按时值平方根及0.5系数收紧，组间自然间距及撑满权重保持原规则。音符到小节线的规则不变。等宽小节来自谱源 `{equal-measures=true}`。段首冗余普通小节线不产生空谱行。

连续与分页布局共用谱行测量和碰撞几何。连续模式核心净空固定24px；分页先按16px核心净空和8px装饰碰撞净空确定分页，再保持分页不变，为每页（包括末页）寻找16～32px内能容纳的最大核心净空参数。每处间距取核心要求与碰撞要求的最大值，不直接给所有行间累加距离；装饰碰撞净空始终取核心参数的一半（分页8～16px，连续12px），碰撞主导的间距随此净空共同调整，必要时实际间距可超过32px。到32px后仍有空白则留在页底。标题与署名块间距、额外段间距不参与拉伸。谱行元数据包含实际音乐与附件边界，供页面与导出容器使用。谱集规则另见[谱集](SCOREBOOK.md)。

## 检查

自研测试覆盖事件身份、测量、间距、行高、分页、关系、歌词及显示变换。`tools/verify-native-ink.mjs` 检查最终SVG的裁切和碰撞；`tools/verify-format-rendering.mjs` 检查格式化前后SVG相同；实际应用交互由Playwright验证。

多曲合页由公共入口 `renderSharedNumberedNotationScores` 共用已测量谱行：以16px核心参数检查共同版宽下的总高度，固定曲间留白，再为整页各曲共同求16～32px的参数。仅调整纵向坐标，不重复横向排版，不分别缩小曲目。
