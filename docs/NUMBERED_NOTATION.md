# M3N 简谱渲染

当前纵向规则见[共享纵向间距求解](VERTICAL_SPACING.md)：两种谱式独立配置0.8em下限，舒适区由下限的1.5～2倍推导；已删除谱源行距指令。行内几何固定；三档分别选断行，再搜索保持页数的最大统一行距，最后统一评分。
链路为 `M3N → ScoreDocument → @m3n/numbered-notation → SVG`。公共入口 `NumberedNotationScore` 使用自研实现，音乐输入只读取领域文档。

## 调用与模块

```ts
import { NumberedNotationScore, prepareNumberedNotationFonts } from '@m3n/numbered-notation'

await prepareNumberedNotationFonts(document)
const score = NumberedNotationScore.create(document)
const pages = score.render({ width: 720, paged: false })
```

`native-model.ts` 建立领域投影；`native-horizontal.ts` 测量横向间距；`native-layout.ts` 组织谱行、纵向布局与分页；`native-svg.ts` 绘制SVG；`lyrics.ts` 负责歌词槽位与遍次。应用统一通过 `src/lib/render-score.ts` 调用，屏幕和导出消费相同排版结果。

`scoreEventIds(document)` 提供渲染、源码定位与演奏共用的事件身份。DOM `id` 唯一，`data-m3n-id` 可在拆分片段中重复；连音组子音符与增时线保留原事件关联。改变版宽或分页不会重建播放器。

阅读页先完成最优宽度搜索，再按选中宽度首次绘制。简谱固定宽度内以紧8px、松16px两档最小净空求全曲横向代价最小的分行，不允许压缩；随后分页。跨宽度先取页数最少者，再取“逐间隔拥挤／过疏代价＋行间均匀度＋字体缩小代价”最低者，同分取较窄宽度。生产选宽不生成独立验收SVG，内部几何避让始终保留；独立越界和碰撞扫描以 `--audit-layout` 启用。实际测量与显示使用相同谱内页边距；设计度量模式至少保留2px绘制余量。简谱和五线谱共用选宽与评分算法。公式和搜索范围见[宽度搜索](WIDTH_SEARCH.md)。

小节入口的调号按实际演奏连接判断，包括跳房子、反复、D.S.／D.C.、Coda跳转与具名乐段顺序。只要任一实际前序小节的结束调性不同，就在入口显示调号；所有前序均已处于该调时省略，不以谱面上相邻的上一房子为依据。此规则也用于五线谱的调号显示。具名乐段按访问次数换调时，紧凑首调谱以第一遍调性比较段内连接，仅在段入口和真正的内部转调处显示分遍调号；后续升调访问不会使每个小节重复标调。实际播放仍按各遍的真实调性执行。

To Coda 在跳转小节末显示，Coda 起点使用Bravura圆十字轮廓和Barlow文字，测量、占位、绘制及碰撞检测使用相同图形；不依赖系统音乐字体。Coda 可用 `{br}` 独立起行。首调简谱保留紧凑导航，固定调或换调五线谱展开时沿用实际路线和歌词遍次。

## 显示选项

- `width`、`paged`、`pageMargin`：版宽、分页和谱内边距。统一应用入口默认谱内边距为0，留白由A4纸张或外部画布提供。
- `includeBass`：是否显示低音；不重编号其他事件。
- `fixedDo`：按实际音高显示固定C调简谱，保留 `1=C`；不改变演奏音高。
- `transpose`：半音偏移，更新调号；固定调模式同时重写数字及八度点。页面把相同偏移传给播放器，原文档不变。
- `tempoScale`：显示速度倍率，与页面演奏倍率同步。
- `measureNumbers`：仅在每行主旋律末尾小节线上方显示书写小节号；多小节休止按实际小节数累计。小节号按实测文字右边缘对齐行末小节线实际墨迹的最右侧，与小节线上方保留2px间距；配从文字墨迹向上、下、左各扩展2px、右侧不扩展的白底，置于顶层，不参与行间碰撞避让，但编号及白底的完整墨迹参与页面上下边界和容量检查。反复次数仍按实测文字墨迹检查画布边界，越界时向内移动。
- `coreGap`：指定谱行核心区之间的最小净空，供共同宽度合页等场景使用；省略时采用下述连续／分页策略。实际间距还需满足装饰碰撞净空。
- `minimumNoteGap`：显式设置时只排指定最小净空，单位为谱面设计px；省略时分别对紧8px、松16px求最优断行，再先比较完整分页的页数，同页数比较全谱逐间隔拥挤、过疏与不均匀代价。没有自然间距或压缩。`minimumNoteGapFloor` 为短音单侧净空下限的双侧合计，默认0，不超过基础净空。

完整类型以公共入口导出的选项为准。阅读偏好、移调按钮、速度与播放操作见[架构](ARCHITECTURE.md)。

## 字体、墨迹与避让

升降号、力度、奏法、装饰音、导航记号、圆点、琶音及声部括号钩头统一使用Bravura的SMuFL字符，按同一字体实际墨迹测量、缩放与避让；网页使用WOFF2，PNG与PDF使用轮廓一致的TTF。固定字形及保留布局几何的完整清点见[音乐符号绘制清单](MUSIC_SYMBOL_RENDERING.md)。

独立字号和版面间距采用谱面设计px，集中配置于 `packages/numbered-notation/src/score-layout-config.ts`；主音符字号为24px，标题、歌词保留独立字号；简谱核心上下间距配置为主音符的1.2em，声部间距和谱头留白等外层净空由它乘系数推导。音符附属字号、附点、延音横线、弧线及笔画尺寸在测量和绘制代码中按核心字号乘em比例计算，不各自提供配置项。整张谱在展示和导出时等比缩放。文字使用真实字体的上伸、下伸及左右外伸，图形使用最终绘制图元及描边包络，贝塞尔曲线求实际极值。逻辑推进宽度与墨迹范围分别保存。

布局与SVG共用绘制几何。减时线计入圆头端点的实际横向占宽，三连音括线端点为半个描边宽度预留行边界，零谱内边距时左右笔画均保持完整。渐强／渐弱线跨行续接从该行音乐分配边缘开始，不额外向左外伸；左右边界包含半个描边宽度，零谱内边距时笔画也完整留在画布内。避让查询只考虑横向重叠的真实笔画；房子、器乐括号、发夹等内部空白不成为实心障碍。浏览器先准备当前乐谱使用的Barlow Semi Condensed、Bravura和思源黑体子集；无Canvas环境可注入 `textMeasurer`，默认离线估算不等同于字体实测。

简谱数字直接使用原字体族名 `Barlow Semi Condensed`，与西文共用 Medium（500）字面；浏览器仅注册一次该字体，独立SVG也以原名字体族和相同字重内嵌原始字体。

简谱按作用范围由内向外组织记号：数字、变音记号、八度点、附点与减时线组成音符本体；跳音、保持音、重音、颤音、波音、指法、单音延长及换气记号贴近所属音符，完整参与局部墨迹、横向占位和弧线端点测量；三连音等节奏括线、同音延音线与圆滑线从这些单音记号外侧避让，渐强／渐弱线再位于圆滑线外侧。力度（包括单音起始的p、f、sfz）及渐变、速度文字仍作为外层表情放置，不按书写位置误归为单音附属记号。这是本项目的简谱刻谱策略，不直接套用五线谱的记号层级。当前延长记号仅支持有音高的普通音符或和音组，不扩展为休止、小节线或全局停顿记号。

跨行延音线或连奏线若在续行首音结束，断行和水平排版为弯曲段补足必要的行首前间距（正常转弯长度为主音符字号的0.54倍，即24px字号时12.96px）；该空间计入可用版宽，不增加统一页边距，也不影响没有此类续接的行。关系层先放置贴近音符的同音延音线，再按区间跨度由内向外放置节奏括线与圆滑线，最后放置渐强／渐弱线。三连音内部的延音线或短圆滑线位于括线内侧，覆盖整组的长圆滑线位于括线外侧，分别按连音组数字、横线和竖钩的实际占位避让，不把整组包围盒的空白作为障碍；从组内连向组外的延音线仍优先贴近所属音符。渐强／渐弱线统一处于圆滑线外侧，不受指令书写顺序或跨度长短影响；延音线、连奏线、渐变线、外侧奏法、房子线、歌词和标题分别参与最终谱行包络。房子标签与钩线按实测墨迹定位，左右端点为半个描边宽度预留画布边界，避免零谱内边距的行首钩线及跨行续段被裁切；跨行续段保留区间身份，不重复首段标签。

## 音符与关系

连音组数字与括线保持整体形状，分别按数字、横线和竖钩覆盖范围内的实际墨迹确定最低安全位置，保留主字号0.14倍的最小净空；两侧八度点不额外为中间数字预留高度。同一小节、同一谱行、同一声部内连续相邻的连音组保持同高，小节边界、普通音符、换行或声部边界中断对齐组。

单音、和音、低音、休止、倚音、连音组、八度点和减时线都直接从领域事件生成。减时线按拍组连接；复拍子按三个分母单位分组。和音按所有音高的完整墨迹占位。变音记号的小节内显示状态独立于实际演奏音高。多个倚音组成刚性块，组内相邻音符按完整实际墨迹（包含变音记号、八度点和减时线端点）紧贴排列，不保留额外净空；间距不随倚音时值、主音符间距或谱行拉伸变化，倚音组与主音的间距另行保留。

常规连音组仅显示分子，非常规组显示完整比例（如5:3）。同音延音线使用更平、更薄的弧形，与圆滑线分开对齐，不继承相邻圆滑线的弧高；跨行各段也保留收尖曲线，不绘制水平带。同音延音的完整拍可显示增时线；切分、短拍及跨小节连接保留弧线。增时线保留独立点击与播放身份，不额外消费歌词。显式关闭后重新开始的连奏区间分开，嵌套关系从内到外排布。每条圆滑线按自身横向跨度计算弓高，不再按相邻乐句分组或统一弓高。同音延音线和圆滑线均对小节线实际笔画保留主字号1/12的最小净空（24px字号时2px），不随核心行距变化；避让通过整体上移完成，测量和绘制共用最终曲线。八度区间与音符本身八度累加，只显示最终八度点。

`{tip}` 表示跳音／断奏（staccato），`{brk}` 表示特短断奏（staccatissimo）。为避免与八度点混淆，简谱跳音保留Bravura小字号倒三角（`articStaccatissimoAboveSmall`），特短断奏使用独立的楔形字形（`articStaccatissimoAbove`），使谱面直接区分两种奏法；五线谱分别绘制圆点与楔形记号。琶音独立使用和音组的 `{arp}`，不使用 `{brk}`。 跳音按自身横向范围内的实际墨迹定位：通常贴近数字及上方八度点，不因左侧升降号较高而整体抬升；仅在升降号墨迹横向重叠时避让。升降号仍计入音符完整墨迹和谱行包络。

## 谱头、歌词与分行

主标题字号32px、换行基线距36px，副标题字号16px、换行基线距18px。标题到左侧调拍速信息默认留17.28px；有副标题时，标题到副标题留8.64px。副标题块、署名行及换行音域之间保留5.76px净空。副标题、左侧调拍速与右侧作词／作曲／来源按实际占位共享垂直空间；副标题与左右信息发生横向碰撞而错开时，墨迹净距为8.64px。副标题不强制独占一行。谱头与首谱行、演奏顺序上方及各顺序行之间的基础净空为23.04px，采用固定雕版基准，不参与分页行距拉伸。演奏顺序读取领域访问顺序；顺序标签之间及续行的箭头使用思源黑体U+2192字符，明确加入单曲字体子集；屏幕使用同源WOFF2，PNG轮廓化、PDF嵌入实际字体，避免替代字体的字符映射差异。

独立成行的段名框以所在声部整行音符及歌词的实际顶部为基准，保留6px净空；只有段名框实际覆盖的装饰图形会增加避让，小节线只需保留2px碰撞净空，不把段名与首音之间的空白当作占位。行内段名仍与音乐轴对齐，框外右边缘到下一个可见符号的左边缘固定保留12px净距，随整张谱等比缩放；该间隔计入最小占宽及断行，不参与整行余量分配，框内留白保持原有规则。

歌词的文本、下划线、占位及强制延音目标从领域语义派生；反复遍次使用 `data-m3n-rendition` 和 `data-m3n-passes`。歌词字号为16px；音符主体最低边界到第一排歌词顶部的净空为6px，相邻两排歌词实际墨迹之间的净空为4px，随整张谱等比缩放。旋律与低音声部的完整包络之间预留20px净空。歌词下划线避开文字下伸部，歌词行数与实际墨迹共同决定谱行高度。

空词槽保留在语义模型和带遍次信息的 `lyric-fragment` 分组中，不输出空的文字或下划线；即使整行该遍都没有可见歌词，分组也不随换行消失，以免播放高亮错误回退到其他遍。末尾空词槽不新增空白歌词层，也不产生文字墨迹占位。

默认对8／12／16px三档最小净空分别生成断行；前两档以2/3为普通行占比软目标，最宽档以1/2为目标。低于目标增加断行代价，不淘汰候选；末行、段落末行及强制换行豁免。各档固定断行后在保持基准页数的条件下寻找最大统一行距，再先比页数、后比横纵实际间距及字号总代价，同分取较松档。连续和分页选择相同断行，`coreGap` 只覆盖最终纵排。横向舒适区为12～24px，逐间隔平均包含零代价样本，均匀度保留行节奏间距平均与最差相对偏差。见[共享间距规则](VERTICAL_SPACING.md)。

每次试排只测量最小占宽，再分配正的剩余宽度：最终间距＝最小间距＋剩余宽度×本间隔权重／总权重。没有独立的自然间距，也不压缩最小净空；换行以最小占宽判断候选是否可容纳，单个不可拆分对象仍超宽时保留其最小间距。

最小净空按时值平方根计算；同符杠及延音组内部乘0.5。同小节内相邻独立音符组之间固定预留 `minimumNoteGap` 的净空（默认8px），不按时值缩放。小节线及 Segno、Coda 入口记号音乐时值仍为0，仅左右最小净空与无音高四分音符一致；8px基础净空时每侧4px，再加相邻音符的净空和符号本身的墨迹宽度。Segno 紧接小节线时，两者之间只保留上述最小净空，不参与整行拉伸，避免疏松谱行将返回记号推离小节线。歌词与音乐预留取最大值，避免重复累加。器乐区间圆括号与相邻音符之间同样按四分音符的最小净空预留，两侧各贡献半个基础净空，合计为 `minimumNoteGap`（默认8px）。括号包住音符的完整实绘边界，包括减时线端点；只在整个器乐区间的起点和终点绘制并预留括号，跨行或跨页的中间位置不重复括号，也不预留括号空间；相邻器乐区间合并为一对括号。

伸展权重由节奏计算，独立于实际墨迹宽度：每个音符两侧权重为以四分音符为1拍的时值平方根，组内侧再乘0.5，相邻两侧取平均作为间隔权重；同时声部取最大值，缺席声部不补权重。小节线和零时值控制标记的基准权重为1。歌词、变音记号及器乐括号只影响最小占宽，不增加权重。多小节休止计数使用音符字号的75%，横杠粗细为0.15em、两端竖线为0.075em；横线整体最小宽度为2em（24px音符下48px），计数较长时取数字实测宽度加0.5em；不定长间奏复用此尺寸。多小节休止及其相邻小节线构成刚性组合，内部不分配余量。等宽小节来自谱源 `{equal-measures=true}`，每小节内部仍使用上述规则，小节边缘可伸展间隔的权重为1。段首冗余普通小节线不产生空谱行。

自动换行以每行疏松程度和相邻行密度差评估疏密，并在整个强制换行区间内求总分最低的组合，不逐行贪心锁定。行密度 `d＝该行最小占宽／该行可用宽度`；等宽小节按行内最宽小节的最小占宽×小节数计算，行首关系续接预留从可用宽度扣除。每行代价为 `1＋max(0,1−d)²＋100×max(0,d−1)²`；相邻两行增加密度差平方 `(d后−d前)²`，抑制疏密跳变；不惩罚密度变化方向的转折。这些系数是本项目的排版策略。动态规划状态保留最近一行，使用不含平滑项的后缀代价作下界剪枝，保证全局最优；同分时较早的行优先放更多内容。首尾不补虚拟行，显式换行及既有强制边界重新开始评分。超宽小节内部采用相同评分，保留连音组不可拆分与整拍断点偏好。末行与其他行使用相同的疏松、超宽及相邻密度差代价，不因末行较短而减免。分行评分与下述末行收尾留白独立，短末行仍可在全局总代价最低时入选。

具名乐段内部的中间谱行（包括分页页末）继续撑满。整曲及每个具名乐段的最后一行先按本段上一行的“剩余宽度／总伸展权重”试排；等宽小节模式则继承上一行小节格的宽度，并提高到当前行所需的最小格宽。试排包含当前歌词、符号、刚性组合及行首续接预留：以试排宽度除以当前可用行宽作为占宽比例：≥80%撑满，≤50%保留试排宽度；50%～80%之间，仅当撑满所需的单位伸展量不超过上一行的1.5倍时撑满，否则保留试排宽度。普通模式的单位伸展量为“目标宽度减最小占宽，再除以总节奏伸展权重”；等宽模式比较小节格宽（不含末尾小节线墨迹）。试排超宽时回退到当前行宽内重新分配，所有情况均保留最小净空。此处不等比缩放符号或最小净空。整曲末行及下一具名乐段开始前的末行采用此规则；单独的页末、显式换行和普通 `---` 乐句边界不触发收尾留白。单行曲或只有一行的乐段没有本段可继承前行，沿用撑满规则。没有可伸展间隔时不虚构伸展量，无法容纳的不可拆分对象仍保留最小占宽。当前没有针对中间行的最大伸展间距。

谱行核心的上下边界按音符实际分配的横向空间加权。每个声部以相邻音符列中心的中点划分占宽，首尾到实际音符边缘为止，不计页边距及末行右侧空白。音符主体、八度点、减时线、延音线、圆滑线和三连音数字／括线参与计算；在符号左右端点处分段，同一区间只取上下最外侧边界，避免叠加重复符号高度。弧线使用已经避让后的曲线在各分段中的真实区间极值，不把整条弧线最高点扩展到全行。上下局部高度分别乘区间宽度求和，再除以总占宽，得到平均核心边界。歌词继续保留完整实际占位；多声部各自加权后，按其实际纵向位置合成整行核心。局部突出物权重小，持续覆盖整行的符号权重大。

连续与分页共用测量后的核心和完整实绘墨迹，小节号仅参与页面边界。行间距及分页采用[共享纵向求解](VERTICAL_SPACING.md)，不再按歌词或段落类型改变行间参数；行内歌词、段名和附件的位置保持测量结果。

公开API默认改用独立小节高度缓存：以音乐中心线分别保存上、下核心和非核心高度，整行分别合并上下边界，行间取核心净空与整行包络净空的最大值，后者的附加净空为核心间距的0.3。上文逐笔画的平均核心与0.5碰撞净空策略保留为 rowEnvelope:false 的诊断模式；默认候选分页与最终渲染共用缓存高度。详见[整行高度缓存](NUMBERED_CACHED_ROW_HEIGHTS.md)。

## 检查

自研测试覆盖事件身份、测量、间距、行高、分页、关系、歌词及显示变换。共用双谱式密度门禁检查最终SVG的裁切和碰撞；`tools/verify-format-rendering.mjs` 检查格式化前后SVG相同；实际应用交互由Playwright验证。


单曲选宽先搜索1～11档，即24px的22～32倍（528～768px），再在最佳粗档位左右各24px内以6px细搜。谱集合页先在624px检查整组准入，再在528～624px间以同样的粗搜及细搜规则选择最优共同宽度，详见[当前宽度搜索规则](WIDTH_SEARCH.md)。页面手动滑条另设10～50倍（240～1200px），每步6px。多曲合页由公共入口 `renderSharedNumberedNotationScores` 共用已测量谱行：取各曲 `minimumCoreGap`（默认19.2px）的最大值作为共同下限，检查共同版宽下的总高度，以曲间最小24px留白预留容量，再为整页各曲共同求下限至其2倍的参数（默认上限38.4px）。完成谱行净空拟合后，将版心剩余高度均分给相邻曲目间距；返回的 `scoreGap` 是实际曲间距，调用方据此放置各曲，首曲从版心顶部开始、末曲到达版心底部。仅调整纵向坐标，不重复横向排版，不分别缩小曲目。

## 网页读屏

阅读页、编辑器和文档谱例在谱面前提供普通 HTML 文本读谱。外层“无障碍读谱”使用带 `aria-expanded` 和 `aria-controls` 的按钮控制文本区域，默认折叠且不占普通谱面布局；按钮保留在读屏无障碍树中，键盘聚焦时显示。展开后先提供可选折叠的“简略全谱”，按八小节一段显示数字音级、升降号、休止及和音；再按书写顺序列出各小节，每小节使用原生 `details`，`summary` 包含小节号及反复、转调等说明。用户可先扫读简略全谱定位，再左右滑动找到目标小节并展开。每个音符、休止、和弦或连音组独立放在普通 `p` 中，多声部另列声部名称，保留文本的逐行、逐字朗读能力。多小节休止同样提供文字说明。

文本从 `ScoreDocument` 生成，描述唱名、科学音高与八度、时值、休止、歌词遍次、同音延续、连音组、转调、反复、跳房子及返回标记；移调、速度和记谱方式更新时同步重新生成，仍存在的小节保持展开状态。简略全谱省略八度、节奏、歌词和表情；固定调模式采用固定调数字，其余模式采用首调数字。科学音高记法仅在全谱摘要中说明一次；逐音直接读实际音高，调性、拍号和速度按声部仅在首次出现或变化时读出。没有额外的小节选择器、跳转或继续阅读按钮，不接管读屏手势，不增加逐音 Tab 焦点或实时播报。

谱面容器整体设置 `aria-hidden="true"`，不再向读屏器暴露 SVG 音符图像，避免重复朗读及触摸时跳入谱面。点击谱面保留视觉选中、播放定位与编辑器定位源码的行为，但不再聚焦 SVG 节点。无障碍读谱按钮不占视觉布局且不使用 `display: none` 或 `aria-hidden`；按钮展开后显示文本区域，供触摸浏览与逐行／逐字朗读。键盘聚焦按钮时显示入口。

读谱说明的小节与事件 ID 对应当前显示投影：首调简谱保留书写小节，固定调与五线谱按各自引擎的换调展开规则选择实际演奏音高及相应歌词，避免精简谱面与展开文字错位。小节说明标注开头、反复起点及具名乐段开头的弱起，拍位从小节尾部所占拍开始计算；其他不完全小节注明实际拍数。例如《土耳其进行曲》开头四个十六分音符占第2拍，下一书写小节从第1拍开始。

谱面 SVG 小节与音符不设置 `tabindex`，避免鼠标点击进入已对读屏隐藏的图形。读谱位置由普通文本阅读承载。播放与编辑高亮只更新视觉样式，不设置 `aria-current` 或随音符改写 `aria-label`，避免读屏随播放反复播报“当前项目”。

读谱文字不参与 PNG、PDF 的独立导出，打印时隐藏；不声明导出 PDF 已具备无障碍标签。无需后端、语音接口或新增第三方库。自动化覆盖文本语义、小节折叠、逐音段落、隐藏谱面、设置变化与播放不抢焦点；iOS 旁白与 Android 读屏的左右滑动、逐字／逐行朗读体验仍需真机验收。

文字阅读与谱面编辑、播放独立：编辑音符保持蓝色，播放音符使用深黄色、小节使用淡黄色；同一音符同时被编辑选中与播放时，播放色优先。普通阅读页的点击不再产生编辑蓝色。播放更新谱面高亮及内部状态，阅读页按需滚动跟随当前小节；不移动 DOM 焦点、不改变文字小节的折叠状态，也不改写逐音文本或增加实时播报。

乐谱主标题中的西文使用 `Barlow Semi Condensed`，中文使用思源黑体（`Noto Sans SC`），标题与正文字重配置均为500，不额外拉伸字形。标题测量、换行、居中和SVG使用同一字体顺序；PNG轮廓及PDF嵌入按实际字体族选择字形。其他谱面文字继续使用原字体策略。

不定长间奏 `{interlude}` 复用多小节休止符号，省略上方数字，不显示文字，按实测墨迹预留刚性宽度，不占播放时长、不累加小节号，也不生成音符播放高亮。其前后的局部人声节拍各自保留。

## 核心字号与独立px配置

统一入口为 `packages/numbered-notation/src/score-layout-config.ts`：`fonts` 配置字体族、字重和字形测量基准；`numbered` 保存核心音乐字号 `music`、核心间距 `coreGapEm`、独立文字字号和版面参数，`staff` 保留五线谱自己的字形尺度与内部版面参数；`lyrics` 保存共用歌词字号等参数；歌词到音乐及歌词行间不再有独立参数，均引用各谱式的附件净空；两种谱式共用相对于音乐字号的净空比例：普通附件及歌词÷12、段名／注释÷6、和弦标记÷4；简谱24px字号下为2／4／6px，随字号缩放，不随档位或行距变化。`imageExport`、`scorebook`、`rendering`、`pageWidth` 分别保留导出、谱集、离屏位置和选宽配置。标题字重为500，简谱接口和谱集合页的曲间基础留白均为24px；合页拟合后实际曲间距可大于该值。

音符附属尺寸在共用测量／绘制实现中由核心字号计算。简谱以 `numbered.music` 为1em，五线谱以 `staff.music` 为最终逻辑1em；进入五线谱引擎时除以 `staff.engine.scale`。SMuFL的一个字体em对应四个谱线间距，所以谱线、符干、符杠等使用 `staffMusicSize() / 4` 乘比例；这不是另一个独立尺寸配置。音乐字号在每次计算时读取，测量与绘制共用最终比例。

简谱的第二个核心配置是 `coreGapEm: 1.2`；`nativeCoreGap()` 计算 `music × coreGapEm`，默认24px字号下为28.8px。其他外层上下净空在使用处按这个核心间距乘系数：声部0.7、谱头到音乐0.8、标题到副标题0.3、标题到侧边信息0.6、谱头信息行0.2、谱头碰撞0.3、房子避让0.07。行间距另按0.8em下限及其1.5～2倍舒适区配置；默认整行包络的附加净空为当前谱行核心参数的0.3；逐笔画诊断模式使用0.5。歌词到音乐及歌词行间均引用音乐字号÷12的附件净空；段名／注释上方为音乐字号÷6，和弦标记为÷4；渲染选项 `coreGap` 仍为px，只控制最后的谱行排布，不重新测量内部净空。每曲的基础间距显式保存在谱行上下文中，不修改全局配置，合页和独立测量任务不会互相污染。渐强／渐弱中心线继续保持距障碍顶部0.5个音符em，默认12px。

比例优先保留一位小数；笔画、圆点及精细净空用两位，避免取整后尺寸变化过大。不将逐项比例重新集中成另一份配置表。跨行连奏线的高度增长按无单位跨度计算，保证改变核心字号时仍等比变化。

谱头音域与正文共用圆形八度点绘制函数及位置规则，直径均为其数字字号的0.15倍；音域的数字字号较小，圆点同比缩放。固定调、移调后的上下端点仍按实际音高显示相应数量的点。回归直接比较谱头与正文的圆形元素及直径／字号比例，浏览器用例检查高低音域与移调结果。

同一谱行内发生横向重叠的表情文字，按音乐先后保持层级：先出现的总体表情位于后续局部表情上方。先安置后续文字，再向外避让较早文字；每条文字仍锚定自己的音符，不改变音符间距或将局部提示提前到开头。以 `Andante, dolce`／`legatiss.` 的合成谱例纳入320／600／800／1000px、连续／分页模式的真实字体顺序回归。


## 最小间距与全曲分行

简谱从硬净空和实际占位出发，只分配正的剩余宽度，保留时值平方根权重与组内比例。8／12／16px三档分别按占比软目标及拉伸平方和选断行；目标以下增加代价，不淘汰档位。末行、段落末行与强制换行豁免软目标。固定断行后搜索保持页数的最大统一纵向行距，最后按实际间距、均匀度、纵向拥挤及字号评分。末行仍使用既有单位节奏间距继承及舒适度保护。五线谱共用同一搜索流程。详见[共享间距规则](VERTICAL_SPACING.md)。

简谱阅读器使用随谱字体的设计轮廓与字距排版，不使用浏览器栅格墨迹决定断行或选宽。准备、合成样式及导出策略见[字体设计度量](FONT_DESIGN_LAYOUT.md)。系统字体编辑预览与未准备字体的直接调用仍保留原测量回退。
