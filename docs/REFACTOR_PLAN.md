# 项目重构验收清单

本轮落实整体审视中的架构、M3N 语法、渲染与 UI 改进。以现有公共转换 API、曲库语义、源码定位与本地资源约束为兼容基线；按可验证阶段提交，不以某一阶段通过代替整体完成。

## 领域与语法

- [x] 初始设置及元数据消费语法树，注释和正文后续设置不污染初始状态；补回归。
- [x] 和弦语法由共享定义驱动解析、校验与投影；修复 maj7/maj9，支持字母和弦、斜杠和弦与 N.C.。
- [ ] 支持复拍子常用的附点拍速显示，内部保持 qpm 时间语义，规范与示例同步。
- [ ] 分析会话复用 token、语义与诊断；MEI 按需派生，避免重复校验。

## 应用架构与保存

- [x] 曲库索引构建时生成，正文按曲目异步加载；索引不在浏览器逐首分析。
- [x] 编辑分析在 Worker 中运行，合并旧请求，中文输入期间不触发排版。
- [ ] 屏幕、预览、导出共享排版入口，播放、布局与交互具有独立生命周期。
- [x] 自动草稿恢复、更新现有作品、可靠存储失败反馈、文件导入导出；明确本地作品与临时分享的保存期限。
- [ ] 包边界自动检查，README、架构图和实际构建／测试流程一致。

## 渲染与练习

- [ ] 阅读适应容器宽度，打印宽度独立保存；手机保持可读字号。
- [ ] SVG 与矢量 PDF 输出，验证中文字体和多页内容完整性。
- [ ] 选中小节播放、A–B 循环、声部静音与播放跟随。

## 编辑与页面

- [ ] 编辑器支持高亮、行号、括号匹配、补全和可定位诊断。
- [ ] 手机切换源码／预览，桌面可拖动分栏，键盘操作可用。
- [ ] 保存／预览／分享动作清楚，过期与错误状态可恢复。
- [ ] 曲库手机占满可用宽度，提供紧凑列表、最近编辑、本地及音乐属性筛选。
- [ ] 首页展示可试听、可切换谱式的示例，文档示例可进入编辑器试改。

## 完成门槛

- 每个修复先验证失败回归；新增音乐语义同时验证领域、MEI 与简谱投影。
- `npm run check` 全部通过，包括曲库几何与端到端测试。
- 桌面和手机实际浏览器检查编辑、保存、阅读、播放、导出及异常恢复。
- 同步文档并创建 Git 提交，完成前逐项检查本清单与实际实现。
