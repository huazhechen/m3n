# 保留三个八度的 C6 音列优化分析

此分析使用当前 `src/lib/harmonica-scales.ts` 的技术负担评分，不代表实测演奏难度，未修改网站提供的四种调律。

## 搜索范围

- 12 孔，每四孔重复一个八度，完整覆盖 C4–C7 的全部 37 个半音音高。
- 按键统一升高半音；每组松键吹音、吸音分别严格递增，基础音限于相对 C 的 0–11 半音。
- 枚举两行各四个基础音的组合，排除缺少半音的音列。整体交换吹吸在当前评分中等价，合并后共 1,645 种。
- 沿用现有七个五音窗口、上下行两个八度音阶，以及 40% 瓶颈、40% 窗口平均、20% 整体负担的评分。三个完整八度是音域约束，并非十二个调都能从各自主音演奏三个八度。
- 搜索用独立动态规划实现；四个重点候选和均匀抽取的 25 个组合通过项目原始评分函数复核，十二调分数全部一致。四个重点候选也逐音验证完整半音音域。

## 推荐先试：C6 的 E／F 吹吸对调

每四孔基础音：

| 音列 | 吹 | 吸 |
| --- | --- | --- |
| C6 | C E G A | D F A B |
| 候选 | C F G A | D E A B |

第 2、6、10 孔的吹吸基础音 E／F 对调，按键音仍各升半音。其余音位不变。三组分别整体升高一个八度。

| 调 | C6 | 候选 |
| --- | ---: | ---: |
| C | 52 | 41 |
| D♭ | 46 | 40 |
| D | 141 | 77 |
| E♭ | 38 | 38 |
| E | 141 | 77 |
| F | 38 | 31 |
| G♭ | 79 | 72 |
| G | 92 | 45 |
| A♭ | 45 | 45 |
| A | 142 | 76 |
| B♭ | 36 | 36 |
| B | 143 | 77 |
| 十二调平均 | 82.75 | 54.58 |
| 最难调 | 143 | 77 |

例如 G 大调中的 D–E–F♯–G–A，C6 的最初四音必须吸—吹—吸—吹；候选可奏为吸—吸—吹—吹—吹，打断连续反向吹吸。十二调中九调分数下降、三调不变。

取舍是既有 C 调吹气 C–E–G 和弦及相应肌肉记忆改变。当前模型未衡量和弦、大跳、实际乐句、音色、长句气息平衡，也未单独惩罚持续按键或按键频率，因此不能据此认定实际演奏全面优于 C6。

## 允许重排时的候选

同样保留 C4–C7 的完整半音音域，基础音后的按键音均升半音：

| 目标 | 吹 | 吸 | 十二调平均 | 最难调 |
| --- | --- | --- | ---: | ---: |
| 四个基础音位改变，十二调分数均优于 C6 | C D G A | D♭ E♭ F B | 39.00 | 46 |
| 搜索范围内最小化最难调，再最小化平均 | C D E B | E G♭ A♭ B♭ | 37.58 | 39 |

第二项的十二调分数依次为 C 35、D♭ 38、D 39、E♭ 38、E 37、F 36、G♭ 39、G 36、A♭ 38、A 39、B♭ 38、B 38。B♭ 比 C6 的 36 分略高。该最优性只适用于上述有限搜索范围和当前评分，不适用于所有口琴结构或真实演奏。

重排会改变音程在孔位上的分布与吹吸习惯；较低的顺阶音型分数不能代替实际曲目试奏。推荐先比较 E／F 对调候选与 C6，再决定是否探索整体重排。
