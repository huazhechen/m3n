# 选宽碰撞数据复用

2026-11-27，接续[全图页数预检查](WIDTH_SEARCH_PREFLIGHT_PERFORMANCE.md)。CPU采样显示，五线谱基本功仍在反复准备固定附件净空数组、排序和扫描相同谱行的图元。改动集中在共享的`layout/page-geometry.ts`、`page-collision.ts`及`ink-separation.ts`，两种谱式、精确分页和分页代价求解共用。

归一化几何创建私有的图元副本，随后明确登记为不可变碰撞输入。固定附件的上／下净空转换、含页边标签的合并数组、退化图元列表按这些数组身份复用。首次比较仍直接扫描；相同方向被再次使用时，才按原图元边缘建立精确的极值轮廓。相邻等高区间可以合并，之后两个轮廓线性归并求最大分离量。最大值仍来自实际横向相交图元的`upper.bottom-lower.top`，没有改变曲线、采样粒度、净空、评分或搜索覆盖。普通公开可变数组不登记，每次仍重新计算。

## 矩形盒子与圆滑线

现有避让输入本来就是逐图元矩形。普通符头、附点和常见符尾已是单盒，谱号与变音记号多为2～4个盒子；曲线另有窄条包围盒和精确的局部范围查询。继续将组件合并成单盒会扩大占位，可能增加行距或页数，并非没有布局影响的性能替换。

按实际横向元素边缘拆分长曲线可以作为独立试验，但每段必须包含曲线在该区间内的全部极值，不能只连接端点或固定点采样。改变现有分段也可能改变保守避让量，需要同时比较耗时、分页、选宽与实际碰撞。此提交没有实施这种模型变化。
