# 分页最小核心净空16px与24px试排

2026-11-19，基于 `00670d0` 的横向占宽加权核心规则，对97份谱源（96首乐曲及基本功）逐曲试排。各曲以720px、网页谱内边距0及实际浏览器字体测量；只把分页核心净空的下限从16px提高到24px，上限保持32px。碰撞净空跟随核心参数的一半，相应下限从8px提高到12px。不更改版宽、字号、横向分行、连续模式或谱集合页规则。

运行 `node tools/audit-page-gap.mjs`，无需服务器。产物保存在 `.tmp/page-gap-audit/report.json`，包括每曲源码摘要、前后实际核心参数及每页行数。试排复用当前排版器测得的完整谱行，通过共用分页器重新分页，16px基线逐曲与当前分页结果一致；增加页数的条目及Valsentino还与直接传 `coreGap: 24` 的渲染结果核对页数。固定24px与24～32px的分组相同：上限拟合只在最小净空确定页组后进行。

本报告为修改默认值之前的评估快照。此后分页下限已按用户指令改为24px；下表仍按原版宽比较，540～720px重新选宽的结果见[24px版宽试排](PAGE_GAP_24_WIDTH_SEARCH.md)，其中区分精确720px与邻近宽度稳定性的差异。

- 21首乐曲从1页增至2页；其余75首乐曲页数不变。
- 基本功从2页增至3页。
- 全部条目的独立乐谱页数合计101→123，增加22页；不包含曲集封面、目录或合页。
- 增页的21首乐曲中，20首第二页只有1行；卡农为2行。当前分页按顺序容纳完整谱行，没有为剩余一行重新平衡前一页。
