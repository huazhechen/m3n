# 五线谱选宽性能复用

在独立工作树的 `2a4d6c27` 谱源和评分规则上对照117首五线谱，使用一个浏览器、共享字体、全部生产剪枝和6px局部细搜。没有碰撞或越界审计；没有修改搜索范围、评分、页数优先级或动态规划精度。

| 实测 | 累计选宽 | 整批脚本 | 峰值进程RSS |
| --- | ---: | ---: | ---: |
| 修改前 | 48.280秒 | 57.033秒 | 1310MiB |
| 优化后 | 29.508秒 | 36.604秒 | 1409MiB |

累计选宽减少38.9%。加入固定音符边界及加线模板缓存之前，同一轮优化的两次实测为30.034秒与30.258秒；这些结果没有混作最终代码的重复采样。累计选宽包含各候选的真实求解；整批脚本另包含打包、启动浏览器、字体准备、检查与报告写入。不能把整批脚本称为30秒以内。当前最慢《半音阶口琴基本功》为1.592秒，10首超过600ms，尚未达到每首600ms。

117首赢家及1440个被测候选的宽度、页数、行数、字体代价、间距代价和断行代价均与修改前一致（浮点误差门限1e-8），总页数保持128页。对照报告位于 `.tmp/staff-perf-before/current.json` 和 `.tmp/staff-perf-final-bounds/current.json`。

## 复用范围

- 小节最小占宽、节奏权重、间距基底和伸展权重跨宽度复用；音符的符头边界、字形度量和加线模板也只统计一次，实际坐标保持原浮点运算次序。
- 单页横向最优直接满足页数上限，无须再次雕版贪心方案；同一断行的横向排版只计算一次。
- 当前分片图的事件索引负责判断关系端点在行前、行内或行后，不再生成行外小节的横向间距。跨分片父组保留原有最后出现位置语义。
- 选宽读取实际行的完整几何边界。逐元素墨迹列表与左侧缩进延后到输出或几何检查时生成，SVG阅读诊断仅在序列化时计算。
- 无连音线时跳过连音所需的小节线和签名扫描；关系放置和最终避让共用一次几何读取器。每小节梁组装只展开一次音符列表。
- 谱线、符干和加线用单线段数值路径，保留原路径舍入、边界、终点及SVG路径文本。

渲染器397项测试、乐谱生成物校验及独立生产构建通过；lint仅有既存的未使用参数警告。新增回归覆盖跨行关系、延后生成的墨迹和诊断、先测量再输出，以及单线段路径与通用路径的等价性。没有用缓存小节最终高度替代实际行高，也没有新增不安全的页数或评分剪枝。

复现：先执行 `python3 tools/run-low-memory.py npm run build:packages`，再串行执行 `python3 tools/run-low-memory.py node tools/benchmark-numbered-spacing.mjs --staff --prune --local-refine --output=.tmp/staff-perf-repeat/current.json`。测试使用单worker和有界Node堆，总进程RSS由1700MiB看门狗限制，工作区上限为2GB。
