# 门禁与测试去重

## 验收预算

`npm run check` 串行运行两个独立阶段：

| 入口 | 范围 | 硬预算 |
| --- | --- | ---: |
| `npm run check:non-e2e` | 包构建、全部单元及工具测试、边界、lint、生成物、应用类型检查、真实字体布局和谱集浏览器回归 | 120秒 |
| `npm run test:e2e` | 隔离生产构建及全部核心页面端到端场景 | 120秒 |
| `npm run check` | 上述两阶段，E2E复用本轮包构建与类型检查，重新生成隔离网页 | 每阶段120秒，总计240秒 |

`tools/verify-project.mjs` 记录每阶段及总耗时到 `.tmp/verification-<mode>.json`，超过预算返回非零；失败不会标为完成，启动时先写未完成状态，意外中断也不会保留上次的成功报告。完整检查分别执行两个子入口的预算检查，不能用总时长掩盖某个阶段超时。`check:ci` 保留推送门禁的生成物、检测器和真实字体密度检查。

所有重检查串行执行，单worker，Node堆512MiB，聚合内存守卫默认1700MiB停止，低于项目2GB上限。网页构建写入隔离目录，避免覆盖托管的 `/score/` 产物。单独运行其他检查也必须使用 `python3 tools/run-low-memory.py`。

## 修复的门禁契约

真实字体密度门禁曾把《玛丽有只小羔羊》的历史两行排版、《基本功》的整句同排当成硬约束。普通 `---` 是可自动换行的乐句分隔，不能固定历史分行。现在保留高度、行数上限、字号、事件数和墨迹检查；《基本功》在768px验证谱源 `{br}` 指定的小节26必须位于行末。非有限数及空布局也会失败。

## 共用基础设施

宽度候选排序和谱集赢家缓存共用 `compareWidthMeasurements`。生产搜索、评分、分页和精确几何算法保持不变；测试矩阵的收敛不改变生产候选或搜索语义。

Chromium选项集中在 `tools/lib/chromium-options.mjs`，本地与CI默认使用Playwright配套浏览器，允许显式 `CHROMIUM_PATH`，禁用单进程模式。浏览器按小批次释放原生字体缓存，每个输入使用新上下文。E2E每三个场景文件共用一轮浏览器与静态预览，11个文件分四轮，测试上下文仍独立，批次结束回收进程。浏览器fixture字体每次入口新建临时目录，只生成一次并在串行子进程间共用，结束清理，不使用上次运行缓存。谱集浏览器直接安装归档的共享曲库TTF，删除重复生成旧谱集字体的准备步骤；绘制边界与碰撞检测共用一轮浏览器。

包构建由 `tools/build-packages.mjs` 使用一个TypeScript编译宿主依次构建三个包，共用已解析的标准库；每次强制重新检查和输出全部包，不依赖先前构建或增量缓存，并在成功后复制字体资产。密度回归共用字体资源代理，将相同TTF／WOFF2作为二进制响应加载，避免在每个页面解析内联字体；脚本从约27MB缩至1.9MB。改造时完整密度报告逐项相等，字号、行数、事件数和墨迹阈值保持不变。

单测配置集中在 `tools/vitest-settings.ts`，一个线程复用环境，每文件通过 `test-file-setup.ts` 重置模块、替身、环境变量、计时器及DOM；弹窗测试恢复原型描述符。两种谱式及应用此前均通过固定种子20261128的打乱顺序验证。离线Node工具测试串行共用进程，避免逐文件重复加载TypeScript工具链；浏览器文件保持进程隔离以释放原生字体缓存。禁止依赖测试执行顺序。`tsconfig.e2e.json` 将保留的浏览器测试及Playwright配置纳入严格类型检查，避免删除场景时漏掉仍需使用的辅助函数。

全库视觉诊断需要时手动运行密度工具的 `--all`；常规门禁的代表集负责真实字体几何回归，全库投影与音乐契约负责内容完整性。

## 耗时依据

收敛前的成功基线：完整892.09秒，其中191项E2E为709.04秒。E2E用例体约631.65秒，50轮浏览器／预览启动等额外约77.39秒。六音色重复播放约106秒、控件约59秒、分页矩阵约55秒、高亮约46秒，因此仅减少浏览器启动不能达到预算。非E2E约183秒，主要是长谱重复排版、谱集重复搜索和完整字库穷遍。

本次最终实测见[发布说明](RELEASE_NOTES_2026-11-28.md)；耗时从入口开始计量，含构建及所有规定检查，不用单元测试时长代替完整成绩。

音频浏览器回归在实际小节开始后清零采样统计，排除预备拍提示音；只验收音源接通、非静音与输出峰值。六音色的具体响度、音区和衰减契约集中在真实PCM单测，避免用提示音的RMS冒充乐器响度。
