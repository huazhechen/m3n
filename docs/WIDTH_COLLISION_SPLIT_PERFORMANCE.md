# 共享分页碰撞查询简化

2026-11-27，独立工作树 `perf/single-worker-600`，基于 `55e26ed0`。沿用已冻结的117首谱源、真实归档TTF及 `a5a4c30b` 排版规则，单Worker，完整528～720px、6px网格及安全剪枝不变。

固定附件与上一行的距离原先先构造普通墨迹和边界墨迹的完整并集，再去重、排序并缓存。现在分别查询两组墨迹后取最大值，使用集合并集上的最大距离恒等式；普通行可复用已有轮廓，只为额外边界排序。共享横向扫描另对空数组、单区间和已经没有潜在交集的尾部减少堆操作。严格重叠条件、无穷区间、端点相接和零宽图元语义保持不变，没有近似曲线或减少搜索范围。

## 未保留的查询包络及符梁路径实验

共享查询包络原型把横向起止完全相同的一组矩形替换成其精确上下极值，再移除被该包络完全支配的正宽矩形。仅改碰撞查询数据，绘图不变；保留零宽与反向宽度图元，禁止横向合并不同跨度，以免改变反向宽度邻居的原有严格比较语义。新增穷举对照及共享分页共34项测试通过，117首五线谱1733组赢家／候选与基线一致。但全量38.213秒、基本功1759.8ms、聚合RSS峰值1447MiB，没有提速，已撤回。使用离线替代文字度量的结构诊断中，大量行只有约80～120个盒子，基本功一组全曲行的普通图元从3566个仅压至2864～3539个，压缩准备成本没有被抵消。该结构诊断不是字体或性能验收。原型及测试留在 `.tmp/ink-bands-prototype.ts`、`.tmp/ink-bands-prototype.test.ts`，全量报告为 `.tmp/ink-bands/staff.json`。

符梁路径原型直接记录四个顶点，省去通用命令对象和坐标数组；沿用原有0.001px逐顶点取整、先平移后取整、闭合端点及SVG文本。专门与原通用路径及独立SVG解析结果对照，两个文件17项测试通过；全量1733组赢家／候选一致。但全量38.193秒、基本功1744.9ms、聚合RSS峰值1446MiB，没有支持提速，亦已撤回。报告为 `.tmp/beam-path/staff.json`，补丁为 `.tmp/beam-path-prototype.patch`。这两个原型均不属于最终生产实现。
