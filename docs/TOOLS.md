# 练琴工具

`/tools` 通过顶部“练琴工具”入口访问，仅显示“音阶图”和“节拍器”两个入口，不显示标题、介绍或工具正文。点击分别进入按需加载的 `/tools/scales` 和 `/tools/metronome`。音阶图已开放，节拍器二级页暂显示“计划中”。

## 固定音列与图示

固定为 12 孔 C 调标准独奏音列。每四孔为一组：松键吹音 C、E、G、下一八度 C，松键吸音 D、F、A、B；按键使每个音升高半音。最低音 C4，最高按键吹音 C♯7。第四孔吹音高于吸音。此图不适用于布鲁斯、复音口琴或其他调律。

页面只提供大调选择，按钮按照五度圈 G♭、D♭、A♭、E♭、B♭、F、C、G、D、A、E、B 排列，下方显示该调总分；背景按十二调总分的最小值到最大值，归一化后从绿色经黄色渐变到红色，选中状态另用深色边框表示。没有孔数、音区和方向选择器。第六个半音调标为 G♭，与 F♯ 等音。中心为紧凑的线条口琴与孔号，正方形音块按孔位排列：上方内行吹、上方外行按键吹、下方内行吸、下方外行按键吸。

方框内为所选调的首调简谱，以该调在第 4 八度的主音为无点 1；高低八度用上下点，非调内音使用变化音级，例如 D 大调中的 C4 显示带下点的降 7。实际音名、孔位和动作放在音块提示中。

选调后所有调内音统一加粗，非调内音进一步灰显，灰色方块与其文字先绘制，连线最后绘制，置于所有音块之上。同孔竖直连线覆盖相同区间时，按相邻音对的音高分别向左右平移，低音对靠左、高音对靠右，避免重叠。窄屏按 SVG 的 790∶318 比例整体缩小，完整显示所有 12 孔和四行音块，不设置最小图宽或横向滚动，也不裁切图示。页面仅保留标题、12 孔 C 调标识、调选择与按钮总分、当前调主音和音阶图；不显示音列说明、连接说明、评分规则、颜色图例或可展开的得分明细。

## 参考评分与替代音

参考用户提供文章中 do、fa 的替代音及“单音夹段”原则，以实际音列计算，不把调号数量直接当作难度，也不硬编码必须转调的结论。最低 C4 没有低音 B3 按键吸的替代音，边界不能凭空增加不存在的吹法。

相邻两音的基础动作代价：

```
按键状态变化 × 1 + 孔号差的绝对值 × 2 + 吹吸变化 × 4
```

按键从松到按或从按到松都计 1；移两孔计 4；吹转吸或吸转吹计 4。不变化计零。

若一个音的前后均为相反吹吸，就形成“吸—吹—吸”或“吹—吸—吹”的单音夹段。增加 4 分惩罚，分摊到前后两条边各 2 分。对每条候选边，分别检查两端外侧的邻音：只有相邻两音已切换吹吸、且外侧邻音不存在同吹吸替代音时，才增加该端的 2 分；没有外侧邻音时不推断夹段。

上下行各自独立穷举每对相邻调内音的所有替代吹法，选择上下文得分最低的边；总分相同则优先减少按键，再选较低孔号。允许同音的进出边落在不同方块，不强制为一条全局指法。双向路线重合时合并绘制一条连线，不绘制箭头。连线使用圆端实线，线宽通过 `clamp(2px, .25vw, 3px)` 在手机的 2px 与宽屏的 3px 之间平滑调整，并使用 `non-scaling-stroke` 避免随 SVG 缩小而变成细线。

颜色使用固定 0–11 分色标，由绿色经黄色到红色插值，超过 11 分保持红色。普通移孔／按键的得分较低，连续反向吹吸的边因夹段惩罚进一步偏红。各调按钮总分为全音域、去重升序调内音之间的局部最优单程分数总和；是音阶连接参考分，不承诺它等于任意实际旋律的演奏难度，也不意味着在同音处断开的局部边可直接拼成一条完整演奏指法。

数据、音级、连续性评分和双向连接计算位于 `src/lib/harmonica-scales.ts`；页面不依赖乐谱渲染或音源。单元测试独立穷举全部调的每条候选连接验证最低得分，并检查标准音列、首调八度、替代音断开与夹段惩罚。
