# 共用字体设计度量

简谱与五线谱阅读器使用随应用提供的TTF设计轮廓和字距决定文字布局。浏览器的像素墨迹随渲染引擎、系统和设备缩放变化，不能作为跨终端选宽的稳定输入；实际绘制墨迹仍用于独立越界／碰撞验收。

`font-design.ts` 在字体准备阶段用fontkit解析发布的TTF字节；共享曲库FontFace安装相同字节，独立页面可使用同源WOFF2显示和TTF设计度量。按三个发布字体的覆盖范围分段，执行字距调整和连字塑形，再累加字形推进、偏移及路径曲线极值。曲线边界复用引擎的精确多项式求极值，直接消费完整路径命令，避免fontkit将二次曲线转为三次曲线后近零系数消减带来的数值偏差；不使用其保留两位小数的SVG序列化。推进宽度与设计墨迹分别保存，不以字形全行框代替笔画边界。缺字或非空白字形轮廓缺失会报错，不交给系统替代字体。缓存包含字体修订号。

`font-design-path.ts` 还修正fontkit 1.1.1对部分TrueType轮廓的解码：起点为曲线控制点时，原实现可能多插一段二次曲线；以Bravura U+E080为例，斜切后的右边界误差约3.638字体单位。现按TrueType隐含点规则从原始轮廓点重建路径，度量和PNG轮廓化共用，不改变原始TTF字节或PDF嵌入轮廓。固定回归覆盖全控制点轮廓及具有真实曲线上点的轮廓。

简谱SVG关闭系统粗斜体合成。粗体使用0.015em显式描边，斜体使用12°剪切；测量、绘制、PNG轮廓及PDF保留相同样式。设计边界与栅格边界仍可能不同：基本功实测曾出现1.128px的边缘外伸，因此统一保留2px页面绘制余量。该余量独立于字符度量，在候选测量与最终绘制中一致使用；用户指定更大的页边距仍生效。

已验证的部署字体字节与离线归档一致。FontTools与设计度量独立核对共享TTF全部3,248个有效码位（中文1,845、西文525、音乐878）的原始轮廓边界（常规及12°斜体）及推进宽度，修正后全部一致；未发现整字轮廓丢失，但确实发现并修复了上述曲线误插。对照直接读取编码轮廓，不混入FontTools高层绘图接口的侧边距平移；fontkit枚举出的cmap空洞与结束标记另验证为.notdef，不算有效码位。旧Canvas路径在Linux WebKit桌面和平板模拟中分别选744／750px，说明同一字体也可能测出不同边界；这不等于复现了用户真实设备的738／720px，也没有证明TTF丢失轮廓。设计路径在Chromium／WebKit的桌面／平板模拟中，基本功、梦幻曲、爱的礼赞全部候选评分及完整几何逐项一致，分别选720／534／558px；12例实际墨迹验收无越界或碰撞，基本功67～70小节保持2＋2。模拟验证不能代替物理iPad验收。

回归命令（按仓库内存限制串行执行）：

```sh
python3 tools/run-low-memory.py node tools/verify-font-design-outlines.mjs
python3 tools/run-low-memory.py node tools/verify-numbered-font-design.mjs
python3 tools/run-low-memory.py node tools/review-numbered-widths.mjs
```

后者记录真实阅读器宽度，再独立枚举528～768px、6px步长的全部41档；比较生产搜索、完整搜索、同页更大字体候选，并对选定替代方案执行实际墨迹审计。`--score=片段`可筛选，`--output=目录`保存报告，`--resume`校验代码／谱源摘要后续跑，`--dist=目录`可验证隔离构建。

五线谱的`textMeasurer`现复用同一`fontDesignMeasurer`，将字形推进映射为宽度、实际设计轮廓映射为左右及上下边界，不再调用Canvas参与生产选宽；五线谱音乐符号继续使用原有Bravura字形度量。系统字体编辑预览及未准备字体的直接调用仍使用原回退。SVG根节点的`data-m3n-metrics="font-design"`可确认设计路径已启用。阅读器最优宽度缓存绑定换调、速度等影响几何的设置。小节号显隐只控制绘制，始终预留相同的边界，不重新选宽，也不改变断行或分页。

导航、拍号、调号及速度控件直接测量实际绘制几何，不先测量其语义标签。Segno的内部标签`𝄋`不作为文字绘制，不能要求文字字体覆盖它；实际绘制使用Bravura SMuFL字形。《花之舞》以真实发布字体执行完整绘制回归，避免缺字检查再次误拒绝这类控件。

所有单曲及共享中文子集同时覆盖渲染器生成的固定谱头文字，包括“演奏顺序：”。字体预加载、准备和生成使用相同文字覆盖范围；没有演奏顺序时不测量这段前缀，避免独立作品因不可见文字而报缺字。

五线谱回归使用`node tools/verify-staff-font-design.mjs`，支持`--webkit-executable=路径`。它在Chromium／WebKit的桌面及平板模拟中禁止选宽过程调用Canvas文字测量，并逐项比较候选评分与完整数值几何，再单独验收实际SVG墨迹。基本功、土耳其进行曲、大谱表谱例共12例通过，分别自动选690px／3页、588px／2页、534px／1页，无碰撞或越界。修改前本地Chromium及Linux WebKit均选基本功612px／4页；修改后均选690px／3页，与用户iOS Safari报告的选宽页数一致，但没有复现旧版真实iOS测量过程，不能据此断言690与612的原始差异已完全定位。S=7.5、M=24及所有间距参数保持不变。

后续可见间隔规则统一后，最新五线谱断行与验证结果见[五线谱可见间隔统一](STAFF_BOUNDARY_SPACING.md)；上文690px／3页等数据属于切换字体设计度量时的历史结果。
