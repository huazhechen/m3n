# jpFun 彻底移除

公共显示入口切换并验收后，按用户要求删除jpFun，而非继续保留开发依赖或参考引擎。

## 删除范围

- 删除`packages/jpfun`整包，包括引擎、解析器、转换器、绘制器、上游测试及包内文档。
- 删除旧参考适配器`packages/numbered-notation/src/score.ts`、`projection.ts`、`svg.ts`及对应的旧适配器测试套件。
- 删除`@m3n/jpfun`依赖、workspace锁记录、独占依赖`@xmldom/xmldom`及根构建／类型检查／测试中的jpFun步骤。本地安装也已清理失效workspace链接。
- 删除`tools/compare-numbered-engines.mjs`。自研快照测试和实绘检查不再复制或构建旧引擎；格式化检查只运行当前公共引擎一次，不将同一自研类重复作为两版检查。
- 删除未使用的旧适配器构建产物，保留自研公共入口、布局、绘制、字体和独立演奏编译器。

## 回归保留

纯参考AST、脚本投影、录制绘制命令与跨引擎比较退出当前测试。混合测试保留自研的实测包络、附件净空、横向边界、分行、分页、歌词及事件身份断言；旧适配器的大型套件由现有`native-score.test.ts`直接覆盖当前引擎。原有源码／领域／播放测试保留。

额外将段首冗余分隔、小节编号、反复次数墨迹居中、延音事件身份、最后实音连奏端点、歌词对齐及固定调显示改成直接的自研回归，不依赖旧AST或旧SVG分组。编号测试按当前系统内实际绘制的小节线定位，不假设标签属于旧适配器的小节分组；注入测量器同时给出一致的墨迹左右沿与中心偏移。

保留`public/licenses/jpfun`中的Apache-2.0文本及来源声明，因为保留的部分音乐符号轮廓有上游来源。它不包含可执行引擎、入口、回退或兼容模式。字体与其独立许可证同样保留。历史迁移报告仍可提到jpFun，用于解释此前验证；这不代表当前存在该包。

用户正在重做的导出实现不在本次修改范围内。未启动开发服务器、覆盖正式dist或部署。
