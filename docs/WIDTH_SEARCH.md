# 当前宽度搜索规则

简谱、五线谱阅读器及本地／在线PDF单曲选宽共用 `tools/scorebook-width.mjs`。有效候选先比较页数，**最少页数一定优先**；同页数才比较横向质量，同分取较窄宽度。页底留白和最终行距均不参与单曲排名。

## 简谱

固定宽度内，紧8px和松16px只定义最小净空，不设置自然间距、不允许压缩。两档分别在全曲候选行图上求横向总代价最低的分行，再只按不均匀代价选择档位，同分取紧档。只对该赢家完成纵向放置、分页及最终行距拟合。固定宽度内不按页数挑选断行；行距不反馈进横向求解。

每行 `r=max(0,1-M/W)`，`M`是准确独立约束链的最小占宽，`W`是扣除续接弧线等行首预留后的可用宽度。动态规划断行代价为 `sum(r²)+sum((r-mean(r))²)`，全谱末行也按铺满计分；不可拆超宽对象保留溢出惩罚。最终排名只使用不均匀项 `sum((r-mean(r))²)`，加上 `max(0,(版宽/528)²-1)` 字体缩小代价及必要的溢出惩罚。总拉伸项仅用于动态规划，不参与最终档位或宽度排序。不同宽度按“页数、总代价、版宽”依次升序排名。对外的兼容质量分 `qualityScore=1/(1+totalCost)` 只用于保持旧接口的高分优先语义，实际排名等价于最小化总代价。

搜索先访问528～768px的11个24px粗档，生产模式先48px再补24px；随后补齐整个范围内未测的6px网格，不再只精搜最佳粗档周围。这样不会漏掉其他区间因断行突变而产生的更佳细档。有效的已有单页赢家允许安全剪枝：非负横向代价保证任意宽度的最高质量不超过 `(528/版宽)²`；只有上界严格低于赢家时才跳过，等分仍测量。多页赢家不能据字体界限排除其他宽度，因为后者可能节省页面。两档横向分数都严格不能胜出时可省去整个宽度的纵向雕版。

档位准备由 `NumberedLayoutTask` 管理，共用未放置投影、关系拓扑、最小跨度及谱头准备；每档横向断行状态独立，不共享放置坐标。设置或字体变化不能复用旧准备，新任务从空状态开始。生产选宽不生成独立验收SVG；审计模式完整访问所有6px档并检查笔画。策略版本为 `levels-1-11-quality-528-768-refine-6-v23`。求解算法见[间距与分行](ELASTIC_SPACING.md)。

## 五线谱

五线谱暂时保留原策略：528～768px、24px粗搜，再在最佳粗档左右24px内以6px精搜，不向外扩展。相同页数下，以字号保留比例平方除以 `1+自然密度变异系数+0.5×末行留白+4×过度伸展代价` 评分。基础间距候选9／12／15px及其自身分行、页数下界剪枝不在此次简谱改动范围内。所有间距和可能的尾页调整都须纳入其安全质量上界。

在线五线谱在单曲搜索期间只保留当前最佳的一份完整排版；单曲选宽结束后固定此项，合页补测不会替换它。最终宽度相同时直接取用并释放，不同时重建并释放旧项。不设整册缓存行数预算，仍执行总进程内存限制。测量报告单列命中、宽度不匹配、保留行数及最终排版／SVG耗时。最终SVG节点直接用于拼页，避免序列化后再次解析；PDF转换继续读取浏览器坐标。

## 谱集合页

合页先以624px（24px的26倍，第5粗档）判断准入：成员逐曲为单页，且连续高度之和加最小曲间距可装入A4版心才允许合页。通过后，在528～624px、24px粗档中按成员平均质量择优，再在粗搜最佳宽度左右各24px内以6px细搜，不越出528～624px。每个细搜宽度都须全员单页且满足整组容量；同分取较窄宽度。所有可行分组都补测邻档后再优化章节组合，任务内同曲同宽不重复测量，合页补测不改变单曲独立选宽。

剪枝模式按需补测合页候选：先测准入宽度，再枚举原有合法分组；组宽度只能在平均质量上界无法胜出、已有成员不合格或已知成员的部分高度已超容量时提前停止。补测保存在独立候选集合，不回写单曲选宽结果。`tools/verify-scorebook-search.mjs` 在两个新建浏览器中分别运行完整搜索和剪枝搜索，比较全部独立选宽、分组及最终SVG页面摘要。

合页准入和整册装订是独立的容量策略；单曲最优宽度使用上述规则，不因合页补测而覆盖。
