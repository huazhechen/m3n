# 当前宽度搜索规则

简谱、五线谱阅读器及本地／在线PDF单曲选宽共用 `tools/scorebook-width.mjs`。有效候选先比较页数，**最少页数一定优先**；同页数才比较横向质量，同分取较窄宽度。页底留白和最终行距均不参与单曲排名。

## 简谱

固定宽度内，紧8px和松16px只定义最小净空，不设置自然间距、不允许压缩。两档分别求全曲最优断行，按横向代价升序完成纵向放置与虚拟A4分页；仅在页数下界已劣于当前赢家时跳过未雕版档位。先取页数少的档位；同页数比较实际单位节奏间距的“不均匀＋紧凑”代价，同分取松档。各档内部动态规划保持原有 `sum(r²)+sum((r-mean(r))²)` 目标，`r=max(0,1-M/W)`；每档先以贪心最紧凑断行确定页数上限，再求不增页条件下的横向最优。候选页数使用实际行的数值几何，默认逐元素避让，非核心间距系数为0.3。行内歌词先统一基线，再计算核心和墨迹；不再拼接独立小节的最终高度。

最终评价以铺满状态下各行单位节奏净空 `g` 为共同基准，`spacingCost=mean(d²)+max(d²)+mean((16/g)²)`，其中 `d=(g-mean(g))/mean(g)`。扣除音乐字形占宽，归一化时值和连组权重，不减去各档最小间距。末尾短行也按铺满计算。跨宽度加入 `4 * max(0,(版宽-528)/240)²` 字体缩小代价及不可拆对象溢出惩罚，再按“页数、总代价、版宽”依次升序排名。额外拉伸量仅用于每档内部断行，不参加档位及宽度最终排名。兼容质量分 `qualityScore=1/(1+totalCost)` 保持高分优先语义。具体测量定义见[间距与分行](ELASTIC_SPACING.md)。

搜索先访问528～768px的11个24px粗档，生产模式先48px再补24px；随后只在最佳粗档左右24px内以6px局部细搜；保留全范围测量作为诊断对照。局部细搜不保证全范围离散最优。有效的已有单页赢家允许安全剪枝：非负横向代价保证任意宽度的最高质量不超过 `1/(1+4*((版宽-528)/240)²)`（简谱）；只有上界严格低于赢家时才跳过，等分仍测量。多页赢家不能仅据字体界限排除其他宽度；数值模式另计算全图核心高度页数下界，只有证明候选不能省页时才叠加字体界限。数值几何模式下，页数约束可能改变断行与最终评分，因此停用仅依据约束前横向分数的宽度／档位剪枝；保留安全字体上界及局部细搜。

档位准备由 `NumberedLayoutTask` 管理，共用未放置投影、关系拓扑、最小跨度及谱头准备；每档横向断行状态独立，不共享放置坐标。任务内按间距／等宽设置缓存完整小节跨度的精确最小占宽，跨宽度复用；宽度相关的分片跨度不缓存。设置或字体变化不能复用旧准备，新任务从空状态开始。生产选宽不生成独立验收SVG；审计模式完整访问所有6px档并检查笔画。策略版本为 `levels-1-11-quality-528-768-refine-6-v34`。求解算法见[间距与分行](ELASTIC_SPACING.md)。

## 五线谱

五线谱也使用0.6／1.2谱间双档、同一最终代价及局部6px细搜，先48px粗搜再补24px。
安全字体上界为同一系数4曲线，候选页数读取实际宽度下的候选行包络缓存；固定小节数据跨宽度复用，动态完整高度不作此假设。行数不独立排序。
具体时值与净空定义见[五线谱](STAFF_NOTATION.md)。

五线谱测量任务跨宽度缓存各小节的最小占宽、节奏权重和固定间距基底。候选行只计算自己的横向位置；跨行关系读取当前分片图的事件索引，无须生成行外小节的间距。单页无约束最优不再雕版贪心方案，相同断行复用一次横向排版结果。候选阶段仍用实际行的完整几何边界分页；逐元素墨迹数组、左侧谱表缩进和SVG阅读诊断延后到输出或审计时生成。曲线及歌词避让没有改用近似值，分片事件索引保留父组最后出现位置的原有语义。实测与限制见[五线谱性能复用](STAFF_PERFORMANCE_REVIEW.md)。

在线五线谱在单曲搜索期间只保留当前最佳的一份完整排版；单曲选宽结束后固定此项，合页补测不会替换它。最终宽度相同时直接取用并释放，不同时重建并释放旧项。不设整册缓存行数预算，仍执行总进程内存限制。测量报告单列命中、宽度不匹配、保留行数及最终排版／SVG耗时。最终SVG节点直接用于拼页，避免序列化后再次解析；PDF转换继续读取浏览器坐标。

## 谱集合页

合页先以624px（24px的26倍，第5粗档）判断准入：成员逐曲为单页，且连续高度之和加最小曲间距可装入A4版心才允许合页。通过后，在528～624px、24px粗档中按成员平均质量择优，再在粗搜最佳宽度左右各24px内以6px细搜，不越出528～624px。每个细搜宽度都须全员单页且满足整组容量；同分取较窄宽度。所有可行分组都补测邻档后再优化章节组合，任务内同曲同宽不重复测量，合页补测不改变单曲独立选宽。

剪枝模式按需补测合页候选：先测准入宽度，再枚举原有合法分组；组宽度只能在平均质量上界无法胜出、已有成员不合格或已知成员的部分高度已超容量时提前停止。补测保存在独立候选集合，不回写单曲选宽结果。`tools/verify-scorebook-search.mjs` 在两个新建浏览器中分别运行完整搜索和剪枝搜索，比较全部独立选宽、分组及最终SVG页面摘要。

合页准入和整册装订是独立的容量策略；单曲最优宽度使用上述规则，不因合页补测而覆盖。

## 简谱测量口径

`tools/benchmark-numbered-spacing.mjs` 默认完整测量41个宽度，便于核对全局最优候选；加 `--prune` 使用与阅读器相同的安全宽度剪枝和横向质量筛选。两种模式都复用一个浏览器、页面和共享字体／文字度量。报告记录实际请求数、跳过宽度与各阶段耗时。完整搜索时间与生产剪枝时间必须分别列示，不混作网页性能。

字体代价为 `4*((版宽-528)/240)²`；528、552、744、768px分别为0、0.04、3.24、4。简谱上界与该曲线共用同一个实现；五线谱共用此上界，兼容旧评分的合页平均分仍采用两者较大的安全上界。多页赢家仍不允许仅按字体代价跳过宽度；必须同时取得不能省页的下界证明。

## 局部细搜对照模式

当前系数8的master／当前全范围实测与局部重放见[系数8对照](NUMBERED_FONT8_REVIEW.md)。

117首同谱源实测的耗时、5首宽度差异及字体曲线影响见[字体代价与局部细搜实测](NUMBERED_FONT_COST_REVIEW.md)。

`--prune --local-refine` 使用48px粗采样、补齐24px粗档，再只在最佳粗档的左右24px内以6px细搜；仍启用字体质量上界、横向质量筛选、单页下界档位剪枝和任务内最小跨度缓存。该模式已用于简谱阅读和谱集导出的生产搜索；全范围6px网格保留作对照。局部模式使用 `-local` 策略后缀，与全范围候选缓存区分；它可能遗漏粗搜赢家附近以外的断行突变，因此不能声称保证全范围离散最优。

## 简谱数值几何与逐元素避让

公开简谱API默认 `numericLayout:true`、`avoidance:element`。任务跨宽度复用音符、文字基础度量与最小跨度；完整行高度在实际断行、实际宽度下重组。分行后的歌词共同基线、弧线和标记进入同一组几何，分页和绘制消费相同结果。完整行快照用于相同行坐标下的候选复用；渐强和跨行连音组的外部端点几何进入缓存键，不能仅按小节编号复用这些行的最终高度。

`--numeric-layout --avoidance=row|measure|element` 可比较三种避让粒度。旧 `--row-envelope` 独立小节高度模型保留为诊断对照，不能等同于当前整行数值几何。主要音符、文字与曲线使用数值边界；少量谱头、房子线和编号等辅助符号仍经局部SVG测量，选宽不生成整页SVG。

无约束横向最优未超出贪心页数时直接返回。否则先求带乐观分页约束的代价DP，使用基础高度下界和已解析行几何收紧；可行的松弛最优解即为约束最优解。难例按每个合法前行分别解析末行撑满／继承间距两种几何，并在需要时保留本节间距总和与计数，按与绘制相同的平均值规则选择；统计在实际分节处重置，包含同声部中的标题分节。单页搜索另用反向最短高度下界排除不可能完成的前缀。仍不可行时以Lawler前缀分区调用该松弛求解器，实际分页确认每个返回方案。没有搜索数量上限或高度量化；最坏情况仍可能昂贵。

### 数值求解的性能复用

同一任务内，完整小节跨度的水平约束链按间距档位复用，换宽只重绑私有投影的坐标目标；纯间距查询直接读取不变约束。正向伸展复用最小位置与累计权重，固定间距组也复用折叠结果。原浮点运算顺序保持不变，不近似间距或量化动态规划状态。

固定符号墨迹、歌词局部度量及不依赖宽度的核心高度下界跨宽度复用；歌词度量上下文在布局返回或抛错时释放，独立修改歌词样式会重新测量。圆滑线、三连音与渐强只在一次关系放置期间共享行内障碍物，放置结束释放，后续修改不会读到过期几何。分页复用不可变行块的归一化墨迹和排序；完整图元仍参与实际元素避让。超宽小节分片保留原小节编号，缓存键额外包含分片音符身份，防止同一小节的不同片段误用位置或高度。没有上方文字或外层标记的行省略无人读取的避让区域。候选阶段只确定页数，选定档位后统一拟合最终行距并写入纵坐标。

分页代价DP共享相同后缀统计，并用已知可行代价限制后缀集合；前缀方差、剩余高度与横向代价的联合下界只用于安全淘汰。无约束最优已经一页、或贪心页数下界已经达到无约束方案页数时，不再重复雕版贪心方案。
