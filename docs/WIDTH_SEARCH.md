# 当前宽度搜索规则

简谱、五线谱阅读器及本地／在线PDF的单曲选宽共用 `tools/scorebook-width.mjs`。先遍历1～11档，即528～768px、24px步长，再在最佳粗档位左右各24px内以6px步长细搜；不越出搜索范围，不重复测量已测档位。粗搜没有有效候选时不精搜。

粗搜和精搜沿用同一规则：排除失败或独立验收不通过的候选，先取最少页数，再选综合质量分最高者，同分取较窄宽度。简谱和五线谱均以字号保留比例的平方（`(528／版宽)²`）除以 `1＋谱行自然密度变异系数＋0.5×末行横向留白比例＋4×过度伸展代价` 评分。同一显示宽度下，较窄版宽能放大音符与歌词；平方提高字号的权重，同时保留横向均匀度的平衡作用。页底留白不参与评分。过度伸展代价为各行 `max(0, 1−1.5×自然密度)²` 的平均值；末行自然密度按其实际目标宽度归一，避免惩罚有意缩短的收尾。单行曲没有行间疏密比较，该项为0。该项给均匀但过松的多行版面增加代价，复用收尾策略的1.5倍伸展限制与共享分行的平方代价形式，不修改字形或最小碰撞净空。

固定版宽内，简谱使用8px最小／16px自然净空，五线谱暂时试排9／12／15px基础净空（适配为0.25／0.3125／0.375）。先取谱行数最少者，再按共用横向评分选择，同分取较小间距；不再让各自的谱行高度／A4页数决定横向间距档。跨版宽搜索仍按上一段的页数优先规则。五线谱的分行容量取自身实际碰撞下限，自然占宽按整首基础时值、实际符头宽及每翻倍增加1.2个谱间的规则估计；不将简谱数字与延长音槽占宽作为硬下限，也不复制简谱换行结果。同宽下允许五线谱使用更少行，以自身横向密度补偿较大的谱行高度。字号因子在这些候选间相同，不改变选距优先级。候选保留完整布局和内部避让，生产模式不执行独立SVG审计。

粗搜最优值与有效细搜档位比较，得到最终宽度；不会沿细搜结果继续扩展。搜索支持取消、错误记录及可选的独立SVG验收。报告记录全部实际测量档位和实际请求数量，策略版本为 `levels-1-11-quality-528-768-refine-6-v20`。

生产选宽先以48px步长访问528、576、624、672、720、768px，再补齐原24px档位，最后在原粗搜赢家周围以6px细搜。启用有证明上界的剪枝，档位、评分、页数优先及同分规则保持原样。所有横向惩罚非负，因此任意宽度的质量分至多为 `(528／版宽)²`。已有有效单页候选时，只有上界严格低于当前最佳分的宽度才能跳过；多页候选不能据此排除其他宽度，也不假定页数或评分随宽度单调变化。若上界仍可能胜出，先求三个原有间距档的横向评分；基线及所有可能替代它的试排分数均严格低于当前单页最佳分时，省去该宽度的纵向雕版。主线按页数优先比较间距档，因此上界包含全部间距试排；五线谱还包含尾页调整可能访问的行代价试排。等分仍保留，避免改变较窄宽度的优先级。独立审计及默认离线探测继续完整遍历，支持与生产剪枝逐项比较。

合页先以624px（24px的26倍，第5粗档）判断准入：成员逐曲为单页，且连续高度之和加最小曲间距可装入A4版心才允许合页。通过后，在528～624px、24px粗档中按成员平均质量择优，再在粗搜最佳宽度左右各24px内以6px细搜，不越出528～624px。每个细搜宽度都须全员单页且满足整组容量；同分取较窄宽度。所有可行分组都补测邻档后再优化章节组合，任务内同曲同宽不重复测量，合页补测不改变单曲独立选宽。

剪枝模式按需补测合页候选：先测准入宽度，再枚举原有合法分组；组宽度只能在平均质量上界无法胜出、已有成员不合格或已知成员的部分高度已超容量时提前停止。补测保存在独立候选集合，不回写单曲选宽结果。`tools/verify-scorebook-search.mjs` 在两个新建浏览器中分别运行完整搜索和剪枝搜索，比较全部独立选宽、分组及最终SVG页面摘要。

简谱的任务内准备由 `NumberedLayoutTask` 管理：页面选宽、在线谱集和本地谱集在各自任务中共用未放置投影、关系拓扑、各间距档的小节最小跨度及谱头准备。谱头中的字体与乐谱相关部分跨宽度复用，文字换行仍按宽度区分。试排先放置末行，求出原横向质量；只有可能胜出的间距试排才放置其他谱行并构建纵向几何。未被剪枝的候选仍独立放置、避让和分页；字体或设置变化不能复用旧准备，新任务从空状态开始。它不保存跨任务排版或选宽结果。

在线五线谱在单曲搜索期间只保留当前最佳的一份完整排版；单曲选宽结束后固定此项，合页补测不会替换它。最终宽度相同时直接取用并释放，不同时重建并释放旧项。不设整册缓存行数预算，仍执行总进程内存限制。测量报告单列命中、宽度不匹配、保留行数及最终排版／SVG耗时。最终SVG节点直接用于拼页，避免序列化后再次解析；PDF转换继续读取浏览器坐标。

简谱采用固定8／16px最小与自然净空，不再枚举间距档；横向质量低于已有单页赢家时可省去确定不能胜出的纵向雕版。五线谱间距试排暂沿用页数、谱行数与质量比较顺序。搜索阶段只求最小行距下的分页归属；最终输出才拟合页内行距，不改变原20次拟合算法。非交互整册输出直接生成音乐字形拆字后的等价节点，普通文字继续由浏览器测量字符位置。

五线谱还可按谱表核心最小高度与最小歌词净空，保守计算一页最多容纳的谱行数，再求页数下界。谱头、页边空白、额外音符和装饰均忽略，只会高估每页容量。所有可能选中的间距试排都至少需要当前最佳页数、且横向质量仍严格不能胜出时，省去纵向雕版；页数下界更高也可直接排除。显式行距继续使用原路径。这不依赖宽度或页数的单调性。

2026-11-25，将此前加入的页底留白指标撤回，改为提高字号权重。以《你是我心爱的姑娘》原试排数据比较，702px与738px都只需一页，字号平方评分选择702px；同一显示宽度下音符与歌词约放大5.1%。页数仍优先，严重不均匀的候选仍可能输给稍宽的版面。

真实字体抽查：《欢乐颂》保持576px／1页，《茉莉花》保持576px／1页，《花之舞》保持642px／2页；《你是我心爱的姑娘》按原一次方字号评分为738px，平方评分为702px，均为1页。四首选中版面的独立SVG越界及碰撞诊断均为空。

2026-11-26，统一两种谱面的过度伸展代价，以及默认行距、歌词后净空、分页伸展上限和显式行距语义。音乐尺度以五线高度与简谱小节线高度相近校准，详见[谱面密度归一](NOTATION_DENSITY.md)。


横向分行采用[自然间距与弹性模型](ELASTIC_SPACING.md)，分别比较压缩与拉伸代价；跨版宽候选和质量评分保持原有规则，简谱另以固定源码基线验证最优宽度与页数。
