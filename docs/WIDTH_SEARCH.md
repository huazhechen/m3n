# 当前宽度搜索规则

简谱、五线谱阅读器及本地／在线PDF的单曲选宽共用 `tools/scorebook-width.mjs`。先遍历1～11档，即528～768px、24px步长，再在最佳粗档位左右各24px内以6px步长细搜；不越出搜索范围，不重复测量已测档位。粗搜没有有效候选时不精搜。

粗搜和精搜沿用同一规则：排除失败或独立验收不通过的候选，先取最少页数，再选综合质量分最高者，同分取较窄宽度。简谱和五线谱均以字号保留比例的平方（`(528／版宽)²`）除以 `1＋谱行自然密度变异系数＋0.5×末行横向留白比例＋4×过度伸展代价` 评分。同一显示宽度下，较窄版宽能放大音符与歌词；平方提高字号的权重，同时保留横向均匀度的平衡作用。页底留白不参与评分。过度伸展代价为各行 `max(0, 1−1.5×自然密度)²` 的平均值；末行自然密度按其实际目标宽度归一，避免惩罚有意缩短的收尾。单行曲没有行间疏密比较，该项为0。该项给均匀但过松的多行版面增加代价，复用收尾策略的1.5倍伸展限制与共享分行的平方代价形式，不修改字形或最小碰撞净空。

固定版宽内，两种谱式均试排共用的9／12／15px基础净空（五线谱适配为0.25／0.3125／0.375）。先取谱行数最少者，再按共用横向评分选择，同分取较小间距；不再让各自的谱行高度／A4页数决定横向间距档。跨版宽搜索仍按上一段的页数优先规则。五线谱的分行容量取自身实际碰撞下限，软阅读占宽按普通符头加2.2个谱间距的预算及共用节奏权重估计；不将简谱数字与延长音槽占宽作为硬下限，也不复制简谱换行结果。同宽下允许五线谱使用更少行，以自身横向密度补偿较大的谱行高度。字号因子在这些候选间相同，不改变选距优先级。候选保留完整布局和内部避让，生产模式不执行独立SVG审计。

粗搜最优值与有效细搜档位比较，得到最终宽度；不会沿细搜结果继续扩展。搜索支持取消、错误记录及可选的独立SVG验收。报告记录全部实际测量档位和实际请求数量，策略版本为 `levels-1-11-quality-528-768-refine-6-v19`。

合页先以624px（24px的26倍，第5粗档）判断准入：成员逐曲为单页，且连续高度之和加最小曲间距可装入A4版心才允许合页。通过后，在528～624px、24px粗档中按成员平均质量择优，再在粗搜最佳宽度左右各24px内以6px细搜，不越出528～624px。每个细搜宽度都须全员单页且满足整组容量；同分取较窄宽度。所有可行分组都补测邻档后再优化章节组合，任务内同曲同宽不重复测量，合页补测不改变单曲独立选宽。

简谱的任务内准备由 `NumberedLayoutTask` 管理：页面选宽、在线谱集和本地谱集在各自任务中共用未放置投影、关系拓扑及按宽度区分的谱头准备。所有候选仍独立放置并执行完整内部避让、分页和评分；字体或设置变化不能复用旧准备，新任务从空状态开始。它不保存跨任务排版或选宽结果。
