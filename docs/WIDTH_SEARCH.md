# 当前宽度搜索规则

简谱、五线谱阅读器及本地／在线PDF的单曲选宽共用 `tools/scorebook-width.mjs`。先遍历480～720px、20px步长的13档，选出粗搜最优宽度，再实际测量该宽度左右10px的两个精准档位。超出480～720px范围的档位直接跳过，不钳制到边界重复测量。最多测量15档，边界最优时为14档；粗搜没有有效候选时不精搜。

粗搜和精搜沿用同一规则：排除失败或独立验收不通过的候选，先取最少页数，再选综合质量分最高者，同分取较窄宽度。粗搜最优值与有效的左右档位比较，得到最终宽度；不会沿精搜结果继续扩展。精搜同样支持取消、错误记录及可选的独立SVG验收。报告记录全部实际测量档位和实际请求数量，策略版本为 `coarse20-refine10-quality-480-720-v9`。

这是实际候选的质量比较，不是旧版宽度扰动稳定性检查；相邻候选页数不要求相等。合页仍独立以640px判断准入，再在480～640px、20px共同档位上选择可容纳且平均质量最高的宽度。

本说明更新此前文档中“仅13档、20px整档选宽”的描述。评分公式及合页容量规则见 [谱集说明](SCOREBOOK.md#最佳宽度)。
