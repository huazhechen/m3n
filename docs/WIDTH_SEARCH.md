# 当前宽度搜索规则

简谱、五线谱阅读器及本地／在线PDF的单曲选宽共用 `tools/scorebook-width.mjs`。先遍历1～9档，即576～768px、24px步长，再在最佳粗档位左右各24px内以6px步长细搜；不越出搜索范围，不重复测量已测档位。粗搜没有有效候选时不精搜。

粗搜和精搜沿用同一规则：排除失败或独立验收不通过的候选，先取最少页数，再选综合质量分最高者，同分取较窄宽度。简谱评分为字号保留比例（576／版宽）除以 `1＋谱行自然密度变异系数＋0.5×末行横向留白比例＋0.5×页底留白比例`。页底留白取各页最后谱行底部至版心底部的空白高度占该页版心高度的比例，再对所有页求平均；页边距不计入空白。五线谱暂沿用原来的横向评分。

页底指标只参与简谱版宽选择；固定版宽内的9／12／15px音符间距仍按原来的横向评分选择，避免为了填满页面而扩大音符间距。候选保留完整布局和内部避让，生产模式不执行独立SVG审计。

粗搜最优值与有效细搜档位比较，得到最终宽度；不会沿细搜结果继续扩展。搜索支持取消、错误记录及可选的独立SVG验收。报告记录全部实际测量档位和实际请求数量，策略版本为 `levels-1-9-quality-576-768-refine-6-v12`。

合页固定以576px判断准入并排版，逐曲单页且连续高度之和加最小曲间距可装入A4版心才允许合页。合页不重新搜索宽度。

简谱的任务内准备由 `NumberedLayoutTask` 管理：页面选宽、在线谱集和本地谱集在各自任务中共用未放置投影、关系拓扑及按宽度区分的谱头准备。所有候选仍独立放置并执行完整内部避让、分页和评分；字体或设置变化不能复用旧准备，新任务从空状态开始。它不保存跨任务排版或选宽结果。

2026-11-25，用真实三字体复核《你是我心爱的姑娘》：原评分选择738px、7行、1页，页底留白20.37%；加入页底指标后选择702px、8行、1页，页底留白5.67%。谱源及音符间距均保持原样。
