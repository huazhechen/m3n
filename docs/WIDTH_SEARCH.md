# 当前宽度搜索规则

简谱、五线谱阅读器及本地／在线PDF的单曲选宽共用 `tools/scorebook-width.mjs`。先遍历1～11档，即528～768px、24px步长，再在最佳粗档位左右各24px内以6px步长细搜；不越出搜索范围，不重复测量已测档位。粗搜没有有效候选时不精搜。

粗搜和精搜沿用同一规则：排除失败或独立验收不通过的候选，先取最少页数，再选综合质量分最高者，同分取较窄宽度。简谱和五线谱均以字号保留比例的平方（`(528／版宽)²`）除以 `1＋谱行自然密度变异系数＋0.5×末行横向留白比例` 评分。同一显示宽度下，较窄版宽能放大音符与歌词；平方提高字号的权重，同时保留横向均匀度的平衡作用。页底留白不参与评分。

固定版宽内，简谱9／12／15px和五线谱0.25～0.375音符间距均完整比较所有可用候选，先取最少页数，再按共用横向评分选择，同分取较小间距；字号因子在这些候选间相同，不改变选距优先级。候选保留完整布局和内部避让，生产模式不执行独立SVG审计。

粗搜最优值与有效细搜档位比较，得到最终宽度；不会沿细搜结果继续扩展。搜索支持取消、错误记录及可选的独立SVG验收。报告记录全部实际测量档位和实际请求数量，策略版本为 `levels-1-11-quality-528-768-refine-6-v14`。

合页先以624px（24px的26倍，第5粗档）判断准入：成员逐曲为单页，且连续高度之和加最小曲间距可装入A4版心才允许合页。通过后，在528～624px、24px粗档中按成员平均质量择优，再在粗搜最佳宽度左右各24px内以6px细搜，不越出528～624px。每个细搜宽度都须全员单页且满足整组容量；同分取较窄宽度。所有可行分组都补测邻档后再优化章节组合，任务内同曲同宽不重复测量，合页补测不改变单曲独立选宽。

简谱的任务内准备由 `NumberedLayoutTask` 管理：页面选宽、在线谱集和本地谱集在各自任务中共用未放置投影、关系拓扑及按宽度区分的谱头准备。所有候选仍独立放置并执行完整内部避让、分页和评分；字体或设置变化不能复用旧准备，新任务从空状态开始。它不保存跨任务排版或选宽结果。

2026-11-25，将此前加入的页底留白指标撤回，改为提高字号权重。以《你是我心爱的姑娘》原试排数据比较，702px与738px都只需一页，字号平方评分选择702px；同一显示宽度下音符与歌词约放大5.1%。页数仍优先，严重不均匀的候选仍可能输给稍宽的版面。

真实字体抽查：《欢乐颂》保持576px／1页，《茉莉花》保持576px／1页，《花之舞》保持642px／2页；《你是我心爱的姑娘》按原一次方字号评分为738px，平方评分为702px，均为1页。四首选中版面的独立SVG越界及碰撞诊断均为空。
