# 当前宽度搜索规则

简谱、五线谱阅读器及本地／在线PDF单曲选宽共用 `tools/scorebook-width.mjs`。有效候选先比较页数，**最少页数一定优先**；同页数才比较横向质量，同分取较窄宽度。页底留白和最终行距均不参与单曲排名。同页更大字体替代方案及逐曲判断见[简谱选宽全量复查](NUMBERED_WIDTH_REVIEW.md)。

自动搜索上限现为720px，两种谱式统一使用此上限。字体缩小代价继续绑定搜索范围，720px对应代价4。历史性能报告中的768px／41档是当时配置，不代表当前范围。

## 共享求解架构约束

选宽、横向断行、分页代价动态规划、几何下界收紧、精确分页复核及全局分支回退属于共享层。简谱和五线谱只提供间距规则、行几何下界、精确行几何和段尾宽度上下文，不各自实现搜索策略。性能优化应在共享层一次实现并验证两种谱式；渲染方式不同不能成为复制求解算法的理由。

`layout/refined-page-breaking.ts` 统一分页约束求解流程：先求乐观高度模型中的最低代价方案，精确测量其实际谱行，再收紧已知几何并继续求解。乐观最优方案经精确分页确认可行，即证明真实最优；尚未证明时，使用同一套前缀分区搜索及分页代价下界完成求解。未知行仍用安全下界，不提前雕版全部候选行。几何缓存版本变化使求解器重新检查高度界限，已证明的横向代价下界继续复用。

## 简谱

固定宽度内，紧8px和松16px只定义最小净空，不设置自然间距、不允许压缩。两档分别求全曲最优断行，按横向代价升序完成纵向放置与虚拟A4分页；仅在页数下界已劣于当前赢家时跳过未雕版档位。先取页数少的档位；同页数比较逐间隔拥挤、过疏与不均匀代价，同分取松档。各档内部动态规划保持原有 `sum(r²)+sum((r-mean(r))²)` 目标，`r=max(0,1-M/W)`；每档先以贪心最紧凑断行确定页数上限，再求不增页条件下的横向最优。候选页数使用实际行的数值几何，默认逐元素避让，非核心间距系数为0.5。行内歌词先统一基线，再计算核心和墨迹；不再拼接独立小节的最终高度。

最终评价逐个测量铺满状态下的单位节奏净空 `g_i`，以12～24px为拥挤／过疏零代价舒适区。`spacingCost=mean(max(0,12/g_i-1)²)+mean(max(0,g_i/24-1)²)+mean(d_r²)+max(d_r²)`，其中 `d_r=(r-mean(rowGaps))/mean(rowGaps)`，`r` 为各行原有的 `unitRhythmicGap`，先逐间隔计算，再跨全曲平均，零代价间隔也参与分母。扣除音乐字形占宽，归一化时值和连组权重，不减去各档最小间距。均匀度保留行间平均与最差相对偏差两项，避免异常短行被全曲平均稀释。末尾短行也按铺满计算。跨宽度加入 `4 * max(0,(版宽-528)/192)²` 字体缩小代价及不可拆对象溢出惩罚，再按“页数、总代价、版宽”依次升序排名。舒适区内不再因增大净空持续获益，但仍需综合均匀度与字号。额外拉伸量仅用于每档内部断行，不参加档位及宽度最终排名。兼容质量分 `qualityScore=1/(1+totalCost)` 保持高分优先语义。具体测量定义见[间距与分行](ELASTIC_SPACING.md)。

搜索先访问528～720px的9个24px粗档，生产模式先48px再补24px；随后补齐528～720px全范围6px网格，共33档，只通过可证明的代价上界剪枝。断行可在任意粗档之间突变，不能仅检查粗搜赢家附近。有效的已有单页赢家允许安全剪枝：非负横向代价保证任意宽度的最高质量不超过 `1/(1+4*((版宽-528)/192)²)`（简谱）；只有上界严格低于赢家时才跳过，等分仍测量。多页赢家不能仅据字体界限排除其他宽度；数值模式另计算全图核心高度页数下界，只有证明候选不能省页时才叠加字体界限。数值几何模式下，页数约束可能改变断行与最终评分，因此停用仅依据约束前横向分数的宽度／档位剪枝；保留安全字体上界，完整覆盖可能胜出的6px候选。

档位准备由 `NumberedLayoutTask` 管理，共用未放置投影、关系拓扑、最小跨度及谱头准备；每档横向断行状态独立，不共享放置坐标。任务内按间距／等宽设置缓存完整小节跨度的精确最小占宽，跨宽度复用；宽度相关的分片跨度不缓存。设置或字体变化不能复用旧准备，新任务从空状态开始。生产选宽不生成独立验收SVG；审计模式完整访问所有6px档并检查笔画。策略版本为 `levels-1-9-quality-528-720-refine-6-v60`。求解算法见[间距与分行](ELASTIC_SPACING.md)。

## 五线谱

五线谱使用0.8／2.4谱间双档、同一最终代价及全范围6px网格。与简谱共用先48px再补24px粗档、随后补齐528～720px全部33档的搜索流程，仅以可证明的界限剪枝。阅读器、本地与在线谱集导出均使用此配置。
安全字体上界为同一系数4曲线，候选页数读取实际宽度下的候选行包络缓存；固定小节数据跨宽度复用，动态完整高度不作此假设。行数不独立排序。
具体时值与净空定义见[五线谱](STAFF_NOTATION.md)。

五线谱测量任务跨宽度缓存各小节的最小占宽、节奏权重和固定间距基底。候选行只计算自己的横向位置；跨行关系读取当前分片图的事件索引，无须生成行外小节的间距。单页无约束最优不再雕版贪心方案，相同断行复用一次横向排版结果。候选阶段仍用实际行的完整几何边界分页；逐元素墨迹数组、左侧谱表缩进和SVG阅读诊断延后到输出或审计时生成。曲线及歌词避让没有改用近似值，分片事件索引保留父组最后出现位置的原有语义。实测与限制见[五线谱性能复用](STAFF_PERFORMANCE_REVIEW.md)。

在线五线谱在单曲搜索期间只保留当前最佳的一份完整排版；单曲选宽结束后固定此项，合页补测不会替换它。最终宽度相同时直接取用并释放，不同时重建并释放旧项。不设整册缓存行数预算，仍执行总进程内存限制。测量报告单列命中、宽度不匹配、保留行数及最终排版／SVG耗时。最终SVG节点直接用于拼页，避免序列化后再次解析；PDF转换继续读取浏览器坐标。

## 谱集合页

合页完整搜索528～624px的全部17个6px离散档位。每档独立检查所有成员的单页、安全几何与连续高度之和，加上最小曲间距后必须装入A4版心。624px不再作为准入门槛；其他宽度可行的组合即使在624px失败也参与求解。断行与高度可以随宽度突变，因此不能用某一档的失败推断其他档失败。

每个“成员集合＋共同宽度”都是章节求解候选，不再先按平均质量锁定一个组宽度。整章先最小化总页数，再比较 `pageWeight * pages + densityPenalty + qualityWeight * readingCost`，目前两个权重均为1。疏密代价沿用目标填充率0.75、稀疏阈值0.65和拥挤阈值0.85；合页组的阅读代价为成员的横向／字号总代价平均值；独占曲目取自身代价，多页曲目也只计一次，章节累加各组代价。当前候选直接读取 `totalCost`；兼容质量分使用 `1/qualityScore-1` 还原代价。独占页面沿用独立选宽，同样参与章节评分。同分稳定保留较早曲目及较小分组，再取较窄宽度。

所有正式章节允许重排，以精确集合分组动态规划联合选择曲目组合与宽度。章节和显式 `breakBefore` 是搜索边界；`sharePage:false` 只禁止该曲合页，仍可移动，不阻止其前后短曲配对。曲内不拆分，最小曲间距及精确墨迹要求保持不变。

合页补测保存在独立候选集合，同任务同曲同宽复用，不覆盖单曲独立选宽。剪枝只能根据已知成员的精确安全性、页数和容量事实证明某档不存在可行搭档；未知高度采用安全的零下界，不根据单曲质量上界跳过可能有不同疏密收益的宽度。测量直接按曲目／宽度进行，无须先枚举指数数量的组合。在线简谱仅保留当前曲目的跨宽度测量准备，单曲结束或切换曲目时释放；最终绘制用相同字体与文字度量精确重建选定宽度，不让延迟绘制句柄保留全册候选几何。`tools/verify-scorebook-search.mjs` 在两个新建浏览器中分别运行完整搜索和剪枝搜索，比较独立选宽、分组及最终SVG页面摘要。

此前0.6／1.8五线谱规则下的共享求解器优化见[分页状态复用实测](WIDTH_PAGE_STATE_PERFORMANCE.md)。此前全范围搜索切换结果见[单线程全范围实测](WIDTH_FULL_GRID_PERFORMANCE.md)。

## 简谱测量口径

此前117首完整搜索／局部搜索对照、网页首次打开和基本功瓶颈见[当前简谱选宽性能](NUMBERED_WIDTH_PERFORMANCE.md)。

`tools/benchmark-numbered-spacing.mjs` 默认完整测量33个宽度，便于核对全局最优候选；加 `--prune` 使用与阅读器相同的安全宽度剪枝和横向质量筛选。两种模式都复用一个浏览器、页面和共享字体／文字度量。报告记录实际请求数、跳过宽度与各阶段耗时。完整搜索时间与生产剪枝时间必须分别列示，不混作网页性能。

字体代价为 `4*((版宽-528)/192)²`；528、552、696、720px分别为0、0.0625、3.0625、4。简谱上界与该曲线共用同一个实现；五线谱共用此上界；合页使用容量剪枝，不使用单曲质量上界。多页赢家仍不允许仅按字体代价跳过宽度；必须同时取得不能省页的下界证明。

## 搜索完整性

两种谱式统一全范围6px搜索，已删除局部细搜实现、调用参数与基准开关。即使全部24px粗档失败，仍补齐细档，避免遗漏仅在某个6px宽度可行的方案。安全剪枝仍需逐档证明，不能凭赢家所在区间缩小搜索范围。历史报告中的局部搜索只描述当时版本。

## 简谱数值几何与逐元素避让

公开简谱API默认 `numericLayout:true`，仅使用逐元素精准避让。任务跨宽度复用音符、文字基础度量与最小跨度；完整行高度在实际断行、实际宽度下重组。分行后的歌词共同基线、弧线和标记进入同一组几何，分页和绘制消费相同结果。完整行快照用于相同行坐标下的候选复用；渐强和跨行连音组的外部端点几何进入缓存键，不能仅按小节编号复用这些行的最终高度。

整行和小节矩形避让的实现、选项及对照工具已删除。简谱与五线谱共用逐元素碰撞、非核心净空、远行复核、分页和弹性行距拟合；适配器只提供实际核心、墨迹及固定附件净空。安全高度下界仍用于搜索剪枝，不参与实际避让。主要音符、文字与曲线使用数值边界；少量谱头、房子线和编号等辅助符号仍经局部SVG测量，选宽不生成整页SVG。

无约束横向最优未超出贪心页数时直接返回。否则先求带乐观分页约束的代价DP，使用基础高度下界和已解析行几何收紧；可行的松弛最优解即为约束最优解。难例按每个合法前行分别解析末行撑满／继承间距两种几何，并在需要时保留本节间距总和与计数，按与绘制相同的平均值规则选择；统计在实际分节处重置，包含同声部中的标题分节。单页搜索另用反向最短高度下界排除不可能完成的前缀。仍不可行时以Lawler前缀分区调用该松弛求解器，实际分页确认每个返回方案。没有搜索数量上限或高度量化；最坏情况仍可能昂贵。

简谱和五线谱共用横向全局断行与分页约束的前缀分区搜索。每个分区先以当前可行方案的代价为上限，求无分页约束的横向最优；横向已无法胜出的分区，在任何行高可行性检查或分页代价求解之前淘汰。通过检查的横向解直接传给后续求解器，避免重复计算。固定前缀累计、候选权重缓存、前缀方差下界及同分断行规则也在共享求解器中维护。两种谱式只提供各自的几何、分页可行性检查与必要的约束细化。

### 数值求解的性能复用

同一任务内，完整小节跨度的水平约束链按间距档位复用，换宽只重绑私有投影的坐标目标；纯间距查询直接读取不变约束。正向伸展复用最小位置与累计权重，固定间距组也复用折叠结果。原浮点运算顺序保持不变，不近似间距或量化动态规划状态。

固定符号墨迹、歌词局部度量及不依赖宽度的核心高度下界跨宽度复用；歌词度量上下文在布局返回或抛错时释放，独立修改歌词样式会重新测量。圆滑线、三连音与渐强只在一次关系放置期间共享行内障碍物，放置结束释放，后续修改不会读到过期几何。分页复用不可变行块的归一化墨迹和排序；完整图元仍参与实际元素避让。超宽小节分片保留原小节编号，缓存键额外包含分片音符身份，防止同一小节的不同片段误用位置或高度。没有上方文字或外层标记的行省略无人读取的避让区域。候选阶段只确定页数，选定档位后统一拟合最终行距并写入纵坐标。

分页代价DP共享相同后缀统计，并用已知可行代价限制后缀集合；前缀方差、剩余高度与横向代价的联合下界只用于安全淘汰。无约束最优已经一页、或贪心页数下界已经达到无约束方案页数时，不再重复雕版贪心方案。

两种谱式最慢曲目的精确CPU采样、重复计算优化及全量回归口径见[选宽性能分析](WIDTH_SEARCH_PERFORMANCE.md)。

简谱阅读器在字体准备阶段解析实际使用的TTF设计轮廓，候选测量不读取Canvas像素墨迹；相同字体与设置的选宽不随设备像素比变化。页面固定保留2px绘制余量，所有候选与最终SVG使用同一余量。具体实现与验证见[字体设计度量](FONT_DESIGN_LAYOUT.md)。

候选雕版前的全图页数预检查及共享的按需几何／可行路径复用，见[预检查性能测量](WIDTH_SEARCH_PREFLIGHT_PERFORMANCE.md)。路径只负责提前保留候选；失败后继续完整图检查，不能仅凭贪心路径失败淘汰宽度。

共享分页对不可变图元、固定附件和精确极值轮廓的复用及两种谱式全量性能，见[碰撞数据复用](WIDTH_COLLISION_PERFORMANCE.md)。

固定附件也可使用完整包络安全跳过远行扫描，证明及后续全量实测见[固定附件碰撞上界](WIDTH_COLLISION_ENVELOPE_PERFORMANCE.md)。
