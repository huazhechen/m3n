## 1. 文档与乐句

### 1.1 文件与基本结构

M3N 是 UTF-8 纯文本，推荐扩展名为 `.m3n`。乐谱由乐句组成，也可以用乐段组织多个乐句。

```m3n
{title=旋律示例}
{key=C} {4/4} {120qpm}
N: 1 2 3 4 | 5 6 7 1e |
---
N: 1e 7 6 5 | 4 3 2 1 |||
```

前三行分别填写标题、初始设置和旋律；`---` 开始下一乐句，`|||` 结束乐曲。

- 调号、拍号和速度的默认值分别为 `{key=C}`、`{4/4}`、`{120qpm}`。
- 除歌词行外，空格、Tab 和普通换行只用于分隔元素，不直接控制谱面换行。
- `//` 开始至行末为注释，注释中的内容不作为设置或乐谱信息解析。
- 首个音符之前的调号、拍号、速度和力度建立初始状态。正文中的后续设置从所在位置向后生效，不改变前面的内容。

### 1.2 乐句与行类型

一个乐句以一条 `N:` 旋律行为核心。补充行与它属于同一个乐句，同时使用时按下表顺序排列：

| 顺序 | 前缀 | 用途 | 每个乐句的数量 |
| --- | --- | --- | --- |
| 1 | `N:` | 旋律 | 必须一条 |
| 2 | `B:` | 独立低音谱表 | 至多一条 |
| 3 | `C:` | 和弦标记 | 至多一条 |
| 4 | `L:` 或 `L1:`、`L2:` 等 | 歌词 | 可不写；模式见[歌词](#6-歌词) |

```m3n
{4/4}
N: 1 2 3 4 |||
B: 1d^^ |
C: I |
L: 一起唱歌
```

这一小节中，旋律唱四个音，低音保持四拍，和弦标记为 I，歌词逐字对应旋律。

用 `---` 分隔相邻乐句。它划分书写单位；强制谱面换行使用 [`{br}`](#102-换行与段名显示)。

**边界规则：**

- `N:` 可以在小节中间结束；下一乐句接着写剩余部分，两部分须合成一个满拍的小节。
- `N:` 不能以前反复线 `||:` 或 `:||:` 结束乐句。
- 同一乐句的所有小节必须有相同的实际播放次数。反复或导航使部分小节多播放几次时，用 `---` 分开。
- 延音和连奏可以跨普通 `---`，不能跨跳房子边界。
- `B:`、`C:`、`L:` 中的 `|` 用于与旋律小节对齐，不单独控制反复或播放结束。

### 1.3 乐段

`===` 开始新乐段，同时开始新乐句；后面可以附带名称。它必须放在两个乐句之间，不能插入 `N:` 与其补充行之间。

```m3n
{4/4}
===A
N: 1 2 3 4 ||
===B
N: 5 4 3 2 |||
```

未指定演奏顺序时，先播放 A，再播放 B；调号、拍号、速度和力度按书写顺序延续。段名不含 `{`、`}`、`,` 或 `=`。

用段名重复调用旋律，见[演奏顺序](#51-指定乐段演奏顺序)；段名如何显示，见[换行与段名显示](#102-换行与段名显示)。

## 2. 音符与节奏

### 2.1 音级与休止符

`1` 至 `7` 表示当前调号和调式中的音级，`0` 表示休止。普通音符和休止符的基础时值都是四分音符。

```m3n
{key=C} {4/4}
N: 1 2 3 0 |||
```

依次演奏 C、D、E，再休止一拍。

### 2.2 八度

在音级后追加 `e` 升高八度，追加 `d` 降低八度；重复字母可移动多个八度。

| 写法 | 含义 |
| --- | --- |
| `1e` | 高一个八度的 1 |
| `1ee` | 高两个八度的 1 |
| `1d` | 低一个八度的 1 |
| `1dd` | 低两个八度的 1 |

同一音符只能选用一个方向，不能混用 `e` 和 `d`。未修饰的 `1` 位于以 C4 为起点的主音记名八度中，其他音级向上排列，并在越过 C 时进入下一八度。

```m3n
{key=C} {4/4}
N: 1d 1 1e 1ee |||
```

四个音依次为 C3、C4、C5、C6。

整段升降八度可用 `{8va}...{/}` 或 `{8vb}...{/}`：

```m3n
{key=C} {4/4}
N: {8va}1 2{/} 1 2 |||
```

前两个音为 C5、D5，后两个音为 C4、D4。八度区间可嵌套，并与音符自身的 `e`、`d` 累加。

### 2.3 临时变音

临时变音写在音级后、八度前，例如 `2#e`。

| 写法 | 相对于当前调号和调式的默认音高 | 限制 |
| --- | --- | --- |
| `2#`、`2##` | 升高半音、全音 | `#` 最多两个 |
| `2b`、`2bb` | 降低半音、全音 | `b` 最多两个 |
| `2=` | 恢复默认音高 | `=` 只能一个 |

同一音符不能混用 `#`、`b`、`=`。显式变音会影响同一小节内同音级、同八度的后续音符；新的显式变音覆盖旧设置，小节线和调号变化清除临时变音。

```m3n
{key=C} {4/4}
N: 2# 2 2= 2 | 2 2 2 2 |||
```

第一小节演奏 D♯、D♯、D、D；第二小节全部为 D。`=` 恢复的是调号和调式定义的音高。

### 2.4 时值与括号

圆括号使内部音符的时值减半；每增加一层，再减半一次。休止符也适用。

| 写法 | 时值 |
| --- | --- |
| `1` | 四分音符，一拍 |
| `(1 2)` | 两个八分音符，合计一拍 |
| `((1 2 3 4))` | 四个十六分音符，合计一拍 |
| `(0 1)` | 八分休止符加八分音符，合计一拍 |

这里以四分音符为一拍。圆括号必须在同一小节内闭合，每层至少包含一个音符、休止符或分组。

音符或分组后可紧接时值后缀：

| 后缀 | 含义 | 例子 |
| --- | --- | --- |
| `^` | 时值翻倍，可重复 | `1^` 为二分音符，`1^^` 为全音符 |
| `.` | 附点，可重复 | `1.` 为附点四分音符，`1..` 为双附点四分音符 |

多个附点从第二个起，每次增加前一次增量的一半。组合时先写 `^`，再写 `.`，例如 `1^.` 是附点二分音符，不能写成 `1.^`。

```m3n
{4/4}
N: (1 2) ((3 4 5 6)) 7^ | 1^. 0 |||
```

第一小节是“一拍八分音符＋一拍十六分音符＋两拍长音”；第二小节是三拍长音加一拍休止。

### 2.5 延音

`~` 连接同音，使后一个音延续前一个音，不重新发音。它不改变两端各自占用的时值。

```m3n
{4/4}
N: 1^~ 1^ |||
```

两个二分音符连成四拍的持续音。`1^ 1^` 则会发音两次。

**连接规则：**

- 目标是紧随其后的第一个音乐元素，不能跳过不匹配的音符寻找目标。
- 两端音高必须相同。普通音符可以连接连音组的第一个音；连音组最后一个有音高的音也可以连接后续普通音符。
- 和音组只能连接音高集合相同的和音组；连音组不接受来自和音组的延音。
- 可以跨小节线、指令和普通乐句边界，不能跨跳房子边界；显式演奏顺序中的跨段限制见[§5.2](#52-演奏顺序的完整限制)。

同音延续只需 `~`。包含多个不同音的连奏使用 [`{lg}...{/}`](#92-连奏)，避免为同一段同音延续重复添加连奏弧线。

### 2.6 和音组

`[音高 音高 ... :h]` 使多个音同时发声，整组默认占一个四分音符时值。

```m3n
{4/4}
N: [1 3 5:h]^^ |||
```

1、3、5 同时发声，持续四拍。和音组至少含两个音，不能含休止符。

整组可以使用 `^`、`.`、圆括号、`~` 和后置琶音标记 `{arp}`。组内只能写音高，不能写时值后缀、指令、圆括号或嵌套分组；整组必须位于同一小节。

### 2.7 连音组

`[音高或0 音高或0 ... :正整数]` 让组内元素依次发声，均分冒号后指定的总基础时值。

```m3n
{4/4}
N: ([1 2 3:2]) 4 5 6 |||
```

`[1 2 3:2]` 原占两个四分音符时值；外层括号减半后，三个音均分一拍，构成常用的三连音。后面的 4、5、6 各占一拍。

**限制：**

- 至少两个元素，可以包含休止符 `0`。
- 组整体可使用 `^`、`.`、圆括号；最后一个有音高的元素可使用 `~`。
- 组内不能使用时值后缀、指令、圆括号或嵌套分组，整组不能跨小节。

### 2.8 小节时值与弱起

小节容量以四分音符为 1，计算为“拍号分子 × 4 ÷ 拍号分母”。例如 4/4 容纳四个四分音符，6/8 容纳六个八分音符。

通常每小节必须满拍。首小节可以弱起，由末小节补足：

```m3n
{4/4}
N: 5 | 1 2 3 4 | 3 2 1 |||
```

首小节一拍、末小节三拍，合计四拍；中间小节仍须四拍。

- 时值校验按实际的小节边界进行。相邻乐句中的不完整片段只有合起来恰好满拍才合法。
- 没有弱起时，末小节也必须满拍。
- 只有一个完整小节的乐谱不能再使用首尾弱起互补规则。
- 演奏顺序中的跨段弱起另见[§5.2](#52-演奏顺序的完整限制)。

### 2.9 多小节休止

`{rest=N}` 表示休止 N 个完整小节，N 为正整数。

```m3n
{4/4}
N: 1 2 3 4 | {rest=2} | 4 3 2 1 |||
```

演奏一小节，休止两小节，再演奏最后一小节。多小节休止必须独占一个小节位置，不能置于圆括号中，也不能带时值后缀。

## 3. 乐谱信息与设置

### 3.1 标题与署名

信息字段写在文档首部，每个字段至多声明一次，值不能为空。署名建议使用通行简称，例如“莫扎特”“肖斯塔科维奇”；同姓音乐家保留必要的区分信息。

```m3n
{title=旋律练习} {subtitle=四分音符} {composer=张三}
{4/4}
N: 1 2 3 4 |||
```

| 字段 | 含义 |
| --- | --- |
| `title` | 标题 |
| `subtitle` | 副标题 |
| `singer` | 演唱者 |
| `composer` | 作曲者 |
| `lyricist` | 作词者 |
| `arranger` | 编曲者 |
| `copyright` | 版权 |
| `source` | 来源 |
| `note` | 备注 |
| `transpose` | 播放移调，见[§3.5](#35-播放移调) |

谱头按作词、作曲、编曲、演唱的顺序显示已填写的署名，并带角色标签；未填写的角色不占行，同一人担任多个角色时分别显示。简谱、图片和 PDF 导出采用相同规则。

### 3.2 调号与调式

写法为 `{key=主音调式}`。主音使用 `A` 至 `G`，可带一个 `#` 或 `b`。

| 调式后缀 | 含义 | 例子 |
| --- | --- | --- |
| 省略 | 大调 | `{key=C}` |
| `m` | 小调 | `{key=Am}` |
| `dor` | 多利亚 | `{key=Ddor}` |
| `phr` | 弗里几亚 | `{key=Ephr}` |
| `lyd` | 利底亚 | `{key=Flyd}` |
| `mix` | 混合利底亚 | `{key=Gmix}` |
| `loc` | 洛克里亚 | `{key=Bloc}` |

调号从后一个音符起生效，直到下次设置。

```m3n
{key=C} {4/4}
N: 1 2 3 4 | {key=G}1 2 3 4 |||
```

两小节都写 1、2、3、4，第一小节按 C 大调演奏，第二小节按 G 大调演奏。

### 3.3 拍号

写法为 `{分子/分母}`，分子为正整数，分母为 2 的幂，例如 `{3/4}`、`{6/8}`。

```m3n
{3/4}
N: 1 2 3 | {2/4}4 5 |||
```

第一小节三拍，第二小节改为两拍。拍号只能在正文或具名乐段的起始处，或刚结束的小节线之后设置，不能在未结束的小节中改变。

### 3.4 速度与变速

`{正整数qpm}` 设置每分钟四分音符数，`qpm` 必须小写。速度从后一个音乐元素起生效，直到下次设置。

```m3n
{4/4} {120qpm}
N: 1 2 3 4 | {60qpm}1 2 3 4 |||
```

第一小节每分钟 120 个四分音符，第二小节减为 60。

**谱面显示的拍值：**

速度记号使用拍号分母对应的音符，不加附点；显示数值为 `qpm × 分母 ÷ 4`。

| 拍号与输入 | 谱面速度记号 | 播放速度 |
| --- | --- | --- |
| `{4/4}{120qpm}` | 四分音符 = 120 | 120 qpm |
| `{6/8}{120qpm}` | 八分音符 = 240 | 120 qpm |
| `{2/2}{120qpm}` | 二分音符 = 60 | 120 qpm |

9/8、12/8 与 6/8 使用相同换算。谱中变速按当时的拍号显示，输入始终使用 qpm。

**渐快与渐慢：**

`{accel=N}...{/}` 从当前速度连续变到 N，`{rit=N}...{/}` 同理表示渐慢。N 为正整数 qpm，区间结束后保持目标速度。

```m3n
{4/4} {80qpm}
N: {accel=120}1 2 3 4{/} | {rit=80}5 4 3 2{/} |||
```

第一小节由 80 渐快到 120，第二小节由 120 渐慢到 80。

### 3.5 播放移调

在首部写 `{transpose=整数}`，按半音改变播放音高：正值升高，负值降低。

```m3n
{key=C} {transpose=-2} {4/4}
N: 1 2 3 4 |||
```

相对于原来的 C 调音高，整段播放降低两个半音。该字段不改写源码中的音符。

## 4. 小节线与反复

### 4.1 小节线类型

| 写法 | 含义 | 适用行 |
| --- | --- | --- |
| `\|` | 普通小节线 | N:、B:、C: |
| `\|\|` | 双小节线 | N:、B:、C: |
| `\|\|\|` | 终止线 | N:、B:、C: |
| `\|\|:` | 前反复起点 | N: |
| `:\|\|` | 后反复终点 | N: |
| `:\|\|\|` | 后反复终点与终止线 | N: |
| `:\|\|:` | 结束当前反复，立即开始下一反复 | N: |

相邻小节线不能产生空小节。`B:`、`C:` 的双小节线和终止线可写在行末，用于与旋律同步标记结构结束。

### 4.2 成对反复与次数

```m3n
{2/4}
N: ||: 1 2 | 3 4 :||
---
N: 5 6 |||
```

先演奏 `1 2 | 3 4` 两遍，再演奏 `5 6`。未写前反复线时，后反复线隐式从当前整份乐谱开头反复。

在后反复线后写 `{xN}` 指定总遍数：

```m3n
{2/4}
N: ||: 1 2 | 3 4 :|||{x3}
```

这两小节总共演奏三遍。次数可以跟在 `:||`、`:||:` 或 `:|||` 后。

**限制：**

- 反复不能嵌套或重叠，也不能跨整份乐谱的边界。
- 可以跨普通 `---`，但同一乐句中的小节仍须具有相同播放次数，必要时拆分乐句。
- 显式演奏顺序中的段内反复使用成对反复线，见[§5.2](#52-演奏顺序的完整限制)。

### 4.3 跳房子

`---V1` 开始第一遍的结尾，`---V2` 开始第二遍的结尾。每个房子是一个独立乐句。

```m3n
{2/4}
N: ||: 1 2 |
---V1
N: 3 4 :||
---V2
N: 5 6 |||
```

第一遍演奏 `1 2 | 3 4`，第二遍演奏 `1 2 | 5 6`。

多个遍次用逗号分隔，例如 `---V1,V3`。同一反复内，各房子的遍次不能重叠，且必须覆盖所有遍次。延音和连奏不能跨房子边界。

没有段内反复、按乐段访问次数选择结尾的写法，见[§5.3](#53-按乐段访问次数选择结尾)。

### 4.4 D.S.、D.C. 与 Fine

| 标记 | 含义 |
| --- | --- |
| `{segno}` | 标记 D.S. 的返回位置，显示在小节开头 |
| `{ds}` | 返回 Segno，显示在小节结尾 |
| `{dc}` | 返回全曲开头，显示在小节结尾 |
| `{fine}` | 标记返回后的结束位置，显示在小节结尾 |

```m3n
{2/4}
N: {segno}1 2 | 3 4{fine} |||
---
N: 5 6 | 7 1e{ds} ||
```

先演奏四小节，再由 D.S. 返回第一小节，演奏到第二小节的 Fine 结束。

每份乐谱至多使用一个 `{ds}` 或 `{dc}`；使用 `{ds}` 时必须有唯一的 `{segno}`。不能与显式 `{order=...}` 混用。

## 5. 演奏顺序与替代旋律

### 5.1 指定乐段演奏顺序

在文档首部写 `{order=段名,段名,...}`，按照列出的顺序播放，每个乐段只排印一次。

```m3n
{2/4} {order=A,B,A}
===A
N: 1 2 ||
===B
N: 3 4 |||
```

演奏结果为 `1 2 | 3 4 | 1 2`。简谱顶部显示 A → B → A，播放和 MIDI 使用同一顺序。

**歌词的遍次：**

没有段内反复时，编号歌词对应本乐段第几次被访问：

```m3n
{2/4} {order=A,B,A}
===A
N: 1 2 ||
L1: 春风
L2: 花开
===B
N: 3 4 |||
L: 吹来
```

第一次访问 A 唱“春风”，B 唱“吹来”，再次访问 A 唱“花开”。多次访问共用同一歌词时，使用单行 `L:`。

### 5.2 演奏顺序的完整限制

**声明与名称：**

- `order` 只能在首部声明一次，最多列出 256 次乐段访问。
- 所有小节必须属于具名乐段，每个乐段名称唯一，且至少在顺序中出现一次。
- 弱起写在对应乐段开头，不能单独拆成 Intro 或放在所有具名乐段之外。

**反复与房子：**

- 段内可以使用成对、非嵌套反复线及其跳房子，每次访问乐段都从第一遍重新开始。
- 反复和房子不能跨具名乐段边界。
- 每小节的歌词遍次同时计入段内反复和整段再现。
- 不含段内反复的乐段可以按访问次数选择结尾，见[§5.3](#53-按乐段访问次数选择结尾)。
- 不能与 D.S.、D.C.、Fine 混用。

**边界与设置：**

- 乐段边界通常放在完整小节之间。
- 允许同段首尾、实际演奏顺序中相邻段的边界，或全曲首尾互补的弱起；跨段不完整小节必须在每次实际访问时互补。
- 全曲开头的弱起可随所在乐段重现，按实际时值播放，不自动补休止。
- 延音和区间标记不能跨段。
- 乐段须以普通音符或休止符开头；多小节休止可以放在段内。
- 重新进入乐段时，调号、拍号、速度和力度恢复为该段在源码中起点的状态。

未声明 `order` 时，按书写顺序及小节线反复、跳房子、导航记号播放。

### 5.3 按乐段访问次数选择结尾

没有段内反复线时，乐段末尾的房子编号表示第几次访问该乐段。

```m3n
{2/4} {order=A,B,A}
===A
N: 1 2 |
---V1
N: 3 4 ||
---V2
N: 5 6 ||
===B
N: 7 1e |||
```

实际演奏为：A 第一次 `1 2 | 3 4` → B `7 1e` → A 第二次 `1 2 | 5 6`。

- 房子只选择本次访问的结尾，不触发额外回跳。
- 所有房子必须位于乐段末尾，遍次不能超出该段的访问次数，并且不重不漏地覆盖全部访问。
- 多个访问共用结尾时可写 `---V1,V3`。
- 每次选择的结尾都须满足弱起互补规则。
- 有成对反复线时，房子仍按段内反复遍次解释，每次访问从第一房子开始；不能混用两种解释。

### 5.4 替代旋律

重复演奏时，如果只改少数小节，可在当前乐句加入替代行：

```text
Ns[遍次]: 起始小节号: 旋律
```

```m3n
{2/4}
N: ||: 1 2 | 3 4 :|||
Ns[2]: 2: (5 6) 7 |
```

第一遍演奏 `1 2 | 3 4`，第二遍演奏 `1 2 | (5 6) 7`。第二小节的两种写法都占两拍。

**编号与显示：**

- 起始小节号为正整数，从当前 `N:` 的第一个小节起按 1 计数。
- 遍次为 1 至 256 的整数，不能超出该小节实际演奏次数；适用于反复线和显式演奏顺序。多个遍次用逗号分隔，如 `Ns[2,3]`。
- 替代旋律以括号简谱置于主旋律及其歌词下方，与主谱同字号。通常的第二遍不另标“2.”；其他分支在行首标注遍次。
- 播放、MIDI 和高亮按遍次选择对应旋律；没有歌词也可以使用。

**与歌词一起使用：**

```m3n
{2/4}
N: ||: 1 2 | 3 4 :|||
L1: 春风 | 吹来
L2: 花儿 | 轻轻开
Ns[2]: 2: (5 6) 7 |
```

第二遍的第二小节有三个音，“轻轻开”对应这三个替代音符。歌词按当遍实际选中的旋律对位。

**替换范围与限制：**

- 可以连续替换多个小节，每小节总时值必须与对应主小节相同。
- 同一小节的同一遍次不能重复指定。
- 替代旋律继承起始小节的调号、拍号、速度和八度设置。
- 允许音符、休止、分组、奏法、力度和完整区间（包括八度区间）；不允许调号、拍号、速度等谱中设置、反复、跳房子、导航或多小节休止。
- 连续替换不能跨越调号、拍号、速度或八度设置变化，遇到变化应拆成独立替代行。
- 替换范围的外侧边界不能截断主旋律延音或区间；完整包含在范围内的跨小节延音可以保留。

较大的结构差异使用跳房子或乐段演奏顺序。替代行会增加局部谱面高度。

## 6. 歌词

### 6.1 单行歌词与逐字对位

歌词行与同乐句的 `N:` 对位，写在该乐句其他补充行之后。

```m3n
{4/4}
N: 1 1 5 5 | 6 6 5^ |||
L: 一闪一闪 | 亮晶晶
```

中文按字对位，字符间的空白不占位置。可选的小节线不改变对位结果，但方便阅读，并将对位检查细化到每小节。

英文按词对位；空白用于分词，`-` 拆分音节：

```m3n
{4/4}
N: 1 1 5 5 | 6 6 5^ |||
L: Twin-kle twin-kle | lit-tle star
```

两小节各有四个、三个音；英文也分别提供四个、三个音节。

### 6.2 多遍歌词与引用

| 模式 | 写法 | 含义 |
| --- | --- | --- |
| 共用 | 单行 `L:` | 每遍都唱同一行 |
| 分遍 | `L1:`、`L2:` 等 | 每遍使用相应编号的歌词 |

同一乐句不能混用两种模式。分遍编号从 1 连续递增，行数必须等于该乐句的实际演奏遍数。

```m3n
{2/4}
N: ||: 1 2 | 3 4 :|||{x3}
L1: 春风 | 吹来
L2: 花儿 | 盛开
L3: {L1}
```

第一遍唱“春风吹来”，第二遍唱“花儿盛开”，第三遍通过 `{L1}` 再唱“春风吹来”。`{LN}` 只能引用同乐句中更早的编号歌词行。

遍次按本乐句实际经过的次数计算。反复和跳房子可能使不同乐句经过不同次数，不能直接以全曲总遍数代替；显式顺序下还要计入乐段再现，见[§5.1](#51-指定乐段演奏顺序)。

### 6.3 跳过、合字与额外对位

延音目标和休止符默认不参与歌词对位。以下写法可以调整：

| 写法 | 占用对位数 | 效果 |
| --- | --- | --- |
| `%` | 1 | 当前音符不填歌词 |
| `{%N}` | N | 连续跳过 N 个音符 |
| `(起来)` | 1 | 两字放在同一个音符下，并加下划线 |
| `+乙` | 1 | 将“乙”对位到延音目标或休止符 |

```m3n
{4/4}
N: 1 2 3 4 |||
L: 风%(吹来)了
```

第一个音唱“风”，第二个音无词，第三个音下放“吹来”，第四个音唱“了”。

```m3n
{4/4}
N: 1~ 1 2 0 |||
L: 春+风来
```

“春”对位第一个 1，“风”通过 `+` 对位延音目标，第三个音唱“来”，休止符不填词。

### 6.4 器乐区间与校验

`{inst}...{/}` 标记不唱词的器乐部分；区间内的音符不参与歌词对位。

```m3n
{4/4}
N: {inst}1 2{/} 3 4 |||
L: 春风
```

前两拍为器乐，后两拍唱“春风”。简谱用圆括号标示器乐区间，跨行或跨页时分段显示。

**对位规则：**

- 每个乐句在每一遍都必须覆盖全部可对位音符，歌词项数必须与该遍实际旋律的可对位数量一致。
- 跳房子歌词只在经过该房子的遍次生效，各房子独立计算数量。
- 播放高亮在只有第一段歌词可见时，后续反复会复用并高亮该段；存在后续段歌词时按当前遍选择，缺词处保持空白。

## 7. 和弦行

### 7.1 基本写法与时值

`C:` 显示和弦标记，不自动生成伴奏，也不改写低音行。

每个和弦符号默认占一个小节；圆括号将它的时值减半。

```m3n
{key=C} {4/4}
N: 1 2 3 4 | 5 4 3 2 |||
C: I | (IV) (V) |
```

第一小节显示 I，第二小节前半显示 IV、后半显示 V。和弦行的时值单位是小节，与旋律音符的四分音符基础时值不同。

### 7.2 和弦符号

**罗马数字：**

罗马数字按当前调号和调式取根音。大写为大和弦（`I`、`IV`、`V`），小写为小和弦（`ii`、`iii`、`vi`）。

**绝对字母：**

根音使用 `A` 至 `G`，可带一个 `#` 或 `b`。例如 `C`、`Dm`、`F#dim`，不随 `{key=...}` 改变。

两种根音写法都可附加以下后缀：

| 后缀 | 含义 |
| --- | --- |
| `m`、`m7`、`m9`、`m11`、`m13` | 小和弦及其扩展；也可用小写罗马数字 |
| `dim` | 减和弦 |
| `aug` | 增和弦 |
| `sus2`、`sus4` | 挂留和弦 |
| `7`、`9`、`11`、`13` | 属和弦 |
| `maj7`、`maj9` | 大七、大九和弦 |

**斜杠和弦与无和弦：**

`G/B` 在 `/` 后指定绝对低音；罗马和弦也可以写成 `V/B`。`N.C.` 表示没有和弦。

```m3n
{key=C} {4/4}
N: 1 2 3 4 | 5 6 7 1e | 1e 7 6 5 | 4 3 2 1 |||
C: Cmaj7 | Dm7 | G/B | N.C. |
```

### 7.3 延续与对齐

用 `~` 连接相同和弦，使时值延续：

```m3n
{4/4}
N: 1 2 3 4 | 5 4 3 2 |||
C: I~ | I |
```

I 延续两个小节。连接两端的和弦符号必须相同。

- 和弦行必须与对应旋律行的小节数一致，每小节时值总量也必须匹配。
- 小节线使用 `|`；行末可用 `||` 或 `|||` 同步标记结构结束。
- 跳房子中的和弦与对应旋律遵循相同遍次。

## 8. 低音行

### 8.1 基本写法

`B:` 显示独立低音谱表，与旋律共享调号、拍号和速度的时间轴。写在 `N:` 之后、`C:` 和歌词之前。

```m3n
{key=C} {4/4}
N: 1 2 3 4 | 5 4 3 2 |||
B: 1d^^ | 5d^^ |
```

每小节旋律演奏四个音，低音各保持四拍。

需要同时演奏多个低音时，使用和音组：

```m3n
{4/4}
N: 1 2 3 4 |||
B: [1d 3d 5d:h]^^ |
```

### 8.2 允许内容与限制

- 允许音符、休止符、和音组、连音组、圆括号、时值后缀和延音。
- 调号、拍号、速度等设置继承旋律时间轴，不在低音行独立声明。
- 不允许独立反复、跳房子、排版或演奏标记。
- 只能使用 `|`，以及行末的 `||`、`|||`，不在低音行另写反复线。
- 必须与旋律小节数量相同，每个对应小节的总时值相等。

## 9. 演奏标记

### 9.1 力度与渐变

持续力度写在音前，从后一个音乐元素起生效，直到同类设置覆盖：

`{ppp}` `{pp}` `{p}` `{mp}` `{mf}` `{f}` `{ff}` `{fff}`

```m3n
{4/4}
N: {p}1 2 {f}3 4 |||
```

前两个音弱奏，后两个音强奏。

| 区间 | 含义 | 显示 |
| --- | --- | --- |
| `{cresc}...{/}` | 渐强 | 发夹 |
| `{decres}...{/}` | 渐弱 | 发夹 |
| `{cresc=text}...{/}` | 渐强 | 文字 |
| `{dim=text}...{/}` | 渐弱 | 文字 |

```m3n
{4/4}
N: {cresc}1 2 3 4{/} | {decres}5 4 3 2{/} |||
```

第一小节渐强，第二小节渐弱。区间也可以只包含一个音，显示为该音时值内的短发夹。

### 9.2 连奏

`{lg}...{/}` 为区间内的音符添加连奏标记。

```m3n
{4/4}
N: {lg}1 2 3 4{/} |||
```

四个音属于同一个连奏乐句。同音持续使用 `~`；连奏区间中仍可以包含必要的同音延音。

### 9.3 后置奏法与指法

后置标记紧跟其作用的音符或和音组：

```m3n
{4/4}
N: 1{tip} 2{hold} 3{str} 4{fermata} |||
```

四个音依次标记为跳音、保持音、重音、延长记号。

| 标记 | 含义 | 限制或说明 |
| --- | --- | --- |
| `{sfz}` | 突强 | — |
| `{arp}` | 琶音 | 仅用于和音组 |
| `{tr}` | 颤音 | — |
| `{prall}` | 上波音 | 本音、调内上方二度、本音；当前播放保留主音，尚不展开辅助音 |
| `{str}` | 重音 | — |
| `{brk}` | 琶音记号 | — |
| `{tip}` | 跳音 | — |
| `{hold}` | 保持音 | — |
| `{fermata}` | 延长记号 | — |
| `{breath}` | 换气记号 | — |
| `{f1}` 至 `{f5}` | 指法 1 至 5 | — |

后置标记只能作用于有音高的普通音符或和音组；休止、多小节休止和连音组中的音符不能作为目标。连续写多个后置标记时，它们作用于同一个目标，例如 `1{tip}{f1}`。

### 9.4 倚音

倚音也是后置标记：`{ac(音高序列)}` 为短倚音，`{ap(音高序列)}` 为长倚音。

```m3n
{4/4}
N: 1{ac(7d)} 2 3 4 |||
```

在主音 1 上添加短倚音 7d。短倚音不改变主音时值；改为 `1{ap(7d)}` 则为长倚音，从主音借用时值。

- 括号可以嵌套，必须成对，最内层至少有一个音高。
- 每增加一层括号，单个倚音时值减半。
- 括号内不能包含休止、时值后缀或其他指令。

### 9.5 区间的关闭与嵌套

力度渐变、连奏、八度、器乐和速度渐变等区间都必须显式关闭。

```m3n
{4/4}
N: {lg}1 {cresc}2 3{/cresc} 4{/lg} |||
```

连奏覆盖四个音，渐强只覆盖中间两个音。

- `{/}` 关闭最近打开、尚未关闭的区间。
- `{/名称}` 关闭最近打开的同名区间，例如 `{/lg}`；名称必须与当前最内层区间一致。
- 不能缺失关闭、多写关闭或交叉关闭。先打开的区间必须后关闭。

## 10. 文字与排版

### 10.1 位置文字

`{text=内容}` 在当前位置添加文字，内容不能为空，不改变音符时值。

```m3n
{4/4}
N: {text=自由地}1 2 3 4 |||
```

在旋律起始位置显示“自由地”。文字只作提示；改变播放速度应使用 qpm 或速度渐变指令。

### 10.2 换行与段名显示

`{br}` 强制简谱在当前位置换行：

```m3n
{4/4}
N: 1 2 3 4 | {br}5 4 3 2 |||
```

第二小节另起一行。普通文本换行不强制谱面换行；`---` 用来划分乐句。

具名乐段默认另起一行，名称以方框显示在音符同行的行首，段间增加留白。若希望段名独占上方一行，将 `{br}` 直接加在段名之后：

```m3n
{4/4}
===练习一{br}
N: 1 2 3 4 |||
```

段名和后面的音乐分行显示，分页时段名与首个谱行保持在一起。演奏顺序顶部的段名也使用方框，箭头在框外，长顺序自动折行。

### 10.3 行内小节等宽

在文档首部设置 `{equal-measures=true}`，让每一谱行的小节占用相同横向宽度。

```m3n
{equal-measures=true} {4/4}
N: 1^^ | (1 2) (3 4) (5 6) (7 1e) | 1 2 3 4 |||
```

如果三小节排在同一行，即使音符数量不同，它们仍占相同宽度；每小节内部继续按时值、歌词和音乐记号排列。

- 省略或写 `{equal-measures=false}` 时关闭。
- 每份文档只能声明一次，仅接受小写 `true` 或 `false`，不能在正文中途切换。
- 不同谱行可以有不同小节数；自动换行依据该行最密小节所需的宽度分配容量。过密的单小节仍可在完整节拍处分行。
- 显式换行、反复、跳房子和播放顺序保留；该设置不改变音高或演奏时值。

## 11. 规则速查

### 11.1 术语

| 术语 | 本手册中的含义 |
| --- | --- |
| 乐句 | 以一条 `N:` 为核心，包含其补充行的书写单位 |
| 乐段 | 由 `===` 开始，包含一个或多个乐句的单位 |
| 音乐原子 | 占用时间轴的元素：音符、休止符、分组或多小节休止 |
| 分组 | 和音组或连音组 |
| 验证单位 | 整份乐谱；独立检查小节时值与结构规则的范围 |
| 区间 | 开始指令与对应关闭指令之间的内容，可以嵌套 |
| 指令 | 以 `{内容}` 书写的控制元素 |

### 11.2 指令分类

| 类别 | 作用 | 例子 |
| --- | --- | --- |
| 信息 | 文档首部，每个字段至多一次 | `{title=标题}` |
| 排版 | 文档首部声明，作用于整份简谱 | `{equal-measures=true}` |
| 状态 | 从后一个音乐元素起持续生效，直到同类设置覆盖 | `{key=D}`、`{mf}` |
| 后置 | 作用于紧邻的前一个有音高音符或和音组 | `5{tr}`、`1{sfz}` |
| 位置 | 作用于当前位置，不改变时值 | `{br}`、`{text=自由地}` |
| 区间 | 作用于开始与关闭指令之间的内容 | `{cresc}1 2{/}`、`{8va}1 2{/}` |

### 11.3 指令适用行

| 指令 | N: | B: | C: | L: |
| --- | --- | --- | --- | --- |
| 信息与首部排版设置 | 放在文档首部 | — | — | — |
| 状态：调号、拍号、速度、力度 | 可以 | 继承 | — | — |
| 后置：sfz、tr、arp、tip 等 | 可以 | — | — | — |
| 位置：br、text | 可以 | — | — | — |
| 区间：cresc、lg、8va、inst 等 | 可以 | — | — | — |

`===`、`---`、`---V1` 等是独立的结构分隔符，不属于上述任何一行。歌词中的引用和对位指令使用[§6](#6-歌词)的专门规则。

### 11.4 形式语法记法

本节用于核对结构。`*` 表示零次或多次，`?` 表示可选，方括号表示可选部分，尖括号内为需要填写的值。

```text
文档       = 首部 (乐段分隔)? 乐句组 (乐段分隔 乐句组)*
首部       = (信息字段 | 初始设置 | 演奏顺序 | 排版设置)*
乐段分隔   = === [名称]
乐句组     = (乐句分隔)? 乐句 (乐句分隔 乐句)*
乐句分隔   = --- [跳房子标记]
跳房子标记 = V<正整数> (,V<正整数>)*
音高       = <音级><变音?><八度?>
调号       = {key=<主音><调式?>}
拍号       = {<正整数>/<2的幂>}
速度       = {<正整数>qpm}
```

语法中的方括号表示可选内容；实际旋律中的 `[...]` 是和音组或连音组，按[§2.6](#26-和音组)和[§2.7](#27-连音组)解释。

### 11.5 错误分类

以下错误应报告，不应静默忽略。诊断会指出源码位置和违反的规则。

| 简写 | 类别 | 检查范围 |
| --- | --- | --- |
| P | 配对 | 圆括号闭合、区间关闭、反复线匹配 |
| S | 结构 | 行类型与顺序、终止线位置、乐段定义与引用、跳房子遍次覆盖 |
| V | 取值 | 指令名称、调号、拍号、速度、分组模式、和弦符号、遍次、信息与文本值 |
| M | 语义 | 小节时值、延音目标、拍号位置、歌词对位、和弦与低音行对齐 |
| R | 约束 | 后缀顺序、分组和倚音内容、变音与八度方向、标记附着位置 |
| L | 歌词 | 遍次范围或重叠、项目分隔、`+` 目标、歌词与演奏路径的对位数量 |
