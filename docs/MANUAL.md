# M3N 手册

> [返回简介](README.md)

本手册是 M3N v0.2 唯一的规范性参考，定义 M3N 的语法、语义和校验约束，面向需要准确查询规则的用户。首次使用 M3N 时，建议先阅读 [M3N 指南](GUIDE.md)。

《简介》和《指南》分别承担概览与教学功能，不新增或改变语法规则；当其他文档的简化说明与本手册存在歧义时，以本手册为准。

---

### 1. 文档结构

#### 1.1 文件与空白

- M3N 使用 UTF-8 纯文本，扩展名为 `.m3n`。
- 在乐谱正文中，音符、指令、小节线等元素之间的空格、Tab 和换行只用于排版，不改变音乐含义。
- 大括号内部的空白属于指令内容，由具体指令解释。例如，乐谱信息中的空白是字段值的一部分，`{parts=A B A C}` 中的空白用于分隔乐段名称。
- 音符分组和装饰音的元素序列中，元素之间的空白无语义。
- 歌词块中的歌词项必须使用半角空格分隔。
- `//` 从当前位置注释到行尾，注释内容不参与解析。

#### 1.2 文档组成

```
乐谱信息（可选）
乐谱正文（设置、音符、结构和演奏标记）
补充块（可选，歌词块以及至多一个低音谱表块）
```

- 未声明设置时，默认调号为 `{key=C}`、拍号为 `{4/4}`。
- 未声明速度时，M3N 不指定播放速度，由渲染器决定。
- 未使用具名乐段时，正文必须以唯一的 `|||` 或 `:|||` 结束。
- 使用具名乐段时，所有 `part` 定义关闭即表示正文结束，乐段内不使用终止线。
- 补充块只能写在正文结束之后。

#### 1.3 指令与块

M3N 指令统一写在大括号中。不同指令具有不同的作用方式，其中区间指令和补充块必须成对出现：

| 类型 | 作用方式 | 示例 |
| :--- | :--- | :--- |
| 乐谱信息 | 描述整份文档，同一字段只声明一次 | `{title=欢乐颂}` |
| 状态指令 | 从当前位置生效，直到被同类指令覆盖或当前状态作用域结束 | `{key=C}`、`{120qpm}`、`{mf}`、`{chord=V}` |
| 前置指令 | 写在目标之前，只作用于该目标 | `{sfz}5`、`{sfz}[135:h]` |
| 后置指令 | 写在目标之后，只作用于该目标 | `5{tr}`、`[135:h]{ac(2)}` |
| 位置点指令 | 作用于其书写位置，不附着音乐原子 | `{br}`、`{text=自由地}` |
| 区间指令 | 作用于一段内容，开始时入栈并在结束处关闭 | `{lg}1 2 3{/}`、`{part=A}...{/}` |
| 补充块 | 包含另一类文档内容，开始时入栈并在结束处关闭 | `{lyrics}...{/}`、`{bass}...{/}` |

乐谱信息、状态指令、前置指令、后置指令和位置点指令不入栈，也不需要关闭。所有区间块和补充块共用一个栈，遵循后进先出规则。

`{/}` 是匿名关闭指令，总是关闭栈顶块。`{/名称}` 是具名关闭指令：
```m3n
{cresc}{lg}(1 2 3 4 5 6 7 1e) | (1e 7 6 5 4 3 2 1){/}{/cresc} |||
```

缺少关闭指令、没有对应开始指令的关闭，以及具名关闭与栈顶名称不一致，均为语法错误。

### 2. 乐谱信息

| 字段 | 含义 |
| :--- | :--- |
| `{title=...}` | 标题 |
| `{subtitle=...}` | 副标题 |
| `{composer=...}` | 作曲者 |
| `{lyricist=...}` | 作词者 |
| `{arranger=...}` | 编曲者 |
| `{copyright=...}` | 版权 |
| `{source=...}` | 来源 |
| `{note=...}` | 备注 |
| `{transpose=N}` | 播放移调，单位为半音 |

`transpose` 的值为整数；正数升高，负数降低，`0` 表示不移调。该指令改变播放音高，不改写 M3N 音符。

谱面头部依次显示标题、副标题；其下第一行左侧为移调、右侧为作曲者，第二行左侧为具名乐段顺序、右侧为编曲者。系统语言为中文时字段标签使用中文，其他语言统一使用英文，例如“作曲者：...”或“Composer: ...”。作词、版权、来源和备注仍会保存为乐谱元数据，但不在谱面头部占用空间。

乐谱信息必须写在第一个音乐原子之前，同一字段只能声明一次。第一个 `=` 用于分隔字段名和值，值从 `=` 后开始，到 `}` 前结束；值不能为空，内部空格会被保留。M3N v0.2 不提供 `}` 的转义，因此字段值不能包含 `}`。

示例：
```m3n
{title=标题} {subtitle=副标题}
{composer=作曲者} {lyricist=作词者}
{arranger=编曲者} {copyright=版权}
{source=来源} {note=备注}
{transpose=2}

{key=C} {4/4} {120qpm}
1 2 3 4 | 5 6 7 1e |||
```

### 3. 乐曲设置

乐曲设置从声明位置生效，持续到同类设置再次出现或当前状态作用域结束。未使用具名乐段时，乐谱正文是一个状态作用域；使用具名乐段时，状态作用域按照第 7.3 节确定。低音谱表按照正文时间轴共享调号、拍号和速度，具体规则见第 9.2 节。

#### 3.1 调号

语法为 `{key=<音名><调式后缀>}`。音名使用大写 A 至 G，可带一个升号 `#` 或降号 `b`；调式后缀使用小写。

音名规定音级 `1` 对应的音高，调式后缀规定调式。

下表以主音为 `0`，列出音级 `1` 至 `7` 相对主音的半音位置：

| 后缀 | 调式 | 音级半音位置 | 示例 |
| :--- | :--- | :--- | :--- |
| 无 | 大调 | `0 2 4 5 7 9 11` | `{key=C}` |
| `dor` | 多利亚 | `0 2 3 5 7 9 10` | `{key=Ddor}` |
| `phr` | 弗里几亚 | `0 1 3 5 7 8 10` | `{key=Ephr}` |
| `lyd` | 利底亚 | `0 2 4 6 7 9 11` | `{key=Flyd}` |
| `mix` | 混合利底亚 | `0 2 4 5 7 9 10` | `{key=Gmix}` |
| `m` | 自然小调 | `0 2 3 5 7 8 10` | `{key=Am}` |
| `loc` | 洛克里亚 | `0 1 3 5 6 8 10` | `{key=Bloc}` |

调号从后方第一个音乐原子开始生效，持续到下一个调号或当前状态作用域结束。调号变化会清除当前小节的临时变音状态。

```m3n
{180qpm}
// 不同音名
{key=C} (1 2 3 4 5 6 7 1e) | (1e 7 6 5 4 3 2 1) ||
{key=D} (1 2 3 4 5 6 7 1e) | (1e 7 6 5 4 3 2 1) ||
{key=F} (1 2 3 4 5 6 7 1e) | (1e 7 6 5 4 3 2 1) ||
{key=G} (1 2 3 4 5 6 7 1e) | (1e 7 6 5 4 3 2 1) ||
{key=Bb} (1 2 3 4 5 6 7 1e) | (1e 7 6 5 4 3 2 1) ||
// 不同调式
{key=C} (1 2 3 4 5 6 7 1e) | (1e 7 6 5 4 3 2 1) ||
{key=Cdor} (1 2 3 4 5 6 7 1e) | (1e 7 6 5 4 3 2 1) ||
{key=Cm} (1 2 3 4 5 6 7 1e) | (1e 7 6 5 4 3 2 1) |||
```

#### 3.2 拍号

拍号语法：`{每小节中单位拍的数目/单位拍的音符时值}`

分子必须为正整数；分母必须是 2 的非负整数次幂，以对应可表示的音符时值，例如 `1`、`2`、`4`、`8`、`16`。因此 `{3/3}` 非法，因为不存在三分音符。

M3N 以四分音符时值为 `1`，拍号 `{N/D}` 规定每小节的容量为 `N × 4 / D`。拍号指令只能写在乐谱或具名乐段的第一个音乐原子之前，或者小节线之后、下一个音乐原子之前；不得在尚未结束的小节中改变拍号。

```m3n
// 常见拍号
{4/4} 5 5 5 5 | {2/4} 5 5 | {2/2} 5 5 5 5 |
{3/4} 5 5 5 | {6/8} (5 5 5) (5 5 5) |||
```

#### 3.3 速度

速度语法为 `{Nqpm}`，其中 `N` 是正整数，`qpm` 使用小写。`qpm` 表示每分钟四分音符数（quarter notes per minute），其含义不随拍号改变。速度从后方第一个音乐原子开始生效，持续到下一个速度指令或当前状态作用域结束。

渐快和渐慢使用区间指令：`{accel=N}...{/}` 和 `{rit=N}...{/}`，`N` 是目标速度。它们从区间起点的当前速度平滑变化到目标速度，并在区间结束后保持目标速度；谱面分别显示 `accel.` 和 `rit.`。低音谱表与正文同步使用该速度变化。

```m3n
// 速度变化
{120qpm} (1234)(5671e) |
{60qpm} (1234)(5671e) |

// 渐快与渐慢
{120qpm} {accel=144}1 2 3 4{/} |
{rit=96}5 4 3 2{/} |||
```

### 4. 音符

#### 4.1 音符结构

音乐原子是占据书写时间轴的基本单位，包括普通音符、休止符、和音组、连音组和多小节休止。圆括号用于改变其中音乐原子的基础时值；指令、小节线和装饰音不属于音乐原子。

普通音符及音符分组中的音高按以下顺序书写：

```text
音高 = <音级><临时变音?><八度修饰?>
```

各类音乐原子的完整形式如下。`*` 表示前一元素可以不出现或重复出现，`?` 表示最多出现一次。

| 类型 | 完整形式 |
| :--- | :--- |
| 普通音符 | `<音高><^*><.*><~?>` |
| 休止符 | `0<^*><.*>` |
| 和音组 | `[<音高><音高>...:h]<^*><.*><~?>` |
| 连音组 | `[<音高或休止符><音高或休止符>...:<正整数>]<^*><.*>` |
| 多小节休止 | `{rest=<正整数>}` |

临时变音、八度修饰和时值后缀的内部规则分别见第 4.2、4.3 节。音符分组至少包含两个组内元素，具体规则见第 4.4 节。多小节休止按完整小节计，不使用圆括号或时值后缀。

#### 4.2 音高

| 元素 | 写法 | 说明 |
| :--- | :--- | :--- |
| 音级 | `1 2 3 4 5 6 7` | 首调音级 |
| 升号 | `#` | 相对音级的默认音高升高半音，最多重升 `4##` |
| 降号 | `b` | 相对音级的默认音高降低半音，最多重降 `7bb` |
| 还原号 | `=` | 恢复音级的默认音高 |
| 高八度 | `e` | elevate，升高一个八度，可叠加 |
| 低八度 | `d` | descend，降低一个八度，可叠加 |
| 休止符 | `0` | 无音高，参与时值计算 |
| 高八度区间 | `{8va}`...`{/}` | 区间内所有音提高八度 |
| 低八度区间 | `{8vb}`...`{/}` | 区间内所有音降低八度 |

规则：

- M3N 使用科学音高记法，C4 是中央 C。未带八度修饰的音级 `1` 使用主音在 C4 至 B4 这一记名八度中的位置，音级 `2` 至 `7` 从主音向上排列，跨过 C 时进入下一八度。
- 音级的默认音高由当前位置的调号和调式决定，`#`、`b` 和 `=` 均以此为基准。
- 升号和降号可以分别叠加至多两个，但不能混用；还原号 `=` 只能单独出现一次。
- `4##`、`7bb` 和 `2=` 合法；`4#b`、`4#=` 和 `4==` 非法。
- 临时变音持续影响当前小节内相同音级和八度的后续音符。相同音级和八度出现新的临时变音时，新状态替换旧状态；小节线或调号变化会清除临时变音状态。
- 例如在 D 大调中，音级 `3` 默认为 F♯；`3b` 表示 F，后续的 `3=` 恢复为 F♯。
- 八度修饰只作用于当前音符，每个 `e` 升高一个八度，每个 `d` 降低一个八度。同一音符只能选择一个方向：`1ee` 和 `1dd` 合法，`1ed` 非法。
- `{8va}` 和 `{8vb}` 是区间指令，使区间内所有有音高的音乐原子分别升高或降低一个八度，并遵守统一的栈式关闭规则。
- 八度区间可以嵌套，也可以与音符自身的 `e`、`d` 叠加，效果按八度累加。休止符不受八度修饰和八度区间影响。

示例：
```m3n
1 2 3 4 |
// 临时变音持续生效
1# 2b 1 2 |
// 临时变音叠加还原
1## 2bb 1= 2= |
// 八度修饰
1dd 1d 1e 1ee |
// 八度区间嵌套
{8va}1 {8va}2{/} 3{/} 4 |
{8vb}3 2 1^{/}|||
```

#### 4.3 时值

普通音符、休止符和音符分组使用同一套时值系统。当前位置的一份基础时值默认为四分音符，通过圆括号和时值后缀进行修改。多小节休止按照第 7.5 节以完整小节为单位计算。

| 写法 | 含义 | 以四分音符为基准 |
| :--- | :--- | :--- |
| `1` | 四分音符 | 1 倍 |
| `(1)` | 括号内时值减半 | 1/2 倍 |
| `((1))` | 减半两次 | 1/4 倍 |
| `(((1)))` | 减半三次 | 1/8 倍 |
| `1^` | 时值翻倍 | 2 倍 |
| `1^^` | 翻倍两次 | 4 倍 |
| `1.` | 附点 | 1.5 倍 |
| `1..` | 双附点 | 1.75 倍 |
| `1^.` | 先翻倍后附点 | 3 倍 |
| `5~ 5` | 延音 | 相加 |

规则：

- 时值后缀必须直接附着在音乐原子后，顺序为零个或多个 `^`、零个或多个 `.`、最多一个 `~`，即依次为 `^*`、`.*`、`~?`。
- 每层圆括号将其中音乐原子的基础时值减半。圆括号可以嵌套，但必须在同一小节内闭合，并且至少包含一个音乐原子。
- 每个 `^` 将时值翻倍。第一个附点增加当前时值的一半，后续附点依次增加前一次增量的一半。`~` 不改变单个音乐原子的时值。
- `~` 只能用于有音高的普通音符和和音组，连接紧接其后的同类音乐原子。
- 查找延音目标时忽略小节线和指令；随后遇到的第一个音乐原子是唯一候选，不能跳过它寻找更后的目标。当前校验单位结束时仍未遇到目标，延音无效。
- 普通音符的延音目标必须具有相同的绝对音高；和音组的延音目标必须包含相同的绝对音高集合。绝对音高按照调号与调式、临时变音、音符八度修饰和八度区间共同计算。
- 小节时值以未分段的乐谱正文、每个具名乐段和低音谱表块为校验单位；双谱表之间的对齐规则见第 9.2 节。
- 每个校验单位的普通小节必须恰好满拍，少拍和超拍均不合法。
- 第一个小节可以少于当前拍号规定的容量，此时它是弱起小节；最后一个小节必须用剩余时值与弱起小节共同组成一个完整小节。
- 没有弱起时，最后一个小节必须满拍；只包含一个小节的校验单位也必须满拍。
- 符杠由渲染器按拍号分组，圆括号只改变时值，不直接决定符杠。在 `4/4` 中，连续八分音符以半小节为默认单元：不跨越第 2、4 拍边界时，每 4 个八分音符连为一组。因此一小节连续 8 个八分音符通常记为 `4 + 4` 两组，适合表现加沃特等两拍律动。

示例：
```m3n
// 括号/翻倍
1 (1(1 1)) 1^ |
// 附点
1. (1) 1.. ((1)) |
// 延音
(1 2~) 2~ (2 3) 1 |
// 组合
1^.~ (1 1) |||
```

#### 4.4 音符分组

音符分组分为和音组和连音组，完整形式见第 4.1 节。

| 写法 | 含义 | 说明 |
| :--- | :--- | :--- |
| `[135:h]` | 和音组 | 3 个音同时发声，占 1 份基础时值 |
| `[123:2]` | 连音组 | 3 个元素依次发声，均分 2 份基础时值 |

模式 `h` 表示和音组，组内元素必须是至少两个有音高的音符，所有音同时发声。正整数模式表示连音组，组内至少包含两个按文本顺序发声的音高或休止符；所有元素均分整组时值。

组内元素不能使用时值后缀，也不能包含指令、圆括号或嵌套分组。分组必须完整位于同一小节内。组整体可以使用 `^` 和 `.`，也可以放在圆括号中，并按照第 4.3 节的公式计算整体时值；只有和音组可以使用 `~` 和后置指令 `{arp}`。“和音组”表示同时发声的音符，不要与第 6.4 节的和弦标记混淆。

示例：
```m3n
{3/4}
[135:h] [572e:h] [135:h] |
([135:2]) ([572e:2]) ([066:2]) |||
```

### 5. 小节线

- `|` → 普通小节线
- `||` → 双小节线（段落线）
- `|||` → 终止线
- `||:` → 前反复起点
- `:||` → 后反复终点
- `:|||` → 后反复与终止线合并
- `:||:` → 后反复结束后立即进入新前反复
- `:||{xN}`、`:||:{xN}`、`:|||{xN}` → 后反复总共演奏 N 遍

相邻的结构小节线用于组合段落和反复边界，不在两者之间产生空小节。

对未分段正文而言，`|||` 和 `:|||` 是终止线，只能在正文最后一个音乐位置出现一次。终止线之后只能出现补充块、空白和注释。具名乐段不使用终止线，以免终止语义随乐段的重复引用进入演奏序列。低音谱表块内的 `|||` 只结束该谱表，规则见第 9.2 节。

### 6. 演奏标记

#### 6.1 力度记号

`{ppp}`、`{pp}`、`{p}`、`{mp}`、`{mf}`、`{f}`、`{ff}` 和 `{fff}` 是持续力度。它们是状态指令，从后方第一个音乐原子开始生效，直到被新的持续力度覆盖。

`{sfz}` 是前置指令，只作用于后一个有音高的普通音符或和音组。它与目标之间可以有空格或注释；除此之外，后方第一个元素必须是目标。休止符、多小节休止和连音组不能作为目标。

渐强和渐弱是区间指令。

| 写法 | 含义 |
| :--- | :--- |
| `{cresc}...{/}` | 渐强区间 |
| `{decres}...{/}` | 渐弱区间 |
| `{ppp}` | 极弱 |
| `{pp}` | 很弱 |
| `{p}` | 弱 |
| `{mp}` | 中弱 |
| `{mf}` | 中强 |
| `{f}` | 强 |
| `{ff}` | 很强 |
| `{fff}` | 极强 |
| `{sfz}` | 突强 |

示例：
```m3n
{cresc}1 2 3 4{/} | {decres}5 4 3 2{/} |
{pp}1 2 3 4 | {p}5 4 3 2 |
{mp}1 2 3 4 | {mf}5 4 3 2 |
{f}1 2 3 4 | {ff}5 4 3 2 |
1 5 {sfz}[135:h]^ |||
```

#### 6.2 奏法记号

`{lg}` 是区间指令。其余奏法是后置指令，写在所修饰的有音高的普通音符或和音组之后。休止符、多小节休止和连音组不能作为目标。

目标带有时值后缀时，后置指令写在完整时值后缀之后。空格和注释不影响附着。后置指令可以连续使用并作用于同一目标；小节线、其他音乐原子、状态指令、位置点指令或区间指令会结束附着关系。

| 写法 | 含义 |
| :--- | :--- |
| `{lg}...{/}` | 连奏区间 |
| `{tr}` | 颤音 |
| `{arp}` | 琶音 |
| `{str}` | 重音 |
| `{brk}` | 断音 |
| `{tip}` | 跳音 |
| `{hold}` | 保持音 |
| `{fermata}` | 延长记号 |
| `{breath}` | 呼吸记号 |
| `{f1}` 至 `{f5}` | 指法 |

`{arp}` 只能附在和音组后，表示从低到高依次奏出和音中的音。播放时，`{brk}` 的发音比 `{tip}` 更短，`{tip}` 会缩短发音时值，`{str}` 会提高力度；`{hold}` 保持其书写时值。

示例：
```m3n
{lg}1 1 1 1{/} |
5{tr} 5{tr} 5{tr} 5{tr} |
[135:h]{arp} [135:h]{arp} [135:h]{arp} [135:h]{arp} |
5{str} 5{str} 5{str} 5{str} |
5{brk} 5{brk} 5{brk} 5{brk} |
5{tip} 5{tip} 5{tip} 5{tip} |
5{hold} 5{hold} 5{hold} 5{hold} |
5{fermata} 5{fermata} 5{fermata} 5{fermata} |
5{breath} 5{breath} 5{breath} 5{breath} |
5{f1} 5{f2} 5{f3} 5{f4} |||
```

#### 6.3 装饰音

| 写法 | 名称 | 说明 |
| :--- | :--- | :--- |
| `{ac(...音高...)}` | 短倚音 | acciaccatura，带斜线小音符，目标时值不变 |
| `{ap(...音高...)}` | 长倚音 | appoggiatura，不带斜线，从目标借用时值 |

装饰音是后置指令，写在所修饰的有音高的普通音符或和音组之后，遵守第 6.2 节的附着规则。休止符、多小节休止和连音组不能作为目标。`ac` 或 `ap` 后必须跟同层配对的一组或多组圆括号，最内层包含 N 个音高（N >= 1），不允许休止符、时值后缀或其他指令。圆括号每增加一层，每个倚音的时值减半：`{ac(2)}` 的单倚音为八分音符，`{ac((34))}` 的两个倚音各为十六分音符。短倚音不改变主音时值；长倚音从主音借用时值。

示例：
```m3n
{key=C} {4/4}
3{ac(2)} 3{ac(2)} 3{ac(2)} 3{ac(2)} |
5{ac((34))} 5{ac((34))} 5{ac((34))} 5{ac((34))} |
5{ap(6)} 5{ap(6)} 5{ap(6)} 5{ap(6)} |||
```

#### 6.4 和弦标记

和弦标记的语法为：

```text
{chord=<级数><后缀?>}
```

级数只能是 `I`、`II`、`III`、`IV`、`V`、`VI`、`VII` 或对应的小写形式。后缀是可选部分，最多出现一次：

| 后缀 | 和弦性质 |
| :--- | :--- |
| 无 | 大写级数表示大和弦，小写级数表示小和弦 |
| `m` | 小和弦 |
| `dim` | 减和弦 |
| `aug` | 增和弦 |
| `sus2` | 挂二和弦 |
| `sus4` | 挂四和弦 |
| `N`，其中 `N` 是 2 至 13 的整数 | 在级数大小写规定的和弦性质上添加数字扩展 |

和弦根音取当前调号和调式中对应音级的默认音高，包括调号本身规定的升降变化。

和弦标记是状态指令，从后方第一个音乐原子开始生效，持续到下一个和弦标记或当前状态作用域结束。调号改变后，正在持续的罗马级数从后方第一个音乐原子开始按照新调号和调式重新换算。

| 写法 | 含义 | C 调示例 |
| :--- | :--- | :--- |
| `I` | 大三和弦 | C |
| `ii` | 小三和弦 | Dm |
| `iii` | 小三和弦 | Em |
| `IV` | 大三和弦 | F |
| `V` | 大三和弦 | G |
| `vi` | 小三和弦 | Am |
| `viidim` | 减三和弦 | Bdim |
| `V7` | 大五级和弦添加 7 扩展 | G7 |
| `vi7` | 小六级和弦添加 7 扩展 | Am7 |

示例：

```m3n
{key=C} {4/4}
{chord=I}0^^ | {chord=V}0^^ | {chord=vi}0^^ | {chord=IV}0^^ |
{chord=I}0^^ | {chord=V}0^^ | {chord=ii}0^^ | {chord=V}0^^ |||
```

这是常用的 `15634125` 进行。在 C 大调中依次为 C、G、Am、F、C、G、Dm、G；`0^^` 是一个完整的四分之四拍休止小节，便于只观察和弦标记。

### 7. 乐曲结构

#### 7.1 小节线反复

`||: ... :||` 构成一个反复区域。演奏到后反复线时，从与其配对的前反复线开始再次演奏该区域，默认总共演奏两遍。紧跟后反复线的 `{xN}` 将总遍数改为 N；N 必须是大于等于 2 的整数。

反复区域以未分段正文或每个具名乐段为校验单位，不能跨越单位边界，也不能嵌套或重叠。后反复线没有对应的前反复线时，使用当前校验单位的开头作为隐式起点；每个校验单位最多使用一次隐式起点。

`:||:` 在同一个小节边界关闭当前反复并立即开启下一个反复。它只连接两个首尾相接的反复，不产生空小节，也不构成嵌套。`:|||` 关闭当前反复并同时结束乐谱正文。

示例：
```m3n
1 2 3 4 :||{x3} 5 4 3 2 ||: 1 2 3 4 :||: 5 3 1^ :|||
```

#### 7.2 不同结尾

`volta` 的参数是遍次范围，规定该结尾在哪些遍次使用：

| 写法 | 含义 |
| :--- | :--- |
| `{volta=N}` | 第 N 遍使用的结尾 |
| `{volta=N,M}` | 第 N、M 遍使用的结尾 |
| `{volta=N~M}` | 第 N 到第 M 遍使用的结尾 |
| `{volta=X,N~M}` | 第 X 遍以及第 N 到第 M 遍使用的结尾 |

遍次范围的语法为：

```text
遍次范围 = 范围项 ("," 范围项)*
范围项   = 正整数 | 正整数 "~" 正整数
```

闭区间的起点必须小于终点。将所有范围项展开后，遍次必须严格递增，因此同一个表达式中不能出现重复或重叠的遍次。

`volta` 是区间指令，不同 `volta` 不能嵌套。每个 `volta` 必须在对应结尾之后关闭；关闭指令与随后的后反复线、双小节线或终止线之间只包含空白或注释。同一反复结构中的不同 `volta` 必须具有互不重叠的遍次范围。

示例：

```m3n
3 3 4 5 | 5 4 3 2 | 1 1 2 3 |
{volta=1}3. (2) 2^{/} :||
{volta=2}2. (1) 1^{/} |||
```

#### 7.3 具名乐段

使用 `{part=名称}...{/}` 定义具名乐段，通过 `{parts=名称 名称 ...}` 指定演奏顺序。

乐段名称区分大小写，是不含空白、`{`、`}` 或 `=` 的非空文本。顺序表至少包含一个名称，同一名称可以出现多次。

`{parts=...}` 只能声明一次，必须写在第一个 `part` 或音乐原子之前。只要使用 `part`，就必须提供顺序表；每个名称只能定义一次，每个定义至少被引用一次，每个引用也必须存在对应定义。乐段定义的书写顺序不影响演奏顺序。

`part` 是只能出现在乐谱正文顶层的区间指令，不能嵌套，也不能被其他区间块包裹；其他区间块可以写在 `part` 内。使用具名乐段后，所有音乐内容都必须位于某个 `part` 内，每个乐段至少包含一个音乐原子，并且不能包含 `|||` 或 `:|||`。第一个 `part` 开始后，正文阶段的顶层只能继续出现 `part` 定义、空白和注释；所有乐段定义关闭后，可以直接进入补充块区域。

第一个 `part` 之前的状态指令构成所有乐段共同的初始状态。每次进入乐段时，都从这份初始状态开始；乐段内部的状态变化在离开该乐段时结束，不影响其他乐段。每个乐段独立校验小节、弱起和延音，不能跨乐段连接。

示例：
```m3n
{key=C} {4/4}
{parts=A B A}

{part=B}
{key=G} 5 4 3 2 ||
{/}

{part=A}
1 2 3 4 ||
{/}
```

该例先定义 B，再定义 A，但演奏顺序为 A、B、A。B 内的 G 调在离开 B 时结束，两次进入 A 都使用共同初始状态中的 C 调。

#### 7.4 反复导航

`{segno}`、`{ds}`、`{dc}` 和 `{fine}` 是基础反复导航标记。`segno` 写在后方第一个音乐原子之前；`ds`、`dc` 与 `fine` 写在对应位置的最后一个音乐原子之后。播放到 `fine` 的位置时立即停止。

`{ds}` 跳回唯一的 `segno`，`{dc}` 跳回乐谱开头。两者只执行一次；回跳后遇到 `{fine}` 时停止。导航标记不能用于低音谱表，`segno` 最多出现一次，`ds` 与 `dc` 总共最多出现一次。

```m3n
{4/4}
{segno}1 2 3 4 |
5 6 7 1e{fine} |||
1e 7 6 5{ds} ||
```

#### 7.5 多小节休止

`{rest=N}` 是一个完整的音乐原子，表示连续休止 `N` 个小节，`N` 必须是正整数。它必须独占一个小节位置，不能与普通音符、音符分组或另一个 `{rest=...}` 共同占据该位置。

```m3n
{key=C} {4/4}
1 2 3 4 | {rest=4} | 4 3 2 1 |||
```

### 8. 排版与标注

`{br}` 和 `{text=...}` 是位置点指令，作用于其书写位置，不附着音乐原子，也不影响节拍。它们可以写在小节线前后，不要求存在相邻音符。

- `{br}` 建议渲染器在当前位置换行。
- `{text=...}` 在当前位置补充谱面文字。第一个 `=` 分隔指令名和值，值从其后开始，到 `}` 前结束；值不能为空，也不能包含 `}`。

```m3n
{key=C} {4/4}
{text=主题}1 2 3 4 |{br}
{text=自由地}4 3 2 1 |||
```

### 9. 补充块

补充块写在乐谱正文结束后，是互不嵌套的顶层同级块，排列顺序不改变语义。第一个补充块开始后，不能再出现乐谱正文内容。每个补充块都必须按照第 1.3 节的规则关闭。

#### 9.1 歌词块

| 元素 | 说明 |
| :--- | :--- |
| 普通歌词项 | 消耗一个歌词位置并显示文字 |
| `%` | 消耗一个歌词位置，不显示文字 |
| `-` | 将一个英文单词拆分为音节，每个音节依次消耗一个歌词位置 |

规则：

- 歌词项必须使用半角空格分隔。
- 有音高的普通音符和和音组各产生一个歌词位置。
- 连音组中的每个有音高元素各产生一个歌词位置，其中的休止符不产生歌词位置。
- 普通休止符、多小节休止和装饰音不产生歌词位置。
- 延音线连接的一串音符或和音组只在起点产生一个歌词位置。
- 多个汉字无空格时视为一个歌词项，消耗一个歌词位置。
- 歌词只与正文旋律对位，不与低音谱表对位。
- 每个歌词块的歌词项分别与各适用遍次实际经过的演奏路径对位，包括该遍进入的不同结尾；歌词项数量必须与每条路径产生的位置数相同。

带参数的歌词块使用第 7.2 节定义的遍次范围：

| 写法 | 含义 |
| :--- | :--- |
| `{lyrics=1}` | 仅第 1 遍 |
| `{lyrics=2,3}` | 第 2 和第 3 遍 |
| `{lyrics=1~3}` | 第 1 到第 3 遍 |

无参数的 `{lyrics}` 适用于全部遍次。每份文档可以包含多个歌词块；存在多个歌词块时，每个块都必须指定遍次，并且各块的有效遍次范围必须两两不相交。

```m3n
{key=C} {4/4}
1 1 5 5 | 6 6 5^ |
4 4 3 3 | 2 2 1^ :|||

{lyrics=1}
一 闪 一 闪 亮 晶 晶
满 天 都 是 小 星 星
{/}
{lyrics=2}
Twin-kle twin-kle lit-tle star
How I won-der what you are!
{/}
```

#### 9.2 低音谱表

`{bass}...{/}` 用于补充与正文同步演奏的低音谱表。每份文档最多包含一个非空低音谱表块。M3N v0.2 只允许低音谱表与未使用具名乐段的正文组合。

低音谱表与正文共享同一条书写时间轴。两者不要求音乐原子一一对应，但必须具有相同数量的书写小节，并且对应小节的总时值必须相等。弱起小节参与对齐；`{rest=N}` 按连续 `N` 个小节计算。

正文中的调号、拍号和速度变化在相同音乐时间同时作用于低音谱表，这些设置只在正文声明。反复线和 `volta` 也只在正文声明，低音谱表按照正文的结构同步演奏。

低音谱表可以使用以下谱表级内容：

- 普通音符、休止符、和音组、连音组和多小节休止；
- 圆括号、时值后缀、临时变音和延音线；
- `|`、`||` 和 `|||`；
- 力度、奏法、装饰音、连奏、渐强渐弱、八度区间以及 `{text=...}`。

低音谱表中的临时变音、延音、区间和演奏状态独立于正文，并在低音谱表块结束时终止。调号、拍号、速度、和弦标记、`{br}`、反复与不同结尾、具名乐段及补充块不属于低音谱表内容。

```m3n
{key=D} {4/4}
3 3 4 5 | 5 4 3 2 | 1 1 2 3 | 2. (1) 1^ |||

{bass}
1d^^ | 5d^^ | 1d^^ | 5d^ 1d^ |||
{/}
```

### 10. 语法校验

本节规定 M3N v0.2 的主要校验类别。解析器遇到以下情况应明确报错，不得静默忽略。

#### 10.1 配对类

成对标记的闭合与匹配约束。

| 编号 | 非法语法 | 说明 |
| :--- | :--- | :--- |
| P1 | 小节内括号不匹配 | `()` 或 `[]` 在小节内未闭合 |
| P2 | 块关闭缺失 | 区间块或补充块没有对应关闭指令 |
| P3 | 块关闭冗余 | 关闭指令没有对应的开始指令 |
| P4 | 块关闭顺序错误 | 具名关闭指令与栈顶块名称不匹配 |
| P5 | 反复线不匹配 | 前反复线没有对应的后反复线，或反复线跨越校验单位边界 |

#### 10.2 结构类

文档与乐谱的整体结构约束。

| 编号 | 非法语法 | 说明 |
| :--- | :--- | :--- |
| S1 | 补充块出现在正文之前 | `{lyrics}` 或 `{bass}` 在未分段正文终止前或 `part` 定义尚未全部关闭时出现 |
| S2 | 空补充块 | 歌词或低音谱表内容为空 |
| S3 | 乐段引用不一致 | 缺少 `{parts=...}`、引用没有对应定义，或定义没有被引用 |
| S4 | 乐谱信息位置非法 | 乐谱信息出现在第一个音乐原子之后 |
| S5 | 乐段顺序位置非法 | `{parts=...}` 出现在第一个 `part` 或音乐原子之后 |
| S6 | 乐段顺序重复声明 | `{parts=...}` 在同一文档中出现多次 |
| S7 | 乐段定义重复 | 同一乐段名称定义多次 |
| S8 | 乐段层级非法 | `part` 发生嵌套或被另一个区间块包裹 |
| S9 | 乐段外正文非法 | 第一个 `part` 开始后、补充块区域开始前，正文顶层出现 `part` 定义、空白和注释以外的内容 |
| S10 | 空乐段 | `part` 内不包含音乐原子 |
| S11 | 低音谱表重复 | 同一文档中出现多个 `{bass}...{/}` 块 |
| S12 | 低音谱表与具名乐段混用 | 同一文档同时包含低音谱表块和 `part` 定义 |
| S13 | 歌词遍次重叠 | 多个歌词块的有效遍次范围发生重叠，包括无参数歌词块与其他歌词块并存 |
| S14 | 不同结尾遍次重叠 | 同一反复结构中的多个 `volta` 指定了相同遍次 |
| S15 | 反复区域重叠 | 反复区域发生嵌套或重叠，或者同一校验单位多次使用隐式起点 |
| S16 | 不同结尾位置非法 | `volta` 发生嵌套，或关闭后没有紧接后反复线、双小节线或终止线 |
| S17 | 正文终止非法 | 未分段正文缺少、重复或提前使用终止线，或者具名乐段内出现终止线 |
| S18 | 补充块后恢复正文 | 第一个补充块开始后再次出现乐谱正文内容 |

#### 10.3 取值类

指令值的格式与范围约束。

| 编号 | 非法语法 | 说明 |
| :--- | :--- | :--- |
| V1 | 未知指令 | 不支持的指令名 |
| V2 | `key` 指令格式非法 | 音名、变音记号或调式后缀不符合第 3.1 节的格式 |
| V3 | 拍号格式非法 | 拍号分子必须为正整数，分母必须为 2 的非负整数次幂 |
| V4 | 非法正整数取值 | 速度值、连音组时值份数、休止小节数等必须是正整数 |
| V5 | 分组模式非法 | 分组冒号后必须为 `h` 或正整数 |
| V6 | 和弦标记值非法 | 和弦值不符合第 6.4 节规定的级数与单个可选后缀格式 |
| V7 | 遍次范围非法 | 表达式不符合第 7.2 节的格式、区间方向或递增规则 |
| V8 | 乐谱信息值为空 | 乐谱信息的字段值不能为空 |
| V9 | 谱面文字值为空 | `{text=...}` 的值不能为空 |
| V10 | 乐段名称非法 | 乐段名称为空或包含空白、`{`、`}`、`=` |
| V11 | 移调值非法 | `transpose` 的值不是整数 |

#### 10.4 语义类

语法合法但语义矛盾的约束。

| 编号 | 非法语法 | 说明 |
| :--- | :--- | :--- |
| M1 | 小节时值不合规 | 普通小节必须恰好满拍；弱起首末小节必须互补 |
| M2 | 延音目标非法 | `~` 没有紧接的同类目标，或目标的绝对音高不一致 |
| M3 | 休止符非法属性 | 休止符使用八度修饰、临时变音、延音、奏法等与音高相关的属性 |
| M4 | 拍号位置非法 | 在尚未结束的小节中改变拍号 |
| M5 | 多小节休止位置非法 | `{rest=N}` 与其他音乐原子共同占据一个小节位置 |
| M6 | 歌词对位数量不匹配 | 歌词项数量与任一适用遍次的实际演奏路径所产生的位置数不一致 |
| M7 | 双谱表时间轴不一致 | 正文与低音谱表的小节数量不同，或对应小节的总时值不相等 |

#### 10.5 约束类

特定上下文中的限制规则。

| 编号 | 非法语法 | 说明 |
| :--- | :--- | :--- |
| R1 | 乐谱信息重复声明 | 同一字段只允许声明一次 |
| R2 | 时值后缀非法 | 后缀未直接附着在音乐原子后，或顺序不符合 `^*`、`.*`、`~?` |
| R3 | 分组内含非法元素 | 组内出现时值后缀、指令、圆括号或嵌套分组，和音组出现休止符，或连音组整体使用延音线 |
| R4 | 分组元素不足 | 和音组或连音组少于两个元素 |
| R5 | 装饰音内含非法元素 | 装饰音内出现时值后缀、奏法等非音高修饰 |
| R6 | 空装饰音 | 装饰音内至少需要一个音高 |
| R7 | 临时变音组合非法 | 同一音符混用升号、降号或还原号，或者重复使用还原号 |
| R8 | 八度方向混用 | 同一音符同时使用 `e` 和 `d`，例如 `1ed` |
| R9 | 空时值分组 | 圆括号内不包含音乐原子 |
| R10 | 后置指令位置非法 | 指令没有紧跟有音高的普通音符、和音组或作用于同一目标的后置指令 |
| R11 | 前置指令位置非法 | 指令后方第一个非空白、非注释元素不是有音高的普通音符或和音组 |
| R12 | 低音谱表内含非法元素 | 低音谱表块包含第 9.2 节规定范围之外的内容 |
| R13 | 多小节休止修饰非法 | `{rest=N}` 使用圆括号或时值后缀 |
