# M3N 手册

> [返回简介](README.md)

本手册是 M3N v0.2 唯一的规范性参考，定义 M3N 的语法、语义和校验约束，面向需要准确查询规则的用户。首次使用 M3N 时，建议先阅读 [M3N 指南](GUIDE.md)。

《简介》和《指南》分别承担概览与教学功能，不新增或改变语法规则；当其他文档的简化说明与本手册存在歧义时，以本手册为准。

---

## 1. 文档结构

### 1.1 文件与空白

- M3N 使用 UTF-8 纯文本，扩展名为 `.m3n`。
- 在乐谱正文中，音符、指令、小节线等元素之间的空格、Tab 和换行只用于排版，不改变音乐含义。
- 大括号内部的空白属于指令内容，由具体指令解释。例如，乐谱信息中的空白是字段值的一部分，`{parts=A B A C}` 中的空白用于分隔乐段名称。
- 音符分组和装饰音的音高序列中，音高之间的空白无语义。
- 歌词块中的歌词项必须使用半角空格分隔；Tab 不能作为分隔符，换行只用于组织歌词行。
- `//` 从当前位置注释到行尾，注释内容不参与解析。

### 1.2 文档组成

```
乐谱信息（可选）
乐谱正文（设置、音符、结构和演奏标记）
补充块（可选，歌词块、低音谱表块）
```

示例：

```m3n
// 乐谱信息
{title=标题} {composer=作曲者}

// 乐谱正文
{key=C} {4/4} {120qpm}
1 2 3 4 | 5 6 7 1e |||

// 补充块
{lyrics}
do re mi fa sol la si do
{/}

{bass}
1d 5d 1 5d | 1d^^ |||
{/}
```

未声明设置时，默认调号为 `{key=C}`、拍号为 `{4/4}`；速度没有默认值。正文通常以 `|||` 或 `:|||` 结束，补充块必须写在正文之后。

### 1.3 指令类型

M3N 指令统一写在大括号中。不同指令具有不同的作用方式：

| 类型 | 作用方式 | 示例 |
| :--- | :--- | :--- |
| 乐谱信息 | 描述整份文档，同一字段只声明一次 | `{title=欢乐颂}` |
| 状态指令 | 从当前位置生效，直到被同类指令覆盖 | `{key=C}`、`{120qpm}`、`{mf}`、`{chord=V}` |
| 点指令 | 只作用于当前位置或相邻音符 | `{br}`、`5{tr}` |
| 区间指令 | 作用于一段内容，开始时入栈 | `{lg}1 2 3{/}`、`{part=A}...{/}` |
| 补充块 | 包含另一类文档内容，只能写在正文之后 | `{lyrics}...{/}`、`{bass}...{/}` |

`{/}` 是匿名关闭指令，总是关闭最后开始但尚未关闭的区间或补充块。嵌套内容必须按与开始顺序相反的顺序关闭：

```m3n
{cresc}{lg}1 2 3 4{/}{/}
```

也可以使用具名关闭形式，例如 `{/lg}`。具名关闭的名称必须与栈顶指令一致，不能跨过尚未关闭的内层区间。

## 2. 乐谱信息

| 字段 | 含义 |
| :--- | :--- |
| `{title=...}` | 标题 |
| `{subtitle=...}` | 副标题 |
| `{composer=...}` | 作曲者 |
| `{lyricist=...}` | 作词者 |
| `{arranger=...}` | 编曲者 |
| `{copyright=...}` | 版权 |
| `{source=...}` | 来源 |
| `{note=...}` | 备注 |
| `{transpose=N}` | 播放移调，单位为半音 |

`transpose` 的值为整数；正数升高，负数降低，`0` 表示不移调。该指令改变播放音高，不改写 M3N 音符。

同一乐谱信息字段禁止重复声明。

## 3. 乐曲设置

乐曲设置从声明位置生效，持续到同类设置再次出现或文档结束。

### 3.1 调号

语法为 `{key=<音名><调式后缀>}`。音名使用 A 至 G，可带一个升号 `#` 或降号 `b`。

音名规定音级 `1` 对应的音高，调式后缀规定调式。

调式后缀：

| 后缀 | 调式 | 示例 |
| :--- | :--- | :--- |
| 无 | 大调 | `{key=C}` |
| `dor` | 多利亚 | `{key=Ddor}` |
| `phr` | 弗里几亚 | `{key=Ephr}` |
| `lyd` | 利底亚 | `{key=Flyd}` |
| `mix` | 混合利底亚 | `{key=Gmix}` |
| `m` | 自然小调 | `{key=Am}` |
| `loc` | 洛克里亚 | `{key=Bloc}` |

```m3n
// 不同音名
{key=Bb} (1d 2d 3d 4d 5d 6d 7d 1) |
{key=F} (1 2 3 4 5 6 7 1e) |
{key=C} (1 2 3 4 5 6 7 1e) |
// 不同调式
{key=Dm} (1 2 3 4 5 6 7 1e) |
{key=Dmix} (1 2 3 4 5 6 7 1e) |||
```

### 3.2 拍号

拍号语法：`{每小节中单位拍的数目/单位拍的音符时值}`

分子必须为正整数；分母必须是 2 的非负整数次幂，以对应可表示的音符时值，例如 `1`、`2`、`4`、`8`、`16`。因此 `{3/3}` 非法，因为不存在三分音符。

```m3n
// 常见拍号
{4/4} 5 5 5 5 | {2/4} 5 5 | {2/2} 5 5 5 5 |
{3/4} 5 5 5 | {6/8} (5 5 5) (5 5 5) |||
```

### 3.3 速度

速度语法为 `{Nqpm}`，其中 `N` 是正整数。`qpm` 表示每分钟四分音符数（quarter notes per minute），其含义不随拍号改变。

`qpm` 使用小写。`{tempo=120}`、`{120bpm}` 等形式不属于 M3N v0.2 语法。

```m3n
// 速度变化
{120qpm} (1234)(5671e) |
{60qpm} (1234)(5671e) |||
```

## 4. 音符

### 4.1 音符结构

普通音符的完整形式为：`<音级><临时变音?><八度修饰?><时值后缀?>`。各部分必须按此顺序书写。休止符以 `0` 代替音级，并且不能带音高修饰。

### 4.2 音高

| 元素 | 写法 | 说明 |
| :--- | :--- | :--- |
| 音级 | `1 2 3 4 5 6 7` | 首调音级 |
| 升号 | `#` | 升高半音，可叠加 `4##` |
| 降号 | `b` | 降低半音，可叠加 `7bb` |
| 还原号 | `=` | 还原同小节前面的临时变音 |
| 高八度 | `e` | elevate，升高一个八度，可叠加 |
| 低八度 | `d` | descend，降低一个八度，可叠加 |
| 休止符 | `0` | 无音高，参与时值计算 |
| 高八度区间 | `{8va}`...`{/}` | 区间内所有音提高八度 |
| 低八度区间 | `{8vb}`...`{/}` | 区间内所有音降低八度 |

规则：

- 升号和降号可以分别叠加，但不能混用；还原号 `=` 只能单独出现一次。
- `4##`、`7bb` 和 `2=` 合法；`4#b`、`4#=` 和 `4==` 非法。
- 临时变音持续影响当前小节内相同音级和八度的后续音符，遇到新的临时变音或小节线时失效。
- 八度修饰只作用于当前音符。同一音符只能选择一个方向：`1ee` 和 `1dd` 合法，`1ed` 非法。
- `{8va}` 和 `{8vb}` 是区间指令，遵守统一的栈式关闭规则。

示例：
```m3n
1 2 3 4 |
// 临时变音持续生效
1# 2b 1 2 |
// 临时变音叠加还原
1## 2bb 1= 2= |
// 八度修饰
1dd 1d 1e 1ee |
// 八度区间
{8vb}3 2 1^{/}|||
```

### 4.3 时值

每个音符默认为四分音符，通过括号系统和时值后缀可以修改其时值。

| 写法 | 含义 | 以四分音符为基准 |
| :--- | :--- | :--- |
| `1` | 四分音符 | 1 倍 |
| `(1)` | 括号内时值减半 | 1/2 倍 |
| `((1))` | 减半两次 | 1/4 倍 |
| `(((1)))` | 减半三次 | 1/8 倍 |
| `1^` | 时值翻倍 | 2 倍 |
| `1^^` | 翻倍两次 | 4 倍 |
| `1.` | 附点 | 1.5 倍 |
| `1..` | 双附点 | 1.75 倍 |
| `1^.` | 先翻倍后附点 | 3 倍 |
| `5~ 5` | 延音 | 相加 |

规则：

- 时值后缀的顺序为零个或多个 `^`、零个或多个 `.`、最多一个 `~`，即依次为 `^*`、`.*`、`~?`。
- 圆括号可以嵌套，但必须在同一小节内闭合。
- `~` 表示延音线，可以跨越小节线；后方下一个有音高的音乐原子必须与当前音符的绝对音高相同。
- 除第一个和最后一个弱起小节外，每个小节必须满拍。弱起乐曲的首末小节拍数之和必须等于一个完整小节。

示例：
```m3n
// 括号/翻倍
1 (1(1 1)) 1^ |
// 附点
1. (1) 1..((1)) |
// 延音
(1 2~) 2~ (2 3) 1 |
// 组合
1^.~ (1 1) |||
```

### 4.4 音符分组

完整形式为 `[<音高><音高>...:<模式>]<时值后缀?>`。组内连续扫描音高词法单元，音高之间的空白无语义，例如 `[135:h]` 与 `[1 3 5:h]` 等价。

| 写法 | 含义 | 说明 |
| :--- | :--- | :--- |
| `[135:h]` | 和声组 | 音符同时发声，占 1 份时值 |
| `[123:2]` | 连音组 | 3 音均分 2 份时值 |

模式 `h` 表示同时发声的和声组；正整数表示所有音共同占用多少份当前位置的基本时值。组本身可以使用 `^`、`.` 和 `~`，也可以放在圆括号中改变基本时值。

分组必须完整位于同一小节内，且至少包含两个音乐原子。普通连音组允许休止符，例如 `[066:2]`；和声组不允许休止符。组内不允许时值后缀、点指令、圆括号或嵌套分组。“和声组”表示同时发声的音符，不要与第 6.4 节的和弦标记混淆。

示例：
```m3n
{3/4}
[135:h] [572e:h] [135:h] |
([135:2]) ([572e:2]) ([066:2]) |||
```

## 5. 小节线

- `|` → 普通小节线
- `||` → 双小节线（段落线）
- `|||` → 终止线
- `||:` → 前反复起点
- `:||` → 后反复终点
- `:|||` → 后反复与终止线合并
- `:||:` → 后反复结束后立即进入新前反复

## 6. 演奏标记

### 6.1 力度记号

`{ppp}` 至 `{fff}` 等力度是状态指令，从当前位置生效，直到被新的力度覆盖。渐强和渐弱是区间指令。

| 写法 | 含义 | 写法 | 含义 |
| :--- | :--- | :--- | :--- |
| `{cresc}...{/}` | 渐强区间 | `{decres}...{/}` | 渐弱区间 |
| `{ppp}` | 极弱 | `{fff}` | 极强 |
| `{pp}` | 很弱 | `{ff}` | 很强 |
| `{p}` | 弱 | `{f}` | 强 |
| `{mp}` | 中弱 | `{mf}` | 中强 |
| `{sfz}` | 突强 | | |

示例：
```m3n
{cresc}1 2 3 4{/} | {decres}5 4 3 2{/} |
{pp}1 2 3 4 | {p}5 4 3 2 |
{mp}1 2 3 4 | {mf}5 4 3 2 |
{f}1 2 3 4 | {ff}5 4 3 2 |
1 5 {sfz}1^ |||
```

### 6.2 奏法记号

`{lg}` 是区间指令。其余奏法是点指令，写在所修饰的音符之后。

| 写法 | 含义 | 写法 | 含义 |
| :--- | :--- | :--- | :--- |
| `{lg}...{/}` | 连奏区间 | | |
| `{tr}` | 颤音 | `{echo}` | 回音 |
| `{str}` | 重音 | `{hold}` | 保持音 |
| `{brk}` | 顿音 | `{breath}` | 呼吸记号 |
| `{tip}` | 跳音 | `{f1}` 至 `{f5}` | 指法 |
| `{wav}` | 上波音 | `{wav-}` | 下波音 |

示例：
```m3n
{lg}1 2 3 4{/} |
5{tr} 5{str} 5{brk} 5{tip} |
5{echo} 5{hold} 5{breath} 5{wav} |
5{wav-} 5{f1} 5{f3} 5{f5} |||
```
### 6.3 装饰音

| 写法 | 名称 | 说明 |
| :--- | :--- | :--- |
| `{ac(...)}` | 短倚音 | acciaccatura，带斜线小音符，主音时值不变 |
| `{ap(...)}` | 长倚音 | appoggiatura，不带斜线，从主音借用时值 |

装饰音是点指令，写在主音之后。括号内至少包含一个音高，不允许休止符、时值修饰或其他指令。长倚音的具体时值分配由渲染器决定。

示例：
```m3n
{key=C} {4/4}
3{ac(2)} 4 5{ac(34)} 3 |
5{ap(6)} 4 3{ap(2)} 1 |||
```

### 6.4 和弦标记

和弦标记的语法为 `{chord=<级数><后缀?>}`。它是状态指令，从当前位置持续到下一个和弦标记。级数使用 I 至 VII 的罗马数字，并根据当前调号换算和弦根音。

| 写法 | 含义 | C 调示例 |
| :--- | :--- | :--- |
| `I` | 大三和弦 | C |
| `ii` | 小三和弦 | Dm |
| `iii` | 小三和弦 | Em |
| `IV` | 大三和弦 | F |
| `V` | 大三和弦 | G |
| `vi` | 小三和弦 | Am |
| `viidim` | 减三和弦 | Bdim |

大写罗马数字默认表示大三和弦，小写默认表示小三和弦。可用后缀包括 `m`、`dim`、`aug`、`sus2`、`sus4` 和 `2` 至 `13` 的扩展音数字。例如 `VI` 是大六级和弦，`vi` 和 `VIm` 都是小六级和弦，`V7` 是属七和弦。

示例：

```m3n
{key=D} {4/4}
{chord=I}3 3 4 5 | {chord=V}5 4 3 2 |
{chord=I}1 1 2 3 | {chord=V}3. (2) 2^ |
{chord=I}3 3 4 5 | {chord=V}5 4 3 2 |
{chord=I}1 1 2 3 | {chord=V}2. (1) {chord=I}1^ |||
```

## 7. 乐曲结构

### 7.1 小节线反复
语法为 `||: ... :||`，意思是演奏到后反复线，从前反复线开始再演奏一次。
如果只有后反复线，通常表示从乐曲开头再演奏一次。
示例：
```m3n
1 2 3 4 :|| 5 4 3 2 ||: 1 2 3 4 :||: 5 3 1^ :|||
```
### 7.2 不同结尾

| 写法 | 含义 |
| :--- | :--- |
| `{volta=N}` | 第 N 房子 |
| `{volta=N,M}` | 第 N、M 房子 |
| `{volta=N~M}` | 第 N 到第 M 遍使用 |
| `{volta=X,N~M}` | 第 X 遍以及第 N 到第 M 遍使用 |

`volta` 是区间指令，必须在对应结尾之后关闭。通常在关闭后紧接后反复线或终止线。

示例：

```m3n
3 3 4 5 | 5 4 3 2 | 1 1 2 3 |
{volta=1}3. (2) 2^{/} :||
{volta=2}2. (1) 1^{/} |||
```

### 7.3 段落标记

使用 `{part=A}...{/}` 定义具名乐段，然后通过 `{parts=A B A C}` 指定演奏顺序。`part` 是区间指令，每个乐段都必须关闭；同一文档中的乐段名称必须唯一。

示例：
```m3n
{key=D} {4/4}
{parts=A B A C D C}

{part=A}
3 3 4 5 | 5 4 3 2 ||
{/}

{part=B}
1 1 2 3 | 3. (2) 2^ ||
{/}

{part=C}
1 1 2 3 | 2. (1) 1^ ||
{/}

{part=D}
2 2 3 1 | 2 (3 4) 3 1 | 2 (3 4) 3 2 | 1 2 5d 3~ | 3 3 4 5 | 5 4 3 2 ||
{/}
```

### 7.4 多小节休止

`{rest=N}` 是一个完整的音乐原子，表示连续休止 `N` 个小节。`N` 必须是正整数；该原子必须单独占据当前位置的小节。

```m3n
{key=C} {4/4}
1 2 3 4 | {rest=4} | 4 3 2 1 |||
```

- 使用 `{text=...}` 在音符处补充谱面文字。

## 9. 补充块

补充块写在音乐正文结束后，不允许嵌套。

### 9.1 歌词块

| 元素 | 说明 |
| :--- | :--- |
| 半角空格分隔的歌词项 | 每项对应一个有音高的音符 |
| `%` | 无歌词占位，该音符不配歌词 |
| `-` | 英文单词拆音节 |

规则：
- 休止符 `0` 不占歌词位置
- 附点和延音不额外产生歌词位置
- 多个汉字无空格时视为整体附着到同一音符
- 歌词项必须使用半角空格分隔，Tab 和换行不能代替空格

遍次范围：

| 写法 | 含义 |
| :--- | :--- |
| `{lyrics=1}` | 仅第 1 遍 |
| `{lyrics=2,3}` | 第 2 和第 3 遍 |
| `{lyrics=1~3}` | 第 1 到第 3 遍 |

```m3n
{key=C} {4/4}
1 1 5 5 | 6 6 5^ |
4 4 3 3 | 2 2 1^ :|||

{lyrics}
一 闪 一 闪 亮 晶 晶
满 天 都 是 小 星 星
{/}
{lyrics}
Twin-kle twin-kle lit-tle star
How I won-der what you are!
{/}
```

### 9.2 低音谱表

通过 `{bass}...{/}` 包裹的内容来补充低音谱表。
低音谱表使用与正文相同的音高、时值、小节线语法，应只包含谱表级内容（音符、时值、演奏标记等）。

```m3n
{key=D} {4/4}
3 3 4 5 | 5 4 3 2 | 1 1 2 3 | 2. (1) 1^ |||

{bass}
1d^^ | 5d^^ | 1d^^ | 5d^ 1d^ |||
{/}
```

## 10. 语法校验

本节规定 M3N v0.2 的主要校验类别。解析器遇到以下情况应明确报错，不得静默忽略。

### 10.1 配对类

成对标记的闭合与匹配约束。

| 编号 | 非法语法 | 说明 |
| :--- | :--- | :--- |
| P1 | 小节内括号不匹配 | `()` 或 `[]` 在小节内未闭合 |
| P2 | 区间关闭缺失 | 区间起始标签无对应关闭标签 |
| P3 | 区间关闭冗余 | 区间关闭标签无对应起始标签 |
| P4 | 区间关闭顺序错误 | 具名关闭标签与栈顶区间不匹配 |
| P5 | 反复线不匹配 | 仅有前反复线而无对应的后反复线 |

### 10.2 结构类

文档与乐谱的整体结构约束。

| 编号 | 非法语法 | 说明 |
| :--- | :--- | :--- |
| S1 | 补充块出现在正文之前 | `{lyrics}` 或 `{bass}` 必须在乐谱正文之后 |
| S2 | 空补充块 | 歌词或低音谱表内容为空 |
| S3 | 段落引用不一致 | 段落声明与 `{parts=}` 引用无法严格匹配 |

### 10.3 取值类

指令值的格式与范围约束。

| 编号 | 非法语法 | 说明 |
| :--- | :--- | :--- |
| V1 | 未知指令 | 不支持的指令名 |
| V2 | `key` 指令格式非法 | 音名和调式后缀须为合法值 |
| V3 | 拍号格式非法 | 拍号分子必须为正整数，分母必须为 2 的非负整数次幂 |
| V4 | 非法正整数取值 | 速度、连音时值、休止小节数等须为合法正整数 |
| V5 | 分组指令非法 | 分组冒号后必须为正整数或 `h` |
| V6 | 和弦名称非法 | 和弦级数无法解析 |
| V7 | 遍次范围非法 | 不同结尾、歌词等遍次范围无法解析 |

### 10.4 语义类

语法合法但语义矛盾的约束。

| 编号 | 非法语法 | 说明 |
| :--- | :--- | :--- |
| M1 | 小节拍数不合规 | 普通小节必须满拍；弱起乐曲的首末小节拍数之和必须等于完整小节 |
| M2 | 延音目标非法 | `~` 后方无音符，或首个音符绝对音高与当前音符不同 |
| M3 | 休止符非法属性 | 休止符使用八度修饰、临时变音、延音、奏法等与音高相关的属性 |

### 10.5 约束类

特定上下文中的限制规则。

| 编号 | 非法语法 | 说明 |
| :--- | :--- | :--- |
| R1 | 乐谱信息重复声明 | 同一字段只允许声明一次 |
| R2 | 时值后缀顺序错误 | 顺序必须为 `^*`、`.*`、`~?` |
| R3 | 分组内含非法元素 | 分组内出现时值后缀、奏法等非法元素，或和声组出现休止符 |
| R4 | 分组音数不足 | 分组内至少需要两个音高 |
| R5 | 装饰音内含非法元素 | 装饰音内出现时值后缀、奏法等非音高修饰 |
| R6 | 空装饰音 | 装饰音内至少需要一个音高 |
| R7 | 临时变音组合非法 | 同一音符混用升号、降号或还原号 |
| R8 | 八度方向混用 | 同一音符同时使用 `e` 和 `d` |
