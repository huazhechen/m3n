# 简谱小节高度缓存与不增页断行试验（历史）

本文记录旧独立高度模型；当前默认已迁移到按实际行重组的数值几何与逐元素避让，见[宽度搜索](WIDTH_SEARCH.md)。下文“默认／上线”均指当时版本。

当前默认字体代价系数为4，宽松项逐行计分，均匀项同时包含平均和最差行偏离。
下文系数8的统计保留为历史结果；最新评分及末行修复见[评分与结尾复核](NUMBERED_SPACING_ENDINGS_REVIEW.md)。

本轮使用独立 worktree 的简谱实现，谱源冻结为 master fcc3f355 的117首，
与字体系数8全范围基线逐首校验源码及共享字体摘要。没有运行图片审视、碰撞或越界审计。
本方案已作为公开简谱API的默认模式，覆盖阅读、单曲导出及谱集导出；
内部直接调用 layoutNativeScore 及显式 rowEnvelope:false 仍可用于精准避让对照。

## 高度模型

所有小节以第一声部的音乐视觉中心线对齐，分别保存：
coreAbove、coreBelow、extraAbove、extraBelow，以及是否有歌词。
不能只存核心总高度，也不能把上下两侧强制平分。

一行的核心上高度、核心下高度分别取所属小节的最大值。
完整上边界取 max(coreAbove + extraAbove)，完整下边界同理；
从完整边界减去整行核心边界得到非核心高度。
这样不会把不同小节的核心峰值和非核心峰值叠加成不存在的空白。

相邻两行的中心线距离为：

    上行核心下高度 + 下行核心上高度
    + max(G, 上行非核心下高度 + 下行非核心上高度 + 0.3 * G)

G 沿用原有最小核心间距、歌词缩距和分节覆盖规则。
标题沿用标题间距；页末均衡和页内行距伸展仍保留，不改变最小间距下的页数。

## 雕版复用

每个任务、每个8/16px档位，只进行一次“每小节独占一行”的规范测量。
规范宽度取 max(768, 各小节最小宽度 + 弧线前留白 + 两侧页边距)，上取整后加64px。
测量包含歌词、符号、曲线、注释和声部位置；随后只保留每小节的四个高度。
测量以 nativeMusicAxis 修正字体基线，不能把文字基线当作音乐中心。

小节测量、整行合并结果在不同候选宽度间复用；
断行方案的页数直接由缓存数值计算，最终雕版也使用同一组高度分页。
超宽小节分片沿用原小节完整高度作保守预留。
字体版本、测量器及记谱选项变化会隔离任务缓存；
档位、等宽小节、最小间距下限、核心间距、小节编号、页边距隔离高度缓存。

这是一种独立小节包络模型：宽度相关曲线和跨小节关系按规范测量中的分段高度预留，
并不声称等于每个候选宽度重新完整雕版所得的精确墨迹包络。
本轮没有单独验证这些近似在所有谱面上的碰撞表现。

## 求解与剪枝

固定宽度和间距档位先贪心排出最紧凑方案，以它的实际页数作上限。
原横向动态规划方案若未增页，直接采用。
否则以 Lawler 前缀分区继续调用原凸包动态规划，寻找不增页条件下横向代价最小的方案。
目标仍为总拉伸与全曲拉伸不均匀之和；不引入新增行代价。
这里的最优是“贪心页数上限内的横向最优”，不是证明所有可能排法的最小页数。

只检查每个完整方案的页数会产生组合爆炸；首次全量在《如愿》处主动停止。
修正后增加整组候选的精确高度可行性动态规划：
按最后一行及其结束位置，保留最少已用页、再最低中心线的状态。
整行避让仅依赖相邻行，这个状态能支配同一最后一行的其他位置；
没有能装入页数上限的路径时，整组候选直接排除，再也不进入横向动态规划。
小规模随机图用完整枚举及实际分页器逐一核对，包含非对称核心、歌词缩距、
固定核心间距、分节留白和标题。无高度量化、候选数量上限或近似淘汰。

搜索启用48px粗搜、补24px、局部6px细搜，以及已有安全字体上界、
横向质量和一页档位剪枝。局部搜索仍不保证全范围离散最优。
两个间距档位仍分别求解，再以页数、共同间距评分选出结果。

## 与带分页约束的精准避让对照

补测《黑色幽默》《老男孩》，相同冻结谱源、字体、当前工具、局部细搜和宽度剪枝。
两组均以各自贪心方案的页数作为上限；精准模式启用已有的行几何缓存，
包络模式启用独立小节高度缓存及高度可行性剪枝，分别使用各实现可安全采用的档位剪枝。
这是两套完整求解实现的实测，不是相同断行路径下单独替换分页函数的微基准。

## 默认模式上线

公开API默认使用整行高度、不增页方案；阅读、在线谱集、本地谱集选择宽度时启用局部细搜和已有剪枝。策略缓存版本升为v29。五线谱保持现有默认行为。

## 基本功第63—66小节的3＋1案例

714px、8px最小间距时，维持其他断行不变：3＋1的全曲断行代价为4.603450、2页；
2＋2的代价更低，为4.203107，但增加到3页，因此被贪心页数上限排除。
第63—65小节一行的完整包络为58.2px，第66小节单行为41px；
改为63—64及65—66后，完整包络为58.2px和44.88px。
第二行的核心上高度也从14.507px增为19.403px，核心下高度从12.772px增为13.2px。
这一变化越过第二页容量：页内行数从17/20变为17/18/2（末页两行来自尾页均衡）。
该例体现硬页数约束与横向均匀度的交换，不代表均匀评分偏爱3＋1。

714px与720px均为2页、37行；720px下第63—66小节可排为2＋2。
714px的字体／不均匀／紧凑代价分别为4.805000／0.390750／0.277286，总分5.473037；
720px为5.120000／0.140204／0.299321，总分5.559525。
720px同A4字号仅小0.83%，但字体代价增加0.315，超过不均匀项改善0.250546；
714px短尾行的较大间距还使紧凑项改善0.022035。
这是跨宽度评分与短尾行平均间距奖励的已知取舍，本次上线未修改字体系数8。

主线整合后，以当前117首谱源和重新生成的共享字体复测，目标最优宽度、页数、行数117首全部一致。
生产回归基线更新为该目标结果，回归命令显式开启 --row-envelope --prune --local-refine；
历史master对比数据保留在独立报告中。
