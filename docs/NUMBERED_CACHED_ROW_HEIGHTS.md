# 简谱小节高度缓存与不增页断行试验

本轮使用独立 worktree 的简谱实现，谱源冻结为 master fcc3f355 的117首，
与字体系数8全范围基线逐首校验源码及共享字体摘要。没有运行图片审视、碰撞或越界审计。
试验通过 rowEnvelope 选项启用，尚未切换网页默认模式。

## 高度模型

所有小节以第一声部的音乐视觉中心线对齐，分别保存：
coreAbove、coreBelow、extraAbove、extraBelow，以及是否有歌词。
不能只存核心总高度，也不能把上下两侧强制平分。

一行的核心上高度、核心下高度分别取所属小节的最大值。
完整上边界取 max(coreAbove + extraAbove)，完整下边界同理；
从完整边界减去整行核心边界得到非核心高度。
这样不会把不同小节的核心峰值和非核心峰值叠加成不存在的空白。

相邻两行的中心线距离为：

    上行核心下高度 + 下行核心上高度
    + max(G, 上行非核心下高度 + 下行非核心上高度 + 0.3 * G)

G 沿用原有最小核心间距、歌词缩距和分节覆盖规则。
标题沿用标题间距；页末均衡和页内行距伸展仍保留，不改变最小间距下的页数。

## 雕版复用

每个任务、每个8/16px档位，只进行一次“每小节独占一行”的规范测量。
规范宽度取 max(768, 各小节最小宽度 + 弧线前留白 + 两侧页边距)，上取整后加64px。
测量包含歌词、符号、曲线、注释和声部位置；随后只保留每小节的四个高度。
测量以 nativeMusicAxis 修正字体基线，不能把文字基线当作音乐中心。

小节测量、整行合并结果在不同候选宽度间复用；
断行方案的页数直接由缓存数值计算，最终雕版也使用同一组高度分页。
超宽小节分片沿用原小节完整高度作保守预留。
字体版本、测量器及记谱选项变化会隔离任务缓存；
档位、等宽小节、最小间距下限、核心间距、小节编号、页边距隔离高度缓存。

这是一种独立小节包络模型：宽度相关曲线和跨小节关系按规范测量中的分段高度预留，
并不声称等于每个候选宽度重新完整雕版所得的精确墨迹包络。
本轮没有单独验证这些近似在所有谱面上的碰撞表现。

## 求解与剪枝

固定宽度和间距档位先贪心排出最紧凑方案，以它的实际页数作上限。
原横向动态规划方案若未增页，直接采用。
否则以 Lawler 前缀分区继续调用原凸包动态规划，寻找不增页条件下横向代价最小的方案。
目标仍为总拉伸与全曲拉伸不均匀之和；不引入新增行代价。
这里的最优是“贪心页数上限内的横向最优”，不是证明所有可能排法的最小页数。

只检查每个完整方案的页数会产生组合爆炸；首次全量在《如愿》处主动停止。
修正后增加整组候选的精确高度可行性动态规划：
按最后一行及其结束位置，保留最少已用页、再最低中心线的状态。
整行避让仅依赖相邻行，这个状态能支配同一最后一行的其他位置；
没有能装入页数上限的路径时，整组候选直接排除，再也不进入横向动态规划。
小规模随机图用完整枚举及实际分页器逐一核对，包含非对称核心、歌词缩距、
固定核心间距、分节留白和标题。无高度量化、候选数量上限或近似淘汰。

搜索启用48px粗搜、补24px、局部6px细搜，以及已有安全字体上界、
横向质量和一页档位剪枝。局部搜索仍不保证全范围离散最优。
两个间距档位仍分别求解，再以页数、共同间距评分选出结果。

## 复现

    python3 tools/run-low-memory.py node tools/benchmark-numbered-spacing.mjs \
      --source-root=/root/project/m3n-spacing-master-audit/src \
      --baseline=.tmp/font8-full/current.json \
      --prune --local-refine --row-envelope \
      --output=.tmp/row-envelope-search-pruned/current.json

取消 --row-envelope 即为相同搜索配置的旧模型对照。
--page-bound 单独启用逐行精确雕版的早期试验，可用于比较，
但不得把它的开销当成缓存数值分页的开销。

## 历史包络评估

NUMBERED_ROW_ENVELOPE_COMPARISON.csv 来自最初的固定旧最优宽度评估，
非核心系数为0.5，并先完整雕版再提取包络；
它不代表本轮0.3系数、独立高度缓存、重新选宽的结果。
当时逐行精确避让为124页，仅换整行包络为158页，
再改为独立小节核心最大值为160页；取消歌词缩距则174页。
可见整行避让的空间成本需要重新选宽才能评估。
