# 简谱数值几何与逐元素避让

当前117首同谱源、相同共享字体、相同8／16px档位、字体系数4、生产字体剪枝及6px局部细搜。旧对照是改动前的独立小节高度＋整行避让方案，报告 `.tmp/numbered-measure-whole/current.json`；首次数值几何报告 `.tmp/numeric-element-final-v2/current.json`，性能优化后的报告 `.tmp/perf-final-verified/current.json`。未重跑master历史数据，未做图片、碰撞或越界审计。候选没有渲染错误；报告的零碰撞计数仅表示未启用审计。

| 指标 | 改动前 | 首次数值几何 | 性能优化后 |
| --- | ---: | ---: | ---: |
| 累计选宽 | 27.673秒 | 76.726秒 | 29.443秒 |
| 整批墙钟 | 32.675秒 | 81.917秒 | 34.951秒 |
| 总页数 | 124 | 123 | 123 |
| 总行数 | 1187 | 1218 | 1218 |
| 聚合进程RSS峰值 | 1371MiB | 1457MiB | 1365MiB |

66首宽度相同、45首变窄、6首变宽；102首变化不超过24px。116首页数相同；《星星点灯》由558px／2页改为756px／1页。这符合页数优先规则，同A4字号约缩小26.2%，不能只据页数减少断言可读性更好。其余较大移动包括《贝加尔湖畔》600→666px、《第二圆舞曲》666→606px、《暗香》714→666px。全部逐首数据见 [CSV](NUMBERED_NUMERIC_GEOMETRY_REVIEW.csv)。

新方案的收益是共享歌词基线、曲线与标记按实际行重组，分页和绘制共用几何；不再依赖独立小节最终高度的跨宽度近似。基础音符／文字度量仍跨宽度复用；安全的相同行快照在候选间复用。少量谱头、编号、房子线等辅助符号仍保留局部SVG测量，选宽不生成整页SVG。

性能优化保留实际逐元素避让和不增页的全局断行目标。117首累计选宽29.443秒，相对首次数值几何减少61.6%；整批34.951秒含打包、浏览器启动、字体安装和报告写入，不能混作选宽耗时。117首最优宽度、页数、行数全部不变；1385个实际测量候选的页数、行数、评分与首次报告一致（浮点容差1e-8），无候选错误。最慢为《半音阶口琴基本功》1.276秒、联奏1.036秒及《Valsentino》0.990秒；仍有8首超过600ms，不代表已达到逐首600ms目标。

联奏606px紧档的贪心方案与横向最优均15行，但分别为1页和2页。只枚举完整方案会组合爆炸；改为分页代价DP、单页后缀高度下界和按需末行几何缓存。本节末行是否撑满依赖本节先前行的平均间距，难例DP保留间距总和与计数；同声部的标题分节也重置统计。已解析几何必须显式标记，否则会错误跳过元素避让。未设置搜索数量上限或放弃全局目标，局部选宽本身仍不保证全范围网格最优。

复现：

```sh
python3 tools/run-low-memory.py node tools/benchmark-numbered-spacing.mjs \
  --numeric-layout --avoidance=element --prune --local-refine \
  --baseline=.tmp/numeric-element-final-v2/current.json \
  --output=.tmp/perf-final-verified/current.json
```

复用和安全剪枝的实现边界见[宽度搜索](WIDTH_SEARCH.md#数值求解的性能复用)。同一浏览器和字体度量在曲目之间复用；没有预设赢家宽度、减少曲目、改评分、限制搜索状态数量或放宽几何精度。

回归验证：简谱完整单元测试1157项通过；另有4项失败（圆滑线局部高度、括号净空、三角记号坐标、密集小节断行），均在干净master 9f17a64e复现。性能优化发现的分片缓存混用、连续布局回退及布局后歌词修改问题已修复，完整重跑没有新增失败。

最终隔离生产构建、生成物校验通过；五线谱394项测试全部通过。两次全量性能测量分别为29.427秒和29.443秒，后者包含缓存生命周期及分片身份修正。
