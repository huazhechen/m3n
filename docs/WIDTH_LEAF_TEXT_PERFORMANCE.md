# 五线谱普通文字的局部边界复用

2026-11-27，独立工作树 `perf/single-worker-600`，基于 `4a70f3e3`。冻结117首谱源、真实归档TTF及 `a5a4c30b` 的6px谱间、0.6／1.8间距规则。单Worker，完整528～720px、6px网格及安全剪枝不变；此冻结测量不能替代最新主线的全量验收。

普通文字没有嵌套节点时，直接读取本节点字号，省去递归查找。内部精确几何读取器还复用该节点未变换的文字矩形，每次检查文字、字号、继承粗斜体、坐标和锚点；祖先变换和描边仍实时应用。嵌套文字继续完整遍历，默认公开读取器也继续调用可变的文字度量函数。该优化只作用于五线谱几何适配器，共享搜索、评分和分页算法没有变化。
