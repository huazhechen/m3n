# 纯音乐谱行直接收集精确图元

2026-11-27，独立工作树 `perf/single-worker-600`，基于 `55f51283`。继续冻结117首谱源、真实归档TTF及 `a5a4c30b` 的6px五线谱谱间、0.6／1.8间距规则；单Worker，完整528～720px、6px网格及安全剪枝保持不变。此报告不能替代后续主线规则和谱源的全量验收。

五线谱没有歌词和可移动附件的行，仍会进入歌词分组、附件搜集及静态树编译。此前延迟收集模式虽有提前返回，真正读取图元时还会重新进入完整整理流程；立即消费的分页模式则总是执行完整流程。现在这些行直接进入原有精确分区收集，并把最终核心、普通图元、额外边界和固定净空的收集提为同一个函数。带歌词或附件的行继续原有整理。没有删除图元、近似曲线或另写分页算法，绘制和共享分页仍消费同一组精确几何。

## 全量测量

每批新建Chromium，批内共享字体和文字度量，无预热、profiler或最终SVG。串行运行，Node堆384MiB、浏览器堆256MiB、聚合RSS守卫1700MiB。为核对小幅收益，在首轮修改后重新构建并测量未经修改的基线，再恢复修改复测；基线渲染包SHA-256与此前 `10cb22b4` 的报告相同。

本轮跨过600ms门槛的是 `works/snail-mushroom-waves.m3n`：606.9→552.6／555.7ms。该结果仍只适用于本报告冻结的规则与环境。

两批各1733组赢家／候选与同环境基线一致，比较宽度、页数、行数、物理间距和全部评分分量，绝对误差阈值1e-8；请求宽度集合、谱源和字体摘要相同。新增语义回归比较相同音乐行有无空歌词容器的完整几何与SVG输出，覆盖立即／延迟图元、数值／普通绘制、两种宽度、符梁、升降记号、谱号及高低音大跳；空歌词使其走原有完整整理，验证提前返回没有改变结果。
