# 器乐括号的宿主实绘边界

两版均保留正常音符推进宽度，并以实际音乐笔画补足边界。括号到宿主的最小水平净空仍为正文数字字号的 0.05 倍，不将歌词宽度带入器乐范围。

本轮修正：

- 自研版原只读取 `musicLeft/musicRight`。升号描边可额外伸出约 0.29568px，减时线圆端伸出约 0.605px；末尾增时线的圆端甚至会用尽右括号前的名义净空。现在复用音乐绘制时已测出的 `inkLeft/inkRight`，统一处理变音、和音、倚音、琶音、减时线及增时线。
- 参考版原读取逻辑／固有盒，仍漏计部分数字字形外伸，以及由连梁附件接管绘制的减时线圆端。现在合并宿主最终绘制区域与装饰保留的 `getIntrinsicInk()`。后一接口即使绘制已委托给连梁，也提供该音符自己的真实局部线段，避免把整条共享连梁错算成单个音符的宽度。
- 现有字体、字号、基线、音符推进宽度、换行求解及播放语义保持原有规则；仅括号的宿主边界改为包含实际笔画。
