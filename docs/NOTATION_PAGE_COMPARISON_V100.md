# 当前双谱式选宽与分页对比

2026-11-29，代码73fae80a、策略v100，重新运行全部117首简谱与117首五线谱。当前配置为歌词三档0／2／4px、共享拉伸抵扣、首个额外页面权重2。已部署至dev.cheesefans.com/score/，页面版本73fa；双谱式浏览器检查无脚本及资源错误。

比较基线为最近一次全量v98（c36b999c）：歌词1／2／3px、共享拉伸抵扣、分页权重2.4。此后还修改了土耳其进行曲Coda的8va记写、删除黑色幽默最后休止小节；差异不能单独归因于歌词或分页权重。共享字体摘要不变，两种谱式的当前谱源摘要与磁盘逐项一致。

## 统计时参数

| 参数 | 简谱 | 五线谱 |
|---|---|---|
| 基准 | M=24px | S=7.5px，音乐字号4S=30px |
| 横向三档 | 8／12／16px | 0.8／1.6／2.4S＝6／12／18px |
| 横向舒适区 | 16～24px | 2.4～3.6S＝18～27px |
| 纵向N范围 | 18～36px | 2～4S＝15～30px |
| 歌词块两两净空 | 0／2／4px，随音乐三档 | 0／2／4px，随音乐三档 |
| 纵向舒适区 | 27～36px | 3～4S＝22.5～30px |

文字字号及附件净空共用M；谱号前固定0.8S（6px）、谱头后固定1.6S（12px）结构净空仅属于五线谱，后者量到首音最左音乐笔画，包含升降号、加线及倚音，计入宽度、不伸展、不评分。音符间方向权重简谱50∶50、五线谱75∶25，简谱组内系数0.75、五线谱为1，结构元素间隔权重均1。五线谱单音权重在四分及以下取时值本身，四分以上取平方根；简谱单音权重继续取平方根。选宽、断行、分页及成本求解共用，首个额外页面的权重为2。两种谱式的拥挤成本均使用逐间隔欠缺比例平方`max(0,1−g/舒适下限)²`，过松及均匀度公式保持不变。纵向成本改为同页相邻系统最终实际核心净空的逐间隔成本平均值，谱头和跨页间距不计；N仍负责布局拟合。纵向舒适区及惩罚公式均未改动。

五线谱普通符干保留3.5S基准，仅外伸时最多收回0.5S；连奏线两端随音高调整。方向可选的普通连梁组在实际行宽下比较完整行墨迹高度，复用既有谱表外空间；该谱表有歌词且高度差不超过S/8（0.9375px）时优先朝上，整行不超过未整形高度。和音、倚音、连音组、奏法记号及延音线端点保持常规方向。

歌词净空只约束同层相邻可见块，不给首尾添加歌词外边距，不另设舒适余量；音乐三档与纵向歌词净空保持原值。遍次序号与正文的2px内部间隔不变。

整行额外拉伸采用[共享抵扣规则](HORIZONTAL_STRETCH.md)，任何硬约束已撑开的空间都抵扣后续拉伸；不按歌词、同音连线等来源区分。
