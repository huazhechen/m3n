# 五线谱分段时值权重

五线谱取消符杠组内0.75折扣，组内系数为1。以四分音符时值为1，单音权重在`0<d≤1`时取`d`，在`d>1`时取`√d`。因此三十二分、十六分、八分、四分、二分、全音符的权重分别为0.125、0.25、0.5、1、√2、2。

相邻音符采用`W=w(d前)^0.75 × w(d后)^0.25`，前音时值主导其后的间距，后音时值适度参与。该权重同时用于音乐笔画间的最小节奏净空、正向拉伸和实际净空的评分归一化。符杠本身继续按音乐分组绘制，但分组不再改变节奏权重。字形、加线、歌词和连线的硬占位约束继续独立计算。

涉及小节线及独立结构元素的间隔保持权重1；行首固定1S净空仍不拉伸、不评分。简谱继续使用平方根单音时值、50∶50加权几何平均和0.75组内系数。两种谱式共用成对权重合成、宽度搜索、断行、分页和评分算法；五线谱只向共用成对权重函数提供不同的单音时值曲线。

S=7.5px、横向三档6／12／18px、舒适区18～27px、纵向范围15～30px、纵向舒适区22.5～30px均保持原值。共用拥挤评分仍为欠缺比例平方。搜索缓存版本更新为v89。

短音符的节奏权重会下降：例如组内十六分从原来的`√0.25×0.75=0.375`变为0.25。这是短时值采用线性比例的结果，不表示忽略墨迹避让。
