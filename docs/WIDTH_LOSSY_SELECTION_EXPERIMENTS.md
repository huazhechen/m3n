# 允许12px偏差的选宽试验

验收边界：相对于当前完整6px搜索，同曲、同谱式的页数不增加，选宽绝对偏差不超过12px；单线程选宽耗时不超过600ms。宽度范围仍为528～720px，字体代价仍绑定这个范围。最终输出继续使用原有精确几何和分页。两种谱式共用试验搜索策略，没有按曲目指定宽度。

前三种近似策略均未通过验收，已撤回对应试验源码。新增的跨宽度行几何复用仍为显式试验开关，正式路径仍完整精确搜索。逐曲结果见[CSV](WIDTH_LOSSY_SELECTION_EXPERIMENTS.csv)。源代码试验补丁及完整JSON留在独立工作树的`.tmp/staged4/`、`.tmp/sampled12/`、`.tmp/staged-bounds/`；这些临时目录不属于发布产物。

## 对照方法

沿用本分支117首冻结谱源，每种谱式一个浏览器、一份字体和文字度量缓存，逐曲串行搜索。基线是`.tmp/measurement-final/{numbered,staff}.json`，使用完整网格及可证明的安全剪枝。曲库批量时间包含此前曲目对引擎的预热，不能代替单曲首次打开时间。五线谱试验同时包含小节放置工作区复用，因此总提速不能全部归因于近似策略。

`tools/compare-width-selection.mjs EXACT.json TRIAL.json`检查完整报告、曲目集合、源摘要、字体摘要、页数、12px偏差和600ms门槛；任何不通过都会返回非零退出码。它只验证这批输入的实测边界，不能证明未知乐谱也满足边界。候选报告中的空越界／重叠数组属于生产测量口径，不代表额外执行了SVG墨迹验收。

第一种策略保留所有33档的横向调查，但将其页数暂视为1。实际最优经常在分页约束下改变断行及间距档位；横向靠前的窄版方案可能占用更多页，少量精测候选不能覆盖真正适合少页的中间宽度。单独测《基本功》时简谱467.2ms、五线谱519.4ms，分别选720px与720px，相对基线720px与708px恰好通过；全量对照则有74个组合不通过，不能以单曲结果推广。

12px网格不保证赢家只偏离6px或12px。断行、分页及评分均不连续，漏掉一个6px位置可能跳到很远的次优方案。简谱《卡农》642→672px、《月亮河》546→528px；五线谱《查尔达什》570→588px、《莫扎特K545》570→612px。这个试验从720向528搜索，访问顺序也使部分短曲无法尽早获得强赢家，简谱总耗时反而变大。

最后一种策略利用现有安全核心下界排除一定不能少页的宽度，显著减少误选，但下界故意省略了未解析的关系、附件和墨迹碰撞，不能把“可能一页”视为“确实一页”。追加下界计算也消耗时间，简谱仍有9首选宽超限、4首超时，故未继续扩大到五线谱。

## 保留的精确优化

五线谱候选现在在测量任务内复用私有小节放置工作区，重写音符锚点、符杠位置和谱表坐标；延迟绘制记录保留独立坐标。普通绘制仍分配独立模型。共享完整搜索、评分、分页和曲线均未改变。

117首五线谱总耗时34,259.9→32,556.2ms，约下降5.0%；《基本功》1,559.6→1,494.1ms；超过600ms的曲目16→14首。全部1,733组赢家／候选字段在1e-8容差内一致，包括相同源文件和字体摘要。该实测只能支持保留工作区复用，不能声称已完成600ms目标。

验证包括完整score-renderer测试、工作区跨宽度／档位／低音高度复用后的延迟SVG与墨迹一致性，以及全曲目数值对照。峰值项目进程内存低于2GB；构建、测试、浏览器和字体生成串行运行。

## 跨宽度行几何复用（继续试验，未启用）

保留全部33档及共享评分、均匀度与分页框架；同一行的首次精确几何作为模板，后续宽度仿射变换横坐标，复用纵向轮廓。预估阶段可在贪心方案代价不超过 `max(0.6, 2 × 横向最优代价)` 时省略昂贵的分页约束最优证明。所有赢家关闭试验开关后重新精确测量；若预估少算页数或精排失败，依次检查后续候选。该复核保证返回结果使用精确几何，但不构成全局页数与12px偏差的证明。

附加12px横向分格将每格内的候选墨迹合并成纵向包络，分别保留间距、页边界通道。分格只影响候选估计，最终精排仍用原始全部图元。共享变换源的相邻行复用横向重叠判定，减少重复排序和扫描。两种谱式使用同一分格与变换实现。

| --- | --- | ---: | ---: | ---: | ---: |
| 行几何复用及分页代价保护（2倍） | 简谱 | 21,285.5ms | 5 | 0 | 0 |

完整报告位于 `.tmp/row-proxy-cost-guard/`、`.tmp/row-proxy-cost-cap/`、`.tmp/row-proxy-bin12/`。最后一批简谱6首选宽改变，最大12px；五线谱5首改变，最大12px。全部234个组合经最终精排后页数不增加。仍超时的是简谱基本功638.3ms、后会无期721.2ms、Valsentino655.0ms，以及五线谱查尔达什624.3ms、Valsentino616.5ms。时间包含最终精排。

以上是冻结117首和旧五线谱参数的批量结果。基本功单曲冷启动在后续下界试验中仍需953.5ms，不能用批量预热结果代替首次打开时间。尚未同步主线后重新验收，也尚未据此切换阅读器、PDF或正式搜索路径。峰值项目RSS1326–1451MiB，重任务串行。

另保留一个精确优化：每次简谱投影内，按实际音高、时值、延音和内层标记复用音符设计几何，独立克隆可变标记位置，装饰和歌词仍逐音处理。正常路径117首23,631.3→23,191.6ms；892组赢家与候选排版数值在1e-8内一致（度量缓存计数允许变化）。完整简谱测试1220项通过，唯一失败为分支原有的五线谱24px与简谱30px小节框比例断言；本次没有修改这两个尺寸参数。

无歌词行使用更松的静态下界也已试验并撤回：虽然省掉了下界内部的两次放置，但减少安全剪枝后，K545从824.3升到1058.4ms、Valsentino从690.6升到754.5ms。不得仅按某个函数减少的工作量判断整次搜索收益。补丁和完整报告保存在 `.tmp/cheap-static-bound/`。

运行试验：先 `npm run build:packages`，再由内存守卫串行运行 `node tools/benchmark-numbered-spacing.mjs --numeric-layout --prune --row-reuse --fast-ceiling --proxy-bin=12 --output=REPORT.json`；五线谱将 `--numeric-layout` 替换为 `--staff`。三个试验开关均须显式传入，`--fast-ceiling` 与 `--proxy-bin` 必须配合 `--row-reuse`，以执行最终精排。`--score=ban_yin_jie` 用于单曲冷启动，不能将整库批次的指标视为冷启动结果。

新增测试验证分格覆盖、通道及共享图元身份、相同／不同变换下的重叠分离、标记副本隔离，以及精排复核的页数纠正、失败恢复和取消传播。score-renderer的437项测试、scorebook的59项测试通过；试验未启用时的正式路径保持精确。

最终关闭全部试验开关后，五线谱117首的1733组赢家／候选与原精确基线在1e-8内一致，报告为 `.tmp/row-proxy-default-exact/staff.json`。包构建和根工程 `tsc -b` 均通过。

## 同步新间距规则后的精确基线

本分支合并主线 b10a141f 后，重新以当前117首谱源、共享字体执行完整精确搜索。简谱总耗时22,508.2ms，4首超过600ms；五线谱34,250.7ms，17首超过600ms。报告位于 `.tmp/main-synced-exact/{numbered,staff}.json`。报告记录的HEAD仍是合并前6513de1c，实际执行的是已合并、尚未提交的代码；其rendererHash、sourceHash和fontHashes记录实际输入。旧规则下234个组合通过质量边界的结论不能代替新规则验收。

简谱与主线配置的117首选宽、页数全部相同。五线谱页数全部相同、116首宽度相同；《蜗牛与蘑菇的海浪》配置660px、当前630px。将主线b10a141f的packages与tools独立归档，以Vite别名直接引用该归档源码，加载同份谱源及字体，运行完整搜索也得到630px、1页（`.tmp/master-reference-snail/staff.json`），因此差异属于旧配置未覆盖后续规则更新，并非本分支合并回归。未据此直接改写主线配置。

合并验证同时修正了测试中的旧物理尺寸断言：leading现为倍率、局部附件净空使用基础尺寸的0.1倍、谱头与首行间距由分页器统一处理。原简谱全套1223项、五线谱440项分别有9项和7项旧断言失败；修改后的全部相关文件各58项测试通过，其余测试在首次全套运行中通过。包构建通过。
