# 跨乐句谱行的等行高

自研原先用谱行第一个音符的乐句编号归并整个谱行高度。谱行同时包含两个乐句时，第二个乐句的高音无法约束后续谱行；反过来，简单把整行高度传播到所有乐句，会让无关乐句也继承第一个乐句的高音。

现在在关系和外层表情放置前，按每个音符实际所属乐句与声部收集主体包络，可见小节线使用同一绘制片段测量。关系、外层表情、和弦、边界附注按所在谱行的全部乐句共享；房子谱行的附件上沿单独归并，主体和下沿仍与普通行共享。歌词与局部标题随后放置，不参与音乐高度传播。自然行距分支不变。

## 连梁与多小节休止的后续修正

剩余差异的原因并非需要额外补偿行距：

- 连梁在参考中属于附件，其下沿会共享到同一谱行承载的全部乐句。自研现在用实际连梁SVG测量下沿，补全该共享规则。《凉凉》房子跨乐句时的1.18px差异由此消除。
- 多小节休止没有音符事件。自研原先固定把它归入首乐句；参考投影则沿用上一乐句，首个休止还会进入独立的默认组。两者现在均按休止小节已有的源码结束位置查找所属乐句，与领域层既有的无音符小节归属判定一致，不改写谱源。《第二圆舞曲》开始的休止与后续音符因此使用同一组实际包络；中间休止也不再污染首乐句。
