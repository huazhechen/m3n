# 按实际核心净空评分

纵向布局仍在原有范围内拟合统一参数N；分页和墨迹避让规则不变。纵向评分改为测量最终坐标中同页相邻音乐系统的核心净空g，再平均每个间隔的成本：

```text
mean(max(0, (comfortable − g) / (comfortable − minimum))²)
```

核心边界由谱式适配器提供。五线谱为五条谱线的实际笔画外接范围；大谱表取整个系统最上方和最下方谱线，不统计内部谱表间隔。简谱沿用其核心边界。谱头不生成样本，跨页不计，零成本样本计入平均，没有行间样本时为零。加线、符干、歌词等继续参与硬避让，撑大的核心净空会体现在评分中；先逐间隔评分再平均，不用平均净空代入公式。

此修改在共用分页器实现，两种谱式共享；舒适区、成本公式、字号成本、增页权重均未调整。宽度搜索缓存策略更新至v90。

五线谱自动赢家由564px／2页／12行变为714px／1页／11行。720px也优于原来的两页方案，714px的字号与横向合计成本更低，因此最终选中714px。上述一页方案的实际核心净空均达到舒适下限22.5px；低N没有造成实际谱线间距拥挤。

## 验证

196个测试文件共1846项包测试全部通过。新增回归同时覆盖简谱和五线谱：非零baseline、墨迹撑开的实际间隔、各间隔成本平均，以及谱头和跨页样本排除。包测试聚合RSS峰值823MiB。

5份固定宽度双谱式密度回归通过原有门槛；《爱如潮水》714px和720px均另外执行双谱式实绘审计，无碰撞或越界。两次浏览器检查串行运行，聚合RSS峰值872MiB；报告分别位于`.tmp/actual-core-spacing/density/report.json`和`target-density/report.json`。生成物已重新准备，包构建通过。
