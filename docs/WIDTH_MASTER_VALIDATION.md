## 全量验证中修复的问题

1. 《暗香》已批准的间奏标记改动遗漏通用谱源契约。先验证旧契约确实对应改动前谱源，再只更新该曲基线，保留现有专项音乐内容测试。
2. 简谱审计没有逐曲准备设计字体。现在在绘制前加载当前谱源需要的字体；标题居中以设计轮廓验证到0.01px，其他独立绘制碰撞与越界检查保留。
3. 双谱表小节线连接段没有与谱表内的反复小节线共享连接身份，导致接缝被误报碰撞。补齐连接标记与回归断言，不改变坐标、笔画或选宽评分。
4. 浏览器测试仍读取默认已关闭的细粒度统计。缓存生命周期测试现在直接测量正式数值适配器，保留重复测量新增调用为零、重建任务恢复冷缓存的断言。
