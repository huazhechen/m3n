# 歌词间距

简谱与五线谱共用 `packages/numbered-notation/src/lyric-spacing.ts` 中的设计尺寸：歌词字号16px，歌词块左右各预留1px，第一层歌词距所属谱表音乐墨迹6px，相邻歌词层的实际墨迹净空4px。数值以22px音乐尺度为基准，随谱面等比缩放。

横向分别测量音乐及歌词占位：先为音乐保留节奏间距，再与带1px单侧留白的歌词占位取较大值，二者不重复相加。因此当歌词主导占宽时，相邻歌词块的最小横向间距为2px；音符、修饰符或谱行伸展可能使实际间距更大。一个音对应多个字时，字在同一文本块内连续排写，附加字距为0；1px留白只加在整个块的左右两侧。字形外伸参与测量，空歌词槽不占可见文本宽度。

简谱在独立歌词层中按实际可见文字避让，空词槽、休止符和小节线不在歌词层添加占位。遍次序号贴着后面的歌词，以正常歌词间距防碰撞，可利用小节线下方的空白；逗号等标点只计实际墨迹，不预留整字字宽。行首和行末仍计入全部可见墨迹，避免裁切。

五线谱以实际符头中心定位歌词，将歌词左右边界换算到时间列坐标后再求占宽；测量、各间距档试排、复用绘制模型和最终刻绘使用相同计算。谱号、调拍号、和弦文字与小节线仍保留各自所需占位。

纵向按所属谱表的音乐墨迹底边放置第一层歌词，再按每层真实文字墨迹排列后续层；大谱表空间不足时重新安排低音谱表。横向规则不会额外改变歌词垂直净空。

英文通过解析所得的词内位置与源位置连接音节，不将连字符当作歌词文字追加。两种谱式共用一个短横：长度为歌词字号的0.25倍、圆端描边0.055倍，位于基线上方0.28倍字号，词边净空从0.1倍字号起。横向测量为词内非末音节预留短横及描边空间；同一谱行内放在相邻同词音节实际墨迹之间，跨小节仍连接。跨行时在上一行音节右侧保留一个短横，下一行不添加前缀；语义不同的词、遍次及中文不据相邻文本猜测连接关系。短横与所属歌词共同参与实绘墨迹及纵向避让。


## 局部阅读余量

碰撞下限与舒适间距分开处理。`native-spacing.ts` 的 `distributeSpacingSurplus` 供两种谱式共用：先保留所有实际墨迹硬约束，再以原节奏弹性分配为基线，识别未达到软目标的歌词间隔。歌词的额外软目标为2px，即歌词块原有两侧合计2px留白之外，再争取2px；它不是强制最小占宽，不参与增加碰撞最小宽度。

最多使用可分配余量的25%补偿局部需求，其余继续按原节奏权重分配。相同时间区间的多遍歌词需求取较大值，不逐遍相加；跨空槽的歌词需求分配到其间的弹性边界。新增量始终非负，保留固定偏移组，不能挤破音乐、歌词或附件的硬下限；没有剩余宽度时不强求舒适目标。歌词与所属音符共享时间列位置，不单独移动文字、不改字块内部字距、不猜测中文词界。

五线谱在每小节的时间列中应用该策略，简谱在谱行的共用约束链中应用；两者沿用各自原有小节伸展和行首结构占位。英文词内短横仍占实际墨迹空间，不被软目标替代。
