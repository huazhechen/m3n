# 歌词间距

简谱与五线谱共用 `packages/numbered-notation/src/lyric-spacing.ts` 中的设计尺寸：歌词字号16px，歌词块左右各预留1px，第一层歌词距所属谱表音乐墨迹6px，相邻歌词层的实际墨迹净空4px。数值以22px音乐尺度为基准，随谱面等比缩放。

横向分别测量音乐及歌词占位：先为音乐保留节奏间距，再与带1px单侧留白的歌词占位取较大值，二者不重复相加。因此当歌词主导占宽时，相邻歌词块的最小横向间距为2px；音符、修饰符或谱行伸展可能使实际间距更大。一个音对应多个字时，字在同一文本块内连续排写，附加字距为0；1px留白只加在整个块的左右两侧。字形外伸参与测量，空歌词槽不占可见文本宽度。

简谱在独立歌词层中按实际可见文字避让，空词槽、休止符和小节线不在歌词层添加占位。遍次序号贴着后面的歌词，以正常歌词间距防碰撞，可利用小节线下方的空白；逗号等标点只计实际墨迹，不预留整字字宽。行首和行末仍计入全部可见墨迹，避免裁切。

五线谱以实际符头中心定位歌词，将歌词左右边界换算到时间列坐标后再求占宽；测量、各间距档试排、复用绘制模型和最终刻绘使用相同计算。谱号、调拍号、和弦文字与小节线仍保留各自所需占位。

纵向按所属谱表的音乐墨迹底边放置第一层歌词，再按每层真实文字墨迹排列后续层；大谱表空间不足时重新安排低音谱表。横向规则不会额外改变歌词垂直净空。
