# 歌词间距

简谱与五线谱共用 `packages/numbered-notation/src/lyric-spacing.ts` 的横向规则：歌词字号为简谱音乐字号M的2/3，即16px。相邻可见歌词块的最小净空绑定各谱式的音乐横向三档，依次为0、M/24、M/12，即0／1／2px；自定义音乐间距使用已达到的最高档，超出范围按最低／最高档处理。简谱第一层及后续歌词层按真实墨迹保留M/8=3px纵向净空；五线谱沿用自身附件净空。

横向分别测量音乐及歌词占位：先为音乐保留节奏间距，再与歌词实际墨迹及当前档位的两两净空约束取较大值，二者不重复相加。因此当歌词主导占宽时，相邻歌词块的最小横向间距为0／1／2px；音符、修饰符或谱行伸展可能使实际间距更大。一个音对应多个字时，字在同一文本块内连续排写，附加字距为0；净空只加在相邻可见块之间，不给行首、行末额外添加歌词外边距。字形外伸参与测量，空歌词槽不占可见文本宽度。窄档0px允许相邻块的墨迹边界相接，仍计入完整字形、下划线及英文短横占位。

简谱在独立歌词层中按实际可见文字避让，空词槽、休止符和小节线不在歌词层添加占位。遍次序号与所属歌词正文之间保留2px内部间隔，整体作为一个歌词块防碰撞，可利用小节线下方的空白；逗号等标点只计实际墨迹，不预留整字字宽。行首和行末仍计入全部可见墨迹，避免裁切。

五线谱以实际符头中心定位歌词，将歌词左右边界换算到时间列坐标后再求占宽；测量、各间距档试排、复用绘制模型和最终刻绘使用相同计算。谱号、调拍号、和弦文字与小节线仍保留各自所需占位。

纵向按所属谱表的音乐墨迹底边放置第一层歌词，再按每层真实文字墨迹排列后续层；大谱表空间不足时重新安排低音谱表。横向规则不会额外改变歌词垂直净空。

英文通过解析所得的词内位置与源位置连接音节，不将连字符当作歌词文字追加。两种谱式共用一个短横：长度为歌词字号的0.25倍、圆端描边0.055倍，位于基线上方0.28倍字号，词边净空从0.1倍字号起。横向测量为词内非末音节预留短横及描边空间；同一谱行内放在相邻同词音节实际墨迹之间，跨小节仍连接。跨行时在上一行音节右侧保留一个短横，下一行不添加前缀；语义不同的词、遍次及中文不据相邻文本猜测连接关系。短横与所属歌词共同参与实绘墨迹及纵向避让。

剩余可用宽度继续按谱行的节奏权重伸展，不另设歌词舒适余量或局部补偿预算。音乐三档、纵向歌词净空及英文短横的实绘约束保持独立。
