# 共用拥挤成本：按欠缺比例评分

简谱与五线谱共用`scoreNumberedSpacing`，横向拥挤项由`mean(max(0,舒适下限/g−1)²)`改为`mean(max(0,1−g/舒适下限)²)`。`g`仍是实际可见间隔按节奏权重归一化后的净空，先逐个间隔评分，再跨曲平均；舒适区内的零成本样本也计入分母。

该项改用“距舒适下限还缺多少比例”，零净空的单样本成本为1，不再随间距趋近零而发散。半个舒适下限的间隔成本为0.25，舒适下限及其以上的间隔拥挤成本为0。过松项仍为`mean(max(0,g/舒适上限−1)²)`；均匀度、字号、纵向、增页成本及各项权重保持原样。

简谱舒适区仍为16～24px，五线谱仍为18～27px；五线谱S=7.5px、横向三档6／12／18px、N范围15～30px、纵向舒适区22.5～30px。两种谱式继续共享选宽、断行、分页与评分算法，没有五线谱专用评分分支。搜索缓存版本为v88。

## 验证范围

单测覆盖零净空有界、半舒适下限成本、舒适区端点、不同谱式尺度、逐样本池化、跨行均匀度与共用权重。浏览器复测包括Chromium／WebKit桌面和平板、两份重点简谱自动选宽与赢家SVG审计、代表谱例双谱式密度审计，以及《突然好想你》702／720px固定宽度审计。

[117首双谱式对比](CURRENT_NOTATION_PAGE_COMPARISON.md)及其CSV保留为修改此曲线前的统计，不代表当前全库结果。本轮不重跑全库简谱基线；新公式的局部复测不能推广为全库页数结论。

报告目录：`.tmp/spacing-deficit/`。`design/report.json`为跨引擎五线谱自动选宽及几何核对；`density/report.json`为固定宽度双谱式密度及墨迹审计；`numbered/report.json`为两份重点简谱自动选宽及墨迹审计；`fixed-widths.json`为《突然好想你》固定宽度审计。

## 实测结果

| 谱例 | 简谱自动宽度／页数／行数 | 五线谱自动宽度／页数／行数 |
|---|---|---|
| 红河谷 | 528px／1页／3行 | 528px／1页／3行 |
| 突然好想你 | 654px／1页／12行 | 702px／1页／11行 |

《红河谷》五线谱继续保持三行；《突然好想你》五线谱由546px／2页／16行改为702px／1页／11行。两份重点简谱与既有基线的宽度、页数及行数一致，这不代表其余简谱也全部一致。

《突然好想你》五线谱702px固定宽度独立实绘审计：横向拥挤成本0.12213、横向总成本0.14687、纵向成本0.09157、字号成本1.64258，总成本1.88101，实际1页／11行，无碰撞或越界。720px为1页／10行，总成本2.23109。自动选宽结果来自新公式下重新运行的完整生产搜索，不仅是旧候选的重评分。

196个测试文件、1842项包测试全部通过。Chromium／WebKit桌面和平板共20例的全部候选评分与完整数值几何一致；两份简谱自动选宽赢家通过实际SVG审计；5份固定宽度双谱式密度谱例通过既有门槛，实际SVG无碰撞或越界。聚合RSS峰值975MiB，所有重检查串行执行。
