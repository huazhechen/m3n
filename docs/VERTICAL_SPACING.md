# 三档候选与统一纵向间距

简谱和五线谱分别配置 `minimumRowGapEm`，当前均为0.75。音乐字号为本谱式的1em；最小核心行间距为 `Nmin = music × minimumRowGapEm`，舒适区为 `[1.5Nmin, 2Nmin]`，自动伸展上限为 `2Nmin`。简谱对应18px下限、27～36px舒适区；五线谱对应19.5px下限、29.25～39px舒适区。

## 每个宽度的候选

横向最小净空采用三个档位：简谱8／12／16px，五线谱0.8／1.2／1.6谱间。两种谱式共享候选断行算法和最终评分，仅实际字形、节奏净空与几何由各自适配器提供。

每行的“不伸展占比”为当前档位硬下限宽度除以可用行宽。前两档软目标为2/3，最宽档为1/2；所有行均参与评分，末行、段落末行和明确强制换行不豁免。共享动态规划最小化所有行 `Σ[(1−ρ)₊² + (1−ρ/t)₊²]`，t为该档软目标；另保留不可拆超宽对象的溢出代价。低于目标只增加代价，不淘汰档位或宽度。每档仅生成一套断行，不再联合枚举替代断行来减少页数。显式 `minimumNoteGap` 保留底层固定间距覆盖语义，不参与自动档位软目标求解。

每档固定断行后，完整测量谱行，在 `Nmin` 下自然分页，得到这套断行的基准页数；它不代表所有断行中的全局最小页数。在 `[Nmin, 2Nmin]` 内二分寻找保持基准页数的最大统一行距，每次重新自然分页，分页位置可以变化。所有页面使用相同N；页面剩余空白保留，不再单页额外拉伸或重排短尾页。

各档按从紧到松计算并完整拟合；页数更多的档位也可能凭较低的间距代价胜出，不再按当前最佳页数提前淘汰。

同一宽度比较增页代价、实际横向间距不舒适代价、均匀度、溢出与纵向代价之和；跨宽度再加入字号代价。增页代价为 `2 × (√P−1)/(√2−1)`，P为页数：一页代价0，第二页增加2，后续每增加一页的边际代价递减。同分保留既有较松档位及较窄宽度规则。横向舒适区为最松档基准净空的1～1.5倍，简谱为16～24px，五线谱为1.6～2.4谱间；硬下限保持原样。横向代价为“均匀度代价＋拥挤代价＋过松代价”，各项权重均为1，简谱和五线谱共用；诊断字段直接记录各项代价。横向代价按全部实际节奏间隔归一化，零代价样本也计入；均匀度仅使用各行单位节奏间距的归一化方差 `mean((gᵢ−mean(g))²) / mean(g)²`，不叠加最大偏差项。纵向代价为 `max(0, (1.5Nmin−N)/(0.5Nmin))²`；舒适区内为零。所有页面均仅有一个音乐系统时不产生行间样本，纵向代价为零。

## 几何与覆盖选项

音乐字号为M。音符、小节、歌词和附件内部几何由音乐／文字字号与实际墨迹测量确定，不随N改变；不再另设行内雕版基准。普通附件净空为M/12，简谱歌词净空为M/8，注释、段名及和弦为M/6；简谱24px字号下分别为2／3／4px。

简谱谱头按实际N计算H=N/6：副标题块、署名行及换行音域的局部间距为H，标题到副标题及其碰撞净空为2H，标题到侧边信息、主体谱头到演奏顺序、顺序行之间及谱头到正文为4H。每次试探N同步重新放置谱头，复用既有文字测量；不改变音乐行内部几何。

合页的所有曲目共用一个N，曲间距严格为1.2N。准入与装箱容量在共同最小N下测量；最终在同页容量约束下拟合最大共同N，超出上限后的剩余空白留在页尾，不再增加曲间距。简谱与五线谱共用此求解器。

共享分页器检查同页所有先前系统的完整实绘几何。核心净空与非核心笔画净空要求取最大值，非核心区域净空为 `0.5N`。歌词和段落边界不再另设行间参数，实际墨迹继续参与避让。超长谱头可以在已测量文本块之间分页，所有块沿用同一个N。

连续输出使用最小行间距，断行选择与分页输出相同。显式像素 `coreGap` 只覆盖最终纵排，不改变选中的断行。谱集合页使用相同最小值与两倍伸展上限。

## 验证与性能记录

2026-11-28，三档软目标版本通过包回归、共享最短路径穷举对照、统一行距上界与分页变更测试。真实字体浏览器审计覆盖5份代表输入、两种谱式，未发现越界或墨迹碰撞。

《Flower Dance》在真实归档字体准备完成后，搜索528～720px的33个6px候选宽度并使用安全剪枝：简谱选宽约796ms，600px／2页／31行；五线谱约1064ms，630px／2页／23行。计时包含选宽，不包含打包、字体准备或最终SVG审计；这是单曲测量，不代表全库上界。本轮保留三档。

复测命令为 `python3 tools/run-low-memory.py node tools/benchmark-numbered-spacing.mjs --score=flower_dance_01 --prune --numeric-layout --external-fonts --minify`；五线谱去掉 `--numeric-layout`，增加 `--staff`。真实字体审计使用 `python3 tools/run-low-memory.py node tools/compare-notation-density.mjs --regression`。
