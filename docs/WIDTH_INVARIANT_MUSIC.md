# 不变音乐子集与延迟音乐输出

独立工作树 `perf/lossless-width-v2` 中，基于 `805d6442` 继续优化。保持单线程、528～720px的完整6px网格、三档断行、共享分页与评分，不改最终字形、曲线和附件间距。新候选调度仍通过 `--prepared-search` 基准入口启用，尚未切入阅读器；全库双谱式600ms目标仍未实现。

## 固定几何与安全退出

主线的柔性符梁组只有单符头，且不带倚音、奏法和延音端口。合法翻向不改变其音头横坐标、音高、临时记号、附点、横向间距输入，其他符梁组各自独立拟合。因此可从已定位模型直接提取实际谱线、音头、临时记号、附点及固定组的符干，形成所有试算均包含的音乐子集。

字形使用原有 `appendStaffGlyphInk`，直线使用原有 `staffLineInk`，保留同一舍入和描边边界。没有用包围整行的矩形代替曲线，也没有改变最终墨迹判定。子集中不包含柔性符干／符杠、曲线、倚音和位置可能变化的奏法。

附件单向界限继续使用原规则：上方文字的初始上沿是最终上沿的上界，下方文字的初始下沿是最终下沿的下界。不变音乐子集可代替此前柔性行仅用谱线的较弱约束。跨行碰撞仍使用放松1e-7px的独立上下沿通道。

另外从同一批单向约束提取标量高度下界，按坐标量级放松64个机器精度单位。它只用于判断无歌词方向偏好时，某次符梁翻向是否已不可能达到原有“高度严格改善超过1e-7px”的接受条件。歌词方向偏好和不能证明的情况，继续执行原有完整整行试算；证明失败也回退完整试算，取消错误继续传出。完整试算的比较顺序与选择规则不变。

首个仅用音乐点的界限没有在基本功测出收益，未独立作为优化结论保留。当前界限同时纳入附件的安全初始位置，且被选宽预检查与符梁试算共用。

## 行执行生命周期

原预检查在建立安全界限前，已经生成了完整音乐输出。现在仍执行原有音符定位和符梁拟合，但只建立谱线／谱号／小节线框架、附件和歌词对象，以不变音乐子集参与预检查。未被证明淘汰的行，才从已定位模型生成原有完整音乐输出，并继续连线、歌词与附件整理。

暂停行独占模型和锚点。晚生成的音乐插回原始位置，保持音乐在歌词之前的SVG顺序，不重新定位、不借用别的宽度留下的锚点。行完成仍只执行一次。普通完整绘制沿用同一音乐生成函数；共享分页器和代价求解器不因这个适配器生命周期变化而分叉。

方向试算只复用预检查已经得到的标量高度界限。没有歌词方向偏好时，若界限证明不可能改善超过原比较器要求的1e-7px，则省略该次整行试算。带歌词的方向偏好仍逐组完整执行。普通完整行不额外计算证明；中间版v108曾为它们建立证明，但全库收益不足，最终版v109撤回这部分额外工作。

碰撞通道沿用1e-7px的坐标放松；标量高度界限另按坐标量级保留64倍机器精度的舍入余量，避免前者的2e-7px高度放松使严格高度比较无法退出。标量仅使用固定音乐的完整上下沿、上方附件的初始上沿及下方附件的初始下沿；没有使用相反方向的附件边缘。逐图元子集检查和真实谱例逐行标量检查分别验证这两种证明。
