# 五线谱分页边界图元去重

2026-11-27，独立工作树 `perf/single-worker-600`，基于 `6b6a697a`。规则仍为 `a5a4c30b` 的6px谱间、0.6／1.8谱间双档；单Worker、528～720px全部33个6px档位和严格安全剪枝保持不变。

共享分页器分别读取普通避让墨迹、额外页边界墨迹及固定附件净空。五线谱适配器此前将完整行图元同时放入普通通道和页边界通道，只有谱号、小节号等少数图元实际只需保留页边界。现在在原有精确分类遍历中直接记录这些额外图元，分页通道不再重复收集普通音符、曲线和文字。

完整行图元仍供原有几何、输出和诊断使用。谱号的固定净空及全部图元的实际坐标不变；发布左侧谱表留白时同步平移额外边界数组。分页及行距查询都消费同一组通道；外部构造的旧行对象没有额外数组时继续使用完整边界。该修改仅调整适配器的数据表示，不增加搜索、分行、分页或评分算法，不近似或删除图元。

## 全量测量

117首，真实归档TTF，每批一个新Chromium，批内共享字体和文字度量，无预热、profiler或最终SVG。各批串行，Node堆384MiB、浏览器堆256MiB，聚合RSS守卫1700MiB。

| 五线谱 | 字形追加版本复测 | 本次 | 本次复测 |
|---|---:|---:|---:|
| 累计选宽 | 38.246秒 | 37.520秒 | 37.828秒 |
| 基本功 | 1802.5ms | 1775.8ms | 1790.2ms |
| 超600ms | 18/117 | 18/117 | 18/117 |
| 聚合RSS峰值 | 1340MiB | 1439MiB | 1331MiB |

相对表中基线累计耗时降低约1.1%～1.9%。前一版本另一次批次为37.979秒；将两次前后批次全部计入，观察到的降幅范围为约0.4%～1.9%，平均约1.2%。这是小幅收益，内存峰值没有明确改善。**所有乐曲、所有谱式600ms目标仍未达到。**逐曲数据见[CSV](WIDTH_BOUNDARY_EXTRA_PERFORMANCE.csv)。

两轮各1733组赢家／候选的宽度、页数、行数、物理间距和全部评分分量与基线一致，绝对误差阈值1e-8；逐曲谱源和字体摘要相同。五线谱24个文件240项测试通过，包构建通过。新增回归分别用完整边界与额外边界分页，覆盖不同宽度、小节号开关、连续／分页、多种页面容量及弹性行距上限，逐项比较页数、行数、每行纵坐标和最终行距。

原始报告为 `.tmp/glyph-append-repeat/staff.json`、`.tmp/boundary-extra/staff.json` 和 `.tmp/boundary-extra-repeat/staff.json`。复现先构建包：
