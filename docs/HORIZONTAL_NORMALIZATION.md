# 双谱式横向策略与页数归一

当前目标是相同纸张和可读尺度下尽量取得一致页数，而非强制相同行数。五线谱单行往往占高更大，允许它发挥符头较窄、长音不需要重复数字延长槽的横向优势，自然使用更少行。谱源、字号、768px自动选宽上限及内部碰撞避让保持原有约束。

## 当前横向规则

两种谱式共用节奏权重、拍组收紧、全局分行规划器、疏密与收尾评分及9／12／15px间距档（五线谱适配为0.25／0.3125／0.375），不复制另一种谱式的换行。

五线谱的硬容量取自身符头、符干／符尾、加线、倚音、调拍号、歌词及小节线实际占宽。正常阅读占宽另以普通符头加2.2个谱间距作为四分音符预算，再乘共用节奏权重，作为软约束；不把简谱数字和延长音槽的占宽强加给五线谱。等宽小节按最密小节分配，行首开销只计一次。尾行阅读预算最多引导到可用宽度，不得把软预算变为越界的硬宽度。

音乐与每遍歌词分别建立横向约束通道，共用 `solveScoreSpacing` 求解器。只在同一通道内预留相邻墨迹间距，不将某音符的宽歌词与下一音符的升降号跨层相加；稀疏歌词在真正有字的列之间持续约束。普通小节没有谱头时不预留空谱号块，小节线两侧以半个谱间距作为基础边缘净空；测量和绘制消费相同的列位置。

歌词后的碰撞净空也随该处核心净空收紧，两种谱式共用规则：默认连续模式从14.4px变为9.6px，分页仍可随局部核心净空伸展到15.84px；不能只缩核心要求却保留原来较大的碰撞净空。

字体准备后在单次任务内复用不可变测量描述，候选独立放置并避让。固定宽度内先取行数最少的间距档，再按横向质量选择；跨宽度仍先最少页数，再按质量评分。不同反复展开导致展示内容不同的曲目单独记录，不能用总行数直接比较。

## 历史：保留同行数约束时的页差试排

在768px固定宽度下，上述5首两种谱式的行数均已一致：分别11、37、12、12、14行，页差仍存在。因此这批页差不能再归因于横向断行；五线谱真实纵向占位和当前搜索上限共同影响分页。

仅作诊断地扩展到792～960px（每24px一档，不改变生产上限）时，《爱如潮水》从792px起两者均1页，《黑色幽默》《后来》《土耳其进行曲》从840px起均1页，基本功从888px起均2页。这轮为快速指标试排，未执行独立墨迹审计，不能据此直接发布新的选宽规则。报告为 `.tmp/page-parity-five-extended/report.json`。888px映射同一A4版心时，五线间距约1.47mm，768px时约1.70mm；应连同真实可读性和全库重新选宽结果评估，不能只看5首候选页数。

最优页数审计工具支持 `--scores=ai_ru_chao_shui_01,hou_lai_01` 限定排查范围；报告明确记录是全库还是选定曲目，并保留每个实际搜索候选的页数、行数和评分，便于区分搜索边界与排版容量问题。

按用户选择，生产选宽上限继续保留768px，优先保证可读性。排查剩余页差时可使用 `compare-notation-density.mjs --core-gap=0` 测量仅去除谱行核心／碰撞净空后的容量边界；此参数仅作用于本次诊断的最终纵排，报告记录传入值，固定回归禁止覆盖。零净空不作为发布方案。

修复奏法记号方向及局部文字固定留白后，5首在768px仍各多一页，独立墨迹审计通过。零行间净空的诊断中4首可同页，但基本功仍需3页，连续高度约2502px，并检测到1处系统间碰撞。这说明继续压行距既不能解决全部差异，也不能作为安全方案。该轮结果为 `.tmp/page-parity-current-five/report.json` 与 `.tmp/page-parity-zero-gap/report.json`；后者的非零退出为真实碰撞诊断，不作为通过的回归结果。


## 当前规则的最终全库验收

2026-11-26，按当前谱源及v18生产规则复核全部114份谱源（112首曲库、1份作品、1份示例），各自完整搜索528～768px的粗档及6px细档。114份最佳选宽结果的页数全部一致；两种谱式的选中结果均未检测到墨迹碰撞或越界。报告为 `.tmp/page-parity-native-all-optimal/report.json`。

首次审计曾因其他工作区任务触发总内存保护而分两批完成；随后发现反复点漏检，修正检测器与左反复占位后，废弃其安全结论，重新从头执行全库审计。

| --- | ---: | ---: |

| 半音阶口琴基本功 | 2页／744px／37行 | 2页／768px／29行 |

字号与搜索上限保持不变。行数不作为相等条件：五线谱允许以较少行补偿单行占高；软阅读预算也按音乐与歌词分别求解，避免将跨层包围盒重复相加。普通四分音符的软阅读预算校准为普通符头加2.2个谱间距，既保留《玛丽有只小羔羊》640px自动两行，也允许歌词曲按实际空间减少行数。

110份展示事件数相同；另4份仍纳入全部页数与安全检查，只不混入按事件数或相同展开内容归一的密度统计：《You Raise Me Up》因分遍换调展开，事件数157／252；《第二圆舞曲》的3个多小节休止虚拟占位导致201／198；《天黑黑》间奏占位导致274／273；《突然好想你》间奏占位导致320／319。后3项是统计口径差异，第一项是展示展开量差异，均不是丢音证据。4首各自最佳宽度下两种谱式均1页。

固定真实字体回归保留墨迹安全、物理字号、连续高度上限、《玛丽》自动两行，以及基本功震音8小节同一行等要求，不再强制两种谱式的行数差不超过一行。最终回归报告为 `.tmp/page-parity-native-regression/report.json`。

另外对原5首页差曲目在五线谱最佳宽度下导出同宽的双谱式对照PNG与10份实际PDF，独立墨迹检查全部通过；PDF均为A4，页数为两种谱式各1／2／1／1／1页。这5首同宽连续高度比中位数1.039、90分位1.095，行数合计为简谱88、五线谱73。结果保存于 `.tmp/page-parity-final-exports/`；该统计只代表这5首，不能替代全库固定宽度密度报告。


## 反复点碰撞与门禁补漏

《Butter Fly》第二小节暴露了两层遗漏：渲染器普通小节起始净空没有计入左反复点向音乐区域伸出的宽度；独立审计仍查旧类名 `g.barLine`，而当前输出是 `g.staff-bar`，并且对象配对过滤没有比较bar与music／control。因此先前零碰撞结果只能说明旧门禁没有报错，不能证明反复点安全。

修正后，左反复记号放在实际行首谱号／调号／拍号之后，按反复点真实墨迹右边界加半个谱间距预留起始区域；行中也使用同样的墨迹净空。门禁同时覆盖当前／旧小节线类名并加入bar与音符／休止的独立像素比较，仍允许五线穿过音符、符干与符杠相接以及相邻小节共用边界。

使用加强后的检测器、保留修复前几何时，《Butter Fly》528／640／768px均检出同一处碰撞，每处19个2倍分辨率不透明重叠像素；修复后3档均归零。前后报告为 `.tmp/butterfly-repeat-before/report.json` 与 `.tmp/butterfly-repeat-after/report.json`。检测器另有故意让反复点覆盖音符／休止的反例测试，移开后须通过，角色临时标记必须还原；该测试已加入Score artifacts CI，曲目本身也加入固定真实字体密度回归。最终全库安全结论必须使用补齐后的门禁重新验收。


补齐反复点检测后，从头重跑114份最佳选宽审计与全库固定640px审计，均无检测到的墨迹碰撞或越界。最佳选宽的114份页数仍全部一致；固定640px的110份事件数一致样本中，99份页数相同、连续高度比中位数1.043、90分位1.171，简谱共919行、五线谱793行。固定宽度的页数一致不是本轮硬约束，仍需保留各自最佳选宽；报告为 `.tmp/page-parity-final-all-640/report.json`。

多宽度门禁不再用旧字号常量寻找三连音数字，改按实际 `data-m3n-relation="tuplet"` 标记定位，继续检查基本功连续三连音的共同基线，避免字号校准后出现空集合误报。简谱审计的打包阶段移入独立子进程，退出后才启动浏览器，降低检查期间的聚合常驻内存。


最终验证覆盖简谱936组多宽度实绘检查、全库114份最佳选宽及固定640px独立审计、谱集浏览器回归、完整字体PDF验收，以及全部38个页面端到端测试文件。端到端检查按文件串行，失败项修复后定向重跑；资源断言同步共享包策略，编辑器检查固定宽度，阅读器检查528～768px／6px选宽结果，高亮与房子线按真实墨迹比较。音域与正文圆点的形状及字号比例另有直接SVG回归。检查过程使用单worker、受限Node堆和聚合RSS保护；可用 `M3N_E2E_LOW_MEMORY=1` 限制浏览器堆及备用渲染进程。
