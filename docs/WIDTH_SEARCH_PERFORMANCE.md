# 精确选宽性能分析

当前v40设计轮廓与完整6px网格的117首实测见[当前简谱选宽性能](NUMBERED_WIDTH_PERFORMANCE.md)。下文保留此前排版规则及局部搜索的历史测量，不能作为当前性能数据。

本轮继续使用逐元素避让和完整曲线几何，不采用搜索阶段的近似弧线、较宽采样条带、状态量化或有损剪枝。简谱和五线谱各117首，使用一个浏览器和共享字体度量，开启生产剪枝及6px局部细搜；不做碰撞、越界或截图审计。

## 最慢曲目的 CPU profile

两种谱式最慢的都是《半音阶口琴基本功》。在全量批次中仅对该曲开启 CDP CPU profile，保留此前曲目的预热及字体复用。profile 会增加耗时，因此性能验收使用另一次不启用 profiler 的批次。

简谱主要路径为候选准备、完整行几何和分页约束搜索。近期采样中，候选准备约229ms，其中投影复制约48ms、横向约束绑定约47ms；完整行几何约88ms；分页约束搜索约116ms。上述是包含子调用的时间，不能相加当作总耗时。垃圾回收约106ms，说明重复创建候选对象也有实际成本。弧线并不是唯一、也不是最大的单一热点。

五线谱主要路径为实际行生成和附件排列。近期采样中，行生成约563ms，其中附件排列约300ms、音符及小节绘制约161ms；共享分页约束搜索约232ms，其中横向断行约103ms。几何收集在不同调用栈中反复出现。优化前的分页可行性闭包约119ms，复用固定前缀后约43ms；不同 profile 仍有采样和 JIT 波动，不能把单次差值当作独立功能的精确收益。

原始 profile：`.tmp/all600-numbered-basic-latest.cpuprofile`、`.tmp/all600-staff-basic-latest.cpuprofile`。这两份采样用于定位，后续修改的整体收益以全量复测为准。

## 已落实的复用

- 两种谱式共享的前缀分区搜索，先用当前可行代价限制横向最优解，再进行高度可行性和分页代价求解。无兄弟分支不复制完整图，不重复求已知横向解。
- 共享横向求解器只准备固定前缀之后需要的候选。保留原浮点加法顺序、凸包和同分断行规则，不设置搜索数量上限。
- 共享高度可行性求解只为可达端点分配状态；分页的相同固定前缀复用精确转移。缓存上限只限制存储，不限制搜索。
- 不可变行块复用归一化、排序和两行之间的精确逐元素分离距离；普通可变输入仍重新测量。
- 简谱换宽时用整数索引重绑横向坐标目标，复用不变的节奏间隔分析、最小约束链及等宽分组。继续为每个候选保留独立坐标、控制符和标记。
- 简谱跨行弧线的行首预留按间距档位和完整小节跨度复用；分片保留原计算。关系放置期间复用障碍物和分组信息，结束后释放。
- 隐藏小节编号延后生成 SVG，行快照保留延后属性，避免搜索时被对象复制强制求值。隐藏编号与可见编号的原分页规则保持一致。
- 五线谱只为当前行可能出现的连音端点扫描签名和小节线；先过滤本行圆滑线，再排序。其余关系保留原绘制顺序。
- 五线谱数值音符直接提供精确墨迹，内部几何读取和静态编译复用这些墨迹；自定义过滤器、文字、复杂音符及公共可变读取保留原遍历路径。附件索引跳过已确认只含音乐图元的子树。

## 验证口径

对照当前修改前提交的同谱源报告，比较每首赢家及共同被测宽度的页数、行数、单位节奏净空、均匀代价、紧凑代价、横向断行代价、字体代价和总代价，容差为1e-8。按宽度匹配候选；安全剪枝省去候选不视为排版变化。只看赢家宽度不足以验证这些缓存和剪枝。

复现：先执行 `python3 tools/run-low-memory.py npm run build:packages`，再串行运行：

```sh
python3 tools/run-low-memory.py node tools/benchmark-numbered-spacing.mjs --numeric-layout --prune --local-refine --output=.tmp/perf-numbered/current.json
python3 tools/run-low-memory.py node tools/benchmark-numbered-spacing.mjs --staff --prune --local-refine --output=.tmp/perf-staff/current.json
```

加 `--profile-score=ban_yin_jie --cpu-profile=.tmp/basic.cpuprofile` 可在完整批次中仅采样《基本功》。构建、测试、字体生成和浏览器批次串行执行，单worker、Node堆384MiB、浏览器堆256MiB，并用聚合RSS看门狗保证工作区进程低于2GB。

| 谱式 | 优化前累计选宽 | 优化后累计选宽 | 《基本功》之前 | 《基本功》之后 | 超过600ms |
| --- | ---: | ---: | ---: | ---: | ---: |
| 简谱 | 29.443秒 | 25.109秒 | 1275.7ms | 825.6ms | 6/117 |
| 五线谱 | 29.508秒 | 21.605秒 | 1592.2ms | 752.9ms | 1/117 |

简谱1502个、五线谱1542个赢家／共同候选组合的上述字段均无超过1e-8的差异。简谱全量看门狗峰值1340MiB，五线谱1406MiB。报告分别为 `.tmp/all600-shared6-numbered/current.json` 和 `.tmp/all600-shared6-staff/current.json`。累计选宽不包含浏览器启动、字体准备及报告写入；不应称为整批脚本耗时。

**仍未达到所有曲目600ms。** 简谱剩余《基本功》825.6ms、《老男孩》621.3ms、《莫扎特K545》755.8ms、《Valsentino》682.8ms、《星星点灯》627.0ms 和 `snail-mushroom-waves` 727.6ms；五线谱剩余《基本功》。本轮只落地保持精度的复用，不用较少候选、较少分页或不同评分来掩盖未达标。

共享分页求解器的新增穷举回归覆盖逐元素与整行分页、逐步收紧几何和相同分页位置的并列状态；五线谱适配器另验证所有小规模断行方案的段尾目标宽度。五线谱完整39个文件407项通过。简谱完整116个文件1175项通过、4项失败；在未修改的 `7d85cf4e` 独立工作树中，四项失败全部复现，断言值完全一致，分别涉及括号端点、三角标记、局部弧线高度和密集小节分片。未放宽或删除这些断言。独立目录的生产构建、生成物更新及校验通过；lint只有既存的未使用参数警告。


## 共享分页求解及进一步热点处理

分页代价求解和控制流程现在全部由 `native-refined-page-breaking.ts` 提供：贪心页数上限认证、乐观资源DP、几何收紧、精确复核、可行上界改进和全局前缀分支回退。简谱与五线谱只提供几何适配器；五线谱的 `staff-page-model.ts` 不包含搜索或评分算法。该约束同时写入 `AGENTS.md`。未知行只用安全高度下界；完整行几何只按实际访问的方案生成，避免为资源DP提前雕版全部候选行。

相对上一提交 `b0467a54`，简谱累计选宽由27.518秒降到25.109秒，五线谱由21.722秒降到21.605秒；《基本功》分别由894.3ms、858.8ms降到825.6ms、752.9ms。全量未开启profiler，也未使用预热单曲结果替代验收。

具体复用与消重：

- 投影复制显式保留完整字段，稳定V8对象结构；依然独立复制可变坐标、控制符、标记和歌词状态。
- 核心高度端点探测复用同档位横向约束模板，避免重复创建节奏间隔链。
- 行轮廓交集改用横向活动集合扫描；保留原边界、退化图元的页边界及所有精确曲线范围。
- 分页DP只给可达端点分配状态。同一行、相同行数、相同参考间距统计及完全相同分页位置的状态，先做统计凸包消重，再并入资源前沿。无需为高度相等的每一对状态展开整条断行路径。
- 无需跟踪段内间距均值时，按前一行复用几何。等宽小节的段尾在前一行已知时直接使用已测得的继承宽度几何。
- 代价上限由已证明的下界开始，先增加0.05、再逐次加倍增量；不按全曲总代价乘1.25后直接放入大量无关状态。这只选择精确求解顺序，不限制最终搜索。
- 渐强渐弱线在一次几何任务内共用端点索引及行内声部成员，避免每条线反复扫描全谱。

试验中，五线谱在原搜索前单独追加资源DP令《基本功》升至1118ms，因此撤回该串联流程；最终两种谱式直接共享求解控制流程。额外的已知轮廓远距离碰撞预检查在117首简谱上零命中，已删除。只缓存编译图元联合边界的试验没有明显收益，也未保留。

`--score=ban_yin_jie --warmup=2` 可在一个浏览器内对单曲预热后诊断，并在报告中标明 `warmupIterations`；此模式只用于快速定位，不作为全量600ms验收。最终全量命令仍不加 `--warmup`。


## 精准避让统一与0.5净空恢复

本轮按新的排版要求恢复非核心净空为核心间距的0.5倍，删除整行／小节矩形避让、独立小节最终高度探测、旧模式开关与对照工具。五线谱原生产路径仍使用整行避让，现改用实际图元；两种谱式共用 `native-page-geometry.ts` 的坐标归一化、`native-page-collision.ts` 的碰撞／固定附件净空、同一精准分页器及分页代价求解器。谱号和房子线的固定净空作为适配器提供的几何数据保留。未知行的高度包络仅是安全搜索下界，不作为横向碰撞矩形。

五线谱谱头保持整行的开头留白约束；输出左侧谱号留白平移后，行块缓存识别几何数组变化，防止缓存旧坐标。已有跨行距的缓存／全新排版SVG一致性测试通过。简谱的排版中提示改为无内容时居中显示，重排时保留已有谱面；排版阶段不再弹出资源对话框。

这次属于明确授权的排版规则变更，不能以旧0.3／五线谱整行避让结果作为不变性门禁。与 `989d9b30` 的117首生产局部细搜＋剪枝报告相比：

| 谱式 | 之前累计选宽 | 本轮累计选宽 | 优宽／页数／行数变化 | 页数变化 | 超过600ms |
| --- | ---: | ---: | ---: | --- | ---: |
| 简谱 | 25.109秒 | 26.110秒 | 26首 | 《星星点灯》1→2页，其余不变 | 6/117 |
| 五线谱 | 21.605秒 | 37.365秒 | 34首 | 全部不变 | 16/117 |

报告为 `.tmp/precise-numbered/current.json`、`.tmp/precise-staff/current.json`，对比明细为对应的 `precise-*-comparison.json`。两批串行、各启动一次浏览器，未预热、未开profiler，聚合RSS峰值1400MiB。精准避让迁移增加了五线谱的开销，600ms目标仍未完成；后续性能优化应保持本轮新规则下的赢家、共同候选分页和评分。
