## 决策范围

可以分别决定：①是否恢复第10小节第二次A4起音；②圆滑线以第一小提琴版为准、以长笛版为准，或逐条保留编配；③是否补曲末延长记号；④是否去掉第二段重复房子。已确认的装饰简化单独保留，不因清理圆滑线而自动撤销。

验证：第11小节修订后，`npm run prepare:scores`、本曲两项回归及 `npm run check:score-artifacts` 均通过。回归新增第11小节无圆滑线区间的检查，既有整段主音起点／时长比较继续验证同音延音；未执行其他待定修订。
