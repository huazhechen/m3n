# 《谐谑曲》两份谱交叉复核（2026-11-26）

来源A为用户上传的Vojtěch Pospíchal三页多声部编配谱；来源B为[Flutetunes独奏谱](https://www.flutetunes.com/tunes/bach-orchestral-suite-no-2-badinerie.pdf)，并以其[MIDI](https://www.flutetunes.com/tunes/bach-orchestral-suite-no-2-badinerie.mid)检查完整主旋律。此次重新下载PDF与MIDI，均与前次保存的文件逐字节一致。

## 结论与范围

两谱共同的主干旋律、音区、2/4拍和两个反复段一致；装饰和奏法并非逐音逐记号相同，不能把“按主旋律化简后吻合”表述成“两份原谱每个音都相同”。M3N以独奏版组织单旋律，保留上传谱中与它兼容的连奏标记，不加入和弦伴奏。

本记录按上传谱的42个书写单元编号：第1、18单元为一拍弱起，第17、42单元为一拍收尾，其余两拍。独奏版不把这些弱起／补足位置全部另计完整小节，故其印刷小节号不能直接等同此表编号。

逐单元从上传谱读取两个四分拍位置的主奏音；在叠置和弦中选择独奏线，在邻音装饰位置回到被装饰主音，得到80个独立锚点。所有锚点与M3N一致；另由独奏MIDI独立取得的228个主音起点和音高继续全部匹配。前者检验编配谱的主奏选择，后者检验完整单旋律；都不将MIDI中的断奏留空或任意颤音展开时长当作谱面时值。

## 本次实际修订

- 第21单元：上传谱圆滑线只从E5到D♯5，收短到第二音；独奏谱此处未标线，音高、节奏相同。
- 第35、36单元：两谱均标出快速下行四音组的圆滑线，恢复B5–A5–G5–F♯5和G5–F♯5–E5–D5两条线；前面的G5、E5同音延音线仍单独保留。这两处在前次低分辨率复核中被误删。
- 第39单元：两谱均只把B4–A♯4连奏，终点不包括后面的C♯5，修正前次越过一个音的端点。
- 曲末：两谱均有C♯5到B4的无斜杠倚音及延长记号，改为长倚音 `{ap(7)}` 并补 `{fermata}`。不人为改变反复总拍数。
- 补齐独奏版第19、22、23、34、38、41单元的断奏点；上传编配谱在部分和弦或装饰中使用不同奏法，未宣称所有奏法都与它逐记号相等。
