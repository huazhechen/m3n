# iPad mini 最优宽度阅读抽查（2026-11-26）

## 范围与方法

基线为 `a02de57f`。在实际托管阅读页逐曲打开自动推荐宽度，10首、两种谱式、横竖屏，共40组；另对6首双谱式补看竖屏中段与末尾。没有改谱源、插入换行或更改刻绘参数。

使用 iPad mini 6/7 的屏幕尺寸模型：竖屏744×1133 CSS px、横屏1133×744 CSS px、DPR 2、触屏及粗指针；为浏览器工具栏假设预留100px高度，实际网页视口为744×1033、1133×644。40组均确认 `(pointer: coarse) and (hover: none)` 生效，不启用桌面端整张A4适高缩放。浏览器为Chromium；这是布局及截图模拟，尚未在实体iPad的Safari、实际观看距离和亮度下验收。

按CSS像素尺度查看双谱式并排图，并放大检查高音加线、八度点、倚音、断音点、多遍歌词及反复区域。数值取实际SVG视口和屏幕变换；歌词字高以加载字体的Canvas墨迹测量，不把CSS行盒当作真实字高。符头字高和简谱数字字高不直接相等比较，五线间距单独列出。以下竖屏表中的尺寸均为CSS px，不是DPR 2截图的设备像素。

临时证据在 `.tmp/ipad-mini-optimal/`：`report.json`为40组首页测量；`supplement.json`为中段／末尾检查；`*-portrait-pair.png`为CSS像素尺度对照；`*-landscape-middle.png`为横屏滚动中段。只使用viewport截图，废弃会改变触屏媒体条件的fullPage截图。两批浏览器审查RSS峰值分别1358／1280MiB，串行执行；资源失败和脚本错误均为0。

## 确认的体验问题与优化顺序

### 1. 屏幕阅读仍承担A4纸边的缩放损失

竖屏744px中，纸张宽726px，实际SVG版心约643.02px；左右12mm纸边各映射约41.49px。保持外侧9px边距，仅在屏幕上收起纸边，版心可由643.02扩至726px，约放大12.9%，无需改变最优逻辑宽度、重新分行或减少碰撞净空。

相应地，《基本功》五线间距约5.86→6.62px，《花之舞》约7.08→7.99px。这个收益只是显示几何推算，还没有实现或用修改后截图验收。应先做屏幕版心呈现，保留打印／PDF的A4纸边和现有分页。短曲可进一步收起仅用于纸张展示的尾部空白，避免《玛丽》横屏滑入整屏空白，但不拉大谱行来填纸；不要直接切换当前“连续”模式代替，因为现有自动选宽只在分页模式启用，直接切换会改变选宽路径。

### 2. 悬浮控制条遮挡滚动途中的谱行

竖屏控制区高约67.28px，位于y=954.09～1021.38。首页截图中《烟花易冷》《青鸟》《花之舞》《基本功》等底部谱行被覆盖；补看的《花之舞》简谱、基本功双谱式中段也确认遮挡。横屏可见谱行更少，相同覆盖更容易打断跟读。

滚动到底后，补看的12份结果最后一行均能完整位于控制条上方，说明末尾已有有效预留，并非谱面内容被裁切。仅继续加长整篇底部空白不能解决中段遮挡。建议提供阅读时收起控制条的方式，或让控制区与可滚动谱面占据各自区域；播放跟随定位应使用扣除顶栏／底栏后的实际可见区域。验收必须包含中段跟读与滚到底，不能只测最后一个音符。

### 3. 相同页数仍有跨曲／跨谱式尺度差异

《基本功》的五线间距5.86px，《Butter Fly》8.52px，相差约45%；简谱数字墨迹高15.56～21.92px，相差约41%。当前规则已经给较窄版宽更高字号权重，但页数优先，密集曲仍可能以较小屏幕尺度换取较少页数。

同曲也存在差异：《烟花易冷》简谱／五线谱歌词em分别16.81／15.73px，五线谱约小6.4%；《青鸟》的逻辑宽度612／660px对应音乐尺度约小7.3%。这来自各自最优版宽映射到同一屏宽，不是核心字号配置失效。

先收回屏幕纸边，再按实际屏幕尺度复核剩余问题；如仍需放大，另评估屏幕阅读的字号偏好与自动分行，不把打印页数当作唯一阅读目标，不通过突破768px上限来换页数。需要同时核对页面推荐值与完整搜索，避免把路径差异当作阅读策略差异。

### 4. 局部刻绘继续精修，避免全局加松

《烟花易冷》的“旧故里草木深”等短音字串与长音字距差别仍可见；已有软余量带来改善，但不能声称消除了词串感。后续宜按最紧连续歌词窗口检验有限重分配与节奏比例，而不是扩大所有字距。

《花之舞》的多层加线与双八度点是音域负担，放大比进一步横向压缩更有效；未确认需要改写八度线。《深情的吻》的双倚音已成组且可辨，长连奏线跨行后仍显悬离；后续单独检查端点靠近音符、跨行片段曲率与线条重量，不能用更大行距掩盖。

## 下一步验收建议

优先完成屏幕纸边收起与控制条遮挡优化，复用本轮10首、各自推荐宽度及横竖屏截图。记录屏幕版心宽度、歌词em／真实字高、五线间距和扣除控制区后的完整可读行数；页数、逻辑版宽与自动分行无意外变化，打印／PDF保持原A4几何。再对仍密集的基本功、高音快速段和歌词窗口做局部调整。

《玛丽》《Butter Fly》《一步之遥》的现状可作为舒展度参考，不要求所有曲目同字号或同行数。本轮是阅读体验抽查，未重新运行全库碰撞门禁，也没有把截图模拟替代实体iPad Safari验收。
