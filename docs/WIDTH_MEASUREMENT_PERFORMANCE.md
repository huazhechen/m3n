建议按以下顺序开展下一轮实现，每项单独测量并核对全部候选：

1. **减少布局中的SVG生成、格式化和再解析。** 小节线、谱头、控制符、符杠等仍有“生成SVG→XML解析→墨迹”的路径；让绘制与测量消费同一份数值图元，直接返回墨迹。保留六位小数的几何语义，避免对同一坐标反复格式化；不能直接用另一种舍入规则替换 `toFixed(6)`。先覆盖高频简单图元，并用直接几何与实绘解析逐项对照。
2. **拆开间距无关的准备与可变排版状态。** 1,365个候选实际进行了3,058次完整试排，曲目投影和谱头也随之重做。先在同一候选的0.4～0.6em试排间共用只读音符度量、已解析音乐事件及相同版宽的谱头准备，分行、坐标、关系线及分页状态每次独立创建；再评估跨候选复用无关宽度的部分。避免缓存整曲排版或直接共用会被修改的投影对象。
3. **优化曲线精确求交。** 每个截面仍对每条边做32次二分、重建控制点数组；先将曲线边及系数准备一次，在同一几何计算内复用，增加可证明安全的包络排除。保持避让和数值精度，用原精确实现、随机障碍及全候选审计作对照，不减少检查覆盖。
4. **降低文字度量命中路径的开销。** 约1,139万次命中仍重复构造字体键、Map查找及复制度量对象；评估内部只读度量通路和预先确定的字体样式标识。对外继续保留返回值修改隔离，字体变化即失效，新任务独立；不能靠扩大跨任务缓存取得收益。

目前分行搜索约1秒、页面拟合约1.6秒，不是优先热点。保留全部13档和当前综合质量评分，不通过缩减候选、关闭避让来加速。上述方向的实际收益需实施后重测，不能从采样占比直接推算总提速。

## 按优先级实施的四步优化

第一步：小节线与符杠的布局测量直接计算与实绘相同的数值墨迹，避免SVG生成、XML解析和重复坐标格式化。反复圆点保留真实字体矩阵墨迹；六位小数语义不变。直接几何对照覆盖全部小节线类型、重复点、负坐标／小数位置与符杠认领；简谱907项测试通过。全量1,365个候选与基线完全一致，独立生产测量为59.260秒（基线67.047秒）。与测试重叠的测量已排除；采用测试结束后的独立测量。明细为 `.tmp/opt1-{probes,timings,comparison}.json`。

第二步：同一候选的间距试排共用只读初始投影与谱头的换行／文字块和音域字形准备。每次试排仍复制坐标、列、小节、控制符、导航与记号状态，变调展开也只准备一次。新增6组固定调／首调与480／640／720px对照，逐次完整重排的SVG与复用版相同；谱集浏览器测试通过。全量候选与第一步完全一致。独立测量为51.918秒；投影构建1,365次，复用1,693次，间距试排仍3,058次。第二步测量移至独立工作目录，排除其他任务并行字体构建／测试造成的受干扰轮次；同时排除了混入其他分行修改的无效对照，最终以纯优化版本、后台空闲后的全量测量为准。明细为 `.tmp/opt2-{probes,timings,comparison}.json`。

第三步：曲线边、控制点和导数只准备一次，同一曲线复用精确横坐标截面；二分热循环读取预先准备的标量坐标，普通截面不提前计算斜率。保留原Bernstein运算顺序和32次二分；曲线平移后重新准备，复用限定在当前曲线／任务内。150组双方向随机曲线、端点、竖直连接及查询上限回归与原实现精确一致，48项相关测试及谱集测试通过。最初仅准备对象的版本为52.392秒，未取得收益，继续调整后的全量耗时为47.440秒，比第二步减少8.63%；全部1,365个候选完全一致。后台构建重叠的轮次不纳入结果；本轮仍可能受其他任务短暂构建影响，耗时为本机单次观测。明细为 `.tmp/opt3-{probes,timings,comparison}.json`。

第四步：任务内度量以冻结对象保存，布局直接读取；公开默认调用仍返回可独立修改的副本。连续相同字体复用已构造的完整样式键和只读文字桶，字体版本变化即重绑，新任务独立。新增内部只读／公开可修改、完整样式隔离、字体成员／状态变化回归；取消内部转发包装，直接由同一个Canvas度量器选择只读通路。字体键构造为1,200,864次，低于8,410,179次度量请求，实际Canvas调用仍2,741次。所有1,365个候选一致。前三轮全量耗时52.342／57.508／87.172秒，均遇到并行字体生成、构建或浏览器测试，不用于推断第四步收益；紧邻对照在没有并行测试／字体生成时重跑：改前47.298秒，改后46.543秒，减少1.60%；同样1,365个候选完全一致，收益较小，单次观测不能视为稳定统计显著。相较第三步首次47.440秒减少1.89%。正式明细为 `.tmp/opt4-{probes,timings,comparison}.json`，紧邻对照为 `.tmp/opt4-ab-{before-probes,before-timings,comparison}.json`。内部曲线求交准备也改为不可枚举属性，保留几何对象值比较；相关回归已修复并复测。

## 整册字体准备与页数一致性修复

中文子集都注册在 `Noto Sans SC` 下，字符覆盖存在交叠。后续子集加入后，浏览器可能为已有字符选择不同的字体face及文字片段，Canvas实际墨迹边界发生变化。复现中，同样22px字号的“半音阶口琴基本功”上沿高度由20px变为19px；自动选距、分行与分页因此不能依赖字体尚未准备完毕时的结果。

本地与在线谱集现均先准备全部曲目字体，再开始选宽；本地新增独立的 `fontPreparationMs` 阶段，在线也区分字体准备与候选测量耗时。保持测量和最终实绘使用相同的已安装字体集合，不增加测量结果缓存。

2026-11-24，全库105首、1,050个候选重新测量，并完成全部独立页、合页和PDF导出：87页，105首链接齐全，无栅格图片，PDF导出越界0页；所有测量／实绘页数一致性断言通过。基本功在已准备完毕的字体状态下选为580px、3页。浏览器回归另验证540／640／720px在重复准备其余曲目字体后仍保持相同行数和页数；谱集24项测试、在线谱集7项测试及类型检查通过。

修复后的逐曲墙钟耗时之和为137.83秒，整册字体准备0.37秒；此轮作为后续生产布局优化的新基线。报告位于 `.tmp/page-count-fixed-baseline.json` 与 `.tmp/page-count-fixed-baseline-probes.json`，整册日志为 `.tmp/page-count-fixed-full-book.log`。旧版字体加载顺序的候选不能用来要求新基线逐项一致。

## 定位与改动

原始测量中，独立质量评分重复排版累计409.43秒；安全的一页曲目还会从头解析、排版连续版。改为每个候选建立一次布局，分页、连续版和评分共用横向排版；同曲各候选复用解析文档与已完成的字体准备。

第一轮仍有298.70秒花在布局内部。真实CPU采样定位到大量文字测量、SVG字符串生成和XML解析；因此歌词布局直接计算与最终文字／下划线绘制相同的墨迹，并遵守SVG的六位小数坐标舍入，省去生成交互属性再解析的往返。最终SVG绘制路径保留，几何测试直接对照其实际图元，覆盖标点、分遍前缀、下划线与空歌词。同时消除歌词函数内的重复文字测量；未添加文字测量结果缓存。

两处碰撞算法保留原有判定：SVG安全验收先按横坐标筛选，再检查超过0.5px的实际相交；纵向分页按横坐标扫描并以两个堆寻找相交墨迹所需的最大分离量，保留严格水平相交条件。随机测试均与穷举逐对计算对照。

## 复测和报告

默认每次全量测量。可明确指定：

```sh
node tools/build-scorebook.mjs --probe-only --force-measure --timing-report=.tmp/width-timing.json
```

每轮保存 `.tmp/scorebook-v75-web/width-probes.json` 的独立副本，再运行 [候选对照工具](../tools/compare-scorebook-measurements.mjs)。该工具拒绝把复用结果混入全量比较，并核对所有候选，不能只比较最后选中的宽度。最终一轮使用完整谱集构建，在全量测量后继续验证最终实绘与PDF。

分段报告含总量、逐曲、逐候选、最慢10首、布局内部子阶段、文字测量次数及碰撞理论／实际比较对数；在线导出也在返回值 `measurementTimings` 中保留测量阶段快照。字段含义和命令参数见 [谱集文档](SCOREBOOK.md)。

本工作区原始明细位于 `.tmp/width-benchmark-before-probes.json`、`.tmp/width-benchmark-after-probes.json`、`.tmp/width-benchmark-targeted-probes.json`，最终计时为 `.tmp/width-benchmark-targeted.json`，完整对照为 `.tmp/width-benchmark-targeted-comparison.json`。最终轮在PDF打包失败前已保存全部逐曲与候选计时，因此计时报告从这些原始数据恢复，不补造全流程耗时；随后独立重试PDF打包通过。实现现在会在测量结束和最终实绘后立即保存计时检查点。上述临时生成物不提交Git，本文保留结果与复测方法。
