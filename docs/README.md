# Max's Markup Music Notation (M3N)

M3N 是一种面向旋律制谱的文本记谱语言。用首调音级输入音乐，即可在浏览器中编辑、播放并渲染为标准五线谱。

它适合希望快速记录旋律、校对乐谱或以纯文本分享音乐的人。

## 快速体验

```m3n
{title=小星星}
{key=C} {4/4}
1 1 5 5 | 6 6 5^ |
4 4 3 3 | 2 2 1^ |||
```

`1` 到 `7` 是首调音级，`|` 分隔小节，`^` 将前一个音的时值加倍，使小节恰好填满 `4/4`。

## 能做什么

- **写旋律**：用音级、八度、临时变音、节奏和休止符记录旋律。
- **组织结构**：使用反复、跳房子和具名乐段表达曲式。
- **丰富演奏**：添加力度、奏法、装饰音和和弦标记。
- **编写完整乐谱**：为旋律添加歌词和低音谱表。
