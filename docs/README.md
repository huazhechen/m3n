# Max's Markup Music Notation (M3N)

学习并使用 M3N 在线制谱、读谱与导出的工具。M3N 是一种面向旋律制谱的文本记谱语言：用首调音级输入音乐，即可在浏览器中编辑、播放并渲染为标准五线谱。

它适合希望快速记录旋律、校对乐谱，或以纯文本分享音乐的人。

## 快速体验

```m3n
{title=小星星}
{key=C} {4/4}
1 1 5 5 | 6 6 5^ |
4 4 3 3 | 2 2 1^ |||
```

`1` 到 `7` 是首调音级，`|` 分隔小节，`^` 将前一个音的时值加倍，使小节恰好填满 `4/4`。

## 在线制谱与导出

[打开在线编辑器](/editor)，输入 M3N 后实时查看五线谱、试听播放，并导出乐谱。适合从一段旋律开始写作，也可以在编辑器中继续修改乐谱库中的曲目。

## 乐谱库读谱与打印

[浏览乐谱库](/scores)，按曲目阅读五线谱、播放试听并直接打印。遇到想调整的曲目，可以从阅读页进入编辑器。
