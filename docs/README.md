# Max's Markup Music Notation (M3N)

> **文档版本**：M3N v0.2  
> **更新日期**：2026-07-31

M3N（Max's Markup Music Notation）是一种以高音谱表旋律为核心、使用首调音级记录音乐的文本制谱语言。
M3N 文本可以直接编辑和分享，也可以转换为五线谱，用于查看、播放和打印。

## 核心原则

**文本优先**

- 使用普通文本编写，不依赖专用编辑器
- 适合通过消息、文档和版本控制系统分享
- 每个音符和标记都能在源文本中直接定位和修改

**简洁克制**

- 以高音谱表单声部旋律为核心
- 使用首调音级 `1` 至 `7` 输入音符
- 优先支持常见、可明确表达的乐谱功能

**清晰直观**

- 文本顺序与音乐顺序一致
- 使用括号表达短时值，并同时体现音符分组
- 设置、区间和演奏标记使用统一的大括号形式

## 快速示例

```m3n
{title=欢乐颂} {composer=贝多芬}
{key=D} {4/4} {114qpm}
3 3 4 5 | 5 4 3 2 | 1 1 2 3 | 3. (2) 2^ |||
```

其中，`{key=D}` 规定音级 `1` 对应 D，`{4/4}` 是拍号，`{114qpm}` 表示每分钟演奏 114 个四分音符。
