# 上方文字按真实墨迹定位

此前参考 `TextAboveAttachment` 使用文字推进盒与笔画的并集进行定位，自研普通注释也有同样问题；自研指法与表情已按实绘定位。这造成两类差别：靠近边界时文字多缩入空白边距；覆盖弧线时空白侧边伸到更高处，平白增加文字到音乐的距离。K.545固定调600px第19系统的 `dim.` 就是后者：推进宽23.4736328125px、实绘宽23.2236328125px，每侧0.125px空白使弧线查询上沿相差约0.003533991px，随后影响后续系统的基线。只读探针 `.tmp/k545-query-probe.mjs` 和 `.tmp/k545-query-spacing.json` 同时记录两种范围，不修改绘制。
