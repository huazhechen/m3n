# 单文件离线版

运行 `npm run build:offline`，生成 `offline/m3n.html`。构建不会覆盖托管站点的 `dist/`。只需复制这一个 HTML，用浏览器直接打开，无需安装或启动本地服务器，也不需要先联网缓存资源。

内置全部曲库、指南和手册、编辑器与转换器、简谱排版、两种播放音色、AudioWorklet，以及 SVG／PNG／PDF 导出模块。使用 HashRouter，页面地址为 `m3n.html#/scores/...`，刷新仍能进入原页面。转换器可从顶部“简谱转换”进入。内嵌数字字体的许可证和来源保存在 HTML 的 `m3n-licenses` JSON 节点中。

本地作品、草稿和偏好仍由浏览器保存，并未写回 HTML 文件；移动 HTML 到另一台设备不会携带这些数据，与在线站点的本地存储也不共享。浏览器可能按文件路径隔离数据，清理浏览器数据也会删除本地作品。可复制编辑器中的源文，保存为 `.m3n` 文本文件备份。

离线版不提供云端分享按钮，无法访问服务器上的分享作品。在线链接仍需要网络；把离线 HTML 发给别人也不会自动包含自己另存的本地作品。这些是服务器／浏览器存储功能的边界，不是内嵌静态资源可以替代的功能。

按用户要求不嵌入中文导出字体，文件约5 MB。中文使用设备的系统字体；SVG 保留文字，跨设备的中文字形可能不同；PNG 和 PDF 将当前字形保存为图片，PDF 中乐谱无法选择文字或无限放大为矢量。在线版仍使用完整字体输出矢量轮廓。建议使用当前桌面版 Chrome／Edge，通过浏览器打开文件；手机文件管理器的 HTML 预览未必允许脚本、下载或音频。浏览器仍要求点击播放后才能发声。

验证：先构建，再运行 `npm run test:offline`。脚本使用独立浏览器上下文，开启离线模式，通过 `file://` 打开 HTML，检查曲库、编辑、本地保存与刷新、转换器、指南手册、合成／钢琴播放以及三种格式实际下载，并断言没有 HTTP 请求或页面脚本错误。需要已安装 Playwright Chromium，或用 `M3N_BROWSER_PATH` 指定 Chromium 可执行文件。下载产物写入 `.tmp/offline-check/`。

自定义产物路径：`node --import tsx tools/build-offline.mts --out /路径/m3n.html`（先完成各包构建）。常规网页构建方式保持不变。
