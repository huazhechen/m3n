## 方法

基线为[原版宽16px/24px评估](PAGE_GAP_AUDIT.md)的16px结果：各曲当时的默认版宽，独立乐谱共101页。扫描复用 tools/build-scorebook.mjs --probe-only，从540到720px、每10px取一个候选；候选还检查左右5px的页数一致性、实绘边界和碰撞。先取页数最少的安全稳定候选，同页数取最窄版宽。每曲39个实际测量版宽，97曲共3783次测量；网页字体及渲染入口与现有曲集流程一致。

运行记录：.tmp/page-gap-24-width-search/width-probes.json，包含渲染器摘要、谱源摘要、全部候选及稳定性结果。逐曲核对谱源摘要与16px基线一致。
