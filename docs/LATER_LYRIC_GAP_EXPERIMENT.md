# 《后来》歌词三档净空试验

2026-11-29，以已部署的be2952a4（v94）为基线，仅将两种谱式共用的歌词块两两净空从1／2／3px临时改为0／1／2px，对《后来》五线谱运行相同的生产选宽策略。音乐三档、字号、舒适区、纵向规则和评分权重均保持原值。此次仅试验该曲，未执行新配置的全库统计。

## 结果

| 项目 | 原配置1／2／3px | 试验配置0／1／2px |
|---|---:|---:|
| 自动选宽 | 564px | 696px |
| 页数 | 2 | 1 |
| 系统行数 | 19 | 11 |
| 含增页的总成本 | 2.185689 | 1.761652 |
| 696px方案 | 2页／17行 | 1页／11行 |
| 720px方案 | 1页／11行 | 1页／11行 |
| 720px含增页的总成本 | 2.224618 | 2.204916 |

试验的696px赢家为窄档0.8S（音乐基准净空6px、歌词净空0px）。横向成本0.230402，字号成本1.531250，纵向与增页成本均为0，总成本1.761652。新配置中最佳两页候选是570px／18行，总成本2.199712；696px以0.438060的差值胜出。

净空减少改变了候选断行：696px原为2页17行，试验后为1页11行。主要收益是更窄的版宽也能得到单页方案，从而降低字号缩小成本；并非720px的横向成本大幅下降。
