# 单参数间距下的紧凑换行

仅显式传入`noteGapEm`、未指定`minimumNoteGapEm`时，参考保留自然宽度的单参数换行策略。自研原先对所有紧凑等宽小节统一使用1.16倍版心容量，遗漏仅允许稀疏小节收紧的限制；候选行代价也只计算相对容量的差值，没有单独计算超出实际版心的压缩量。因此等宽快速音型可能挤进前行，普通小节也可能选择不同的全局分配。

自研现在按时值节点数量、拍长及实测音乐／歌词宽度判定稀疏小节；等宽候选只要包含非稀疏小节就使用正常容量。空余容量与超出版心的压缩量分别计算平方代价，等宽压缩保留较高代价。成对间距分支仍按实际最小宽度判断容量，其代价公式与原先等价，不改动字号或实际绘制片段。
