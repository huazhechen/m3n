# 段首普通小节线的排版

段首的普通 `|` 是冗余分隔符，没有音符或休止时不能形成独立音乐谱行，也不应增加段间距。例如下列两种写法的音乐排版相同：

```m3n
{4/4}{order=A,A}
===A
N: | 1 2 3 4 |||
```

```m3n
{4/4}{order=A,A}
===A
N: 1 2 3 4 |||
```

此规则不删除前反复线 `||:`、含导航的边界或多小节休止，不修改谱源与领域事件身份。

参考投影跳过没有事件、休止、导航或左侧结构的普通分隔壳；换行判断同时确认前面已有音乐，避免首个具名乐段因壳的数组下标而多换一行。自研投影按当前声部块内已生成的音乐小节判断段间距，避免首个有效小节误增12px。
