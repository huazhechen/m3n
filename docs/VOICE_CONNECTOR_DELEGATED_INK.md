# 连谱括线包含委托绘制的减时线

双声部谱行左侧的粗括线与细连谱线应包围对应声部的主音音乐墨迹，包含八度点及减时线。倚音、歌词和外层表情不延伸其端点；每个自动或显式换行后的双声部系统分别测量。

jpFun 原来只读取 `paintedNodeRegions(host, measurer, true)`。连梁接管减时线后，本地装饰不再绘制该笔画，导致括线端点遗漏减时线。自研直接测量主音完整音乐，已包含该笔画，因此两版底端不一致。`parallel-forced-settings.m3n` 的固定调升半音场景中，差异集中在第二系统左侧下钩，约67像素、最大通道差255。

参考版现在合并主音实际绘制区域与 `systemCore` 装饰的 `getIntrinsicInk()`，按宿主坐标转换。共享连梁只计入该主音自己的局部线段；音乐主体以外的装饰不进入端点。自研代码无需修改。
