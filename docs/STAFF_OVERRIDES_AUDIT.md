# 五线谱主动规则审计

以下为2026-11-24的旧引擎规则审计记录；原生替换后的实现以[五线谱显示](STAFF_NOTATION.md)为准，VexFlow对象及导出形状转换已移除，音乐语义规则由原生实现承担。

日期：2026-11-24。范围为 `packages/score-renderer/src/staff/` 的领域投影、VexFlow适配、分行、系统组织、附属记号避让、分页及SVG文字输出；同时检查阅读器使用的选宽元数据。以项目 `MANUAL.md`、`STAFF_NOTATION.md` 和已安装VexFlow 4.2.5源码为依据，不把“与库默认不同”直接等同于错误。

## 确认并修复

| 规则或实现 | 可复现问题 | 修正 |
| --- | --- | --- |
| 除复拍八分拍号外一律按分母单位连杠 | 4/8的八分音符全部散开；6/4的附点二分拍被拆成三个四分拍 | 使用库的拍号分组；4/4仍按四分拍 |
| 弱起从完整小节第一拍开始计拍 | 一拍半弱起中的三个八分音符被连成“前二后一”，而非末拍的“前一后二” | 首小节按缺少的时值补足拍位偏移，末尾互补小节仍从第一拍计拍 |
| 整小节扁平送入自动连杠 | 同一拍中的两个短三连音连成六音一组；跨拍五连音被拆开 | 连音组成为独立分组，普通音符保留原小节拍位 |
| 连音组统一 `ratioed: false` | 5:3等非常规组只显示5，丢失占用时值信息 | 恢复库的比例显示判定 |
| 连音组数字避让只寻找音符容器内的数字 | 新引擎把数字放在谱表下，两者结构不符，旧避让代码不生效 | 绘制时输出数字／括线整体及上下方向，在歌词排版前按3px净空避让，随后排列歌词 |
| 超宽小节片段从零重新计拍，并继承小节起始调号 | 非整拍切分后重新连杠；小节中途换调后续行可能显示旧调号 | 保存原拍位偏移，使用切分处调号 |
| 移调只按目标调名是否含b选择全套升／降音名 | C调升五个半音后，第四级写成A♯，与F调调号不符；升六个半音后第七级写成F而非E♯ | 按调号间音程保留音级，再计算临时变音及八度 |
| 和弦按未移调的原事件显示和测宽 | 旋律已变成F调，IV仍显示F，G/B也不随之改变 | 和弦根音和斜杠低音与旋律同步移调，实际显示文本参与测宽 |
| 超出七升／降号范围时静默回退C调 | G♯大调错误显示C调号，后续移调的来源调号也错误 | 等音规范化为常用调号并重拼音符，G♯对应A♭ |
| 连奏线避让同时读取所有谱表 | 低音声部的连奏线被上方高音音符推到高音谱表上方 | 只读取所属谱表的音乐，歌词不作为连奏线内部障碍 |
| 琶音固定在符头左12单位，且不计横向占宽 | 与临时变音或倚音组合时可能挤占它们的空间 | 使用Stroke修饰器参与测量和左侧排列，保留兼容Bravura的本地波线 |
| 选宽元数据再次乘0.7 | 行宽已经是逻辑px，可用宽度却缩小一次，短末行留白评分失真 | 统一逻辑px，扣除实际内部留白 |
| 行内段名取谱表所有path的首末位置定中心 | 谱号或调号轮廓被误当作最后一条谱线 | 只用明确标记的五条谱线计算中心 |

此前已修复的4/4两拍一组和休止符决定连音组方向，也纳入回归测试。

## 核对后保留的规则

| 主动设置 | 保留依据 |
| --- | --- |
| `Voice.Mode.SOFT` | 项目自行校验小节容量；弱起、分片与不定长间奏不能由VexFlow的满小节校验拒绝 |
| 高／低音谱号与 `auto_stem` | 当前领域模型是旋律、低音各一声部；单音与符杠仍由库选择符干方向 |
| 休止符使用谱表中央的占位音高 | VexFlow以音高键决定休止符位置；休止符的占位符干不再参与有音高连音组的方向选择 |
| 奏法默认上置 | 与当前单声部及库默认位置一致；`av`确为特短断奏，`mordent`在该库映射上波音，未因英文名称误判为错符号 |
| 8va／8vb保留原书写音高并绘制八度线 | 八度线承担音高变化，不能再把书写音符抬高／降低一次；分遍展开另保留访问自身的八度差 |
| 字号、0.7音乐缩放、歌词6px及4px净空 | 已有统一排版策略，实际测量随图形等比处理；不是乐理分组规则 |
| 项目控制时间列、歌词测宽、共有列对齐和分行 | 库只负责局部雕版，项目须满足中文多层歌词、跨谱表对齐、硬换行、等宽小节和交互身份 |
| 基准0.25及更宽间距候选 | 按实际A4页数选距，没有将字形本身横向缩放 |
| 谱线核心、实际墨迹避让、26.4～32px分页净空 | 已有文档及像素验证支持，不统一放大歌词高度或强行填满页尾 |
| 段名、速度、导航、房子与行尾小节号的局部净空 | 保留现有明确设计；按实际横向交叠避让，分组整体参与测量 |
| 多小节休止和不定长间奏的自绘符号 | 后者没有计数和播放时间列；前者保留实测计数及调拍号成本 |
| SVG形状转换和文字逐字定位 | 供屏幕、PNG与现有矢量PDF共用，不能直接删除这些导出适配 |

## 边界

- 文档禁止未结束的小节内改拍号，因此不把这类无效谱源作为分组缺陷；合法的小节间换拍号继续生效。
- 5/8、7/8等拍号本身不能唯一表达2+3、3+2或2+2+3。当前语法没有显式拍组字段，沿用库的默认分组；不凭拍号猜测作者意图。
- 两拍连杠本身并非错误。这里统一采用每拍为基础的4/4默认策略；独立连音组的边界优先，未新增逐曲拍组配置。
