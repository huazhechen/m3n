# 分页状态的精确分组与行几何复用

2026-11-27，在独立worktree中继续单Worker优化。算法仍完整覆盖528～720px全部33个6px档，仅保留原有安全剪枝；没有改变评分、末行均值规则或曲线精度。

共享分页代价求解器有两项变化：

- 普通谱行的几何不依赖本节平均间距。在保留均值统计供末行判断的同时，按前行复用普通行的精确几何查询；末行仍读取各状态自己的实际均值。
- 资源分组以精确的JavaScript数值作为间距累计值的Map键，替代逐状态拼接长字符串。行身份、行数与间距计数以安全整数编码，超过安全整数范围时退回字符串标识；分组的首次出现顺序保持不变。没有四舍五入、量化或合并不同的浮点值。

两项优化只在共享层实现，两种谱式使用相同代码。

## 撤回的试验

以下单曲试验均在旧0.8／1.6五线谱规则下进行，最终未保留：

- 将共享末行均值范围证明接入五线谱：合法路径范围仍太宽，《童话镇》4942ms，基线4846ms。
- 先忽略均值状态、几何收紧停滞后再启用：5008ms，没有建立收益。
- 将已知行的目标宽度查询改为数值索引：4078ms，与普通行复用后的4093ms接近，不足以增加另一层索引。
- 分页代价预算增量由0.05改为0.01：3286ms，原数值分组版本3158ms。仍保留0.05起步及逐次加倍的完整求解顺序。

CPU采样及逐宽度日志显示，旧规则下《童话镇》会执行155次分页代价求解，生成约190万状态；这也是后续减少重复求解与安全收紧几何的重点，不能靠多Worker或局部搜索回避。
