# 简谱跨行连奏线

2026-11-20，改进 `native-arc.ts` 中跨行圆滑线／连奏线（`slur`）的曲线造型。

## 五线谱参考

先阅读本地[五线谱说明](STAFF_NOTATION.md)与当时的旧引擎构建说明（现已删除，可查Git历史），再查看当时随项目分发的 Verovio 6.2.0 源码（当前五线谱已迁移至VexFlow）：`src/view_slur.cpp`、`src/slur.cpp` 和 `src/view_graph.cpp`。通过当前五线谱公共渲染入口实绘三行连奏谱例及 K.545，检查最终SVG路径与截图。

五线谱将跨行首段、中间段和末段分别绘制为完整的贝塞尔曲线，以两条曲线围成具有厚薄过渡的填充区域；贯穿整行的中间段也保留弧度。简谱旧实现仅在首尾用短曲线转弯，中段接水平带，贯穿整行的续段直接成为矩形。

## 简谱实现

跨行连奏线的每个谱行片段改用两条三次贝塞尔曲线围成弓形：两端渐细至尖端，中点保留原有的0.09倍音乐字号厚度。整行续段同样有连续曲率，不再含水平矩形或曲线接直线的拐点。参考五线谱的绘制方式，简谱仍采用适合数字音符统一基线的对称弓形，不复制五线谱依音高、符干方向选择的端点。

弧高随当前片段跨度的平方根增加，在22px音乐字号的设计尺度下以4.4px为基础、最高17.6px，并随字号等比缩放；短收尾片段因此低于整行片段，不再统一使用9.9px。左右端点仍使用已有的音符中心、音乐分配边缘及跨行首音预留，不改变关系身份。

单行完整弧线与同音延音线（`tie`）沿用原造型。音符、八度点、单音奏法、内外弧线和渐强渐弱继续通过实际曲线墨迹避让；最终位置可能因局部障碍向上移动。曲线测量、谱行核心高度和分页共用最终几何，因此局部行高及页数允许随真实占位变化，不以旧页数限制安全避让。
