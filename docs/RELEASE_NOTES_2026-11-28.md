## 验证结果

在单worker、Node堆512MiB、聚合内存守卫下串行实测；从命令入口开始计时，包含规定构建和检查。

| 入口或阶段 | 耗时 | 结果 |
| --- | ---: | --- |
| 完整门禁中的非E2E阶段 | 117.53秒 | 低于120秒 |
| 完整门禁中的E2E阶段 | 95.97秒 | 低于120秒，重新构建网页，复用本轮包构建和类型检查 |
| `npm run test:e2e`独立入口 | 110.94秒 | 低于120秒，包含完整独立构建及24项E2E |
| `CI=1 npm run check:ci`推送门禁 | 22.40秒 | 全部通过 |
| `npm run check`完整门禁 | 213.60秒 | 两阶段均通过，总计低于240秒 |

完整门禁通过2420项离线用例、23项谱集／墨迹浏览器回归和24项E2E；聚合RSS峰值1631MiB。收敛前完整门禁892.09秒，其中191项E2E为709.04秒。
