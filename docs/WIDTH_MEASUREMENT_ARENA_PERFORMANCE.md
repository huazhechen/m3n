# 简谱候选测量与绘图分离

2026-11-28，独立工作树 `perf/single-worker-600`，基于 `95846672`。这是[候选执行架构重构](WIDTH_COMPILED_GEOMETRY_PLAN.md)的中间步骤，600ms目标尚未完成。本轮冻结117首谱源、真实归档TTF及该分支排版规则，不代表最新主线的最终验收。

`PreparedNumberedNotationScore.measure` 只发布评分、页数、行数和独立的精确分页几何；需要绘图或详细布局诊断时，才调用相同排版内核构造一份独立布局。测量任务按不可变度量投影复用私有放置工作区，重置坐标、标记、歌词和控制符状态。保存下来的候选复制评分需要的小节标量，避免后续工作区重用改变旧候选的末行净空。公共绘图入口继续持有独立坐标。

共享选宽、断行、分页代价求解及评分算法没有复制或改动；两种谱式仍执行528～720px完整6px搜索及严格安全剪枝。这一步尚未消除简谱候选内部的完整布局对象，也未改成直接按行执行，更没有实现跨宽度批量DP。
