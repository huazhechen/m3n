# M3N 重构记录

本文件记录以 `MANUAL.md` 为规范来源进行的结构性调整、兼容性判断与验证结果。

## 2026-08-01: 统一源文本词法边界

### 变更

- 新增 `src/lib/notation/m3n-tokens.ts`，集中定义 M3N 的空白、注释、指令、小节线、圆括号、音符分组、音符与未知文本的词法边界，并保留行号和源码偏移。
- `m3n-validate.ts` 与 `m3n-direct.ts` 改为共同消费该 token 流。校验器继续负责规范约束；直解析器继续负责生成事件模型，不在词法阶段混入语义判断。
- 文档示例回归测试覆盖 `README.md`、`GUIDE.md` 与 `MANUAL.md` 中全部 `m3n` 代码块；每个示例都必须同时通过校验和 MEI 转换诊断。

### 判断

手册规定语法错误不得静默忽略。此前校验器与直解析器分别扫描源码，二者对 token 边界的细微差别会导致同一文本出现“能转换但不能校验”或相反的漂移。共享无状态词法层比复制正则更符合该规范，也保留了转换器的源码映射能力。

### 验证

- `npm test`: 93 tests passed。
- `npm run build`: TypeScript 检查与生产构建通过。

## 2026-08-01: 重组规范手册

### 变更

- 将 `MANUAL.md` 从按功能累积的长篇说明重组为七个规范章节：文档与栈、设置、音乐原子、结构、演奏标记、补充块、错误分类。
- 将可执行语法集中为产生式、表格和局部约束；将引导性曲例留给 `GUIDE.md`，手册仅保留消除语义歧义的最小合法例子。
- 明确了状态、前置、后置、位置、区间和补充块的作用域，及其与匿名/具名关闭指令的统一栈规则。
- 将小节完整性、弱起、延音目标、反复/volta、具名乐段、歌词对位和低音谱表时间轴的约束放在各自语法对象之后，避免读者在章节之间来回查找。

### 判断

规范的首要目标是让同一输入能被独立实现作出同一合法性判断。原手册将语法、渲染效果和教学叙述交错陈列，且多次复述同一规则，增加了遗漏条件的风险。重组后，语言接受条件由本手册完整定义；显示与播放的具体实现不再作为语法成立的前提。

### 验证

- `npm test`: 94 tests passed，包括全部文档中的 `m3n` 代码块。
