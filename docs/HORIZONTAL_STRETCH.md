# 共享横向拉伸与已获空间抵扣

简谱与五线谱共用`layout/stretch-spacing.ts`的额度求解器。硬占宽先由同一个`layout/spacing.ts`计算，再分配行内剩余宽度；不缩小已有间隔，不放松歌词、附件、固定连接或音乐笔画的约束。

对每个可伸展边界，记节奏权重为w，硬约束形成的实际列间距比音乐约束多出的部分为e。已获额度为e/w；抵扣只看实际超出的量，不区分歌词、同音连线、和弦文字、括号或其他避让来源；这些约束不直接改变节奏权重。统一额度λ下，新增间距为`max(0, λw−e)`，选择λ使全部新增间距之和等于可分配余量。零权重边界保持固定。

按e/w排序后分段求解λ，保留完整阈值，不用倒数权重、经验系数或近似分箱。所有单位采用调用方的雕版坐标；字号或谱式的单位换算同时作用于e和可用宽度，不改变分配比例。e为0时退化为原有的节奏加权分配。

例如两个相同权重的间隔，音乐最小净空均6px，歌词令实际净空成为6／18px：再分配8px时得到14／18px；再分配20px时得到22／22px。已被撑开的间隔先等待，其他间隔追上后共同伸展。多遍歌词、空词槽、连线等仍通过原有稀疏约束参与硬几何，不重复相加占宽。

## 两种谱式的接入

简谱直接对整行时间列求解。固定偏移组先折叠，再对组间边界分配，组内偏移保持原值。准备缓存保存完整抵扣曲线，多宽度复用与重新准备的结果相同。

五线谱将各小节内部边界的权重和抵扣曲线合并，在整行求出共同λ，再按每小节在这个λ下的新增量分配宽度。内部求解使用相同曲线，因此不会在小节之间先按旧权重重复分配。小节曲线保留所有边界阈值，不以小节平均额度代替。行首谱号、调拍号等结构占宽不参与拉伸额度。

评分与最终绘制共用小节分配；末行继承前行的λ，按本行曲线计算宽度。显式等宽小节继续保留等宽约束，小节内部使用抵扣分配。

歌词三档现为0／2／4px（0、M/12、M/6），两种谱式共用；音乐三档、舒适区、字体代价、增页权重及评分公式不因本次分配调整而改变。具体选宽和页数变化需要重新测量，不能从抵扣规则单独推断。
