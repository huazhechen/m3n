This project extracts GM Programs 0, 22, 25, 40 and 73, compresses each original
sample with Ogg Vorbis quality 3, and maps each standalone preset to Program 0.
Original sample rates, stereo/pan layout, key/velocity zones, envelopes and loops
are retained. No recordings are taken from the modified FluidR3Mono bank.

Rebuild: tools/measure-fluidr3-tones.mts, tools/prepare-fluidr3-playback.mts.
