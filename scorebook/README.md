# 循序渐进乐谱集

第四十八版：[简谱版 PDF](循序渐进乐谱集-简谱-v48.pdf)（80 页，5.95 MB），收录85首乐曲及完整基本功，共86个条目，按三篇编排。页码按实际内容重排。

按要求删除指定器乐曲的谱源、曲库条目、谱集配置、测试数据及相关目录引用。《深情的吻》第二房子缩为三小节，后续旋律不再罩在房子线下。《啤酒桶波尔卡》A 段末尾差异改用第一、第二房子，撤销替代旋律，保留 ABCD 演奏顺序。两首的完整 MIDI 不变。

《爱的礼赞》对照上传钢琴原谱及[参考旋律](https://www.kuaiyuepu.com/jianpu/DDWml1tVr.html)，将伴奏填充位置改为休止，保留当前旋律的时值、重复音、装饰与转调，未照搬网页的节奏重编。

《土耳其进行曲》A/B/C/Coda 方框段名独占一行，在 C 段第一组反复结束后换页。全册分页取消均衡两页留白的评分，优先保留能在一页容纳的完整反复、短乐句与延音，再尽量填满前页。

《致爱丽丝》继续采用 A/B 段内反复与跳房子；其余替代旋律与主谱同字号。具名段落之间额外留白12px，页首不添加额外留白。只在具名段落结尾补双小节线；分类小标题不渲染。渐强渐弱位于音符上方，变音记号在小节内生效。当前仅提供简谱。

运行 `npm run build:scorebook` 重建。详见[布局记录](layout-record.json)、[校订记录](校订记录.md)、[逐页校阅](逐页校阅.md)及[手册](../docs/MANUAL.md)。
