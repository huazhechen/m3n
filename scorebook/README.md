# 循序渐进乐谱集

第四十四版：[简谱版 PDF](循序渐进乐谱集-简谱-v44.pdf)（83 页，6.16 MB），收录 87 首乐曲及完整基本功，共 88 个条目，按三篇编排。比第四十三版减少 3 页；目录按实际内容重排。

《老男孩》《爱如潮水》《深情的吻》均由两页合为一页。《后来》补齐 A、B 段末尾双小节线并保持一页；《欢乐颂》删除副标题。《慢慢喜欢你》《月半小夜曲》改为 A/B/C，《我要你》《一千个伤心的理由》采用显式字母演奏顺序；《超级玛丽》标明顺序并只写一次重复乐段。《听海》删除多余的第一段主歌后反复号。

《童话镇》《贝加尔湖畔》已使用 `Ns[2]` 局部替代旋律。前者主谱数字由约 20.02px 调至 20.42px，后者由约 23.70px 调至 23.48px，均为一页；增大字号的空间有限，主要收益是减少重复分支。《天空之城》《菊次郎的夏天》不再把弱起标成 Intro，开头与 A 段起句接排；《啤酒桶波尔卡》按实际完整乐段重编字母，尾句差异使用替代旋律。

具名段落默认使用行内方框并另起谱行，顶部顺序中的字母也加框。开头未命名的弱起与第一个具名乐段接排，仅演奏一次。`===名称{br}` 在段落标题后强制换行，基本功保留此写法。渐强渐弱位于音符上方，变音记号在小节内生效。

当前仅保留简谱显示和导出。标题按实际 SVG 字形边界居中，过长标题保持字号换行。运行 `npm run build:scorebook` 重建，不启动开发服务器。排版参数和逐曲页码见 [布局记录](layout-record.json)，本次逐曲结果见 [校订记录](校订记录.md)及[逐页校阅](逐页校阅.md)。语法见[手册](../docs/MANUAL.md)。
