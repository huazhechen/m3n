# 循序渐进简谱集

当前成品为第二版 iPad mini 阅读版，共 80 页。按竖屏比例排版，缩小页边距与谱行留白，优先保证屏幕上的音符大小。原谱唯一来源仍是 `src/scores/*.m3n`。

- [第二版 PDF：iPad mini 阅读版](循序渐进简谱集-iPad-mini-v2.pdf)：744∶1133 竖屏比例，窄边距，文字与音符均为矢量轮廓。
- [排序与缩放记录](排序与缩放记录.md)：逐曲编号、难度、页码、版宽、谱行分配、行间留白，以及同屏音符相对第一版的大小。
- [CSV 表格](排序与缩放记录.csv)：同一份记录，UTF-8 BOM，可在表格软件中打开。
- [逐页校阅](逐页校阅.md)：对应第二版 PDF 的逐页检查与合页说明。
- `editorial-plan.json`：可编辑的顺序、分类、难度、版宽与合页规则。
- `layout-record.json`：实际布局、候选方案、原谱校验和、每页位置和谱行范围；由构建生成。
- 第一版对照：[89 页 A4 PDF](循序渐进简谱集-v1.pdf)、[布局快照](layout-record-v1.json)、[逐页校阅](逐页校阅-v1.md)。

难度 1—5 是针对当前编配的相对学习顺序，不是考级定级。81 首乐曲完整保留；《半音阶口琴基本功》拆成 28 项练习，原有音乐行逐行核对。长音与力度放在开篇，其余在专项进阶附篇按学习目标重排。第二版沿用第一版的分类和顺序。

第二版外边距为 8px，谱面自身另留 8px，适宽显示时左右实际留边约占屏宽各 2%。省去正文页的通栏页眉和页脚线，仅保留小号条目标签与页码。谱行最小留白从 24px 降至 18px；7 个含密集关系线的条目保留 20px，以免相交。音符和歌词按比例缩放，没有纵向压扁。

大部分条目的同屏音符较第一版增大约 19%。8 首原跨两页的曲目合为一页；《土耳其进行曲》采用额外的 1020px 版宽，同屏音符约为第一版的 91%，其余合页曲目至少为第一版的 96.56%。《花之舞》保留两页，以保持快速音型清楚。百分比以同一设备适宽显示为基准，不表示印刷字号；在 PDF 阅读器中隐藏工具栏并使用整页或适宽模式即可。

## 再生成与微调

安装项目依赖后，在项目根目录运行：

```sh
npm run build:scorebook
```

需要本地 Chromium，可用 `CHROMIUM_PATH` 指定可执行文件。构建使用 Playwright 的离线浏览器页面，不启动开发服务器，也不请求外部资源。中间 SVG、打印 HTML、逐页 PNG 和布局缓存保存在 `.tmp/scorebook-ipad/`。

修改 `editorial-plan.json` 后再运行命令：

- 移动 `entries` 的条目即可调序；章节仍应保持连续。
- `width` 是优先版宽。当前基准 780px 对应相对缩放 100%，增大版宽会缩小适宽显示的音符。默认比较 760—960px，每首曲目的各页使用同一比例。
- 单曲 `widthCandidates` 可增加额外候选；《土耳其进行曲》增加 980、1000、1020px。添加 `"widthLocked": true` 可锁定 `width`。
- `page` 定义页面比例、外边距、正文上下界、谱内边距、谱行留白与短曲间距；单曲 `systemGap` 可指定优先留白。候选方案遇到上下关系线相交时，自动尝试 20、22、24px。
- `sharePage` 为 `true` 且 `section`、`group` 相同的相邻短曲 / 练习会尝试合页，并平衡每页留白。
- `breakBefore` 为 `true` 可使该条目另起一页。
- `pageBreaks` 指定在第几条完整谱行后分页，例如 `[7]` 表示第 7 行后分页。设置手动分页时应锁定版宽；续页仍须至少三行。
- `reviewNote` 保存人工调整理由并进入曲目记录。

工具检查所有原谱和练习的覆盖、候选布局的横向边界、音符 / 歌词相交、分页切口是否穿过字形或关系线，以及续页孤行。先连续排版，再按完整谱行切页；所有页面共享固定版心，不按内容高度再次缩放。短曲合页保留各自标题、调拍速与署名。导出前裁去页外完整图元，再把文字转换为本地字体路径。

后续可按“第 38 页放大一点”“编号 030 往前移”等方式提出意见。任何调序、换宽或分页修改后，都应重新核对受影响的页面与目录。
