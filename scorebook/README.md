# 循序渐进乐谱集

第四十五版：[简谱版 PDF](循序渐进乐谱集-简谱-v45.pdf)（81 页，6.09 MB），收录 86 首乐曲及完整基本功，共 87 个条目，按三篇编排。比第四十四版减少 2 页，目录与页码按内容重排。

全册补齐段尾双线并取消编辑分类小标题。替代旋律取消上方单独的“2.”，紧贴主歌词。《童话镇》《牵丝戏》《世界赠予我的》新增适合的替代分支；《老男孩》合并共同结尾，仍为一页。《安妮》删除房子，改用演奏顺序；《一千个伤心的理由》撤销字母编排。《月半小夜曲》合并 C 与 A。《如愿》按确认保留原写法。

《天空之城》《菊次郎的夏天》所有小节都有段落归属，入口弱起写在段首。《啤酒桶波尔卡》合并为 ABCD。《致爱丽丝》使用替代旋律并复用共同 Coda，缩至一页。《爱如潮水》前奏补器乐括号与结束双线。《喜洋洋》已从当前曲库删除。

具名段落默认使用行内方框并另起谱行，顶部顺序中的字母也加框。`===名称{br}` 在段落标题后强制换行，基本功保留此写法。渐强渐弱位于音符上方，变音记号在小节内生效。当前只保留简谱显示和导出。

运行 `npm run build:scorebook` 重建，不启动开发服务器。逐曲参数见 [布局记录](layout-record.json)，具体修改见 [校订记录](校订记录.md)及[逐页校阅](逐页校阅.md)。语法见[手册](../docs/MANUAL.md)。
