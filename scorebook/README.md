# Max的半音阶口琴乐谱集

最近一次全量生成记录见[第七十三版](../docs/SCOREBOOK_V73.md)，曲目与分类见[分类与训练要点](分类与训练要点.md)。当前收录97首谱源，第七十三版PDF对应新增《梦幻曲》之前的96首；章节和训练顺序由 `editorial-plan.json` 维护，网站分类由 `library-categories.json` 同步维护。

```sh
npm ci
npm run build:scorebook
```

谱集直接复用网页渲染器。独立曲目搜索540～720px、步长10px，并验证候选±5px下页数稳定、无墨迹越界或音符／歌词相交；同页数选择较小宽度。合页使用共同640px，并验证635／645px容量，成员的单曲建议宽度记为540px。排版保留谱源的音乐、署名、歌词、低音和显式换行；A4仅等比放置网页SVG，四边至少12mm留白。

整册PDF完成字体嵌入、矢量、页数、越界和链接校验后，反写每首谱头 `{preferred-width=…}`。网页默认读取此字段，阅读设置可覆盖。若试排期间谱源改变，摘要保护会拒绝覆盖。

第七十三版另导出 `单曲PDF/` 中的96首单曲，使用反写后的建议宽度；更新六首新增曲目、基本功和《爱的礼赞》的独立校验稿。其后新增《梦幻曲》的单曲PDF与校验稿，核查及首尾拍数调整见[收录记录](梦幻曲收录核查.md)。整册和单曲标题均链接到网站对应曲目。

PDF及详细布局、体积报告、排序CSV均为本地生成物，不新增到Git；已有Git跟踪的基本功两页试排PDF随本次刷新提交。提交谱源、配置、测试与版本记录。当前渲染、合页与选宽规则见[谱集构建说明](../docs/SCOREBOOK.md)和[第六十九版](../docs/SCOREBOOK_V69.md)。旧版校阅与生成记录保留为历史快照。

谱集编写约定：顺读曲目使用普通乐句、反复线和跳房子；确需具名乐段复用时再添加段名与演奏顺序，基本功教学标题保留。无歌词谱面不显示作词人。音乐家署名采用通行简称，保留必要的区分信息。
