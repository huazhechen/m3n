# 循序渐进简谱集

本目录保存可校阅的第一版成品、编排输入和逐曲版宽记录。原谱唯一来源仍是 `src/scores/*.m3n`，本次不改写原谱或网页曲库顺序。

- [PDF 谱集](循序渐进简谱集-v1.pdf)：A4 纵向，含封面、分类目录和连续页码；文字、音符均为矢量轮廓。
- [排序与缩放记录](排序与缩放记录.md)：逐曲编号、相对难度、页码、版宽、相对缩放、分页谱行数及学习重点。
- [CSV 表格](排序与缩放记录.csv)：同一份记录，UTF-8 BOM，可直接在表格软件中打开。
- [逐页校阅](逐页校阅.md)：人工看页后的分页、疏密及调整说明。
- `editorial-plan.json`：可编辑的顺序、分类、难度、版宽与合页规则。
- `layout-record.json`：实际选中的版宽、候选方案、原谱校验和、每页项目位置和谱行范围；由构建生成。

难度 1—5 是针对当前编配的相对学习顺序，不是考级定级。《欢乐颂》保留原谱低音，因此放在入门篇末尾。81 首乐曲完整保留；《半音阶口琴基本功》拆成 28 项练习，原有音乐行逐行核对，长音与力度放在开篇，其余在专项进阶附篇按学习目标重排。

## 再生成与微调

安装项目依赖后，在项目根目录运行：

```sh
npm run build:scorebook
```

需要本地 Chromium，可用 `CHROMIUM_PATH` 指定可执行文件。构建使用 Playwright 的离线浏览器页面，不启动开发服务器，也不请求外部资源。中间 SVG、打印 HTML、逐页 PNG 和布局缓存保存在 `.tmp/scorebook/`。

修改 `editorial-plan.json` 后再运行命令：

- 移动 `entries` 的条目即可调序；章节仍应保持连续。
- `width` 是优先版宽。基准 840px 对应相对缩放 100%，增大版宽会缩小印刷字号。默认比较 800—900px，每首曲目所有续页使用同一比例；只为减少页数或改善布局而做小幅调整。
- 添加 `"widthLocked": true` 可锁定该条目的 `width`；否则工具仍会比较候选宽度，优先减少页数。
- `sharePage` 为 `true` 且 `section`、`group` 相同的相邻短曲 / 练习会尝试合页，并平衡每页留白。
- `breakBefore` 为 `true` 可使该条目另起一页。
- `pageBreaks` 是选定版宽下在第几条完整谱行后分页，例如 `[7]` 表示第 7 行后分页。设置手动分页时应锁定版宽；续页仍须至少三行。
- `reviewNote` 保存人工调整理由并进入曲目记录。

工具检查所有原谱和练习的覆盖、候选布局的横向边界、音符 / 歌词相交、分页切口是否穿过字形或关系线，以及续页的孤行。先连续排版，再按完整谱行切页；所有页面共享固定版心，不按内容高度再次缩放。短曲合页保留各自标题、调拍速与署名。导出前裁去页外完整图元，再把文字转换为本地字体路径。

人工校阅记录对应本目录当前 PDF；任何调序、换宽或分页修改后都需要重新核对相关页与目录。
