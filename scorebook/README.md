全部乐曲启用严格等行高：按整曲最复杂的音乐记号统一每条轨道的上下预留，各音乐行的基础节距固定，歌词按每行实际行数额外增加高度。同曲各页保持一致，页间不再分摊多余行距。不同曲目按各自字号和记号需求采用同一规则。每日基本功包含独立练习标题，保留原有练习间距。第五版封面与正文只呈现音乐相关内容，设备、版宽、缩放及排版说明仅保留在仓库记录中。

## 再生成与微调

在项目根目录运行：

```sh
npm run build:scorebook
```

需要本地 Chromium，可用 `CHROMIUM_PATH` 指定。构建使用离线浏览器页面，不启动开发服务器，不访问外部资源。中间 SVG、打印 HTML、逐页 PNG 和缓存位于 `.tmp/scorebook-v5/`。分页与合页算法的回归测试可运行 `npm run test:scorebook`，也包含在 `npm test` 中。

- 移动 `entries` 即可调序，章节保持连续；每份原谱必须恰好出现一次，基本功须在第一篇开头。
- `width` 是优先版宽，`widthCandidates` 是候选。版宽越小，适宽显示的音符越大；优先满足页数与高度下限，再选择最大可用字号。合页短曲共同选择版宽，范围为 520px 至基准版宽。
- `widthLocked: true` 锁定版宽，`pageCount` 可要求准确页数，例如《土耳其进行曲》两页、快速圆舞曲三页。固定页数的曲目也会比较候选，选择能容纳的最小版宽；不满足页数的候选直接排除。
- 全局 `showCredits: false` 隐藏右侧署名并收回其页头占位；单曲 `includeBass: false` 隐藏低音谱表，例如《欢乐颂》。两项均只影响本谱集的临时排版文档，不修改源文件中的署名和低音；布局记录保存实际显示设置。
- 全局或单曲 `uniformSystemHeight` 控制严格等行高；引擎统一音乐预留，歌词仍按本行可见行数占位。实际每行基线节距写入 `layout-record.json` 的 `baselineSteps`。
- `pageBreaks` 指定完整谱行之后的分页位置；基本功使用 `[14, 30]`，机能训练完整占首页，后两页在练习边界接续。手动分页应锁定版宽。
- `sharePage` 为 `true` 且章节、分组相同的相邻短曲会尝试合页。`breakBefore` 可令条目另起一页。
- `page` 定义页面比例、边距、正文上下界、谱行留白与曲间距；`minimumFillPercent: 90` 要求正文页利用率严格高于 90%。低于或等于该值的候选会排除，最终构建再次检查；`reviewNote` 记录人工调整理由。

构建检查全库覆盖、原谱完整性、候选横向边界、音符与歌词相交、分页切口、续页孤行及轮廓坐标。PDF 使用矢量路径，不依赖阅读设备字体；文字已转为路径，不能搜索或复制。后续由用户检查 PDF 内容、目录和受影响页面，代理负责按反馈调整、生成成品及验证代码与构建记录。
