# 循序渐进乐谱集

第四十二版提供[简谱版 PDF](循序渐进乐谱集-简谱-v42.pdf)（87页，6.16 MB），包含87首乐曲与完整基本功，共88个条目，保留原版全部曲目页码与三篇编排。

具名乐段默认采用快悦谱式行首方框文字，与音符同行，每段强制换行；顶部列出实际演奏顺序。本轮完成优先清单 A1–A8 及追加的《后来》，九首书写单元合计700→504，完整 MIDI 的音符起止时间、音高、力度和总时长均与改写前一致。《同桌的你》主歌保留五行歌词，《后来》按 A → B → A → A → C 演奏。

数字字号均不小于原版；白桦林与深情的吻因强制分段换行，单独调整横向间距，以保留原页数。主标题加粗，渐强渐弱保持在上方，副标题不含“单旋律版”。

当前只维护和导出简谱，五线谱继续暂停。已有第四十版五线谱PDF与 `staff-*`、配对及体积记录作为历史版本保留。

[播放标记优化候选清单](播放标记优化候选清单.md)记录全量核查结果：已完成11首，条件候选待决策18首，暂不优先25首，保留34项。参考和逐曲改写说明见[参考版本与分段复用](参考版本与分段复用.md)。

在项目根目录运行 `npm run build:scorebook` 重建简谱，不启动开发服务器。`editorial-plan.json` 保存排版设置，`paired.enabled: false` 关闭五线谱导出；`pagination-reference.json` 固定87页曲目页码，`layout-record.json` 记录实际布局。语法与限制见[手册](../docs/MANUAL.md#11-乐段)。
