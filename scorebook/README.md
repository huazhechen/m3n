## 第十一版调整

《明天会更好》将副歌移出第二房子，只让不同的主歌结尾留在房子内。相同主歌歌词通过 `{L1}` 合并，相同副歌采用共用歌词，末遍异词单列。保留前面第一房子的反复与末尾 `:|| {x3}`：四遍主歌、三遍副歌。

第 52 页仍为一页，采用 786px 版宽、8 行、18px 行间留白；音符从约 **17.80px 增至 19.48px（+9.4%）**，歌词从约 14.60px 增至 15.97px。自然谱面高度利用率 **99.986%**，没有额外拉伸行距。修正带第一房子提前反复、随后共用副歌的歌词遍次推导，避免要求副歌补写不存在的第四遍。

其余 **81 个条目的 SVG 布局保持第十版原样**。基本功仍在第 5—6 页；《小星星》《欢乐颂》《我和你》合在第 7 页；第 9—10 页保留《哆唻咪》《虫儿飞》互换后的均衡分组；《倩女幽魂》《铁血丹心》合在第 31 页。土耳其进行曲仍为第 83—84 页，9 个反复段全部不跨页；快速圆舞曲仍为第 85—87 页。

全部 83 个正文谱页的高度利用率严格高于 90%，最低 **90.139%**。沿用普通/房子两档等行高，歌词按每行实际可见行数增高，各页不分摊额外行距。普通乐曲字号下限现为《人世间》的 **18.67px**，上限仍为《一步之遥》的 **29.45px**。

## 再生成与微调

在项目根目录运行 `npm run build:scorebook`。需要本地 Chromium，可用 `CHROMIUM_PATH` 指定；构建使用离线浏览器，不启动开发服务器。中间 SVG、打印 HTML、预览和缓存位于 `.tmp/scorebook-v11/`。运行 `npm run test:scorebook` 可检查分页与合页规则。

- 移动 `entries` 可调序，章节及合页分组须连续；每份原谱恰好出现一次，完整基本功位于第一篇开头。
- `width` 越小，整页适宽时音符越大。`widthCandidates` 补充候选，`widthLocked` 锁定已验证版宽，`pageCount` 指定准确页数。
- `pageBreaks` 指定完整谱行后的分页位置，宜与锁定版宽配合。基本功为 `[16]`，《土耳其进行曲》为 `[14]`。反复段是否完整须结合音符与原谱反复边界核对；手动分页不会自动跟踪后续源文件改动。
- `sharePage` 启用相邻同组短曲合页；同页统一字号，合页版宽不超过 780px。`breakBefore` 强制另起页。
- 全局 `showCredits: false` 隐藏署名，单曲 `includeBass: false` 隐藏低音，均不删除源文件内容。
- `uniformSystemHeight` 使用普通/房子两档上方预留，音乐主体与下沿共享，歌词按实际行数占位。`voltaSystems` 与 `baselineSteps` 记录各行分类及节距。
- `minimumFillPercent: 90` 是严格下限，分页、合页和最终构建都拒绝不超过下限的正文页。

构建检查全库覆盖、边界、音符和歌词相交、安全分页、续页孤行及轮廓越界。PDF 只呈现音乐相关内容；文字已转为矢量路径。代理负责修改、生成与自动验证，PDF 内容由用户检查。
