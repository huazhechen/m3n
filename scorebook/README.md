## 第十二版调整

《贝加尔湖畔》采用已确认的 **19.89px 局部反复方案**，由第十一版的第 24—25 页合为第 **24 页**。开头六小节旋律共用，分列两遍歌词，再用第一、第二房子保留不同结尾；后半段沿用原来的反复与尾声。书写小节片段由 47 减为 41，展开演奏仍为 69 个小节片段、273 个事件，全部音高、节奏、连线和各遍歌词保持一致。

采用 770px 版宽、一页 10 行、18px 行间留白；音符约 **19.89px（14.91pt）**、歌词约 **16.31px**，自然高度利用率 **99.141%**。相较原两页的 26.49px 音符缩小约 24.9%；相较原组织直接排一页的 19.00px，去重后增大约 4.7%。

其余 **81 个条目的 SVG 布局和字号保持第十一版原样**。原第 26 页及之后的页码统一提前一页，目录同步更新。基本功仍为第 5—6 页；两组入门曲仍为第 9—10 页；《倩女幽魂》《铁血丹心》合在第 30 页；《明天会更好》为第 51 页，19.48px、一页 8 行，前面第一次反复、后半三遍不变。土耳其进行曲为第 82—83 页，9 个反复段全部不跨页；快速圆舞曲为第 84—86 页。

全部 82 个正文谱页高度利用率严格高于 90%，最低 **90.139%**。沿用普通/房子两档等行高，歌词按实际可见行数增高。普通乐曲最小仍为《人世间》的 **18.67px**，最大为《一步之遥》的 **29.45px**；第二大为《散步》《只要平凡》《直到世界的尽头》，并列 **26.40px**。

## 再生成与微调

在项目根目录运行 `npm run build:scorebook`。需要本地 Chromium，可用 `CHROMIUM_PATH` 指定；构建使用离线浏览器，不启动开发服务器。中间 SVG、打印 HTML、预览和缓存位于 `.tmp/scorebook-v12/`。运行 `npm run test:scorebook` 可检查分页与合页规则。

- 移动 `entries` 可调序，章节及合页分组须连续；每份原谱恰好出现一次，完整基本功位于第一篇开头。
- `width` 越小，整页适宽时音符越大。`widthCandidates` 补充候选，`widthLocked` 锁定已验证版宽，`pageCount` 指定准确页数。
- `pageBreaks` 指定完整谱行后的分页位置，宜与锁定版宽配合。基本功为 `[16]`，《土耳其进行曲》为 `[14]`。反复段是否完整须结合音符与原谱反复边界核对；手动分页不会自动跟踪后续源文件改动。
- `sharePage` 启用相邻同组短曲合页；同页统一字号，合页版宽不超过 780px。`breakBefore` 强制另起页。
- 全局 `showCredits: false` 隐藏署名，单曲 `includeBass: false` 隐藏低音，均不删除源文件内容。
- `uniformSystemHeight` 使用普通/房子两档上方预留，音乐主体与下沿共享，歌词按实际行数占位。`voltaSystems` 与 `baselineSteps` 记录各行分类及节距。
- `minimumFillPercent: 90` 是严格下限，分页、合页和最终构建都拒绝不超过下限的正文页。

构建检查全库覆盖、边界、音符和歌词相交、安全分页、续页孤行及轮廓越界。PDF 只呈现音乐相关内容；文字已转为矢量路径。代理负责修改、生成与自动验证，PDF 内容由用户检查。
