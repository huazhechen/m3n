# 循序渐进乐谱集

第四十一版提供[简谱版 PDF](循序渐进乐谱集-简谱-v41.pdf)（87页，6.36 MB），包含87首乐曲与完整基本功，共88个条目，保留原87页的曲目页码与三篇编排。

当前只维护和导出简谱。按用户决定暂停五线谱导出，待简谱完善后再恢复。已有第四十版五线谱PDF与其 `staff-*`、配对及体积记录作为历史版本保留，不代表本次简谱版本。

《白桦林》采用A/B/C1/C2和四行歌词共用旋律，保留原24px数字，排成八行；《土耳其进行曲》复用插部与叠部再现，数字放大至约26px。两首仍占第18页和第77—78页。主标题加粗，渐强渐弱保持在上方，副标题不含“单旋律版”。

下一批待决策曲目见[播放标记优化候选清单](播放标记优化候选清单.md)：全量核查88个条目，优先8首、条件候选19首、暂不优先25首、保留34项、已完成2首。除已完成两首外，未修改候选曲谱。

在项目根目录运行 `npm run build:scorebook` 重建简谱，不启动开发服务器。`editorial-plan.json` 保存排版设置，`paired.enabled: false` 关闭五线谱导出并保留恢复配置；`pagination-reference.json` 固定87页曲目页码，`layout-record.json` 记录实际布局。
