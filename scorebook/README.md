## 第十九版调整

新增M3N谱头配置`{equal-measures=true}`，令行内小节等宽；`{equal-measures=false}`关闭，省略时默认关闭。基本功及31首乐句规整的曲目在各自源谱开启，包括前20首短曲及《月亮代表我的心》《光阴的故事》《梁祝》等，完整名单见[本版说明](行内小节等宽-v19.md)。

小节内部保留时值、歌词和记号所需的间隔，密集小节决定自动换行容量。少数曲目的行数及额外行间留白相应调整，全部81个条目的字号、页码、页数及既有合页组合保持。

基本功仍为第4—5页两页，**20.31px**、40行按19 + 21行分配，高度利用率99.989% / 98.005%。28项练习的标题、音乐及顺序完整保留。统一行高继续只在原谱段落内共享，段名及练习说明只占所在行，普通/房子两档和实际歌词高度分别计算。

《土耳其进行曲》仍两页23.93px；《慢慢喜欢你》仍一页20.80px；快速圆舞曲仍两页21.69px。普通与全册字号范围均为 **19.04—23.93px**。隐藏署名、欢乐颂仅显示旋律、正文只呈现音乐内容等规则保留。

## 再生成与微调

在项目根目录运行`npm run build:scorebook`，随后运行`npm run compact:scorebook`。需要本地Chromium，可用`CHROMIUM_PATH`指定；工具使用离线浏览器，不启动开发服务器。中间SVG、打印HTML及缓存位于`.tmp/scorebook-v19/`。`npm run test:scorebook`检查分页与合页规则。

- 目录固定两页，每页左右两栏，按栏顺序列出章节、编号、曲目及页码，构建时检查实际文字边界。
- M3N谱头`{equal-measures=true}`开启行内小节等宽，布局记录的`equalMeasures`保存实际布尔值。
- `width`越小，整页适宽时音符越大；`widthLocked`锁定已验证版宽，`pageCount`指定准确页数。
- `pageBreaks`指定完整谱行后的分页位置。基本功本版为`[19]`；土耳其进行曲按两页容量与安全切口选择，允许反复段跨页。
- `sharePage`允许相邻同组曲目合页，同页使用统一字号；`maximumSharedWidth`控制已确认合页上限，`breakBefore`强制另起页。
- `showCredits: false`隐藏署名，`includeBass: false`隐藏低音，均不删除源谱音乐与署名。
- `uniformSystemHeight`按段落、普通/房子两档共享音乐预留，局部标题及歌词实际占位；`paragraphSystems`、`voltaSystems`和`baselineSteps`记录分类及节距。
- `maximumNotePx: 24`限制音符名义字号；`minimumFillPercent: 90`是正文自然高度利用率的严格下限。

构建检查全库覆盖、边界、音符及歌词相交、安全分页、续页孤行与轮廓越界。精简生成器沿用相同字体及固定字形基线，共用嵌入字体，不重新排谱，并检查PDF页数、纸张边界、嵌入字体及零栅格图片。PDF内容由用户亲自检查。
