# 循序渐进乐谱集

第四十六版：[简谱版 PDF](循序渐进乐谱集-简谱-v46.pdf)（81 页，6.08 MB），收录 86 首乐曲及完整基本功，共 87 个条目，按三篇编排。页码按实际内容重排。

《贝加尔湖畔》替代旋律紧贴对应小节实际歌词，不再被其他小节的第二行歌词推远。《老男孩》恢复四组跳房子与 D.S.，保留“得”音修正。《明天会更好》指定句子的第三遍歌词与前两遍合并。《新不了情》改为两个含弱起的 A/B 乐段，顺序 A/B/A/B/B，取消全部房子及跳转。四首均保持一页。

双小节线只补在具名乐段结尾，普通乐句换行不添加；已清理《听海》及全册同类多余双线。原有反复、导航、终止符和指定器乐前奏结束线保留。分类小标题不渲染。

具名段落使用行内方框并另起谱行，顶部演奏顺序中的字母也加框。`===名称{br}` 在段落标题后强制换行，基本功保留此写法。渐强渐弱在音符上方，变音记号在小节内生效。当前只保留简谱显示和导出。

运行 `npm run build:scorebook` 重建。逐曲参数见 [布局记录](layout-record.json)，具体修改见 [校订记录](校订记录.md)及[逐页校阅](逐页校阅.md)。语法见[手册](../docs/MANUAL.md)。
