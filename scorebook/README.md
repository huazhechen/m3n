《爱的礼赞》按[快悦谱参考](https://www.kuaiyuepu.com/jianpu/DDWml1tVr.html)重写，采用D/F调、4/4、每分钟80拍及 A → B1 → A → B2。双音和声取低声部；两遍共同的六拍高音6并入A段末尾，随后两拍休止补满小节；删去间奏，B1/B2从参考谱间奏之后开始。保留参考谱的倚音、细分节奏和转调，38个书写小节均为四拍，独占一页。

K.545取消旧版手工强制换行，保留73小节、原有反复、力度、连奏与时值，由三页压成两页，字号略增。单页试排需约17px，低于正文20px下限，因此不采用。可复用旋律只有一组四小节和两组两小节，ABC方案会增加较多跳转并截断渐强、连奏，继续保留原反复；见[分段复用分析](K545分段复用分析.md)。

《花之舞》字号放大约19%，仍为两页；通过选取版宽让两页都更充实，未恢复全册留白均衡分页。全册继续优先保护可整页容纳的完整反复、乐句与延音，再尽量填满前页。《土耳其进行曲》的独立段名和C段指定换页边界保持原样。

主谱与替代旋律同字号，具名段落间额外留白12px，只有具名段落结尾补双小节线。渐强渐弱位于音符上方，变音记号在小节内生效。当前仅提供简谱。
