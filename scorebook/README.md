## 再生成与微调

在项目根目录运行：

```sh
npm run build:scorebook
```

需要本地 Chromium，可用 `CHROMIUM_PATH` 指定。构建使用离线浏览器页面，不启动开发服务器，不访问外部资源。中间 SVG、打印 HTML、逐页 PNG 和缓存位于 `.tmp/scorebook-v9/`。分页与合页算法的回归测试可运行 `npm run test:scorebook`，也包含在 `npm test` 中。

- 移动 `entries` 即可调序，章节保持连续；每份原谱必须恰好出现一次，基本功须在第一篇开头。
- `width` 是优先版宽，`widthCandidates` 是候选。版宽越小，适宽显示的音符越大；优先满足页数与高度下限，再选择最大可用字号。合页短曲共同选择版宽，范围为 520px 至基准版宽。
- `widthLocked: true` 锁定版宽，`pageCount` 可要求准确页数，例如《土耳其进行曲》和快速圆舞曲均为三页。基本功和部分指定页数曲目锁定已验证的版宽；未锁定版宽时，固定页数曲目会比较候选，选择能容纳的最小版宽，不满足页数的候选直接排除。
- 全局 `showCredits: false` 隐藏右侧署名并收回其页头占位；单曲 `includeBass: false` 隐藏低音谱表，例如《欢乐颂》。两项均只影响本谱集的临时排版文档，不修改源文件中的署名和低音；布局记录保存实际显示设置。
- 全局或单曲 `uniformSystemHeight` 控制分档等行高：普通与房子谱行分别共享对应的上方预留，音乐主体及下沿保持统一，歌词按本行可见行数占位。`layout-record.json` 的 `voltaSystems` 记录每行是否承载房子，`baselineSteps` 记录实际基线节距；核对时需同时考虑前一行歌词行数与后一行房子档位。
- `pageBreaks` 指定完整谱行之后的分页位置；基本功使用 `[16]`，第 6 页从“音阶三连模进倒扣”开始，完整练习不跨页。手动分页应锁定版宽。
- `sharePage` 为 `true` 且章节、分组相同的相邻短曲会尝试合页。`breakBefore` 可令条目另起一页。
- `page` 定义页面比例、边距、正文上下界、谱行留白与曲间距；`minimumFillPercent: 90` 要求正文页利用率严格高于 90%。低于或等于该值的候选会排除，最终构建再次检查；`reviewNote` 记录人工调整理由。

构建检查全库覆盖、原谱完整性、候选横向边界、音符与歌词相交、分页切口、续页孤行及轮廓坐标。PDF 使用矢量路径，不依赖阅读设备字体；文字已转为路径，不能搜索或复制。后续由用户检查 PDF 内容、目录和受影响页面，代理负责按反馈调整、生成成品及验证代码与构建记录。
