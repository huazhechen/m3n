# 循序渐进乐谱集

第四十版同时提供[简谱版 PDF](循序渐进乐谱集-简谱-v40.pdf)（4.71 MB）和[五线谱版 PDF](循序渐进乐谱集-五线谱-v40.pdf)（5.00 MB）。两版均为87页，包含相同的87首乐曲和完整基本功，共88个条目；每首曲目的起止页码一致。

| 篇目 | 简谱版 | 五线谱版 |
| --- | --- | --- |
| 第一篇　每日训练与入门短曲 | 简谱 | 五线谱 |
| 第二篇　经典旋律与流行歌曲 | 简谱 | 五线谱 |
| 第三篇　影视乐曲与经典器乐 | 简谱 | 五线谱 |

保留原简谱版的字号和行距。五线谱逐曲选择固定页数内较大的音符尺寸，使用较细的深灰谱线、较细的符干与连线，并修正说明文字、多段歌词及相邻谱行的避让。密集基本功和多段歌词页受87页约束，尺寸仍有局限。两版渐强、渐弱均置于上方，副标题已删除“单旋律版”。

在项目根目录运行 `npm run build:scorebook` 重建两份PDF及配对记录，不启动开发服务器。`editorial-plan.json` 保存简谱参数和配对设置；自动生成的 `staff-editorial-plan.json` 保存五线谱逐曲参数。`pagination-reference.json` 固定87页的曲目页码与谱源摘要。

`layout-record.json`、`staff-layout-record.json` 分别记录两版布局，`paired-layout-record.json` 核对88个条目的起止页码和谱源。两版排序记录、校阅记录及PDF体积记录可用于复查。

运行 `npm run test:scorebook` 验证分页、同页码约束、五线谱矢量导出与歌词避让。细节见[排版文档](../docs/NUMBERED_NOTATION.md)。
