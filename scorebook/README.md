# 循序渐进乐谱集

第四十七版：[简谱版 PDF](循序渐进乐谱集-简谱-v47.pdf)（82 页，6.08 MB），收录 86 首乐曲及完整基本功，共 87 个条目，按三篇编排。页码按实际内容重排。

《致爱丽丝》A、B 段改为段内反复与第一、第二房子，取消这两段的替代旋律；顶部顺序为 A/B/C/D/E/F/D，保留 D 段再现，完整 MIDI 不变，保持一页。

具名段落在原有行距之外增加12px排版留白，页首不添加这段额外留白；普通乐句换行保持原间距。替代旋律与主旋律统一为22px基准字号，随整页版宽同比缩放，保留括号和对应歌词，紧贴对应小节实际内容。《贝加尔湖畔》《童话镇》均保持一页。

段落名与顶部演奏顺序字母使用方框。`===名称{br}` 在段落标题后强制换行，基本功保留此写法。只在具名乐段结尾补双小节线，普通乐句换行不加；原有反复、导航与终止语义保留。分类小标题不渲染，渐强渐弱在音符上方，变音记号在小节内生效。当前只保留简谱显示和导出。

运行 `npm run build:scorebook` 重建。逐曲参数见 [布局记录](layout-record.json)，具体修改见 [校订记录](校订记录.md)及[逐页校阅](逐页校阅.md)。语法见[手册](../docs/MANUAL.md)。
