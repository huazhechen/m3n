# 循序渐进简谱集

当前交付：[第三十一版精简 PDF](循序渐进简谱集-v31.pdf)，73页，约3.9 MB。针对 iPad mini 排版，保留完整曲目和基本功；全册额外行间留白至少为音符字号的0.5倍。基本功使用等宽小节并保留两页。

## 最终文件

- `循序渐进简谱集-v31.pdf`：唯一发布的乐谱 PDF。
- `editorial-plan.json`：最终排版参数，构建工具读取此文件。
- `layout-record.json`：最终分页、字号及几何检查记录。
- `排序与缩放记录.md`、`排序与缩放记录.csv`：逐曲页码与显示比例。
- `逐页校阅.md`、`全册行距与间距校阅.md`：最终校阅结论。
- `PDF精简说明.md`、`PDF体积记录.json`：文件格式与验证信息。
- `校订记录.md`：当前版保留的谱源校订。

在项目根目录运行 `npm run build:scorebook` 可重建排版和精简 PDF。构建使用本地 Chromium 与 Poppler 工具，不启动开发服务器；中间文件写入 `.tmp/scorebook-v31/`。

构建会对密集谱行进行页面余量反馈试排，在原页数、字号和行距不变的条件下，自动比较更舒展的换行方案；不需要为单首曲目插入专用换行。规则详见 [简谱排版文档](../docs/NUMBERED_NOTATION.md)。
