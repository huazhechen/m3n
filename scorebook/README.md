《爱如潮水》按快悦谱参考重写，24px数字排成两页，主歌／副歌分开；保留三遍副歌及尾段变奏，修正参考谱两处超拍，播放与逐音展开版一致。详见[参考校订](爱如潮水参考校订.md)。

《爱的礼赞》按[快悦谱参考](https://www.kuaiyuepu.com/jianpu/DDWml1tVr.html)重写，采用D/F调、4/4、每分钟80拍及 A → B1 → A → B2。双音和声取低声部；两遍共同的六拍高音6并入A段末尾，随后两拍休止补满小节；删去间奏，B1/B2从参考谱间奏之后开始。保留参考谱的倚音、细分节奏和转调，38个书写小节均为四拍，独占一页。

K.545保持73小节和两页排版，依新上传简谱修正16个小节；《单簧管波尔卡》修正11个小节。主要纠正主题错音、误抄的伴奏、休止及结尾八度，详见[逐小节校订](K545与单簧管波尔卡逐小节校订.md)。原单页试排需约17px，低于正文20px下限，因此不采用。可复用旋律只有一组四小节和两组两小节，ABC方案会增加较多跳转并截断渐强、连奏，继续保留原反复；见[分段复用分析](K545分段复用分析.md)。

《花之舞》字号放大约19%，仍为两页；通过选取版宽让两页都更充实，未恢复全册留白均衡分页。全册继续优先保护可整页容纳的完整反复、乐句与延音，再尽量填满前页。《土耳其进行曲》的独立段名和C段指定换页边界保持原样。

主谱与替代旋律同字号，具名段落间额外留白12px，只有具名段落结尾补双小节线。渐强渐弱位于音符上方，变音记号在小节内生效。当前仅提供简谱。

运行 `npm run build:scorebook` 重建。详见[布局记录](layout-record.json)、[校订记录](校订记录.md)、[逐页校阅](逐页校阅.md)及[手册](../docs/MANUAL.md)。
