## 再生成与微调

在项目根目录运行：

```sh
npm run build:scorebook
```

需要本地 Chromium，可用 `CHROMIUM_PATH` 指定。构建使用离线浏览器页面，不启动开发服务器，不访问外部资源。中间 SVG、打印 HTML、逐页 PNG 和缓存位于 `.tmp/scorebook-ipad-v3/`。

- 移动 `entries` 即可调序，章节保持连续；每份原谱必须恰好出现一次，基本功须在第一篇开头。
- `width` 是优先版宽，`widthCandidates` 是候选。版宽越小，适宽显示的音符越大；单页优先最大可用字号，很短的曲目保留基准大小。合页短曲共同选择不小于 640px 的版宽。
- `widthLocked: true` 锁定版宽，`pageCount` 可要求准确页数，例如《土耳其进行曲》的两页。
- `pageBreaks` 指定完整谱行之后的分页位置；基本功使用 `[14, 26]`，机能训练完整占首页，后两页在练习边界接续。手动分页应锁定版宽。
- `sharePage` 为 `true` 且章节、分组相同的相邻短曲会尝试合页。`breakBefore` 可令条目另起一页。
- `page` 定义页面比例、边距、正文上下界、谱行留白与曲间距；`reviewNote` 记录人工调整理由。

构建检查全库覆盖、原谱完整性、候选横向边界、音符与歌词相交、分页切口、续页孤行及轮廓坐标。PDF 使用矢量路径，不依赖阅读设备字体；文字已转为路径，不能搜索或复制。后续由用户检查 PDF 内容、目录和受影响页面，代理负责按反馈调整、生成成品及验证代码与构建记录。
