# Max的半音阶口琴乐谱集

最新完整PDF见[第七十一版记录](../docs/SCOREBOOK_V71.md)；《秋樱》谱源的出版谱校订见[校订记录](../docs/SCOREBOOK_V72.md)，用户已停止PDF重排，尚未同步至整册，合页规则见[第六十九版记录](../docs/SCOREBOOK_V69.md)。

第六十三版直接复用网页的 `renderScoreInto`。`editorial-plan.json` 只维护三篇编排、曲目顺序和输出文件，不再包含逐曲行距、页边距、隐藏署名／低音、固定页数或基本功特例。

```sh
npm ci
npm run build:scorebook
```

构建逐曲试排540～720px、步长10px的全部19个宽度，验证每个候选±5px仍保持相同页数，复用重复测试宽度；排除越界和音符／歌词重叠的候选，先选页数最少者，再选宽度最小者（同样A4纸张上音符更大）。长曲直接使用网页分页，每页等比放入A4的186×273mm内容区，外侧12mm留白；谱内页边距为0.5em（当前11px），行距随整张谱统一缩放。保留网页显示的署名、歌词与低音。

组合页统一按640px渲染，同页保持同一缩放比例；这些曲目的单曲最佳宽度直接记为540px。核心区包含所有声部音符及歌词，含八度点、附点和减时线，相邻核心区至少留24px；倚音、圆滑线、延音线、连音组数字及括线和其他外侧装饰按实际碰撞留12px净空。房子按顶部横线、标签和端钩的实际墨迹保留2px净空，内部空白不参与避让。

PDF生成成功后，每首最佳宽度直接写回谱头 `{preferred-width=…}`。网页默认读取该字段，缺省720；手动设置的版宽可以覆盖。更改谱源或渲染器后重新构建可更新。源谱中的 `{equal-measures=true}` 是通用语法，基本功通过这一标记保留等宽小节。

本地生成PDF、`layout-record.json`、`PDF体积记录.json`和`排序与缩放记录.csv`，不提交Git。`.tmp/scorebook-v63-web/index.html` 提供逐页预览。`npm run compact:scorebook` 可从最近的原始页面重新打包PDF，不重新排谱；旧的 `--retain-unchanged-sizes` 已移除。

PDF共用字体子集并保留矢量图形，只固定导出字形的位置，不改变网页的断行与分页。封面、目录和三篇编排保留；长曲独立起页，同一篇内相邻短曲允许完整合页。

当前实现与验证规则见 [谱集构建说明](../docs/SCOREBOOK.md)。其他校订、逐页校阅、行距分析文件保留为历史版本快照，最新结果以本地构建报告为准。

网站曲库的六类分组单独维护在 [library-categories.json](library-categories.json)，不影响PDF三篇编排。每首曲子只列入一类；新增谱源时同步补充，未配置的曲目在网站暂归“其他曲目”。

谱集编写约定：按印刷顺序顺读的曲目使用普通乐句、反复和跳房子，不添加只用于演奏定位的具名段落，也不声明与印刷顺序一致的 `order`。确实依靠段名回跳、复用时再添加方框段名与演奏顺序；基本功的教学分类标题保留。音乐家署名使用通行简称，保留区分同姓、复姓和世代编号所需的信息。
