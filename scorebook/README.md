K.545保持73小节和两页排版，依新上传简谱修正16个小节；《单簧管波尔卡》修正11个小节。主要纠正主题错音、误抄的伴奏、休止及结尾八度，详见[逐小节校订](K545与单簧管波尔卡逐小节校订.md)。原单页试排需约17px，低于正文20px下限，因此不采用。可复用旋律只有一组四小节和两组两小节，ABC方案会增加较多跳转并截断渐强、连奏，继续保留原反复；见[分段复用分析](K545分段复用分析.md)。

《花之舞》字号放大约19%，仍为两页；通过选取版宽让两页都更充实，未恢复全册留白均衡分页。全册继续优先保护可整页容纳的完整反复、乐句与延音，再尽量填满前页。《土耳其进行曲》的独立段名现对齐谱行正文最左边缘，C段指定换页边界保留。

主谱与替代旋律同字号，具名段落间额外留白12px，只有具名段落结尾补双小节线。渐强渐弱位于音符上方，变音记号在小节内生效。当前仅提供简谱。
