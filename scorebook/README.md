# 循序渐进简谱集

当前交付：[第三十三版精简 PDF](循序渐进简谱集-v33.pdf)，72页，约3.9 MB。针对 iPad mini 排版，收录80首乐曲和完整基本功；全册额外行间留白至少为音符字号的0.5倍。基本功使用等宽小节并保留两页。

## 最终文件

- `循序渐进简谱集-v33.pdf`：唯一发布的乐谱 PDF。
- `editorial-plan.json`：最终排版参数，构建工具读取此文件。
- `layout-record.json`：最终分页、字号及几何检查记录。
- `排序与缩放记录.md`、`排序与缩放记录.csv`：逐曲页码与显示比例。
- `逐页校阅.md`、`全册行距与间距校阅.md`：最终校阅结论。
- `PDF精简说明.md`、`PDF体积记录.json`：文件格式与验证信息。
- `校订记录.md`：当前版保留的谱源校订。

在项目根目录运行 `npm run build:scorebook` 可重建排版和精简 PDF。构建使用本地 Chromium 与 Poppler 工具，不启动开发服务器；中间文件写入 `.tmp/scorebook-v33/`。

构建会对密集谱行进行页面余量反馈试排，在原页数、字号和行距不变的条件下，自动比较更舒展的换行方案；不需要为单首曲目插入专用换行。规则详见 [简谱排版文档](../docs/NUMBERED_NOTATION.md)。

同页多曲共用字号、最小／自然音符间距、行高策略及额外行距；单曲跨页沿用整曲同一配置，构建时同时校验两种一致性。小范围校订可运行 `node tools/build-scorebook.mjs --retain-unchanged-sizes`，保留当前谱集收录范围及未改谱源的独占页字号，只重算已修改曲目的字号及共页组合；此模式要求渲染器和纸张配置未变，不纳入尚未编排的新增谱源。

选曲建议见[口琴选曲适配评估](选曲适配评估.md)，评估列表中的其余乐曲仍保留。
