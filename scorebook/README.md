# 循序渐进乐谱集

第四十三版提供[简谱版 PDF](循序渐进乐谱集-简谱-v43.pdf)（86页，6.17 MB），包含87首乐曲与完整基本功，共88个条目，按三篇编排。解除原87页及逐曲页码约束，目录随实际内容重新分页。

乐段名采用行首方框，与首音同行；顶部演奏顺序的字母也加方框。显式 `===名称{br}` 将标题后的音乐另起一行，当前仅基本功使用。具名乐段仍从新谱行开始。《后来》按 A → B → A → A → C 演奏，完整排为一页；《童话镇》等曲目同小节、同音级及同八度的重复变音只印一次，音高和播放保持不变。

全册按实际行高收紧留白，允许相邻同篇、同版宽、同样式的短曲跨分组合页。除《后来》约22.58px数字外，各曲数字均不小于原版，部分短曲放大到统一版宽以便合页；基本功保留等宽小节、等行高和两页安排。渐强渐弱保持在上方，副标题不含“单旋律版”。

五线谱继续暂停导出，第四十版文件及配对记录保留为历史版本。[播放标记优化候选清单](播放标记优化候选清单.md)中的其他条件候选保留原谱。

运行 `npm run build:scorebook` 重建简谱，不启动开发服务器。`editorial-plan.json` 保存排版设置，`layout-record.json` 记录实际布局；`pagination-reference.json` 仅保留为历史87页版参考，当前构建不引用。语法见[手册](../docs/MANUAL.md#11-乐段)。
