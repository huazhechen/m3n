## 第十版调整

《土耳其进行曲》删除 7 处乐段名称，保留匿名乐段、音符、表情、反复和全部强制换行。去掉段名占用后，统一基线节距从 97.93px 降为 80.868px（均为谱内坐标）。采用 808px 版宽，按 **14 + 14 行**合为第 **83—84 页**；在第 5 个后反复之后分页，9 个反复段全部不跨页。两页高度利用率为 **99.9%、94.8%**。两页方案的音符为约 18.95px，比第九版三页方案小约 10.9%。

《哆唻咪》与《虫儿飞》互换。第 9 页为《苏珊娜》《小红帽》《虫儿飞》，共用 618px 版宽、约 24.78px 音符，利用率 98.2%；第 10 页为《哆唻咪》《让我们荡起双桨》，共用 588px 版宽、约 26.04px 音符，利用率 98.6%。两页字号差距由约 28.7% 降至约 5.1%。分组相应改为“轻快的旋律”“音阶与连奏”。

其余 76 个条目的 SVG 布局保持第九版原样。快速圆舞曲保留三页和原字号，页码提前为第 85—87 页；《花之舞》仍为第 80—82 页。基本功保留第 5—6 页、16 + 17 行与 1010px 版宽；长音、渐强渐弱、震音继续各占一行。《小星星》《欢乐颂》《我和你》仍合在第 7 页，《倩女幽魂》《铁血丹心》仍合在第 31 页。

全部 83 个正文谱页的高度利用率严格高于 90%，最低为 **90.139%**。利用率按自然谱面占用高度（含曲目标题、续页标题和正常曲间距）除以固定正文区域高度计算；封面与目录保留正常留白。沿用普通/房子两档等行高，歌词按每行实际可见行数增高，各页不分摊额外行距。

## 再生成与微调

在项目根目录运行 `npm run build:scorebook`。需要本地 Chromium，可用 `CHROMIUM_PATH` 指定；构建使用离线浏览器，不启动开发服务器。中间 SVG、打印 HTML、预览和缓存位于 `.tmp/scorebook-v10/`。运行 `npm run test:scorebook` 可检查分页与合页规则。

- 移动 `entries` 可调序，章节及合页分组须连续；每份原谱恰好出现一次，完整基本功位于第一篇开头。
- `width` 越小，整页适宽时音符越大。`widthCandidates` 补充候选，`widthLocked` 锁定已验证版宽，`pageCount` 指定准确页数。
- `pageBreaks` 指定完整谱行后的分页位置，宜与锁定版宽配合。基本功为 `[16]`，《土耳其进行曲》为 `[14]`。反复段是否完整须结合音符与原谱反复边界核对；手动分页不会自动跟踪后续源文件改动。
- `sharePage` 启用相邻同组短曲合页；同页统一字号，合页版宽不超过 780px。`breakBefore` 强制另起页。
- 全局 `showCredits: false` 隐藏署名，单曲 `includeBass: false` 隐藏低音，均不删除源文件内容。
- `uniformSystemHeight` 使用普通/房子两档上方预留，音乐主体与下沿共享，歌词按实际行数占位。`voltaSystems` 与 `baselineSteps` 记录各行分类及节距。
- `minimumFillPercent: 90` 是严格下限，分页、合页和最终构建都拒绝不超过下限的正文页。

构建检查全库覆盖、边界、音符和歌词相交、安全分页、续页孤行及轮廓越界。PDF 只呈现音乐相关内容；文字已转为矢量路径。代理负责修改、生成与自动验证，PDF 内容由用户检查。
