## 再生成与微调

在项目根目录运行 `npm run build:scorebook`。需要本地 Chromium，可用 `CHROMIUM_PATH` 指定；构建使用离线浏览器，不启动开发服务器。中间 SVG、打印 HTML、预览和缓存位于 `.tmp/scorebook-v17/`。运行 `npm run test:scorebook` 可检查分页与合页规则。

- 目录固定两页，每页左右两栏，按栏顺序列出章节标题及曲目，删除难度列；编号、页码和文本边界在构建时检查。
- 移动 `entries` 可调序，章节及合页分组须连续；每份原谱恰好出现一次，完整基本功位于第一篇开头。
- `width` 越小，整页适宽时音符越大。`widthCandidates` 补充候选，`widthLocked` 锁定已验证版宽，`pageCount` 指定准确页数。
- `pageBreaks` 指定完整谱行后的分页位置，宜与锁定版宽配合。基本功为 `[16]`；《土耳其进行曲》不再固定分页位置，由两页容量和安全切口选择，允许反复段跨页。手动分页不会自动跟踪后续源文件改动。
- `sharePage` 允许相邻同组曲目合页，同页使用统一字号，默认版宽上限780px；《一步之遥》《散步》用 `maximumSharedWidth: 800` 保留已确认组合。`breakBefore` 强制另起页。
- 全局 `showCredits: false` 隐藏署名，单曲 `includeBass: false` 隐藏低音，均不删除源文件内容。
- `uniformSystemHeight` 使用普通/房子两档上方预留，音乐主体与下沿共享，歌词按实际行数占位。`voltaSystems` 与 `baselineSteps` 记录各行分类及节距。
- `maximumNotePx: 24` 限制正文音符字号，候选阶段过滤超限版宽，最终按实际选定版宽再次核对。
- `minimumFillPercent: 90` 是严格下限，分页、合页和最终构建都拒绝不超过下限的正文页。

构建检查全库覆盖、边界、音符和歌词相交、安全分页、续页孤行及轮廓越界。PDF 只呈现音乐相关内容；文字已转为矢量路径。代理负责修改、生成与自动验证，PDF 内容由用户检查。
