# K.545 第一乐章：段落演奏顺序评估

以当前73个书写小节编号，完整演奏仍使用第28、73小节结束的两组原反复。按音高、时值、连音组、延音与八度逐事件比较，找到下列连续重复旋律：

| 首次出现 | 再次出现 | 可省书写量 |
| --- | --- | --- |
| 10—13小节 | 55—58小节 | 4小节 |
| 14—15小节 | 16—17小节 | 2小节 |
| 59—60小节 | 61—62小节 | 2小节 |

合计最多省8/73个小节，约11%。但55小节属于54—55小节的连续渐强和连奏，10小节的连奏范围不同；将55—58直接改为复用段会切断音乐处理。现有演奏顺序要求区间不得跨段，不能仅凭旋律相同就认定可完整复用。

如果忽略这一表达差异，按A=1—9、B=10—13、C=14—15、D=18—28、E=29—54、F=59—60、G=63—73分段，需要：

`A B C C D A B C C D E B F F G E B F F G`

七个段名与20次访问只省八小节，还会把两个本来局部的两小节重复改成来回查找。为练习阅读，保留原反复更清楚；本版不实施这一假设方案。
