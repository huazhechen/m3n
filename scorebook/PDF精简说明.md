# 第二十四版PDF精简

建议使用[精简PDF](循序渐进简谱集-v24-精简.pdf)，共75页，约3.9 MB；[原轮廓PDF](循序渐进简谱集-v24.pdf)约16.14 MB。精简版减小75.94%，纸张、页码、音符字号、行距、反复、歌词及音乐编排相同。

原版将每次出现的数字和汉字都画成独立矢量轮廓。精简版共用嵌入的字体字形，数字使用同一Barlow Semi Condensed Medium，中文使用同一Noto Serif CJK SC；仍为矢量内容，阅读不需要另安装字体。

每个字符从原SVG读取实际起笔位置，固定到同一基线上，保留tspan、空白、旋转和歌词对位。粗体采用与轮廓版相同的描边。导出不重新换行、分页或缩小字号。

自动核对75页纸张尺寸、27,273个字形的固定基线位置（误差不超过0.001px）及实际纸张边界；全部116个字体子集已嵌入且带Unicode映射，PDF中没有栅格图片。PDF内容及阅读效果由用户亲自检查。字节数、逐页字形数量和文件摘要见[验证数据](PDF体积记录-v24.json)。

在项目根目录执行`npm run compact:scorebook`可重新生成精简版；谱源或布局改变后，先执行`npm run build:scorebook`。依赖现有Node工具链、本地Chromium以及Poppler的`pdfinfo`、`pdffonts`、`pdfimages`，不需要Python压缩库，不启动开发服务器。
