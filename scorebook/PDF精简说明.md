# 第十七版PDF精简

建议使用[精简PDF](循序渐进简谱集-v17-精简.pdf)，共78页，约3.9 MB。保留[原轮廓版](循序渐进简谱集-v17.pdf)，约16.3 MB，供对照。精简版减小76.2%，纸张、页码、音符字号、行距、反复、歌词及音乐编排均相同。

原版将每次出现的数字和汉字都画成独立矢量轮廓，因此重复字形占用较多。精简版共用嵌入的字体字形，数字使用原来的Barlow Semi Condensed Medium，中文使用原来的Noto Serif CJK SC；仍为矢量内容，放大与打印时保持字形清晰，阅读不需要另安装字体。

每个字符先从原SVG读取实际起笔位置，再固定在同一基线上，tspan、空白、旋转及歌词对位保留。粗体采用与原轮廓版相同的描边。导出不重新换行、分页或缩小字号。

自动核对78页的纸张尺寸、27,653个字形的固定基线位置与实际纸张边界；所有117个字体子集已嵌入并带Unicode映射，PDF中没有栅格图片。没有人工检查PDF内容，内容及阅读效果由用户亲自检查。详细字节数、各页字形数量与文件摘要见[验证数据](PDF体积记录-v17.json)。

在项目根目录执行 `npm run compact:scorebook` 可重新生成精简版；若谱源有变动，先执行 `npm run build:scorebook`。依赖现有Node工具链、本地Chromium以及Poppler中的 `pdfinfo`、`pdffonts`、`pdfimages`，不需要Python压缩库，不启动开发服务器。
