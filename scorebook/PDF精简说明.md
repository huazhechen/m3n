# 最终 PDF

第四十版：[简谱版 PDF](循序渐进乐谱集-简谱-v40.pdf)（87页，4.71 MB）与[五线谱版 PDF](循序渐进乐谱集-五线谱-v40.pdf)（87页，5.00 MB）。同一曲目在两版中占用相同的页码，谱行断点可以不同。

文字嵌入字体，音符及音乐符号均为矢量路径，两版栅格图片均为0。构建核验纸张、页数、字体嵌入、Unicode映射、页面边界及逐曲页码；摘要分别见[简谱体积记录](PDF体积记录.json)和[五线谱体积记录](五线谱PDF体积记录.json)。

运行 `npm run build:scorebook` 重建两版；中间文件位于 `.tmp/scorebook-v40-numbered/` 与 `.tmp/scorebook-v40-staff/`，默认不生成轮廓PDF。
