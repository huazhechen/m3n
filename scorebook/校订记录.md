# 第一版校订过程

1. 盘点全部 82 份原谱，形成四篇乐曲与一个专项练习附篇。按当前简谱的节奏、音域、临时变音、连音组、变拍和反复结构判断难度，并在同类学习目标内推进。
2. 将《半音阶口琴基本功》拆成 28 项可独立调整的练习，逐行核对所有旋律行；只重排练习单元，不改音符、时值、力度或建议速度。长音、渐强渐弱放在开篇，其余练习放在附篇。
3. 初排使用 840px 基准版宽，比较 800、820、840、860、880px，得到 100 页（含封面与四页目录）。所有续页至少三条完整谱行。
4. 审视初排后，将长音与最简单的短曲归入同组，将《哆唻咪》移至相同风格的二拍子短曲组；允许短小器乐主题合页；短曲与练习合页改用均衡分配，避免同组末尾单独落下一小项。
5. 将相邻候选扩至 900px，允许最大约 6.7% 的缩小，以检验部分略超一页的曲目是否可在接近的字号下完整容纳。最终实际版宽、页码与各页谱行数逐曲写入记录。
6. 最终 PDF 逐页生成预览，复核固定比例、完整谱行、续页、密集歌词和合页间距；具体页码与结论见《逐页校阅》。

最终合页再调整：将《蜗牛与黄鹂鸟》并入二拍子民歌组；《温柔的倾诉》移到《梁祝》之后，与《太阳照常升起》共页，分别锁定860px与880px。最终89页，比100页初排减少11页。实际版宽分布为840px 94项、860px 5项、880px 4项、900px 6项。

# 第二版：iPad mini 阅读调整

用户明确以电子设备阅读为目标，要求最小化边距、略减行距、增大音符，并允许将两个大半页适度缩小合成一页。

1. 保留第一版 PDF、布局 JSON 和逐页校阅快照，分类与曲序不变。页面由 A4 改为 744∶1133 的 iPad mini 竖屏比例，正文外边距 8px，谱内边距 8px；去掉通栏正文页眉与页脚线。
2. 渲染器增加可选的页边距与谱行留白参数，普通网页仍使用原默认值。谱集最小留白从 24px 降到 18px；候选方案若发生上下关系线相交，则逐步回退到 20、22、24px。最终 102 项使用 18px，7 项使用 20px。
3. 将优先版宽从 840px 改为 780px，逐曲比较 760—960px；多数条目的同屏音符增大约 18.85%。同一首曲目的各页始终保持相同比例。
4. 《后来》《童话镇》《老男孩》《凉凉》《牵丝戏》《如愿》《Valsentino(快速圆舞曲)》由两页合为一页。其音符大小分别为第一版的 98.62%、100.76%、100.76%、115.88%、113.05%、100.76%、96.56%。
5. 为《土耳其进行曲》额外测试 980、1000、1020、1040px：980 / 1000px 仍超页，1020px 可完整容纳 19 行、占正文高度约 98.1%。实际看页后采用 1020px，音符为第一版的 90.88%，减少一次翻页。1040px 未采用。
6. 《花之舞》在 960px 时仍约需 1.26 页，不进一步缩小；采用 800px 分为 17 + 20 行两页，同屏音符较第一版增大约 24.15%。
7. 最终 80 页，较第一版减少 9 页（8 首长曲各少 1 页，专项练习合页再少 1 页）。逐曲版宽、行距、旧版对比、谱行和页码均写入 Markdown、CSV 与 JSON；最终 PDF 逐页视觉检查见《逐页校阅》。

8. 实际 PDF 放大检查发现《花之舞》续页标题缺笔画，定位为 opentype.js 2 对接近整数的小数坐标使用指数表示舍入而产生 NaN。转换路径前统一舍入到 0.001px，补充真实字体与小数基线的回归测试，并检查全部页面的轮廓坐标。重新生成后的续页标题完整。

9. 续接复核时，校正逐页校阅中6处未同步的版宽说明；对照第一版确认109项条目的顺序与源内容校验和完全一致，并完成完整 `npm run check`（1216项单元测试、680次布局检查、33项浏览器测试）。按 `npm run build:scorebook` 重新生成，核对实际PDF的80页及纯矢量内容，保留第一版对照文件。
