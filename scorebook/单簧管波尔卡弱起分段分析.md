# 《单簧管波尔卡》弱起分段演奏顺序评估

可以通过移动分段边界消除目前全部四组第一、第二房子。方案先保留为分析，不修改正式谱。

演奏顺序：**序 → A → A → B → B → A → C → C → A → A → 尾**。

以下小节编号以第五十一版78个书写小节为准。每段的弱起移自前段结尾，按实际声音转写到该段调号，不能机械照抄转调前的数字。

| 段 | 写法 | 时值 |
| --- | --- | --- |
| 序 | 第1小节及第2小节前三个八分时值 | 3.5拍 |
| A | 半拍弱起5、4；接第3—17小节；结尾三个高音1，各半拍 | 32拍 |
| B | 半拍休止弱起；接G调第20—26小节；结尾三个高音1，各半拍 | 16拍 |
| C | 以F调高音5半拍弱起；接第45—59小节；结尾三个高音1，各半拍 | 32拍 |
| 尾 | 半拍休止，接终止线 | 0.5拍 |

A的五次弱起听起来完全相同。第28小节G调的1、低音降7，以及第61小节F调的2、1，都等于C调5、4，因此可复用同一个A，无需分别建立不同弱起段落。

C第一遍的弱起来自第44小节最后半拍C调高音1，换成F调写作高音5；第二遍来自第60小节末尾的F调中音5，低一个八度。可只为这个半拍标记第二遍替代音，其余相同。若不希望使用替代旋律，也可以单独写C1、C2，但会增加书写量。

按原房子展开为260拍，再按此顺序组合逐事件比较：772个音符／休止事件的实际音高、时值及延音标记一致，包括转调边界和三连音。该比较验证旋律结构；正式采用时还需保留各次力度与奏法，并核对实际渲染和完整MIDI。切段不应跨越现有连奏或渐强范围。

现有78个完整书写小节可变成46个片段（含各段弱起和不满拍结尾），书写片段约减少41%。这个比例不等于页面高度减少41%；最终字号和页数仍需实际排版检验。
