# 《花之舞》分段整理方案

当前[谱源](../src/scores/flower_dance_01.m3n)按完整乐段复用，变奏与收尾连续书写。语法依据[手册](../docs/MANUAL.md#5-演奏顺序与替代旋律)。

## 演奏结构

```m3n
{order=Intro,A,B,A,C,D,E}
```

| 乐段 | 书写小节数 | 演奏处理 |
| --- | ---: | --- |
| Intro | 2 | 第一小节反复七遍，接一小节长音 |
| A | 16 | 完整主题；经过B后整段再现一次 |
| B | 8 | 与A前半段相近，收尾不同，独立顺读 |
| C | 8 | 段内成对反复，原样演奏两遍 |
| D | 16 | 变奏和高八度连续写出 |
| E | 25 | 连接句、主题后半段再现、后续变化及尾声连续写出 |
| 合计 | **75** | **无替代旋律、无跳房子** |

## 为什么回改

上一版为45小节主谱加7小节替代旋律，顶部顺序有14项。它保持了播放内容，但把演奏者的阅读负担估计得过低：

- C第三次访问有4／8小节变化，需要在主谱与多条替代行之间切换，只比独立写出这次变奏净省4小节。
- 把完整16小节主题拆为两个8小节段，使主题再现需要多次查顶部路线；现在恢复完整A段复用。
- 单小节Link与后续主题复用需要额外跳转；现在接入E段顺读。
- 后段仅两小节核心相同却使用两组两小节房子，尾声又叠加反复与替代行；现在直接展开。

回改后主谱75小节，相比上一版包含替代行的52小节多写23小节，换取顶部路线14→7项、替代小节7→0，以及取消所有房子。相较最早99小节的版本，仍保留完整A段再现和C段反复所省下的24小节。书写小节数不等于排版页数，不据此声称页数降幅。

引子七遍反复是连续伴奏音型，C段两遍是完整8小节原样重奏；两者保留段内反复。D的变奏和音区变化保持原样，不再强行并入C。

## 验证

`src/lib/flower-dance-sections.test.ts`检查当前结构、语法诊断及完整演奏指纹。修改前后的1203个事件在实际音高、时值、同音延续、奏法、力度及速度上保持一致；完整演奏仍为105小节、420个四分音符拍，速度100 qpm。

本次验证：花之舞两项专项测试通过；四种宽度、连续与分页模式及通用回归谱例共40组几何检查无异常，并人工查看800px谱面。扩展运行 `src/lib` 共175项测试，174项通过；唯一失败为未涉及修改的手册代码块第15项缺少终止线校验，不属于本曲变更。
