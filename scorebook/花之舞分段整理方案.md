# 《花之舞》分段整理方案

本方案已按用户确认应用于正式谱源。依据当前[谱源](../src/scores/flower_dance_01.m3n)逐小节核对；下文旧段小节号均从各段开头计数，不是全曲小节号。语法采用[手册的演奏顺序、房子和替代旋律](../docs/MANUAL.md#5-演奏顺序与替代旋律)。

## 核对结果

整理前书写75小节：Intro 2、A 16、B 8、C 8、D 16、E 25。演奏顺序为 Intro → A → B → A → C → C → D → E；引子首小节七遍，完整演奏105小节、420个四分音符拍。

| 位置 | 与已有材料的关系 | 必须保留的差异 |
| --- | --- | --- |
| 旧B 1–8 | 对应旧A 1–8；前7小节完全相同 | 第8小节最后一拍：旧A为八分音符高音6、高音3；旧B为四分音符高音6 |
| 旧E 2–9 | 对应旧A 9–16；前7小节完全相同 | 旧E9的后两拍是 `6~ (6 3)`，旧A16是 `6^` |
| 旧D 1–8 | 对应旧C 1–8；第1、2、3、5小节完全相同 | 第4、6、7、8小节不同，不能把D前8小节直接视为C原样再现 |
| 旧D 9–12 | 开头两小节等于旧C 1–2 | 第11小节开头节奏变化，第12小节改了收束音高与节奏 |
| 旧D 13–16 | 第13、14、15小节分别是旧C 1、2、3的高八度 | 第16小节不是C4高八度，而与旧D8完全相同 |
| 旧E 10–17 | 前两小节构成重复核心：E10–11＝E14–15 | E12–13与E16–17各是不同的两小节结尾 |
| 旧E 18–25 | 两个四小节单元：E18–21、E22–25 | 各单元前三个位置中的第3小节不同，仅最后一拍变化；其余对应小节相同 |
| 引子与尾声 | Intro1＝E18、19、21、22、23、25 | Intro2的高音3长音，以及E20、24的变化保留 |

旧C自身的C1、3、5、7完全相同，C2＝C6；旧D内部也有相同音型。这些单小节重复可继续拆分，但会把连续琶音切成许多短段。整理时先处理连续的乐句复用。

## 推荐分段

保留8小节为主体，只把旧E开头的一小节连接句单独标记。以下为新段名，与旧段名有重新对应。

| 新段 | 材料来源 | 主谱小节数 | 差异处理 |
| --- | --- | ---: | --- |
| Intro | 旧Intro | 2 | 保留首小节七遍反复和后接长音 |
| A | 旧A 1–8 | 8 | 第2次访问的第8小节用旧B8替代，另外两次按主谱 |
| B | 旧A 9–16 | 8 | 第3次访问的第8小节用旧E9替代 |
| C | 旧C 1–8 | 8 | 第3次访问第4、6、7、8小节分别用旧D4、6、7、8替代 |
| D | 旧D 9–16 | 8 | 连续保留节奏变奏、高八度及最后的上行连接，不再拆碎 |
| Link | 旧E1 | 1 | 保留连接到旧A后半段的休止与短句 |
| E | 旧E 10–17 | 6 | 两小节核心反复，第一房子为旧E12–13，第二房子为旧E16–17 |
| Outro | 旧E 18–25 | 4 | 四小节反复；第2遍第3小节用旧E24替代 |
| 合计 | | **45** | 另有**7小节替代旋律** |

顶部顺序：

```m3n
{order=Intro,A,B,A,A,B,C,C,C,D,Link,B,E,Outro}
```

路线对应关系：

- 旧A → 新A、B。
- 旧B → 新A第2次访问，最后一拍按替代行。
- 旧A再现 → 新A第3次、新B第2次。
- 旧C两遍 → 新C第1、2次。
- 旧D → 新C第3次、新D。
- 旧E → Link、新B第3次、新E、Outro。

替代行均使用手册已有语法：A为 `Ns[2]: 8:`，B为 `Ns[3]: 8:`，C分为 `Ns[3]: 4:` 和 `Ns[3]: 6:`（后者连续3小节），Outro为 `Ns[2]: 3:`。E使用成对反复与两个两小节房子。无需增加新语法，也不归一或删改任何旋律。

## 压缩量与可读性

- 正文75→45小节；把7小节替代行也计入，实际书写旋律为52小节，减少23小节，约31%。替代行会增加局部高度，这不是PDF页数减少31%的保证。
- 顶部顺序8→14项，换取A/B、E/A及C/D的大段复用。段内两小节和四小节反复不再展开到顶部。
- C/D若改成三小节核心加多组房子，还能进一步省写，但原C会分成四次访问，后续再穿插D的短句；演奏者需要更频繁查遍次和跳转。推荐先保留上述8小节框架。
- 高八度是真实的音区变化，不应靠调号后缀表达。现有 `段名@调性` 是换调功能，不是八度访问功能；推荐方案保留旧D后8小节的完整音区。
- 引子与尾声虽共享单小节音型，但引子还有七遍反复及独立长音；强行跨首尾共用会引入额外访问计数和房子。尾声内部四小节复用已经能省3小节净书写量。

## 草案验证

正式谱源已按上述分段写入，检查结果：

- `validateM3NDiagnostics` 无诊断。
- 主谱45小节，替代旋律7小节。
- 按完整路线及段内反复展开，与整理前正式谱的**1203个事件逐项一致**：实际音高、事件时值、同音延续、奏法、力度及速度均相同。
- 完整演奏仍为105小节、420个四分音符拍，100 qpm。

正式谱源的115项相关测试通过；四种宽度、连续与分页模式及综合回归谱例合计40组几何检查无异常。已人工查看800px连续谱面，顶部14项顺序分两行，替代行及两个房子显示完整。完整播放指纹回归见 `src/lib/flower-dance-sections.test.ts`。
