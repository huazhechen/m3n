# 牵丝戏单页选项

在前次固定歌词比例、谱头及页边留白的测算之外，另测单独调整歌词、谱头和正文高度的方案。以下五种独立排版试算均能放入一页，并达到90%以上自然高度利用率；整册仍为第二十版，尚未选用其中任一方案。

字号均指最终正文中的音符字号。歌词另列，曲名及装饰小字不计入音符字号。所有方案保留完整旋律、节奏、反复、三种结尾和D.S.，没有删去音乐内容。

|---|---|---:|---:|---:|---:|---|
|1|保留全部歌词，回收谱头及上下留白|19.00|15.58|12|99.53%|歌词保持正常比例；标题变小，该页上下留白较少|
|2，推荐|保留全部歌词，歌词小一档|19.50|14.04|11|94.65%|歌词较小，保留常用谱行留白及原页边|
|3|保留全部歌词，进一步缩小歌词|20.00|13.60|11|95.70%|音符再大一点，歌词再小一点|
|4|每个乐句只显示一行歌词|20.00|16.40|12|97.44%|歌词较大，但省略同旋律下的其他段歌词|
|5|纯旋律，不显示歌词|23.93|—|14|99.41%|音符最大，失去全部歌词提示|

推荐选项2：保留完整音乐及全部歌词，音符19.5px、歌词14.04px，额外行间留白18px，页边及曲名大小沿用现有设置。它比单纯把额外行距压到零更适合连续阅读。若更在意音符大小，选项3可在保留全部歌词的同时达到20px。

选项1保持歌词与音符0.82的比例：原生曲名字号32 → 24px、谱头内部间隔5 → 3px，额外行间留白13px。该页正文上沿38 → 24px、下沿1095 → 1109px，正文高度1057 → 1085px；左右正文宽度保持696px。测得占用1079.879px，利用率99.528%。标题最终约20.73px，略大于19px音符。

选项2及3仅改变歌词的排版比例与歌词间距，音符内部的节奏排布保持。歌词字号比例分别为音符的0.72及0.68；原比例为0.82。相邻歌词行留白比例0.24 → 0.16，音乐下沿到首行歌词的留白比例0.32 → 0.24；这些比例用于独立原生排版试算，尚未新增为正式配置。

选项4保留每个乐句第一条可见歌词，因此仍能看到各自独立结尾的歌词，但同一旋律下其他段的歌词不显示。它不是完整歌词版本。选项5隐藏全部歌词，并在现有乐句边界强制换行，以14行维持18px额外行间留白；音符实际23.925px，低于24px上限。

此次未把更复杂的反复重写列为已验证选项。《牵丝戏》已有三种结尾和D.S.，开头与主反复的部分相同旋律若继续合用，需要另行验证演奏路径与歌词遍次，不能直接删除重复小节。

五个候选均重新排版验证，228个原始音乐事件身份完整；选项1—3的306个歌词文字元素及对应身份与原谱相同。谱内横向越界、音符/歌词相交、不安全谱行切口及错误诊断均为0。没有打开PDF或截图进行视觉检查。这些是独立排版测算，正式整册页边、页码和字体导出仍需在选定方案应用后验证。
