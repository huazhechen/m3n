# 全册行距与间距校阅

第四十八版共80页、86个条目。主谱与替代旋律统一22px基准，随版宽同比缩放；正文下限20px，基本功约19.33px。基本功继续使用等宽小节、等行高和两页。

具名段落之间在原行距外增加12px排版留白，页首不增加；普通乐句换行不添加。《土耳其进行曲》各段采用 `===名称{br}`，方框标题独占一行，随首音共同分页。C 段第一组反复结束处保留原谱换行，并按音乐边界换页，不固定写死系统行号。

全册不再以各页空白的均衡程度评分。先保证页面容量、最少页数和安全切页，优先保留能在一页放下的完整反复、短乐句、连奏和延音，再向前页填入尽可能多的谱行。长于一页的反复和乐句允许续页；续页仍至少三行。相邻短曲合页同样不均衡留白。

《深情的吻》和《啤酒桶波尔卡》采用房子后均保持一页，数字分别约23.70px、25.95px。《土耳其进行曲》维持两页，按指定 C 段边界分页。

完整版宽、间距、反复与乐句边界、页码及几何验证见[布局记录](layout-record.json)。
