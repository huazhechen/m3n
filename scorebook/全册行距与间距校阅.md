# 全册行距与间距校阅

第四十六版共 81 页、87 个条目。按实际谱行内容预留高度，基本功保留等宽小节、等行高和两页。正文数字下限 20px，基本功约 19.33px；替代旋律采用 18px 基准，随版宽缩放。

替代旋律以对应横向范围内实际可见的主谱、歌词与连线为边界，不再被同一谱行其他小节的第二行歌词推远。《贝加尔湖畔》两个主要替代位置各消除一整行空歌词占位；正常第二遍不另设“2.”提示行。局部实际间隙为约 2.5px 排版单位，八度点和连线另占必要高度。

《老男孩》恢复跳房子后保持一页，数字约 20.86px；《新不了情》A/B 两段保持一页，数字约 25.95px。
