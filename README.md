# Max's Markup Music Notation (M3N) 文档

> **文档版本**：M3N v0.1 
> **更新日期**：2026-07-28

本文档主要由三部分构成：
- 简介：M3N的创作背景、核心特色等，可以初步认识M3N
- 指南：通过由浅入深的示例，完整阐述功能和涉及思路，用于学习M3N使用并理解其设计原则
- 手册：M3N的语法规则、关键字、使用说明等，方便总览查询M3N规范

## 什么是M3N？

M3N（Max's Markup Music Notation）是一个基于文本格式的五线谱单一谱表制作语言。
按照本规范编写的文本文件，不仅可读性强，而且方便分享和编辑。作者也提供一个库，可以将M3N文本渲染为标准的五线谱，供查看、播放和打印。
语法设计参考了大量文本制谱规范，结合单一谱表五线谱、首调制谱的精准场景，做到了功能性和简洁优雅的平衡。

为了让事情清晰一点，来感受一个简单但完整的例子——《欢乐颂》。
```m3n
{1=D} {4/4} {tempo=114bpm}
3 3 {lg}4 5{/} | {lg}5 4 3 2{/} | 1 1 2 3 | 3. (2) 2^ |
3 3 4 5 | {lg}5 4 3 2{/} | 1 1 2 3 | 2. (1) 1^ |
2 2 {lg}3 1{/} | {lg}2 (3 4) 3 1{/} | {lg}2 (3 4){/} {lg}3 2{/} | {lg}1 2{/} 6d 3~ |
3 {lg}3 4 5{/} | {lg}5 4 3 2{/} | 1 1 2 3 | 2. (1) 1^ |||
```

### 核心原则

**文本格式**
- 便捷，可以在任何平台上直接编写和编辑，在有键盘的场景下效率极高。
- 开放，可以直接通过消息的方式分享给他人，而且可以随时编辑修改。
- 精确，你可以精准修改乐谱中的每一个字节，不会有任何隐藏元素。

**简洁克制**
- 仅支持单声部场景
- 仅支持首调输入
- 仅支持单谱表五线谱渲染

**清晰直观**
- 符合系统尽可能与常见制谱法一致
- 使用可嵌套的括号作为时值系统

以上核心原则会在之后的指南中逐步展开，请随指南上手尝试吧。

## M3N指南

### 从小星星开始

#### 音高、时值、小节

乐谱最核心元素是**音高**和**时值**，将音高时值按照**小节**组织起来，就可以快速编写出小星星的乐谱了！

**音高**由**调号**和**相对音级**确定。
- **调号**使用由大括号包裹的属性`{1=C}`表示。
- **相对音级**使用`1 2 3 4 5 6 7`表示。

> 【简洁克制】强化调性思维聚焦旋律骨架，更适配单声部场景。
> 【清晰直观】如果你有简谱基础，会感觉这种表达和简谱一致性极高。

**时值**由**拍号**分母所对应的**基础时值`B`**，和时值系统确定的**时值比例`N`**相乘确定。
- **拍号**由大括号包裹的属性`{4/4}`表示，即基础时值**`B = 四分音符`**。
- 默认每个音符时值比例**`N = 1`**，可以通过`^`符号将其翻倍。

> 【清晰直观】`^`作为指数符号，符合对时值翻倍效果的直觉 N = N *（2^$）。

**小节线**使用`|`符号表示，**终止线**使用`|||`符号表示。

> 【清晰直观】这是文本记谱领域事实上的通用标准，该选择兼顾了视觉辨识度和输入便利性。

我们已经可以完成小星星的编写了：
```m3n
{1=C} {4/4}
1 1 5 5 | 6 6 5^ | 4 4 3 3 | 2 2 1^ |
5 5 4 4 | 3 3 2^ | 5 5 4 4 | 3 3 2^ |
1 1 5 5 | 6 6 5^ | 4 4 3 3 | 2 2 1^ |||
```
> 音符之间的空格不是必须的，制谱者应当充分考虑可读性自行抉择。

注意到渲染出的五线谱，换行行为与文本完全一致。M3N默认优先遵循文本换行，但渲染引擎保留自动换行与多行合并的可能。
> 【清晰直观】所见即所得的语法更符合直觉。

#### 额外信息

在小星星的编写中，我们已经遇到了两种属性：调号和拍号。在M3N中，属性统一使用大括号包裹。
> 【清晰直观】所有属性均通过花括号`{}`包裹，与音符部分隔离开

除了调号和拍号外，还有一些核心属性：
- **速度**通过以`tempo`为key的属性表示：`{tempo=120bpm}`。
- **标题**通过以`title`为key的属性表示：`{title=小星星}`。
- **副标题**通过以`subtitle`为key的属性表示：`{subtitle=小星星}`。

另外你可以通过自定义的方式提供其他属性，将统一绘制在标题的右下角。例如`{莫扎特}`。

除了给读者提供的额外信息，还有一些信息是提供给制谱人员的。M3N仅支持行内注释，从`//`符号开始直到行尾的内容将不会被解析。

以下是完善了额外信息的《小星星》：

```m3n
{title=小星星} {subtitle=《C大调变奏曲主题》}
{作曲：莫扎特}
{1=C} {4/4} // 这是注释：待补充速度信息
// 这是注释：待补充奏法信息
1 1 5 5 | 6 6 5^ | 4 4 3 3 | 2 2 1^ |
5 5 4 4 | 3 3 2^ | 5 5 4 4 | 3 3 2^ |
1 1 5 5 | 6 6 5^ | 4 4 3 3 | 2 2 1^ |||
```

### 时值进阶

在通过拍号确定了**基础时值`B`**后，音符的时值主要通过**时值比例`N`**决定。
通过括号系统和时值后缀，M3N已经可以表达绝大多数音符的时值。

#### 特殊音符
在开始之前，补充两种特殊的音符：
- `X`：占位音符
- `0`：休止符

#### 括号系统
音乐中的时值系统基于指数二分法，五线谱的符尾数、简谱的减时线数等每增加1，音符时值减半。且符尾组合成符杠、减时线合并等方式，同时也表达了音符分组和节拍信息。M3N通过括号系统优雅实现了这一机制：
- 每嵌套一层括号`()`，每个音符的时值比例`N = N / 2`。
- 每小节括号必须匹配。

以下是常见的时值与节奏的样例：
```m3n
{1/4}
// 前8后16 前16后8 小切分
(x (x x)) | ((x x) x) | ((x)x(x)) |||
```
> 【清晰直观】括号系统既符合时值指数二分的原则，又包含了音符分组信息。


#### 时值后缀

时值后缀符号是紧跟在音符后面，对音符时值进行修改的符号。

**翻倍**符号`^`，根据叠加个数`$`对根据括号系统计算的当前时值翻倍：`N = N * 2^$`。
```m3n
{4/4}
x^ x^ | x^^ | ((x x x x)) ((x^ x x)) ((x x^ x)) ((x x x^))|||
```
> 用于表达二分音符、全音符，也可以用于简化部分节奏型

**附点**符号`.`，根据叠加个数，增加时值的一半：`N = N + N/2 + N/4...`。
```m3n
{2/4}
x. (x) | x..((x)) |||
```
> 附点在叠加时，增加的是前一个附点符号的一半。
> 翻倍与附点叠加时，必须**翻倍在前**。首个附点增加**翻倍后**时值的一半。

**延音**符号`~`，与后方**第一个音符**连接，合并音符时值。
```m3n
{2/4}
x x~ | x x~ | x^~ | x^ |||
```
> 两个音符的绝对音高必须完全相同。可跨小节，可连续延音。

#### 哆唻咪（前半段）

根据以上内容，我们已经可以编写《哆唻咪》的前半段了：
```m3n

{1=C} {4/4} {tempo=132bpm}
1. (2) 3. (1)    | 3 1 3^ |
2. 3 (4 4) (3 2) | 4^~ 4^ |
3. (4) 5. (3)    | 5 3 5^ |
4. 5 (6 6) (5 4) | 6^~ 6^ |
// 未完成
```

### 音高进阶

M3N通过**调号**确定基准音高，用**音级**、**临时升降号**和**八度修饰**确定实际音高。

- 数字 `1 2 3 4 5 6 7` 表示自然大调的调内音级。
- 临时变音：`#`（升）、`b`（降）、`=`（还原），可叠加，作用延续到小节结尾。
- 八度修饰：`e`（高八度）、`d`（低八度），可叠加，仅作用于当前音符。

> **必须按照 `<音级><临时变音><八度修饰>` 的顺序。**

临时变音对于实际音高的影响，采用叠加逻辑而不是五线谱的覆盖逻辑，更加符合首调思维。

```m3n
{1=G}
7 7# 7b 7= 7bb
```


### 反复

乐谱中的反复记号并不复杂，如果对反复记号了解不深入，建议搜索相关资料系统学习。
M3N支持的反复主要有小节线反复记号和结构反复记号两种。

#### 小节线反复记号
最常见的反复记号是两种特殊的小节线，在M3N中分别用**前反复记号`||:`**和**后反复记号`:||`**表示（如果两者合并则记作双侧反复记号`:||:`），它们之间的部分会被反复。

#### 结构反复记号
有一组更加传统反复记号，形如 D.S. 和 D.C. 等，称为结构反复记号。
结构反复记号增加了乐谱的理解难度，因此M3N并不推荐过度使用，仅支持以下反复记号：
| 记号 | 说明 |
| :--- | :--- |
| `segno` | 设置 Segno 标记，可以通过`{segno=A}`的格式设置标记名 |
| `fine` | 设置 Fine 终点 |
| `DC` | 跳回乐谱开头 |
| `DS` | 跳回最近一个 `segno` |

#### 跳房子

通常乐谱中的跳房子记号用于被反复旋律末尾有差异的情况。通过跳房子记号可以选择不同的末端旋律。
M3N中，通过`{volta=$}`来定义跳房子的乐段。其中`$`是房子的编号。
注意到跳房子是一段乐句的属性，对于这类跨小节的区间属性，需要显式标记关闭点。在M3N中通过`{/}`属性栈式关闭前一个未关闭的区间属性，也可以通过`{/属性名}`来提供更好的可读性和校验功能。

在之前的《哆唻咪》中，整体会演奏两遍，而两遍的结尾是不同的。接下来我们完善此乐谱。

```m3n
{title=哆唻咪} {subtitle=《音乐之声》插曲}
{1=C} {4/4} {tempo=132bpm}
1. (2) 3. (1)      | 3 1 3^  |
2. 3 (4 4) (3 2)   | 4^~ 4^  |
3. (4) 5. (3)      | 5 3 5^  |
4. 5 (6 6) (5 4)   | 6^~ 6^  |
5. 1 (2 3) (4 5)   | 6^~  6^ |
6. 2 (3 4#) (5 6)  | 7^~  7^ |
7. 3 (4# 5#) (6 7) | 1e^~ 1e (7 7b) |
6 4 7 5 |{volta=1} 1e 5 3 2 {/}:||
{volta=2} 1e^. 0 | (0 1 2 3 4 5 6 7) |
1e 5 1e 0 {/}|||
```

### 音符属性

除了音符的音高和时值，还有一些额外的属性，包括装饰音符和奏法记号。

#### 装饰音符

装饰音符通过大括号`{}`包裹的属性，作用于前一个音符。
其中，前倚音使用`-`符号开头的属性表示，后倚音使用`+`符号开头的属性表示。
倚音符号后的内容按照单一音符或者音符组处理，支持通过简单的时值系统确定倚音所占用的时值。
```m3n
1 {-(2)} | 1{+(2)} | 1 {-((2))} | 1{+((2))} | 1{-((3 2))} | 1{+((2 3))} | // 装饰音符
(2 1) | (1 2) | ((2)1~(1)) | (1~(12)) | ((32)1) | (1(23)) ||| // 等价展开
```

#### 奏法记号

| 写法 | 说明 |
| :--- | :--- |
| `tr` | 颤音 |
| `wav` | 波音 |
| `echo` | 回音 |
| `str` | 重音 |
| `brk` | 顿音 |
| `tip` | 跳音 |
| `hold` | 保持音 |

```m3n
1 1{tr} 1{wav} 1{echo} | 1{str} 1{brk} 1{tip} 1{hold} |||
```

### 音符分组

接下来，我们处理某些复杂场景下一组音符的时值。
M3N使用中括号 `[notes:?]` 对一组音符进行特殊处理，其中 `notes` 是一组纯音高音符，`?` 是分组的处理方式。

> 音符组内不允许任何其他时值信息
> 分组行为也必须在一个小节内，在M3N中所有的括号都不跨小节线。

#### 连音

当`?`是一个数字`X`时，代表组内的音符均分`X`倍当前时值系数`N`的时值数。
最常见的用法是三连音：
```m3n
{3/4}
1 (1 2) ([1 2 3:2]) :|| // X × N = 2 * 0.5 = 1拍
```

#### 和弦

部分单声部乐器可以演奏简单的和弦，例如口琴的三度/八度和声等，因此M3N对和弦提供简单的支持。
当`?`是一个字母`c`时，代表组内音符同时发声，整体时值 = 当前基准时值 `N × B`。

> 和弦作为一个整体，与单一音符享有相同地位

```m3n
{1=C}{3/4}
[1 3 5:c] [5 7 2e:c] [1 3 5:c] :|| // I-V-I和弦进行
```

### 其他记号

**连奏记号**，要注意和延音线区分。
```m3n
{lg}1 2 3 4~ | 4 5 6 1e~ | 1e^^ |||{/}
```
**强弱记号**不需要闭合。
```m3n
{4/4}
{ppp}1^^ |{pp} 2^^ |{p} 3^^ |{mp} 4^^ |
{mf}1^^ |{f} 2^^ |{ff} 3^^ |{fff} 4^^ |
{fp} 1^^ | {sfz} 1^^ |||
```
**渐强渐弱记号**需要闭合。
```m3n
{4/4}
{cresc}1^^ | 4^^ |{/}{decres} 5^^ | 1^^ |||{/}
```
**高低八度记号**
```m3n
1 2 3 4 | 5 6 7 1e |
{8va}1 2 3 4 | 5 6 7 1e |{/}
{8vb}1 2 3 4 | 5 6 7 1e |{/}
```

## 手册

手册部分用于快速查询 M3N 的语法与约束，不再重复指南中的推导过程。
除非特别说明，下文中的“音符”均指一个完整的音符单元：音高部分 + 可选时值后缀 + 可选作用于它的后置属性。

### 1. 基本约定

#### 1.1 文件与空白

- M3N 是纯文本格式。
- 空格、Tab、换行可作为分隔符使用。
- 连续空白不会改变语义，但会影响可读性。
- 渲染时默认尊重文本换行；是否自动重新排版由具体渲染器决定。

#### 1.2 注释

- `//` 表示行内注释。
- 从 `//` 开始直到行尾的内容均不参与解析。
- M3N 不支持块注释。

#### 1.3 小节边界

- `|`：普通小节线
- `|||`：终止线
- `||:`：前反复记号
- `:||`：后反复记号
- `:||:`：双侧反复记号

除延音 `~` 外，括号、音符分组、绝大多数区间语义均不得跨越小节线。

### 2. 文档级属性

文档级属性使用大括号表示，基本形式如下：

```m3n
{key=value}
{flag}
```

其中 `key=value` 用于具名属性，`flag` 用于无值属性或自定义展示字段。

#### 2.1 常用属性

| 写法 | 含义 | 备注 |
| :--- | :--- | :--- |
| `{1=C}` | 调号 | 必填核心属性之一 |
| `{4/4}` | 拍号 | 必填核心属性之一 |
| `{tempo=120bpm}` | 速度 | `bpm` 为推荐写法 |
| `{title=标题}` | 标题 | 通常显示在谱面顶部 |
| `{subtitle=副标题}` | 副标题 | 通常显示在标题下方 |
| `{segno}` / `{segno=A}` | Segno 标记 | `DS` 的跳转目标 |
| `{fine}` | Fine 终点 | 结构反复终止点 |
| `{DC}` | Da Capo | 跳回开头 |
| `{DS}` | Dal Segno | 跳回最近 `segno` |
| `{volta=1}` | 跳房子编号 | 属于区间属性，需要闭合 |

#### 2.2 自定义属性

- 未被语义引擎特殊处理的属性可作为自定义属性保留。
- 无 `key` 的属性，如 `{作曲：莫扎特}`，通常用于展示性元信息。
- 是否渲染、渲染位置如何确定，由渲染器实现决定。

### 3. 音符语法

#### 3.1 基本形式

一个普通音符的推荐形式可抽象为：

```text
<音级><临时变音><八度修饰><时值后缀>
```

其中只有 `音级` 必填，其余部分均为可选。

#### 3.2 音高部分

| 元素 | 写法 | 说明 |
| :--- | :--- | :--- |
| 音级 | `1 2 3 4 5 6 7` | 首调唱名对应的相对音级 |
| 升号 | `#` | 可连续叠加，如 `1##` |
| 降号 | `b` | 可连续叠加，如 `7bb` |
| 还原号 | `=` | 用于抵消前文同小节临时变音 |
| 高八度 | `e` | 可叠加，如 `1ee` |
| 低八度 | `d` | 可叠加，如 `6dd` |

约束如下：

- 顺序必须为 `<音级><临时变音><八度修饰>`。
- 临时变音在同一小节内持续生效，到小节线处失效。
- 八度修饰只作用于当前音符，不向后传播。
- 临时变音按叠加逻辑解释，而非覆盖逻辑。

#### 3.3 特殊音符

| 写法 | 含义 |
| :--- | :--- |
| `0` | 休止符 |
| `X` | 占位音符 |

`0` 与 `X` 均可参与括号时值系统，也可附加 `^`、`.`、`~` 等时值后缀；不允许附加音高相关属性。

### 4. 时值系统

#### 4.1 基础时值

- 基础时值由拍号分母决定。
- 在 `{4/4}` 中，基础时值 `B` 为四分音符。
- 一个不带括号和后缀的基础音符，其时值比例记为 `N = 1`。
- 实际时值 = `N × B`。

#### 4.2 括号减时

M3N 使用圆括号 `()` 表示时值二分：

- 每嵌套一层括号，当前层内每个音符时值减半。
- 括号必须在小节内配对闭合。
- 括号除控制时值外，也承担节奏分组的可读性功能。

#### 4.3 时值后缀

| 后缀 | 含义 | 规则 |
| :--- | :--- | :--- |
| `^` | 翻倍 | 每增加一个 `^`，当前时值乘以 2 |
| `.` | 附点 | 每增加一个 `.`，增加前一步时值的一半 |
| `~` | 延音 | 与后方第一个音符合并时值 |

补充规则：

- `^` 与 `.` 可以连续叠加。
- 同时使用时，顺序必须先 `^` 后 `.`。
- `~` 连接的两个音符绝对音高必须相同。
- `~` 可以跨小节，也可以连续形成多段延音链。

### 5. 音符后置属性

音符后置属性使用大括号附着在前一个音符之后：

```m3n
1{tr}
1{-(2)}
1{+((2 3))}
```

#### 5.1 装饰音

| 写法 | 含义 |
| :--- | :--- |
| `{-...}` | 前倚音 |
| `{+...}` | 后倚音 |

规则：

- 倚音内容按“单音符或音符组”解析。
- 倚音可使用简化时值系统确定自身所占比例。
- 倚音附着于前一个主音，不独立占据外层语法位置。

#### 5.2 奏法记号

| 写法 | 含义 |
| :--- | :--- |
| `{tr}` | 颤音 |
| `{wav}` | 波音 |
| `{echo}` | 回音 |
| `{str}` | 重音 |
| `{brk}` | 顿音 |
| `{tip}` | 跳音 |
| `{hold}` | 保持音 |

每个音符仅支持单一奏法符号。

### 6. 区间属性

部分属性不是作用于单个音符，而是作用于一段连续区域。

#### 6.1 支持的区间属性

| 写法 | 含义 |
| :--- | :--- |
| `{lg}` | 连奏记号起点 |
| `{cresc}` | 渐强起点 |
| `{decres}` | 渐弱起点 |
| `{8va}` | 高八度记号起点 |
| `{8vb}` | 低八度记号起点 |
| `{volta=1}` | 跳房子 1 |
| `{volta=2}` | 跳房子 2 |

规则：

- 区间属性必须显式闭合。
- `{/}` 关闭最近一个尚未闭合的区间属性。
- `{/属性名}` 语义更清晰，也更利于校验。
- 允许嵌套时，应遵循后开先关。

#### 6.2 即时属性

即时属性作用于当前位置之后的演奏表达，持续范围直到乐曲结束或被下一个同类型属性覆盖。

在乐谱中间出现的拍号、调号、速度被当做即时属性。以下力度记号也是即时属性：

`ppp`、`pp`、`p`、`mp`、`mf`、`f`、`ff`、`fff`、`fp`、`sfz`

### 7. 音符分组

M3N 使用中括号对一组纯音高音符进行整体处理：

```text
[notes:?]
```

其中：

- `notes` 是一组仅含音高信息的音符
- `?` 是分组模式

约束如下：

- 分组内不允许再出现额外时值后缀、括号层级或其他分组。
- 分组必须完整位于同一小节内。
- 分组作为一个整体，占据当前语法位置的一个时值单元。

#### 7.1 连音组

当 `?` 为数字 `X` 时，表示组内音符均分 `X × 当前 N` 的总时值。

示例：

```m3n
[1 2 3:2]
```

表示一个三连音组，总时值等于当前两份最小单位。

#### 7.2 和弦组

当 `?` 为 `c` 时，表示组内音符同时发声。

示例：

```m3n
[1 3 5:c]
```

其整体时值等于当前位置的当前时值。

### 8. 反复与结构跳转

#### 8.1 小节线反复

- `||:` 与 `:||` 成对构成局部反复。
- `:||:` 可视为后反复结束后立即进入新的前反复。
- 反复次数、展开规则若未特别说明，按常规西方记谱习惯解释。

#### 8.2 结构跳转

支持以下结构元素：

- `segno`
- `fine`
- `DC`
- `DS`

说明：

- `{DC}` 表示返回开头。
- `{DS}` 表示返回最近的 `segno`。
- `{fine}` 用于标记结构反复的终止位置。
- 若同时存在命名 `segno`，渲染器可选择是否进行额外校验。

#### 8.3 跳房子

- `{volta=n}` 开启第 `n` 个房子。
- 跳房子通常与 `:||` 配合使用。
- 一个跳房子区间应覆盖一段完整、可替换的末尾乐句。

### 9. 语法速查

#### 9.1 最小可用示例

```m3n
{1=C} {4/4}
1 2 3 4 | 5 6 7 1e |||
```

#### 9.2 常见构件速查

| 目标 | 写法 |
| :--- | :--- |
| 调号 | `{1=C}` |
| 拍号 | `{4/4}` |
| 标题 | `{title=标题}` |
| 速度 | `{tempo=120bpm}` |
| 普通音符 | `5` |
| 升音 | `4#` |
| 高八度 | `1e` |
| 休止符 | `0` |
| 占位音符 | `X` |
| 八分音符 | `(5)` |
| 二分音符 | `5^` |
| 附点音符 | `5.` |
| 延音 | `5~ 5` |
| 倚音 | `5{-(6)}` |
| 和弦 | `[1 3 5:c]` |
| 三连音 | `[1 2 3:2]` |

| 后反复 | `:||` |

### 10. 规范性建议

- 每个文档开头显式声明调号与拍号。
- 音符之间保留适量空格，不依赖“无空格紧凑写法”。
- 区间属性优先使用 `{/属性名}` 闭合，减少歧义。
- 对复杂节奏优先增加括号层次，而不是依赖读者心算。
- 对复杂结构优先使用小节线反复，谨慎使用 `DC/DS`。
- 尽量让每一行在视觉上构成完整乐句，提升“所见即所得”的可读性。
